# 9조 텐션암 이상감지 — 프로젝트 지도

텐션암 진동(2초 × 25 kHz, 단위 g)으로 정상 0 / 고장 1을 가른다. 평가는 F2(재현율 중시). 학습 150개(정상 120 · 고장 30).
이 폴더 하나로 **최종 모델이 어떻게 만들어졌는지**를 처음부터 끝까지 따라갈 수 있다. 각 폴더의 `README.md`만 읽으면 되고, 코드 · 그림 원본 · 표는 폴더마다 `자료/` 안에 있다.

## 최종 모델 (EXP-062 구성 3, 중첩 CV F2 0.971 ± 0.022 · 재현율 0.987 · 오경보율 0.023)
```
신호 50,000점 (2초 × 25 kHz) → 평균 제거 → 11 kHz 초과 제거
 ├ 1–11 kHz 대역통과 → 충격 검출 · 울림 주파수 · 옥타브 첨도/몫 ─→ H 13열 (울림 비율은 축소) ┐
 ├ 1 kHz 위 log PSD → 학습 정상 대비 가장 솟은 봉우리 H16 · H17 ─────────────────────────┴→ ExtraTrees OOF logit ┐
 ├ 30 Hz 저역 → 주기 잠금(박자) L1_lock → 정상 기준 z ──────────────────────────────────────────────────┼→ 로지스틱 ≥ 문턱 ┐
 ├ 200 Hz 고역 → 1초 × 8구간 log PSD → AE(정상만 학습) 복원 오차 → 정상 기준 z ─────────────────────────┘                 │
 ├ 하중 대비 고주파 L2_hfl > 학습 정상 99 % & 충격 ≥ 1 ─→ 규칙 E2 ─────────────────────────────────────────────── OR ┤
 └ 8.3 kHz 봉우리(돌출 · 폭 · 충격성 K83) OR 깨끗한 8 kHz대 공진 충격 ─→ 규칙 8.3k ──────────────────────────── OR ┴→ 0 / 1
```
코드: `src/final.py` `FinalJ(fmax=11000)` · 제출: [7_최종·제출/제출_EXP-062](7_최종·제출/제출_EXP-062/README.md) · 긴 설명: [파이프라인_설명](7_최종·제출/파이프라인_설명.md)
