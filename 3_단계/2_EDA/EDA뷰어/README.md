**신호 전환 (v3, 11-14)**: 머리줄 "신호"에서 평균 제거 ↔ 200 Hz 고역통과를 고르면 모든 그림·지표·태그·정상 백분위가 그 신호로 계산한 값으로 바뀐다 (두 벌을 미리 계산해 실음). 한 개씩 보기 지표 표의 회색 숫자·속 빈 원 = 반대 신호 값. 이에 따라 `h_std`·`h_kurt`는 없앴고(= 고역통과 쪽 `std`·`kurt`), 스펙트럼 모양·물리 대역 비율은 전 대역 기준으로 바꿨다(고역통과 쪽 값 ≈ 예전 "200 Hz 이상" 값). Welch PSD는 `detrend=False`로 바꿔 6 Hz 아래 드리프트가 저주파 비율에 들어간다. 고역통과 쪽의 "저주파" 묶음 값은 필터가 남긴 찌꺼기라 해석하지 않는다

**유의미 모델 전부 선택 (v8, 11-16)**: 머리줄 **"모델"** = `3_단계/5_모델비교/base/`의 실험을 모두 자동으로 읽어(최신 번호 먼저, 기본 = EXP-044) 하나를 고른다. 필터·묶기·배지·지표 표·산점도 테두리·✕·로지스틱 경계·분석 조각(2-12·2-13)이 모두 고른 모델 기준이다. 필터 "모델 결과" = 틀림 · 미탐 · 오경보(3/5 이상) · 한 번이라도 틀림 · 그 모델의 규칙별 켜짐 · **직전 유의미 실험 대비 판정이 바뀐 파일**. 배지 = 고른 모델 결과 + 그 모델 규칙(값 포함) + 다른 모델들의 틀린 횟수 한 줄. 지표 표 = 모델마다 한 열 + 규칙(8.3k · 유격 · 주기 잠금 · 단일 타격 감점)마다 한 열. 주기 잠금 규칙은 문턱이 fold마다 달라 EXP-029와 같은 분할(seed 5 × 5-fold)로 켜짐 횟수/5를 센다(A022 5 · N103 2). ET 입력이 다른 실험(EXP-029)은 경계 평면(AE z × ET z)을 따로 계산한다. result.json에 없는 정보(짧은 이름 · 규칙 · 평면)는 `build_viewer.py`의 `EXP_SPEC`에 한 줄씩. 새 유의미 실험이 거기 없으면 규칙 없음으로 표시하고 `build_log.txt`에 경고

**왼쪽 메뉴 · 분석 조각 화면 (v7, 11-14)**: 머리줄의 화면 버튼을 VS Code식 왼쪽 메뉴로 옮겼다(EDA = 한 개씩·5개씩·지표 표·산점도 / 모델 = 로지스틱 경계 / 분석 조각 = 유격 반복·주기 잠금 / 참고 = 개념 사전, 아래 "메뉴 접기"). 머리줄 오른쪽 = 밝게·어둡게·시스템 전환. 새 화면 둘 — **유격 반복 · 저에너지(2-12)**: ① D6 × D1 지도(r = 1·2 원, 점 크기 = R(2위/1위), 초록 원 = 유격 규칙 켜짐, ✕ = 최종이 틀림) ② **R × 결합 결정값**(EXP-025 평면): 오경보 정상이 "큰 사건 한 번"(R 낮음)에 몰리는지, 같은 자리에 고장이 있는지(= R로 내리면 함께 내려갈 고장) 확인용 / **주기 잠금 충격(2-13)**: r_LP × hit 지도, S 같은 선(정상 95%·정상 최대), S 상위 25. 값은 각 조각 run.py가 남긴 `figs/features.csv`·`figs/lock_score.csv`를 읽는다(조각을 다시 실행하면 뷰어도 다시 만든다). 문서 그림(PNG)은 접어서 함께 실음

**경계 화면 (v6, 11-14)**: 머리줄 "경계" = 유의미 실험(EXP-025·021·020·014·012)을 골라 두 전문가 z 평면(AE z · ET z, OOF seed 0)에 로지스틱 경계(실선 0, 점선 ±1)·고장 쪽 바탕·규칙(◇ 8.3k, ○ 유격)·틀린 파일(✕, 굵게 = 3/5 이상)을 그린다. 경계 근처(|결정값| ≤ 0.5–2, 고를 수 있음)와 틀린 파일은 이름을 자동 표시(겹치면 비켜 놓고, 그래도 겹치면 생략)하고, 오른쪽에 결정값 순 목록을 둔다. 점·목록 클릭 = 정보 카드(결정값·z·이 실험 결과·규칙·실험별 결과·태그, "한 개씩 보기로 열기"). 정의는 `3_단계/5_모델비교/fig_logistic_plane.py`와 같음

**모델 결과 = 최종 모델만 (v5, 11-14)**: 최종 모델을 **EXP-025**(EXP-014 결합 + 8.3 kHz 모드 규칙 + 유격 반복 규칙, 중첩 F2 0.942)로 바꾸고 AE·ET·결합 비교는 뺐다. 배지·표 열 = 최종 미탐·오경보 횟수 + **8.3k 규칙**(돌출·폭) + **유격 규칙**(r · 2위/1위). 필터 "모델 결과" = 최종이 틀림 · 미탐 · 오경보 · 한 번이라도 틀림 · 규칙 켜짐(8.3k / 유격 / 둘 중 하나). 묶기 "모델 결과" = 고장: 최종이 놓침 / 8.3k 규칙으로 잡음 / 유격 규칙으로 잡음 / 결합 점수로 잡음 · 정상: 최종 오경보 / 가끔 오경보 / 문제 없음. 유격 규칙 켜짐은 정상 150개 중심 기준 설명용(평가에서는 fold 안, 켜지는 파일은 25번 모두 같음)

(이전 v4) 기준 모델을 **최종 EXP-021**(EXP-014 결합 + 8.3 kHz 모드 규칙, F2 0.892)로 바꿨다. 배지·표 열 = 최종 · 결합(EXP-014) · AE(EXP-012) · ET(EXP-007) + **8.3k 규칙**(돌출 ≥ 0.75 dec & 폭 ≥ 150 Hz, 돌출·폭 값 표시). 필터 "모델 결과"에 최종 미탐·오경보, 최종에서 새로 잡힘·새로 놓침·오경보 해소, 8.3k 규칙 켜짐 추가(AE·ET 항목은 '전문가' 묶음). 묶기 "모델 결과"와 산점도 검은 테두리는 최종 모델 기준

## 목적
모델이 왜 놓치고 왜 오경보를 내는지 분류하려면, 먼저 **특이한 정상·특이한 고장이 어떤 모양인지** 알아야 한다.
