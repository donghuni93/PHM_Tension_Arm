상태: **초안.** 사령탑 세션에서 사용자와 합의한 내용을 정리한 것. 결정의 원본은 [결정.md](../../1_기준·기록/결정.md), 진행 중 확인 요청과 회신은 루트 [코드세션_연결_1121.md](../../1_기준·기록/세션기록_1121/코드세션_연결_1121.md).

## 0. 한 줄 요약
**충격을 새로 정의하고, "아는 고장과 닮았나"(ET, 고주파 피처 약 18개)와 "하중에 맞춰 덜컥거리나"(박자 블록, 정상 기준)를 max로 합친다.** 예전 사후 규칙·AE·라벨 보고 정한 대역은 쓰지 않는다. 기준(EXP-034 c)과 같은 중첩 CV로 비교해 sd 안이면 단순한 쪽을 고른다.

## 1. 왜 다시 짜나
- 지금 최종(EXP-034 c, 0.955 ± 0.007)은 규칙 3개의 대역·문턱이 모두 **라벨을 본 뒤 정한 값**이다. 사후 장치 없는 기대치는 0.857(EXP-014). 새 데이터 성능이 그 사이 어디인지 모른다
- 충격 정의 2개(200 Hz·8σ, 1 kHz·6×중앙값)가 팀원·초기 모델에서 왔고 근거가 없었다. abn_015는 정의에 따라 충격 0개 / 28개
- AE × ET 상관 0.81 → 두 축이 같은 정보. val에서 AE 점수가 통째로 이동(R-3)
- 진동 공부(11-20~21)로 입력 / 구조 / 맥락, 크기는 길을 잰다는 점, 박자(포락선·변조)를 이해함 → 피처를 물리로 다시 묶을 수 있게 됨

## 4. 피처 명세
### 4.1 H 블록 — ET 입력 (약 18개, 1 kHz 고역 신호·새 충격 정의)
| # | 종류 | 피처 | 정의 | 상태 |
|---|---|---|---|---|
| H1 | 입력 | 충격 수 | log(1 + 새 정의 충격 수) | 확정 |
| H2 | 입력 | 2위/1위 충격 높이 | 바탕 대비 높이의 2위 ÷ 1위 (충격 < 2개면 0) | 확정 |
| H3–H6 | 입력 | 옥타브별 첨도 | 각 옥타브 대역통과 신호의 첨도(로그) | 확정 |
| H7–H10 | 구조 | 충격 울림 옥타브 몫 | 충격마다 울림 주파수(감쇠 사인파 사전 투영) → 옥타브별 비율. 충격 0개면 −1 (ET가 판단) | 확정 |
| ~~H11~~ | 구조 | 빨리 꺼지는 충격 비율 | Q5: 두 감쇠 추정법 순위상관 ζ 0.475 · τ 0.157(< 0.5, 사전 고정 규칙) → 충격 하나의 울림이 너무 짧아 감쇠를 못 믿음. 예전 "ζ ≥ 0.04 비율"(AUC 0.74)은 울림 주파수를 다시 잰 것일 가능성 → H7–H10이 담음 ([사령탑_Q5_감쇠](../../4_피처/4-1_충격정의/자료/사령탑_Q5_감쇠/README.md)) | **제외 (11-21)** |
| H12–H15 | 구조 | 옥타브별 스펙트럼 몫 | Welch 2048점 PSD의 옥타브 파워 ÷ 1 kHz 위 전체 파워 (로그) | 확정 (R-1) |
| H16–H17 | 구조 | 가장 솟은 좁은 봉우리 높이·폭 | 1 kHz 위에서 (파일 로그 PSD − 학습 정상 중앙 로그 PSD)가 최대인 봉우리의 높이(dec)·반높이 폭(Hz). 정상 중앙은 폴드 안 학습 정상으로 | 확정 |
| H18 | 맥락 | 하중 대비 고주파 HFL | log(1 kHz 위 포락선 바탕 중앙값 ÷ 20 Hz 저역 RMS) | 확정 (017용) |

- 구현 전 라벨 없이 피처 상관을 보고 \|ρ\| ≥ 0.8 묶음은 대표 하나(묶음 안 평균 상관이 가장 큰 것)만 남긴다
- 학습 정상에 의존하는 H16–H17은 중첩 CV 폴드 안에서 다시 계산

### 4.2 박자 블록 — 정상 기준 점수
| # | 피처 | 정의 | 상태 |
|---|---|---|---|
| L1 | 주기 잠금 S | 2-13 정의(30 Hz 저역 자기상관 최대 지연 T 0.3–1.2 s, r_LP × hit, hit = T ± 3%에 짝 있는 충격 비율), 충격 시점은 새 정의 | 확정 |
| (L2) | 35–44 Hz 위상 잠금 R | 015 R 0.343 · 정상 최대 0.375 · 정상 99% 선 위 고장·val 0 | **제외** |
- 박자 점수 = S의 학습 정상 기준 강건 z(중앙값·MAD). 문턱 = 학습 정상 박자 점수의 99% 분위(폴드 안). 새 정의 기준 정상 최대 0.449 · 022 0.963 · 014 0.546 · val 최대 0.196
- r_LP·hit 단독은 진단용(단독으로는 정상 051·073 등이 걸림)

## 5. 비교 목록 (실행 전 고정, 뒤에 추가하지 않음)
| 단계 | 구성 | 내용 | 답하는 질문 |
|---|---|---|---|
| 1 | **A** | **EXP-034 b**(c에서 본체 모드 내림을 뺀 것, 기록 0.949 ± 0.007)를 같은 틀에서 재측정. c는 참고로만 | 기준 |
| 1 | **B** | ET 하나에 H 18 + L 피처, 규칙 없음 | 정리한 피처만 넣어도 되나 |
| 1 | **C** | H → ET, L → 박자 점수, 결합은 로지스틱 | 저/고 분리가 이득인가 |
| 2 | C-max · C-lin · C-svm | C 위에서 결합만 바꿈(SVM은 C = 1, gamma = scale 고정) | 어떤 경계 |
| 3 | **D** | 2단계 승자 + 정상 기준 전문가(오류 분석으로 원인 확인된 것만) | 규칙이 필요한가 |
- 선택: 중첩 CV F2 차이 < sd면 단순한 쪽(B → C, max → lin → svm, D는 sd 넘게 좋을 때만)
- 2단계는 C가 B 이상일 때만 진행
- 민감도(선택에 안 씀): 최종 구성의 고주파 차단 1 kHz vs 1.5 kHz

## 6. 평가 방법
- 중첩 CV: 바깥 5 × 안쪽 4, seed 5 (`src/evaluate.py`). ET 기본값(튜닝 안 함). H 문턱 = 안쪽 OOF F2 최대, 박자 문턱 = 학습 정상 99%
- 보고: F2 ± sd, 재현율, 오경보율, 놓친 파일·오경보 파일(5회 중 횟수), 사후 장치 없는 점수, 고장 10%·40% 환산 F2
- 그림(매 실험): H 점수 × 박자 점수 평면과 결합 경계(기준 A의 `logistic_plane`과 나란히), t-SNE(입력 공간별 + 이상 점수 색), 놓친 파일 PSD(정상 5–95% 띠)
- val(라벨 없음): 판정 수, 각 블록이 켜진 파일, 이동 여부. **val 판정 수로 구성을 고르지 않는다**(참사 확인용)

## 7. 실행 순서
1. **충격 정의 확정본을 `src/`로** — `detect_impacts`(사령탑_7b-7e) + 앞뒤 10 ms 제외
2. **"빨리 꺼지는" 기준** — Q5(ζ 0.08의 정체, 사전 0.16·0.32 확장, ms 기준) → H11 정의
3. **피처 구현** — `src/features2.py`(가칭): H 18 + L, 신호 배열 입력(제출 파이프라인과 같은 함수), 캐시 `4_outputs/cache/feat2_*.csv`
4. **라벨 없는 점검(4-7)** — 상관 묶음·대표 선택, train 정상 vs val 분포, 피처별 정상 5–95%
5. **EXP-040** 1단계 A · B · C → **EXP-041** 2단계 → 오류 분석(6단계) → 필요하면 **EXP-042** D
