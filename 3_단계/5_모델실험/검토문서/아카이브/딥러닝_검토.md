# 딥러닝 모델 검토 — 스펙트로그램 비전 모델과 피처 입력 신경망

작성 2026-11-16 · 이동훈. 근거: [EXP-031](../../아카이브/EXP-031_1116_피처MLP/README.md)(이번 실행) · EXP-019 · 022 · 023([실험로그](../../../1_기준·기록/실험로그.md)의 기록) · [6-1 유형별 구분](../../../6_오류분석/아카이브/6-1_1116_유형별_정상고장_구분/6-1_유형별_정상고장_구분.md)

## 결론
1. **피처 입력 신경망(MLP)**: 이번에 같은 분할로 확인하였고 기각하였다. ET 자리에 교체하거나 추가하면 PR-AUC가 0.973에서 0.956으로 하락한다. 단독 성능도 ET보다 낮다(0.838, ET 0.861).
2. **스펙트로그램 비전 모델(2D-CNN 등)**: 11-14에 다른 PC에서 스크리닝한 기록이 있다(EXP-019 · 022). 교체·보완 효과가 없었다. 이 PC에는 PyTorch가 설치되어 있지 않아 다시 실행하지 않았다. 해당 실험 폴더가 zip에 포함되지 않아 모델 구조와 설정은 확인하지 못하였고, 근거는 실험로그의 요약 기록이다.
3. **권고**: 최종 구성을 유지한다. 남은 오류는 모델의 표현력이 아니라 입력 정보와 표본 수의 문제다(2 · 3절). 딥러닝 결과는 발표의 "검토 후 기각한 대안"과 "개선 방향"의 근거로 사용한다.

## 1. 실행 기록

### 1.1 이번 실행 — 피처 입력 신경망 (EXP-031)
입력은 ET와 같은 피처 150개다. 구조는 은닉층 64-32, 설정은 실행 전에 고정하였다. 평가는 quick_cv(5-fold × seed 3, 기준과 같은 분할)다.

| 구성 | PR-AUC | 확실한 고장 | 위험 정상 | 판정 |
|---|---|---|---|---|
| 기준 EXP-025 (AE + ET + 규칙 2개) | 0.973 ± 0.002 | 26 | 0.3 | — |
| 교체 (AE + MLP) | 0.956 ± 0.003 | 26 | 0.7 | 하락 |
| 추가 (AE + ET + MLP) | 0.956 ± 0.003 | 25 | 1.0 | 하락 |
| 단독 ET / 단독 MLP (규칙 없음) | 0.861 / 0.838 | 6 / 7 | 12.3 / 37.7 | MLP가 낮음 |

어려운 파일의 위험도(0 = 안전, 1 = 오류)는 변하지 않는다: 고장 022는 0.59 → 0.61, 정상 025는 0.99 → 0.98, 정상 116은 0.97 → 0.96이다. 같은 피처를 입력으로 하면 모델을 교체해도 같은 파일에서 오류가 발생한다. SVM(EXP-015) · 순위평균 앙상블(EXP-004)에서 확인한 결과와 같다.

### 1.2 기존 기록 — 원신호·스펙트로그램 모델 8종 (EXP-019 · 022 · 023, 11-14)
| 모델 | 입력 | 기록된 결과 |
|---|---|---|
| 2D-CNN | 스펙트로그램 | 교체·보완 효과 없음. 고장 022를 검출하지 못함 |
| 합성곱 AE · Deep SAD | 스펙트로그램 계열, 정상 위주 학습 | 교체·보완 효과 없음 |
| 1D-CNN (창 단위 MIL) · MiniRocket | 원신호 | 교체·보완 효과 없음. 다만 고장 022의 순위를 0.41에서 0.92–0.93으로 올림(그 위에 정상 8개 이상) |
| AR 잔차 · MSPC | 원신호 · 피처 | 고장 017에서 0.91–0.92, 전체로는 효과 없음 |
| CatBoost | 피처 | 추가 시 0.898 ± 0.013 (기준 0.892 ± 0.015), 표준편차 이내 |

- 기존 구성에 추가한 경우 PR-AUC 0.903–0.931, 교체한 경우 0.829–0.928이었다(기준 0.929).
- 큰 타격이 한 번 있는 정상(025 · 116)의 순위는 어떤 모델에서도 하락하지 않았다(EXP-022).
- 여러 모델의 점수를 OR로 결합하면 모델마다 다른 정상이 오경보가 되어 모두 하락하였다(EXP-023).

## 2. 남은 오류와 모델별 가능성

6-1에서 정리한 남은 오류 유형마다 필요한 정보와, 각 모델이 그 정보를 입력으로 받는지를 대응시켰다.

| 남은 오류 유형 | 구분에 필요한 정보 | 피처 MLP | 스펙트로그램 CNN | 원신호 모델 |
|---|---|---|---|---|
| 큰 타격 한 번인 정상 (025 116 055) | 타격 직후 수 ms의 주파수 분포 | 입력에 없음 (EXP-031에서 변화 없음) | 입력에 있음. 기록상 순위 변화 없음 | 입력에 있음. 기록상 순위 변화 없음 |
| 주기 잠금형 고장 (022) | 2초 전체의 타격 시점과 약 1 Hz 하중 주기 | 입력에 없음 | 기록상 검출하지 못함 | 기록상 순위 상승, 검출에는 미달 |
| 조용한 모양형 정상 (059) | 스펙트럼 모양 차이의 원인(고장 또는 측정 조건) | 없음 | AE와 같은 정보 | 없음 |
| 반복 타격 정상과 유격 고장 (001과 025) | 현재 신호에서 확인된 차이 없음 | 없음 | 없음 | 없음 |

- 스펙트로그램 모델이 022를 검출하지 못한 원인은 확인하지 못하였다. 추정은 다음과 같다. 고주파 타격을 분해하려면 시간 창이 짧아야 하고, 이 경우 1 Hz 하중은 주파수 축의 최하단 1칸에 포함된다. 타격 간격 0.94초의 관계는 이미지 전체 폭에 걸친 관계여서 작은 합성곱 커널로는 학습하기 어렵다.
- 정보가 입력에 있는 경우에도 학습 표본이 부족하다. 큰 타격 한 번인 정상과 닮은 고장은 각 9개와 5개, 주기 잠금형은 1개다.

## 3. 표본 수와 과적합

| 항목 | 현재 구성 | 딥러닝 모델 |
|---|---|---|
| 학습 표본 | 파일 150개 (고장 30개) | 같음 |
| 결합 단계의 모수 | 3개 | 소형 CNN 약 1만–10만 개, 사전학습 모델 수백만 개 |
| 표본 증강 | 없음 | 2초를 조각으로 분할하면 표본 수는 증가하나 독립 표본은 150개로 같다(군집 표본). 고장 파일의 조각 대부분은 타격이 없는 구간이어서 조각 라벨이 부정확하다 |
| 판정 근거의 설명 | 규칙 문턱과 두 점수로 파일별 제시 가능 | 별도의 시각화 기법이 필요하며 물리 해석과의 연결이 약함 |

- 문헌의 높은 정확도(예: Sai 2023, 사전학습 VGG16 96.7%)는 다른 데이터와 다른 입력에서 얻은 값이다. 25년 3조의 방식(당시 0.93)을 현재 데이터에 적용한 결과가 0.538이었던 것(EXP-003)과 같이, 다른 데이터의 수치는 이전되지 않는다.
- 과제 PDF는 최종 제출물의 핵심을 "판별 결과와 데이터 기반 판단 근거의 제시"로 명시한다. 딥러닝 사용 가능 여부는 조교 질문으로 남아 있다.
- 사용자 기준(11-16)은 학습 데이터만 있는 조건에서의 과적합 방지다. 모수가 많은 모델의 추가는 이 기준과 반대 방향이다.

## 4. 재시도 조건과 실행안

재시도가 타당한 경우는 조교가 딥러닝 비교를 요구하거나 허용 여부를 확인한 뒤 발표의 비교 모델로 필요한 경우다. 그 경우의 실행안은 다음과 같다. 설정은 실행 전에 고정한다.

| 항목 | 내용 |
|---|---|
| 선행 조건 | PyTorch(CPU) 설치. `environment.yml` 변경이므로 사용자 승인 사항 |
| 입력 | 2초 전체의 log 스펙트로그램 1장(예: 주파수 128칸 × 시간 128칸). 조각으로 분할하지 않음 |
| 모델 | 합성곱 3층 + 전역 평균 + 출력 1개의 소형 CNN. 사전학습 모델은 사용하지 않음 |
| 평가 | quick_cv(5-fold × seed 3), 기존 전문가에 추가하는 구성만. 통과 기준은 EXP-019 · 031과 같음 |
| 예상 소요 | CPU 기준 30–60분 |
| 예상 결과 | 1.2절의 기록으로 보아 통과 가능성은 낮다 |

## 5. 발표 활용안
- "비교한 대안" 항목: 모델 교체(SVM · MLP · CatBoost · CNN 계열)로는 같은 파일에서 오류가 발생하였고, 병목은 입력 정보였다.
- "개선 방향" 항목: 원신호 모델이 022의 순위를 올린 기록은 시점 정보가 파형에 존재한다는 근거다. 데이터가 증가하면 시점 구조를 학습하는 모델(1D-CNN · MiniRocket)이 후보가 된다.
