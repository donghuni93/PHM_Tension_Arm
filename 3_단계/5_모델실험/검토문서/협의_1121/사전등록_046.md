# 사전 등록 — EXP-046 J 위 세 가지 (11-22, 사령탑 고정 · 사용자 승인 "그 세 가지로 실험 진행")

> 실행 전에 고정한다. 결과를 본 뒤에는 구성, 정의, 선택 규칙을 고치지 않는다. 실패한 구성도 표에 남긴다.

## 기준
**J** (EXP-044) = `Add83(TwoAE("lin", ("E2",)))`. 입력 행 `[ns.M, idx, r83]`.
- 구조: ET 안쪽 OOF logit + 박자 z + AE z → 로지스틱, 여기에 E2와 8.3k 규칙을 OR로 붙인다.
- 성능: 중첩 F2 0.977 ± 0.010, 재현율 1.000, 오경보율 0.030.

## 구성 (5개)
| 구성 | 바꾸는 것 | 목적 |
|---|---|---|
| G0 | J 재측정 | 벤치마크 (허용 오차 ±0.01) |
| G1 | J + **고주파 사건 반복 수** (ET 입력 열 1개) | 반복 금속 울림을 고장 증거로 강화 |
| G2 | J + **N1 반동** (ET 입력 열 1개) | 정상 탐색에서 남은 후보 |
| G3 | J에서 8.3k OR 규칙을 빼고 **u_ring을 로지스틱 4번째 입력**으로 (E2 OR는 유지) | 사후 규칙을 모델 안으로 옮김 |
| G4 | G3 + G1 열 + G2 열 | 세 가지 모두 |

## 정의
### hf_rep (고주파 사건 반복 수)
- 대상 충격: `src/impacts.py`로 찾은 새 정의의 충격 중, `impact_rings_v2`의 울림 f가 lo 이상인 것.
- 위 충격을 시간순으로 놓고 간격이 50 ms를 넘으면 새 사건으로 센다. 피처 = `log1p(사건 수)`이고, 해당 충격이 없으면 0이다.
- lo는 격자 {7750, 8000, 8250, 8500, 8750, 9000} Hz에서 **`fit` 안(학습 폴드)**에서 고른다. 기준은 단변량 AUC 최대이고, 동률이면 큰 lo를 고른다.
- 선택된 lo는 모두 기록한다.
- 주의: 사령탑이 8750 Hz에서 라벨을 보고 아이디어를 얻었다. 그래서 격자 선택으로 정직성을 지킨다.

### n1_reb (반동)
- `src/normal_feats.py`의 N1 연속값(사건 후 30–300 ms 후속 충격 비율)을 그대로 쓴다. 정의는 바꾸지 않는다.
- 문턱이 없는 연속 열이다.

### u_ring
- 후보 키 격자는 사전 고정이다: 대역 (8000, 8450) · (8100, 8450) · (8250, 8750) · (7750, 9000) × ζmax {0.01, 0.02, 0.04}.
- 파일마다 각 키에서 "f가 대역 안이고 ζ ≤ ζmax인 울림의 최대 fit"(fit_max, 없으면 0)을 구한다.
- `fit` 안에서 `pick_ring_m`(`code_R/R_step4c_margin.py` 22–33행 그대로, 여유 m = 0.2)으로 키와 t를 고른다.
- u = fit_max / t이고, 0–3으로 자른다.
- 로지스틱 4번째 입력으로 넣는다. 계수 부호는 기록만 한다.
- 키 일치율(25번)이 60% 미만이면 G3·G4는 "참고"로만 둔다.

## 선택 규칙 (실행 전 고정)
1. **열 추가(G1, G2)**: F2가 G0보다 G0의 sd를 넘게 오르면 채택한다. 그렇지 않으면 **보류**한다. sd 안의 차이로는 채택하지 않는다(지식장부 X10).
2. **u_ring 교체(G3)**: F2 ≥ G0 − sd(G0)이고 오경보율 ≤ G0 + 0.010이면 **채택**한다. 사후 규칙을 하나 줄이는 정직성 이득을 미리 인정한 것이다.
3. **G4**: 1·2에서 채택된 것이 모두 포함될 때만 최종 후보로 본다. 그렇지 않으면 보고만 한다.
4. 최종 = 2에서 G3가 채택되면 G3, 아니면 G0(J). 여기에 1에서 채택된 열을 더한다. 그 조합이 G4와 다르면 새 실험 없이 "다음 후보"로 적는다.
