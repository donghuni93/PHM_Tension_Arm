# EXP-052 계획 — 비선형 결합 재실험 (11-22, 실행 전)

상태: **실행 (11-22).** 사용자 결정: kNN 제외, "잘 되는 비선형"은 판단 위임 → 아래 4절 그대로 + ET 결합(잎 3 · 8) 추가, 꼬리 누르기 팔 포함, 5절 교체 규칙 그대로. 폴더는 기준이 J-축소라 `5_울림비율축소/`.
결과 README는 `Experiment`가 따로 만든다(이 파일은 실행 전에 고정한 설계를 남기는 용도). 실제 사다리 칸은 [run.py](run.py)의 `LADDER`가 기준(스플라인 매듭 4 · 6 × C 0.3 · 3, poly2 C 0.1 · 1, SVM C 0.3 · 1 · 3 × γ 0.1 · 0.5, 부스팅 깊이 2 · 3 × 잎 5 · 15, MLP 은닉 8 · 16 × α 0.01 · 0.1)

## 1. 질문
J-축소의 결합기(로지스틱)를 비선형으로 바꾸면 **경계가 더 잘 만들어지고, 그 경계가 val에서도 안정적인가.**

## 2. 왜 다시 하나 — EXP-045의 약점
[EXP-045](../../../4_J모델/EXP-045_비선형결합/README.md)는 "로지스틱 0.975 > 비선형 5종"이었지만 결론을 그대로 쓰기 어렵다.

| # | 약점 | 영향 | 이번에 바꾸는 것 |
|---|---|---|---|
| W1 | 하이퍼파라미터를 값 하나로 고정 (SVM C = 1, 부스팅 100그루 · 깊이 2, kNN k = 7, MLP 8) | 비선형이 진 이유가 "모델"인지 "그 설정"인지 모름 | 모델마다 **용량 사다리**(약 → 강)를 실행 전에 고정해 전부 잰다 |
| W2 | 022(박자 z 8.5) 한 점이 비선형 경계를 좌우 | poly2 · SVM · MLP · kNN · 부스팅 모두 022를 2–5/5 놓침 | 결합 입력에 **같은 꼬리 누르기 변환**을 모든 결합기(로지스틱 포함)에 적용한 팔을 추가 |
| W3 | 기준이 J (지금 기준은 J-축소) | 최신 구성과 비교가 아님 | 기준 = **J-축소** (EXP-050과 같은 분할 · full) |
| W4 | 문턱 정하는 절차가 J와 달라 lin도 0.975 (J 0.977) | 같은 조건 비교가 아님 | 모든 결합기를 **같은 문턱 절차**로 (lin 결과가 J-축소 값을 재현하는지 먼저 확인) |
| W5 | val을 안 봄 | val 뒤 판단 기준(판정 안정성)을 확인 못 함 | EXP-050과 같은 **흔들림 잣대**로 val 판정 비교 |
| W6 | 단조성 없음 | "ET · AE · 박자 점수가 높을수록 고장"이라는 물리 방향을 비선형이 어길 수 있음 | **단조 제약 비선형**(부스팅 단조 · 가법 스플라인)을 후보에 넣음 |

## 3. 고정할 것 (J-축소와 같게)
- 결합 입력 Z = [ET 안쪽 OOF logit (울림 비율 축소, α = 3), 박자 z, AE z]. 폴드 안에서만 만든다
- E2 · 8.3k 규칙은 그대로 OR (결합기만 바꿈)
- 분할: 바깥 StratifiedGroupKFold 5 × seed 5, 안쪽 4 (full, `QE_FULL=1`). 탐색은 quick(seed 2 · ET 100)으로 먼저 돌려 오류만 확인
- 이상치 정상 3개: J-축소와 같은 설정 (학습 포함. EXP-046 기각 이후 J 기준)

## 4. 후보 결합기 (용량 사다리, 실행 전 고정)
| 결합기 | 무엇을 보나 | 사다리 |
|---|---|---|
| lin 로지스틱 (기준) | 직선 경계 | C ∈ {0.1, 1, 10} |
| 가법 스플라인 로지스틱 | 입력마다 곡선, 상호작용 없음 (단조 확인용) | 매듭 3 · 5, C ∈ {0.3, 1} |
| poly2 로지스틱 | 2차 상호작용 | C ∈ {0.03, 0.3, 3} |
| SVM RBF | 둥근 경계 | C ∈ {0.3, 1, 3} × gamma ∈ {0.1, 0.3, 1} (스케일 후) |
| 부스팅 단조 (HistGradientBoosting, 세 입력 모두 +1 단조) | 계단 경계, 물리 방향 유지 | 깊이 2 · 3 × 학습률 0.05 · 0.1 × 잎 최소 5 · 10 |
| MLP | 부드러운 곡선 | 은닉 (4) · (8) · (16) × alpha 1e-3 · 1e-2 · 1e-1 |
- kNN은 뺀다 (3입력 150점에서 경계가 들쭉날쭉, EXP-045에서 가장 약함). 필요하면 사용자 판단으로 추가
- 각 결합기의 사다리 칸은 **안쪽 CV에서 고르지 않고 칸마다 전부 보고**한다 (150개에서 안쪽 튜닝은 잡음에 맞춰짐, EXP-026). 대표값은 "사다리 전체에서 F2가 평평한 구간"으로 읽는다
- 입력 변환 팔 2개: (a) 그대로 (b) 꼬리 누르기 `sign(z) · log1p(|z|)` (모든 결합기 공통, 022 한 점의 지배를 줄이는지 확인)

## 5. 잣대 ([판단기준](../../../../1_기준·기록/판단기준.md) ①)
| 순서 | 잣대 | 기준 |
|---|---|---|
| ① | 중첩 F2 ± sd (full) | J-축소 0.977 ± 0.010 대비 **sd를 넘게** 높아야 개선 |
| ② | 경계 모양 | `logistic_plane`(ET × AE, 박자 z = 0 단면)에서 경계가 물리 방향(점수 ↑ = 고장 쪽)인가, 022 주변에서 접히지 않는가 |
| ③ | 못 잡은 고장 | 오류 분석 표: 022 · 014 · 005 등 미탐이 새로 생기는가, 오경보 116 · 059 · 065는 그대로인가 |
| ④ | val 판정 안정성 | EXP-050과 같은 흔들림 잣대 — (a) 폴드 경계 5개 + 전체 경계에서 판정이 바뀌는 val 파일 수 (b) 부트스트랩 300회 val 결합 고장 수 5–95 % 폭 (J-축소 8–14) |

**교체 규칙 (실행 전 고정)**: ① sd 넘게 개선 **그리고** ④ 흔들림 폭이 J-축소보다 넓지 않을 때만 교체를 논의한다. ①이 sd 안이면 ②–④가 좋아도 로지스틱 유지(단순한 쪽), 단 결과는 기록.
