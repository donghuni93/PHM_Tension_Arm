**깨달음**
- 못 잡는 고장은 놓친 파일을 정상 5–95 % 범위와 겹쳐 보면서 **물리 기전**을 찾았다. 점수를 올린 것은 모델이 아니라 기전이었다
- 규칙 문턱은 라벨을 보고 정한 값(사후)이라 점수가 낙관적이다. 그래서 **기전이 설명되고 겨냥한 고장이 여럿일 때만** 허용했다 ([결정](../../1_기준·기록/결정.md) "사후 문턱 예외")
- 이후(11-16 ~ 19) 규칙을 더 붙였지만(주기 잠금 · 울림 · 9.5 kHz 내림, EXP-029 · 030 · 034 · 036 · 039) 사후 장치만 늘어 [아카이브](../아카이브/README.md)로 내렸다 → [3. 2차 설계](../3_2차설계/README.md)
