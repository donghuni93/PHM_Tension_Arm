# 1. 첫 베이스 모델 (11-13 ~ 14)

**질문**: 고장을 잡는 기본 틀을 무엇으로 세우나.

| 실험 | 한 일 | F2 (중첩 CV) |
|---|---|---|
| EXP-002 (폴더 없음) | ET + 확장 150 피처(대역 필터 뒤 충격 · 첨도 등) | 0.819 ± 0.030 |
| [EXP-012](EXP-012_스펙트럼AE_tSNE/README.md) | 스펙트럼 AE: 정상만 학습, 복원 오차가 크면 고장 (신효섭 보고서 재현) | 0.832 ± 0.027 |
| **[EXP-014](EXP-014_ET·AE결합/README.md)** | ET 점수 · AE 오차를 **정상 기준 z**로 맞춰 로지스틱 결합 | **0.857 ± 0.031** |

**깨달음**
- ET는 "아는 고장과 닮았나", AE는 "정상과 다른가"를 본다. 서로 다른 고장을 잡아 합치면 둘 다보다 낫다 (AE가 ET가 놓친 002 · 029를 잡음)
- 이 결합 틀(전문가 점수 → 정상 기준 z → 로지스틱)이 최종 모델 J까지 그대로 이어진다
- 남은 미탐은 어느 피처에서도 정상 분포 안에 있었다 → 모델이 아니라 신호를 다시 봐야 함 → [2. 규칙 발견](../2_규칙발견/README.md)
