# 3. 2차 설계 — 피처를 물리로 다시 짜기 (11-21, 한 번에 진행)

**질문**: 사후 규칙에 기대지 않고 피처만으로 고장을 가를 수 있나.

**왜 다시 짰나** ([계획](../검토문서/모델구성_계획_1121.md))
- 당시 최종(EXP-034, 0.955)은 규칙 3개의 대역 · 문턱이 모두 라벨을 본 뒤 정한 값 → 새 데이터 성능을 모름
- 충격 정의가 팀원 · 초기 모델에서 와서 근거가 없었다 (015는 정의에 따라 충격 0개 / 28개)
- 진동 공부로 "크기는 길을 잰다 → 비율 · 모양 · 박자로 보자"를 이해함

| 단계 | 실험 | 한 일 | 결과 |
|---|---|---|---|
| 1 | [EXP-040](EXP-040_2차설계_1단계/README.md) | 새 충격 정의 + 1 kHz 고역 H 피처 15열 + 박자 S | C 0.907 ± 0.009 (기준 A 0.949 아래) |
| 2 | [EXP-041](EXP-041_2차설계_2단계결합/README.md) | 결합 방식 max · 로지스틱 · SVM | 로지스틱 승 |
| 3 | [EXP-042](EXP-042_2차설계_3단계전문가/README.md) | 남는 오류 원인별 전문가 E1 · E2 (문턱 = 학습 정상 99 %) | D2 0.916. E2(하중 대비 덜컥) 남김 |
| 4 | **[EXP-043](EXP-043_E1폐기_8.3k규칙/README.md)** | E1 폐기 + 8.3k 규칙 OR → **G** | **0.959 ± 0.014** (A와 sd 안) |

**깨달음**
- 피처만으로는 기준에 못 미쳤다. 8.3 kHz 공진 고장은 피처로 안 잡히고 규칙이 필요했다 → 규칙은 8.3k 하나만 남김
- 대신 피처가 물리로 설명된다: 충격 수 · 2위/1위 · 울림 주파수 비율 · 옥타브 몫 · 하중 대비 고주파 · 박자
- AE는 이 단계에서 뺐다 → 다시 넣은 것이 [4. 최종 모델 J](../4_J모델/README.md)
