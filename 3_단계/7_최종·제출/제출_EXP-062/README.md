## 실행 (프로젝트 어디서 실행해도 같다: 스크립트가 `src/`가 있는 상위 폴더를 루트로 찾고, 산출물은 이 폴더 아래에 만든다)
```
conda run -n qe-phm python "3_단계/7_최종·제출/제출_EXP-062/1_학습.py"     # 학습 150 → 모델/final_model_062.joblib, 결과/학습요약.txt (한 번만)
conda run -n qe-phm python "3_단계/7_최종·제출/제출_EXP-062/2_예측.py"     # val → 출력/submission_val_9조.csv (+ 근거표 · 요약)
conda run -n qe-phm python "3_단계/7_최종·제출/제출_EXP-062/2_예측.py" 2_data/TeamProject_test/test submission_test_9조.csv 2_data/TeamProject_test/submission_test.csv
```
- 인자 경로는 프로젝트 루트 기준 상대 경로(또는 절대 경로). val 기본값: 폴더 `2_data/TeamProject_val/val`, 양식 `2_data/TeamProject_val/submission_val.csv`(있으면 그 열 · 순서 그대로).
- 학습은 한 번만 한다. val · test를 본 뒤 다시 학습하거나 문턱을 고치지 않는다. 제출은 사용자가 직접 하고, 제출 파일 확정은 승인을 받는다.
