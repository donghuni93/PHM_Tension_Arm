# 개념 사전 — PHM 진동 분석 방법론 (선택지 목록)

이 문서는 **정답이 아니라 선택지 목록**이다. 팀 노션 "도메인 지식·파이프라인" 정리(2026-11, 원문은 Gemini·팀원 조사 포함)를 항목별로 옮기고, 항목마다 **우리 데이터에서 확인한 것**을 따로 적는다.
- **원문**: 노션에 적힌 주장. 일반론이거나 다른 설비(회전체) 기준일 수 있다
- **우리 데이터**: 실험·EDA로 확인한 사실만. 근거가 없으면 "미확인"
- **주의**: 노션 정리자 의견 + 우리가 덧붙인 것
- **뷰어**: [EDA 뷰어](2_EDA/EDA뷰어/README.md)에서 이 개념을 보는 지표 키

뷰어가 이 파일을 읽어 "개념" 화면을 만든다. 형식: `## 분류` 아래 `### 이름 {#키}`, 본문은 `- **칸**: 내용`. 고친 뒤 `build_viewer.py`를 다시 실행한다.

## 도메인

### 텐션암과 고무 부싱 {#tension-arm}
- **원문**: 텐션암은 휠의 전후 움직임을 제어하고 제동·가속 하중을 받는 비회전 구조물. 양 끝에 압입된 고무 부싱이 금속 접촉을 막고 강성 K와 감쇠 C를 함께 제공한다
- **원문**: 회전체(기어·베어링)와 달리 RPM × 톱니 수 같은 고정 결함 주파수 공식이 없고 비주기 충격(transient)이 중심 → 시간 영역 Peak·첨도와 대역 에너지로 다차원 특징 공간을 만든다
- **우리 데이터**: 파일당 1열(단일 축) 50,000점(25 kHz × 2초). 가진 방식(정지 가진인지 실차인지)은 데이터 소개 PDF에 없다. "정지 가진"은 팀 가정
- **주의**: 고장 원인이 부싱인지 볼조인트인지는 PDF로 알 수 없다(수리 그림이 부싱 압입이라 부싱일 가능성이 높다는 추정)

### 동역학 모델과 고유진동수 {#sdof}
- **원문**: M·x'' + C·x' + K·x = F(t), 고유진동수 ωn = √(K/M). 결함 → K·C 변화 → 공진 위치와 피크 진폭 변화
- **원문 (Gemini 추정, 실측 확인 필요)**: 1차 공진 100–300 Hz, 고차 모드 1–3 kHz, 응력파 링잉 5–10 kHz. 예: 경화 200 → 230 Hz, 박리 200 → 160 Hz
- **우리 데이터**: 정상 파일에 공통 가진 피크가 없다(H6). 200 Hz 아래는 느린 흔들림이 에너지의 74%를 차지해 1차 공진을 따로 보기 어렵다([3-1](3_전처리/3-1_평균제거·고역통과/README.md)). 첨도 구분력이 가장 강한 대역은 1.25–2.5 kHz로, 추정 "고차 모드 1–3 kHz"와 겹친다(H1)
- **주의**: 추정 대역은 뷰어 PSD에서 "추정 대역" 음영으로만 표시한다. 피처 경계로 쓰지 않는다
- **뷰어**: PSD의 "추정 대역" 켜기

### Payne 효과와 기준선 차이 {#payne}
- **원문**: 카본블랙 충전 고무는 진폭이 클수록 강성이 감소(Payne / Fletcher-Gent). 차량 종류·하중·세팅에 따라 RMS·스펙트럼 기준선이 달라지므로 정상 대비 **상대적 패턴 붕괴**를 봐야 한다
- **우리 데이터**: 절대 로그 PSD를 피처에 넣으면 매번 점수가 떨어지고 정규화(모양) 피처는 +0.026 (EXP-005, H3 부분 지지). 정상 안에도 운전 상태 무리가 여럿 있다(2-1 관찰 4)
- **뷰어**: 비율 지표(`r_lo` `r_mid` `r_hi` `hi_ratio`)와 절대 지표(`e200` `e_lo` …)를 나란히 본다

### 부싱 경화 {#hardening}
- **원문**: 열화·오존·반복하중 → 가교 증가 → 강성 K↑ → 고유진동수 상향 이동, 감쇠 저하로 공진 피크 증폭·RMS 상승
- **우리 데이터**: 미확인. 공진 피크 위치 이동은 공통 피크가 없어 재기 어렵다
- **뷰어**: `centroid` `peak_f` `peak_prom`

### 부싱 박리·파단 {#delamination}
- **원문**: 전단 누적 → 찢어짐·고무-금속 이탈 → 유격 → 강성 급감(하향 이동), 금속 타격(Clunk) → 임펄스, 첨도 급증, 광대역 고주파 노이즈
- **우리 데이터**: 대역 필터 후 첨도가 가장 강한 피처(EXP-002, `P02_kurtosis_012` AUC 0.878, H1 지지). 충격이 0–2개인 고장은 30개 중 1개(2-4). 고주파 몫이 정상 95%를 넘는 고장 18개, 정상 6개(2-4)
- **주의**: 정상에도 단발 큰 충격이 있다(nor_055·116·073) → "충격이 있다"가 아니라 횟수·대역·반복성으로 구분해야 한다
- **뷰어**: `kurt` `n_imp` `prot` `sk_max` `hi_ratio` (신호 "200 Hz 고역통과"에서)

### 본체 호흡 균열 {#breathing-crack}
- **원문**: 열림/닫힘 강성이 다른 이선형 진동자. ω0 = 2ω1ω2 / (ω1 + ω2). 가진 주파수의 정수배 고조파(2ω, 3ω)와 부고조파가 생긴다. 본체 파손은 드물어 보조 가설
- **우리 데이터**: 가진 주파수를 모른다(공통 가진 피크 없음) → 고조파 비율을 정의할 수 없다(H6 보류)
- **뷰어**: 없음 (아래 "고조파" 항목 참고)

### 볼조인트 유격과 체결부 풀림 {#play}
- **원문**: 인장↔압축 하중 전환 순간 틈에서 짧고 날카로운 충격(Clunk/Chatter)이 간헐적으로 발생 → 첨도·파고율·TKEO·서브윈도우 최대 RMS. 볼트 풀림은 다른 축으로 에너지 전이·고조파 왜곡 → 축간 비율·스펙트럼 엔트로피·ZCR
- **우리 데이터**: abn_022는 느린 흔들림의 특정 위상에서 작은 충격 3개(약 0.95초 간격)가 보인다(H4 후보, 미검증). 축간 지표는 단일 축이라 불가
- **뷰어**: `imp_gap` `env_pf` `win_rms_mm`, 파형의 "평균 제거" 보기(흔들림과 충격 시점을 함께 봄)

## 전처리

### 평균 제거 {#mean-removal}
- **원문**: 센서 영점 편향을 빼서 중심을 0으로 (데이터 소개 PDF: +0.7 g → 0 g). 필수
- **우리 데이터**: 평균 −0.87 ~ −1.05 g 파일 4개(nor_097·101·120, abn_016) = 설치 자세(중력) 성분. 빼지 않으면 nor_097 RMS가 0.884 g(실제 진동 0.167 g). 200 Hz 고역통과 뒤에는 결과가 같다(차이 1e-14 g) ([3-1](3_전처리/3-1_평균제거·고역통과/README.md))
- **뷰어**: `mean`

### 이동평균 (MA) {#ma}
- **원문**: 인접 M개 평균 = 저역통과. 센서 고주파 전기 잡음 완화. M이 크면 진짜 Peak도 뭉개짐
- **우리 데이터**: MA 창이 커질수록 첨도·Peak 구분력이 줄어 **미적용**으로 결정(결정.md)
- **주의**: 고장 정보가 고주파·충격에 있으므로 MA는 그 정보를 깎는 방향이다

### 고역통과·대역통과 필터 {#bandpass}
- **원문**: 결함 대역만 남기고 그 신호에서 RMS·Peak·첨도를 다시 구하면 묻혀 있던 충격이 드러난다. 정보를 버리는 게 아니라 **열을 추가**하는 돋보기. 대역은 EDA 이후 정한다
- **우리 데이터**: 200 Hz 고역통과는 정상 에너지의 74%를 지우지만, 지워지는 대역은 구분력이 거의 없다(AUC 0.43–0.58 vs 200 Hz 이상 0.73). 1.25–2.5 kHz 대역 첨도가 최강(H1)
- **주의**: 라벨을 본 뒤 대역을 손으로 고르면 점수가 부푼다(원칙 3). 고정 격자 + 폴드 안 선택으로만 쓴다
- **뷰어**: 머리줄 "신호" 전환 (평균 제거 ↔ 200 Hz 고역통과). 모든 그림·지표가 같이 바뀌고, 지표 표의 회색 숫자가 반대 신호 값. `s200` = 고역통과가 지우는 몫

### 대역 분할 (균등·물리) {#band-split}
- **원문**: 균등 분할(0–12.5 kHz를 10–20칸)은 베이스라인용, 물리 분할(저 0–2 kHz / 중 2–5 kHz / 고 5–12.5 kHz)은 의미를 담을 때. 경계값은 예시
- **우리 데이터**: 고정 1 kHz 격자에서 단변량 AUC 최고는 8–9 kHz 0.827, 3–4 kHz 0.811 (EXP-012 논의 중 계산, 설명용)
- **뷰어**: `b0`…`b12`(1 kHz 격자), `e_lo` `e_mid` `e_hi`(물리 분할, 저역은 200 Hz부터), PSD "물리 대역" 음영

### 포락선 (Hilbert) {#envelope}
- **원문**: 고주파 반송파는 무시하고 충격 때 솟는 윤곽선만 남긴다. 노이즈 속 간헐 충격을 깔끔한 저주파 윤곽으로 분리. 보통 공진 대역을 bandpass한 뒤 만든다
- **우리 데이터**: ext150의 E01 포락선 첨도가 005·014 같은 충격형 고장에서 정상 98–100% 분위(EXP-012 논의). 뷰어는 선택한 신호(평균 제거 / 200 Hz 고역통과)의 포락선을 쓴다(대역 선택 없음)
- **뷰어**: `env_kurt`, 포락선 스펙트럼 그림

### 스펙트로그램 (STFT) {#stft}
- **원문**: 짧은 창마다 FFT → 시간 × 주파수 × 에너지. 언제·어느 대역이 튀는지 본다. Δf = fs/Nw, Δt = Nw/fs (1,024점이면 24.4 Hz · 41 ms). 용도: A 탐색(EDA) · B 시간축 요약 피처 · C CNN 입력
- **우리 데이터**: 뷰어에서 A 용도로 사용(1,024점 창, 50% 겹침). C(CNN)는 파일 150개라 과적합 위험이 커서 미검토
- **뷰어**: 스펙트로그램 그림, `sk_max` `sk_f`

### 웨이블릿·WPD·EMD·켑스트럼 {#advanced}
- **원문**: 웨이블릿 디노이징(백색 잡음 임계값 제거), WPD(노드 에너지), EMD(IMF로 자동 분해), 켑스트럼(고조파 간격 → 한 피크), 교차상관(좌/우 센서)
- **우리 데이터**: 미시도. 교차상관은 단일 센서라 불가
- **주의**: WPD는 웨이블릿·레벨 선택과 피처 수 증가, EMD는 모드 혼합·IMF 개수 불일치. 켑스트럼은 가진 주파수를 모르는 지금은 해석이 어렵다

### 데이터 증강 {#augmentation}
- **원문**: 윈도우 슬라이싱(0.5초, 50% 겹침 → 파일당 7조각), 가우시안 노이즈, 스케일링(0.9–1.1), 시간 이동, SMOTE(특징 후). train에만
- **우리 데이터**: 슬라이싱 평가 틀(`nested_cv_sliced`)은 있으나 효과는 재검토 대상(00_NOW). EXP-012는 1초 × 8구간(86% 겹침)을 AE 학습 샘플로 썼다
- **주의**: 파일 단위로 나눠야 누수가 없다. 정상·고장 같은 방식으로 자를 것. 조각에 충격이 없어도 고장 라벨(라벨 노이즈). 겹친 조각은 독립 샘플이 아니다. 노이즈 주입은 고주파 대역·첨도를 건드린다. Payne 효과 때문에 스케일링은 실제 다른 가진을 재현하지 못한다

## 시간 영역 지표

### RMS·Peak·Peak-to-Peak·MAV {#rms}
- **원문**: RMS = 전체 진동 에너지(경화·노후로 상승, 간헐 충격에 둔감). Peak = 순간 최대(금속 타격). MAV = 평균 |x|
- **우리 데이터**: 평균 제거 후 RMS는 200 Hz 아래 흔들림이 대부분 → 고역통과 RMS를 따로 본다. 최대 |진폭| AUC 0.80, 정상 95%(1.09 g) 초과는 고장 11/30, 정상 6/120 (2-1)
- **주의**: 평균을 뺀 신호의 표준편차 = RMS. 정의로 얽혀 상관이 높다
- **뷰어**: `std` `maxabs` `p2p` `mav` (신호 전환으로 고역통과 RMS)

### 첨도 (Kurtosis) {#kurtosis}
- **원문**: 4차 모멘트, 분포 꼬리 두께 = 충격성. 박리·초기 균열의 간헐 충격에 민감. 결함 시 7–10 이상은 경험적 예시
- **정의 주의**: Pearson 정의는 정규분포 3, 사인파 1.5. **뷰어는 Fisher 정의(Pearson − 3)라 정규 0, 사인 −1.5**. 노션 원문의 "정현파 ≈ 3"은 오류(1.5가 맞음)
- **우리 데이터**: 원신호 첨도 AUC 0.77(2-1). 대역 필터 후 첨도가 더 강함(H1). 정상에도 단발 충격으로 첨도가 매우 큰 파일(nor_073 997)이 있다
- **주의**: "바탕 대비 얼마나 튀나"를 잰다. 충격이 많아지면 그것이 바탕이 되어 오히려 낮아진다(abn_004 k10)
- **뷰어**: `kurt` `win_kurt_max` (신호 전환으로 고역통과 첨도)

### 왜도 (Skewness) {#skewness}
- **원문**: 3차 모멘트, 비대칭. 한쪽으로 쏠리는 마찰·충격
- **우리 데이터**: AUC 0.51 — 구분력 없음(2-1)
- **뷰어**: `skew`

### 파고율·충격·형상·여유 계수 {#shape-factors}
- **원문**: 파고율 = Peak/RMS, 충격 계수 = Peak/MAV, 형상 계수 = RMS/MAV, 여유 계수 = Peak/(평균 √|x|)². 무차원이라 가진 크기에 덜 민감할 수 있다
- **우리 데이터**: 파고율 AUC 0.79(2-1). 나머지 셋은 미확인
- **주의**: 넷 다 Peak·RMS·MAV로 정의되어 서로 상관이 높다
- **뷰어**: `crest` `impulse_f` `shape_f` `clear_f`

### Hjorth 지표 {#hjorth}
- **원문**: Mobility = √(var(x')/var(x)) ≈ 평균 주파수, Complexity = Mob(x')/Mob(x) = 정현파에서 벗어난 정도. FFT 없이 비선형 거동 포착
- **우리 데이터**: 미확인 (뷰어에서 처음 계산)
- **주의**: 평균 제거 신호에 계산하면 저주파 흔들림이 지배한다
- **뷰어**: `hjorth_mob` `hjorth_cpx`

### TKEO (Teager-Kaiser 에너지) {#tkeo}
- **원문**: Ψ[n] = x[n]² − x[n−1]·x[n+1]. 진폭과 주파수를 함께 반영해 미세한 금속성 타격을 강조. Mean·Max·Kurtosis·Energy
- **우리 데이터**: ext150에 `T18_tkeo_kurtosis`가 있고 abn_005에서 정상 98% 분위(EXP-012 논의). 뷰어는 200 Hz 고역통과 신호에 계산
- **주의**: 고주파에 민감 → MA를 걸면 약해진다
- **뷰어**: `tkeo_kurt` `tkeo_mm`

### 영교차율 (ZCR) {#zcr}
- **원문**: 신호가 부호를 바꾸는 비율. 주파수가 높고 불규칙할수록 증가
- **우리 데이터**: 미확인. 뷰어는 고역통과 신호 기준(초당 횟수 ≈ 주된 주파수의 2배)
- **뷰어**: `zcr` `zcr_std`

### 윈도우 통계 (비정상성) {#window-stats}
- **원문**: 2초 전체 통계는 짧은 충격을 희석한다. 0.05–0.1초 창으로 쪼개 창별 RMS·첨도의 최댓값·표준편차를 파일당 1행 피처로. 증강(조각을 샘플로)과 다른 용도
- **우리 데이터**: ext150의 S01(창 RMS max/mean, 변동계수)이 abn_005에서 정상 97% 분위(EXP-012 논의)
- **뷰어**: `win_cv` `win_rms_mm` `win_kurt_max` `floor`, "창별 RMS·첨도" 그림 (50 ms × 40창, 고역통과 신호)

### 충격 검출 (뷰어 정의) {#impulse-count}
- **정의 (우리)**: 200 Hz 고역통과 신호가 바탕 σ(MAD × 1.4826)의 8배를 넘은 사건, 10 ms 안은 하나로. 8σ는 정규 잡음에서 사실상 나오지 않는 값이라 라벨을 보기 전에 정함
- **우리 데이터**: 충격 0–2개: 정상 52, 고장 1. 3개 이상: 정상 68, 고장 29 (2-4) → 있음/없음보다 횟수·간격·대역이 관건
- **뷰어**: `n_imp` `prot` `imp_gap`, 파형 위 눈금

### 자기상관 (ACF) {#acf}
- **원문**: 자기 자신의 과거와 얼마나 비슷한가. 회전체 고장은 주기적이라 ACF가 높고, 텐션암은 불규칙할 수 있다. 특정 지연의 값, 처음 0이 되는 지연 등을 피처로
- **주의**: ACF와 PSD는 푸리에 쌍(Wiener–Khinchin)이라 정보가 크게 겹친다. 반복 충격의 주기는 포락선 스펙트럼으로 보는 것이 더 직접적이다
- **뷰어**: 직접 지표 없음 → `env_pf`(포락선 반복 주파수)로 대신

## 주파수 영역 지표

### FFT·PSD·Welch {#psd}
- **원문**: FFT는 혼합 신호를 주파수별 에너지로 분해. 원신호 전체 FFT 분해능 0.5 Hz
- **우리 데이터**: 뷰어 PSD는 Welch(4,096점, 6.1 Hz 간격). Welch는 창 여러 개를 평균해 잡음을 줄이는 대신 짧은 충격을 희석한다(EXP-012가 005·014를 놓친 원인)
- **뷰어**: PSD 그림 (정상 5–95% 띠 + 정상·고장 중앙값)

### 공진 주파수 이동 {#resonance-shift}
- **원문**: f_shift = 파일 피크 − 정상 120개 평균 스펙트럼 피크. 양수 = 경화, 음수 = 박리·균열
- **우리 데이터**: 정상 평균 스펙트럼에 뚜렷한 단일 공진 피크가 없어 기준 피크를 정의하기 어렵다. 대신 협대역 피크 돌출도를 본다(002·029의 8.2–8.4 kHz, H2)
- **뷰어**: `peak_f` `peak_prom` (매끈한 바탕보다 가장 튀어나온 피크)

### 고조파 에너지 비율 {#harmonics}
- **원문**: (E(2f0) + E(3f0)) / E_total. 이선형 균열 특화
- **우리 데이터**: f0(가진 주파수)를 모른다 → 계산 불가(H6 보류)

### 대역 에너지와 비율 {#band-energy}
- **원문**: 대역별 진폭 제곱합. 고장 시 특정 고주파 대역 에너지 상승. 비율(합 = 1)은 절대 크기를 잃으니 절대값도 함께
- **우리 데이터**: 절대 로그 에너지는 기준선(게인) 차이로 흔들림(H3). 200 Hz 이상 에너지가 정상 95% 초과: 고장 11, 정상 6 (2-4)
- **뷰어**: `e200` `e_lo` `e_mid` `e_hi` `r_lo` `r_mid` `r_hi` `b0`…`b12`

### 스펙트럼 중심·대역폭·롤오프 {#spectral-shape}
- **원문**: 중심 = 에너지 무게중심(유격 마찰음이 늘면 고주파로), 대역폭 = 중심 주변 퍼짐, 롤오프 = 누적 85%·95% 지점
- **우리 데이터**: 중심주파수(200 Hz+) AUC 0.640, 고역 비(8–12.5 kHz / 200 Hz+) AUC 0.786 (EXP-012 논의, 설명용)
- **주의**: 경화는 상향, 박리는 하향이라 이동 부호가 결함마다 다르다
- **뷰어**: `centroid` `bandwidth` `rolloff85` `rolloff95` `hi_ratio`

### 스펙트럼 엔트로피·평탄도 {#spectral-entropy}
- **원문**: 에너지가 여러 주파수에 고르게 퍼졌는가(엔트로피↑) 몇 피크에 몰렸는가. 볼트 풀림·마찰
- **우리 데이터**: 미확인
- **뷰어**: `entropy` `flat`

### 스펙트럼 첨도·커토그램 {#spectral-kurtosis}
- **원문**: 주파수마다 시간에 따른 충격성을 재서 가장 충격적인 대역을 찾는다 → 그 대역을 bandpass → 포락선. STFT 기반
- **우리 데이터**: 뷰어에서 처음 계산 (STFT 1,024점, 24.4 Hz 칸마다 96프레임에 걸친 첨도). 미확인
- **주의**: 프레임 수(96)가 적어 추정이 거칠다. 가장 큰 대역을 라벨 보고 골라 피처로 쓰면 원칙 3 위반 → 최댓값·위치를 파일별로 기술하는 데만 쓴다
- **뷰어**: `sk_max` `sk_f`, 스펙트럼 첨도 그림

### 포락선 스펙트럼 {#envelope-spectrum}
- **원문 (회전체)**: 포락선의 스펙트럼에서 반복 충격의 주기(결함 주파수)를 찾는다
- **우리 데이터**: 텐션암은 결함 주파수 공식이 없지만, 충격이 반복되면 그 반복 주파수가 피크로 나온다(예: abn_022 약 0.95초 간격이면 약 1 Hz). 미확인
- **뷰어**: 포락선 스펙트럼 그림(0–300 Hz), `env_pf` `env_prom`

## 특징 선택

### 다중공선성·VIF·상관 필터 {#collinearity}
- **원문**: 진동 피처는 태생적으로 상관이 높다(Peak·RMS·파고율, 인접 대역). 선형 모델은 필수, 트리는 선택, Mahalanobis는 사실상 필수. |r| ≥ 0.85면 의미가 뚜렷한 쪽만, VIF 5–10 이상 의심
- **우리 데이터**: 상관 0.9 필터는 150 → 100개로 점수 동일(0.827), VIF ≤ 10은 49개로 0.784로 하락 — VIF가 RMS·Peak·첨도 같은 중심 피처를 지웠다(EXP-007)
- **주의**: 정상·고장을 합친 상관에는 클래스 차이가 섞인다 → 정상만의 상관과 비교. 선택은 폴드 안에서

### PCA {#pca}
- **원문**: 상관 높은 피처를 주성분으로 압축
- **우리 데이터**: 스펙트럼 AE 입력에 PCA 복원 오차를 쓰면 k=4·16·32에서 F2 0.732·0.761·0.795로 AE(0.832)보다 낮다(예비 확인, 실험 기록 전)
- **주의**: 주성분은 물리 의미가 사라진다

## 모델·평가

### 중첩 교차검증과 F2 임계값 {#nested-cv}
- **원문**: 파일 단위 그룹 분할, 변환·선택·임계값은 학습 fold 안에서. OOF F2 최대 임계값
- **우리 데이터**: 같은 fold에서 임계값을 고르면 F2가 +0.03–0.045 부풀고 모델 순위가 뒤집힌다 → 바깥 5 × 안쪽 4 × seed 5 중첩 CV로만 비교(결정.md)

### 트리 앙상블 (ET·RF·부스팅) {#trees}
- **원문**: 정형 데이터 강자. 다중공선성에 비교적 강함
- **우리 데이터**: ext150 + ExtraTrees 0.827 ± 0.031, 놓침 002 022 029 (기준선)

### 이상탐지 (IF·OCSVM·Mahalanobis·AE) {#anomaly}
- **원문**: 정상 120개 군집에서의 이탈. 고장 30개는 임계값 튜닝에만
- **우리 데이터**: 스펙트럼 AE 0.832 ± 0.027, 놓침 005 014 017 022(EXP-012). 정규화로도 개선 없음, 상습 오경보 7개는 구성과 무관(EXP-013). 정상만 kNN 등 0.66–0.73(EXP-004)
- **주의**: "정상과 다름" ≠ "고장". 정상과 비슷한 고장은 못 잡는다

### 그 밖의 후보 (TabPFN·MiniROCKET·Elastic-Net·CNN·DTW) {#other-models}
- **원문**: TabPFN(기존 특징 활용도 확인), MiniROCKET(수작업 특징이 놓친 패턴), Elastic-Net 로지스틱(선택 안정성), 1D/2D-CNN, DTW
- **우리 데이터**: 모두 미실험. TabPFN·MiniROCKET은 새 라이브러리라 설치 승인 필요
- **주의**: MiniROCKET도 과적합 가능. DTW는 50,000점에서 쌍당 약 25억 칸이라 원신호에는 비현실적. CNN은 150개로 과적합 위험 큼

### 스케일러 {#scaler}
- **원문**: 충격 극단치가 많으면 RobustScaler(중앙값·IQR)
- **주의**: 정상만으로 fit할지, 정상+고장으로 fit할지 비교. 폴드 안에서 fit
