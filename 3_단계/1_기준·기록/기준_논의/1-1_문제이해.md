# 1-1 문제 이해

상태: 논의 완료 (11-13)
형식: **사실**(원문·데이터로 확인) / **논의** / **합의·미정**

## 사실
출처: 과제 원문 `1_참고자료/2026_품질공학_프로젝트_데이터소개.pdf` (쪽 번호 표기)

- 판정 단위: 파일 1개(2초, 25 kHz, 50,000점, 가속도 g) → 정상 0 / 고장 1. 고장이 양성
- 데이터 취득: 같은 텐션암을 **수리 전에 측정 = 고장**, 부싱 수리·교체 후 측정 = 정상 (p.4)
- train 정상 120 + 고장 30 (라벨 공개). val 40·test 40은 라벨 비공개, **정상·고장 비율도 공개 안 됨** (p.8)
- 지표 F2 = 5PR / (4P + R). "고장을 놓치지 않는 것이 오경보를 줄이는 것보다 중요" (p.9). 성적 = 성능 70% + 발표 30%
- 원문 그림은 "학습 = 정상 패턴 학습, 판정 = 정상 패턴 이탈"(p.6–7)이지만, 학습에 정상 120 + 고장 30을 모두 쓴다고도 한다(p.12) → 지도·비지도 모두 허용으로 읽힘
- 예시 기준선: 정상 RMS 관리도(UCL = 평균 + 3σ)는 고장 30개 중 28개를 놓침, train F2 0.08 (p.13)
- 최종 제출물 5개(p.7): 01 데이터·취득 과정 / 02 정상·고장 비교 분석 / 03 모델·코드 / 04 성능 평가·오류 분석 / 05 한계·개선 방향

## 논의
- F2를 혼동행렬로 풀면 F2 = 5TP / (5TP + 4FN + FP). **미탐 1개 = 오탐 4개만큼 손해.** 그래서 애매하면 고장으로 판정하는 쪽이 유리
- 전부 고장으로 찍으면 P = 고장 비율, R = 1. train 비율(20%)이면 0.556. val·test 비율이 다르면 이 바닥도 바뀐다
- 수리 전·후 측정이라면 고장 파일과 정상 파일이 **같은 부품·차량에서 짝**으로 나왔을 수 있다. 짝이 있다면 CV에서 같은 짝을 학습·검증에 나눠 넣을 때 누수가 생긴다 (1-2 평가 설계와 연결)
- 제출물 5개는 단계 폴더와 대응: 01 → 1단계, 02 → 2단계, 03 → 3–5단계, 04 → 6단계, 05 → 7단계

## 합의·미정
- **합의 (11-13) 짝 구조는 배제한다.** 수리 전·후 짝이 없을 수도 있고 확인할 근거도 없다 → 파일 하나 = 그룹 하나로 CV
- **합의 (11-13) 고장 비율은 특정 값에 맞추지 않는다.** val·test 비율을 모르므로, 특정 비율에 맞춘 점수보다 **일반화 성능**을 확보하는 방향으로 개선하면서 모델을 확정한다. 1-2에서 구체화:
  - train 비율(20%)에서의 F2만 보지 않고, 비율이 바뀌어도 덜 흔들리는 지표·임계값인지 함께 본다
  - 점수 편차(seed·fold 간)와 과적합 징후를 같이 기록한다
- 짝 구조 배제로 상태 = 1-1 완료 → 1-2 평가 설계로
