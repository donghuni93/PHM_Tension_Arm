# 1 문제·평가

무엇을 맞히고, 점수를 어떻게 정직하게 매기나. 11-13 논의(예전 1-1·1-2)와 이후 결정을 합친 것 (11-16). 손계산·상세 표 원문은 커밋 `28b8ed8`의 `3_단계/1_문제·평가/`.

## 문제 (과제 원문 `1_참고자료/2026_품질공학_프로젝트_데이터소개.pdf`)
- 파일 1개(2초 × 25 kHz = 50,000점, 단위 g) → 정상 0 / 고장 1. **고장이 양성**
- 수리 전 측정 = 고장, 부싱 수리·교체 후 측정 = 정상 (p.4)
- train 정상 120 · 고장 30. val 40(11/19)·test 40(11/27)은 라벨도 **고장 비율도 비공개** (p.8)
- 성적 = 성능 70%(F2) + 발표 30%. 예시 기준선 RMS 관리도는 고장 28/30을 놓침(train F2 0.08, p.13)
- 지도·비지도 모두 허용으로 읽힌다 (p.6–7 "정상 이탈", p.12 "정상·고장 모두 학습")
- 제출물 5개 ↔ 단계: 01 데이터·취득 → 1 · 02 정상·고장 비교 → 2 · 03 모델·코드 → 3–5 · 04 성능·오류 → 6 · 05 한계·개선 → 7

## F2가 뜻하는 것
- F2 = 5TP / (5TP + 4FN + FP) → **미탐 1개 = 오경보 4개.** 애매하면 고장 쪽이 유리
- 바닥선: 전부 고장 0.556 (비율 20%)
- 비율이 바뀌면 정밀도만 변한다(재현율·오경보율은 비율과 무관). 같은 모델이 10% 0.76 · 20% 0.83 · 40% 0.87
- val 40개 하나의 운이 비율 효과만큼 크다: 20%에서도 sd 약 0.09(5–95% 0.64–0.95). 고장 1개 놓치면 1.000 → 0.897, 오경보 1개면 0.976
- 그래서 고칠 대상은 비율이 아니라 **재현율↑ · 오경보율↓** (둘이 같이 좋아지면 어떤 비율에서든 F2가 오름)

## 평가 규칙 (지금 기준)

| 항목 | 규칙 | 이유 |
|---|---|---|
| 분할 | `StratifiedGroupKFold`, 파일 1개 = 그룹 1개 | 수리 전·후 짝 구조는 근거가 없어 배제 |
| 탐색 비교 | `quick_cv`: 5-fold × seed 3, 임계값 없는 PR-AUC | 임계값을 안 고르니 부풀림 원인이 없고 빠르다 |
| 유의미 판정·최종 | 중첩 CV(바깥 5 × 안쪽 4, seed 5) F2 평균 ± sd. **차이 < sd면 같은 수준** | 임계값까지 안 본 데이터로 재야 정직하다 (아래) |
| 임계값 | 안쪽 OOF에서 F2 최대(동점이면 낮은 쪽). 제출 모델만 seed 0·1·2 임계값의 중앙값(1.326) | 제출 모델은 한 번만 학습해 seed 하나의 운을 그대로 떠안음. 중앙값 정책 0.938 ± 0.014 ≈ 0.942 |
| fold 안에서만 | 표준화 · 피처 선택 · 튜닝 · 정상 기준 z · 규칙의 정상 중심 | 채점 파일을 본 계산은 모두 누수 |
| 보고 | 중첩 F2 ± sd + 재현율 + 오경보율 + 고장 10%·40% 환산 F2 | 비율을 몰라도 비교 가능 |
| val | 확인용. val을 보고 모델·문턱을 고치지 않는다 | 40개 표본 하나는 sd 0.09 |
| 대역·문턱 | 라벨을 보고 고르지 않는다. 예외는 사후 규칙 2개뿐 ([3_결정](../결정.md)) | 150개 전체를 보고 고르면 CV 점수가 부풀음 |

## 왜 중첩 CV인가 (11-13 실측, ExtraTrees · ext150)
| 채점 방식 | F2 | 뜻 |
|---|---|---|
| 150개로 학습 → 같은 150개 채점 | 1.000 | 외운 것 |
| 5-fold OOF, 임계값도 그 OOF에서 고름 | 0.856 ± 0.008 | 임계값 고를 때 정답을 봄 |
| **중첩 CV** | **0.827 ± 0.031** | val·test와 같은 상황 |
- RBF-SVM은 0.863 → 0.818로 **순위가 뒤집혔다** → 부풀린 점수로 비교하면 틀린다
- 바깥 fold마다 임계값이 0.24–0.43으로 흔들린다 = 경계 근처 파일 약 20개 = 점수 분리가 약하다는 신호. 임계값 보정보다 피처·모델로 분리를 키우는 것이 먼저

## 1단계 합의(11-13)에서 바뀐 것
- **비교는 중첩 CV로만 → 두 단계(11-14).** 1-2가 막으려던 것은 "채점 데이터로 임계값을 고르는 부풀림"인데 PR-AUC는 임계값을 안 고른다. 중첩 CV는 비교 한 번에 학습 125번이라 탐색엔 과함. 유의미 판정은 여전히 중첩 F2
- **seed 5 → 탐색만 seed 3.** 분할 운(sd)은 최종 판정에서만 재면 된다
- **임계값 방식 유지 → 제출 모델만 중앙값(11-16).** 중첩 CV 안은 그대로
- **학습할 수 없는 고장은 쫓지 않는다 → 002·029·014·017은 규칙으로 잡음(11-14).** 합의 자체의 단서 "물리 가설로 원인을 설명할 수 있을 때만 고친다"를 적용한 것. 022는 겨냥 파일이 하나뿐이라 안 잡음 ([3_결정](../결정.md))
