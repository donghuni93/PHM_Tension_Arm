# 판단 기준 — 모델을 무엇으로 판단하는가

모델 · 피처를 판단할 때 펼쳐 보는 한 장 (11-22 문답으로 정리). 여기서 인용하는 실험 · EDA · 피처가 **핵심**이고, 나머지는 각 단계의 `아카이브/`에 있다.
세부 규칙은 [결정](결정.md), 수치는 [실험로그](실험로그.md), 모델이 만들어진 순서는 [5단계 README](../5_모델실험/README.md).

## ① 판단 지표

평가 F2는 미탐 1개 = 오경보 4개 (F2 = 5TP / (5TP + 4FN + FP)). 그래서 **고장을 놓치지 않는 것**이 판단의 중심이다.

| 시기 | 묻는 것 | 보는 것 |
|---|---|---|
| **val 전** (개발) | F2가 오르는가 | 중첩 CV F2 ± sd (full). sd를 넘는 개선만 개선으로 본다 |
| | 고장 경계가 잘 만들어지는가 | `logistic_plane`(결합 경계) · 기본 t-SNE에서 정상 · 고장이 갈리는 모양 |
| | 못 잡은 고장은 **왜** 못 잡는가 | 오류 분석 표(자주 놓친 고장 · 오경보) → 신호를 보고 물리 가설로 설명 |
| **val 후** | 판정이 안정적인가 | seed · 부트스트랩에 따라 val 판정이 흔들리는 폭, 경계 파일의 여유. 실제로 잰 값: J-축소는 바깥 모델 25개 중 **val 31/40이 만장일치**(정상 23 · 고장 8), 흔들리는 건 001 · 025 · 018 ([6-7](../6_오류분석/6-4_val확실도/README.md)) |
| | 만든 경계가 val에서도 잘 나오는가 | val 점의 평면 · t-SNE 위치 (정답 없이 경계와의 거리만) |

## ② 지금 구성 (J-축소)의 부품별 근거
| 부품 | 하는 일 | 왜 들어갔나 (근거) |
|---|---|---|
| 결합 틀: 전문가 점수 → 정상 기준 z → 로지스틱 | 서로 다른 전문가를 한 판정으로 | 1단계 EXP-014. 비선형보다 로지스틱이 낫다 EXP-045 |
| ET (H 피처 15열) | "아는 고장과 닮았나" | 3단계 EXP-040 · 피처 4-6 · 4-7. 충격 수 · 2위/1위(2-14) · 울림 비율(2-16) · 옥타브 몫 · 하중 대비 고주파(2-12) |
| 울림 비율 축소 (k + 3·p₀)/(n + 3) | 충격이 적은 파일의 비율 흔들림 줄이기 | 5단계 EXP-050 · 6-4 경계 진단 |
| 박자 z (주기 잠금 S) | "하중 주기에 맞춰 덜컥거리나" | 3단계 EXP-040 · 2-13 (022) |
| AE z (스펙트럼 AE, 정상만 학습) | "정상과 다른가" → 주로 오경보 줄이기 | 1단계 EXP-012 · 4단계 EXP-044 · 정상 PCA로 대체 불가 EXP-049 |
| E2 (OR) | 하중 대비 고주파가 학습 정상 99 % 초과 & 충격 ≥ 1 → 고장 | 2단계 EXP-025(유격 반복) → 3단계 EXP-042 |
| 8.3k 규칙 (OR) | 8.3 kHz 봉우리 또는 깨끗한 공진 충격 → 고장 (사후 문턱, 낙관적) | 2단계 EXP-021 · 2-9 · 2-10 → 3단계 EXP-043 |

## ③ 핵심 실험
[5단계 README](../5_모델실험/README.md)의 다섯 단계 폴더가 핵심 실험이다. 단계마다 README에 질문 → 한 일 → 결과 → 깨달음 → 근거 EDA · 피처.
1. 첫 베이스 모델 (EXP-014) → 2. 규칙 발견 (021 · 025) → 3. 2차 설계 (040–043) → 4. 최종 모델 J (044 + 검증) → 5. 울림 비율 축소 (050)
