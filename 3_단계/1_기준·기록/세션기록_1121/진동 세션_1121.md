# 진동 세션 인수인계 (11-21)

이 파일을 읽는 새 세션은 진동 기초 문답 학습을 이어서 진행하고, 배운 내용으로 품질공학 팀 프로젝트(텐션암 이상감지) 피처를 점검한다. 첫 인수인계는 [진동 세션.md](진동%20세션.md)(11-20 이전 기록 포함)이고, 이 파일이 최신이다.

## 1. 사용자와 방식
- 산업공학 전공, PHM 연구 예정. 물리·진동 배경 거의 없음
- 미분방정식·푸리에: 수업에서 들어 봄, 계산 경험 없음, FFT 주파수 축 그림만 봄
- 방식: 문답. 한 번에 질문 2–3개 → 맞는 점·빠진 점 피드백 → 다음. Stage 끝에 3문항 퀴즈
- **설명 규칙 (사용자 요청 11-21)**: 기호(ζ, fn, H 등)와 내부 코드 이름(P83, K1, RING 등)을 풀지 않고 쓰지 않는다. 사용자가 직접 만든 기록이 아니라서 모른다. 비유(종·기타·그네·망치) + 쉬운 말 + 우리 데이터 숫자
- **계산 문제 빼기 (사용자 요청 11-21)**: 답이 숫자인 질문(접힘 위치·맥놀이 횟수·간격 계산 등)은 내지 않는다. "왜 / 어느 쪽으로 바뀌나 / 보이나 안 보이나" 개념 질문만. 숫자는 내가 데이터로 계산해 보여 준다
- 배운 개념은 바로 뷰어에 그림으로 넣는다 (사용자가 원함)
- 불확실한 것은 데이터로 계산해서 답한다. 이번 세션에서 계산으로 내 설명을 두 번 정정함(아래 4절)

## 2. 진도
| Stage | 결과 | 헷갈렸던 것 (복습 포인트) |
|---|---|---|
| 1 진동 기본 | 통과 | "재는 것 = 사인파"(→ 변위·가속도를 재고 그 모양이 사인파). 꼭대기에서 가속도를 "작다"고 답함(→ 최대, 변곡점과 혼동). 평균 −1 g 원인을 노이즈로 봄(→ 중력·센서 방향). 평균 제거를 "잔차 제거"라고 부름 |
| 2 단자유도 | 통과 | 없음. 치는 세기가 주파수와 무관하다는 점은 직접 말하지 않음 |
| 3 공진 | 통과 | **세기와 단단함 혼동**("세게 치면 음이 달라진다"). 봉우리 이동 방향(내려감 = 물러짐) 빠뜨림. "첨도"(시간 그래프)와 "봉우리 뾰족함"(주파수 그래프)을 섞음 |
| 4 FFT·샘플링 | 통과 (11-21 확인 질문 20 kHz → 5 kHz 정답) | **앨리어싱 접힘 위치**: 15 kHz → 2.5 kHz라고 답함(→ 12.5 kHz 거울 접힘, 10 kHz). Welch 평균의 이득(안정성)을 몰랐음 |
| 5 변조·포락선 | 통과 (11-21 퀴즈: 리듬은 포락선에만 ✓, 입력/구조 진단 ✓, 변조 정의를 "두 파동 중첩"으로만 답함 → 맥놀이는 한 예일 뿐. 차단 주파수를 abn_017 보고 1.5 kHz로 올리자고 함 → 라벨 보고 고르기 + 1.3–2 kHz 울림 잘림, 1 kHz 유지·CV로 비교 설명. "울림 주파수"는 팀 용어 = 충격이 실제로 들뜬 고유진동수라고 설명) | 맥놀이 횟수(차이 = 부푸는 횟수) 못 맞힘. **"원신호의 느린 쪽에 치는 리듬이 쌓인다"고 생각함**(→ 느린 쪽은 출렁임, 리듬은 포락선에만). 느린 쪽 먼저 버리는 이유를 "노이즈"로 답함(→ 큰 출렁임). 불규칙하면 측대역 뭉개짐 · 규칙 여부는 포락선으로 구분 = 정답 |
| 6 텐션암 결함 | 통과 (11-21, 뷰어 탭 "6 텐션암 결함": 유격 덜컥 · 체결 이완 · 부싱 전달) | 체결 이완 3변화 중 "감쇠↑(울림 짧아짐)"을 빠뜨림 → 이음부 마찰(젓가락 비유)로 설명. "본체 음이 안 내려간 이유"는 못 답함 → 변화 작음/풀린 곳이 7 kHz 주인 아님/유격 단계 셋 제시. 망치 단단함 틀: B(8.3 kHz) = 단단한 금속 타격, 022 = 고무 사이 둔한 충돌(가설). 결함 표(정상·A 유격·A′ 022·B 8.3k·B′ 9.5–10k·C 체결·D 부싱·미분류)는 채팅으로만 정리 → 필요하면 4-5나 물리가설에 옮길 것 |
| 7 PHM 특징 | 통과 (11-21, 뷰어 탭: 피처 세 조건 · 중복 지도 · 무작위 피처 과적합 데모, `scripts/stage7_export.py` → feat7.json). **진동 공부 7단계 완료** | "하중 대비 충격 바탕"(출렁임 상관 0.69)이 나쁜 피처인지 몰랐음 → 맥락 피처는 길 상태를 재는 게 역할, 혼자 판정에 쓰지 않음. 사용자 제안: "판정 = 하중 뺀 고주파 피처, 저주파 = 맥락" → **모델 정리 때 논의하기로 함**. 라벨 없이 피처 고르는 법(물리로 먼저 정함 · 중첩 CV · 사후 표시) 설명 |

### 대기 중
1. Stage 4 확인 질문: "우리 센서로 20 kHz 진동은 어디에?" (답: 25 − 20 = 5 kHz)
2. HD-map 세션 전달: 인수인계 원본은 대상 이름을 `hdmap-study-4f`로 적었으나, 11-21 ListAgents에 그 이름은 없고 `claude-f4` 하나뿐. **사용자에게 맞는지 확인 후** SendMessage. 보낼 내용 초안: "Stage 1–4 통과. 샘플링·나이퀴스트·STFT·분해능 이해. 앨리어싱 접힘 위치 한 번 틀렸다 보충. Welch 이득은 설명 듣고 이해. 변조·포락선 미학습." Stage 5 뒤에 한 번에 보내도 됨
3. Stage 5 시작: 변조(AM, 측대역) → 포락선(힐베르트). 우리 데이터 연결 = 1 kHz 고역통과 → 포락선 → 충격 검출(`src/final.py` `impact_rings`), 대역 포락선 첨도, 022 주기 잠금. 사용자가 처음 막혔던 개념이 "변조"였음

## 4. 우리 데이터에서 계산으로 확인한 사실 (11-20 ~ 11-21)
- 가속도 파워 대역별 몫(파일 중앙값): 2–20 Hz 29% · 20–200 Hz 20% · 0.2–1 kHz 5% · 1–5 kHz 8% · 5–12.5 kHz 8%. 속도로 바꾸면 2–20 Hz 99% → **"가속도는 저주파를 못 본다"는 내 설명은 틀림(정정함)**
- 원래 평균 < −0.5 g: nor_097 · 101 · 120(−0.87), abn_016(−1.04). 나머지 −0.02~0.06
- 정상 중앙 PSD 봉우리: 0.73 · 1.31 · 1.88 · 3.78 · 4.87 · **6.89(가장 뚜렷)** · 10.9 kHz. 6.89 kHz = 충격 울림 분석의 "7 kHz 본체 음"과 일치
- 실제 충격 맞춤: nor_001 7.25 kHz · 감쇠 0.01(충격 19개) / abn_002 8.25 kHz · 0.01(충격 1개) / abn_022 2.0 kHz · 0.08(충격 5개)
- 첨도(1 kHz 고역통과) 중앙값 정상 31.5 · 고장 174, 충격 수 3 · 12, 충격 감쇠 중앙값 0.020 · 0.040. 첨도 ↔ 충격 수 순위상관 0.61, ↔ 감쇠 0.12 → **"감쇠가 크면 첨도↑"라는 내 예상은 틀림(정정함)**. abn_002 첨도는 정상 하위 11%
- 정상 범위(95%선) 초과: abn_002는 8.0–8.6 kHz만 +0.75 dec. abn_015는 0–50 Hz +3.19 · 50–200 +2.12 · 0.2–1 kHz +1.98 · 11.5–12.5 kHz +1.35 dec. 둘 다 봉우리 이동 없음
- 정상 PSD는 12.45 kHz까지 평평, 급한 감쇠 없음 (9 kHz 위는 바닥 수준이라 판단 불가)

## 6-1. 11-21 오후 문답에서 확인한 것
- 37 Hz 근처: 정상·고장 차이 없음(봉우리 돌출 AUC 0.49). 고장은 40–200 Hz가 0.3–0.6 dec 낮아 상대적으로 튀어 보였던 것. abn_022의 34 Hz는 사용자가 다른 파일에도 있음을 확인 → 공통 봉우리
- 충격 ≥ 10개: 정상 27 · 고장 21. 7 kHz 본체 음 몫 중앙 정상 92% · 고장 9%, 2–4 kHz 몫 0% · 17% → 충격 수가 아니라 울림 음으로 가름. nor_045(충격 30)는 1.3–1.45 kHz로 울림, 오경보 아님
- 저주파는 판정 재료가 아니라 맥락(하중 분모 K2, 주기 잠금 시계)으로 쓰임

## 6-2. 진동 공부 완료 후 남은 것 (11-21)
- 뷰어: Stage 1–7 모두 열림. Stage 5–7 탭은 사용자 화면 확인: 5 정상 확인, 6·7 미확인
- 모델 논의 항목: 판정용(하중 제거 후 고주파) vs 맥락용(저주파) 피처를 나누는 구조 (사용자 제안)
- EXP 후보: 4-5의 C1 · C2(크기 계열만) · C5(빨리 꺼지는 충격 비율) · C6(대역별 첨도 하나) 한 번에 비교
- HD-map 세션 전달은 여전히 대기 (대상 `claude-f4`/`claude-23` 중 미확인)
