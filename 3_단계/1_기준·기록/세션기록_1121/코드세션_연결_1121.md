# 코드 세션 ↔ 사령탑 연결 (11-21)

두 세션이 이 파일 하나로 주고받는다.
- **사령탑 세션** = 모델 구성 논의·판단·계획 확정 (코드는 직접 안 돌림)
- **코드 세션** = 사령탑이 낸 확인 요청을 코드·그림으로 확인하고 사용자에게 보여 줌

## 0. 코드 세션이 처음 할 일
1. 루트 `CLAUDE.md`, `3_단계/1_기준·기록/00_NOW.md`, 이 파일 1–3절을 읽는다
2. 사용자에게 "3절 확인 요청 중 무엇부터?"라고 묻고, 하나씩 진행한다
3. 결과는 그림으로 **사용자에게 먼저 보여 주고**, 사용자가 질문하면 같이 본다

## 1. 주고받는 방법
- **사령탑 → 코드**: 3절 "확인 요청"에 Q 번호로 적는다
- **코드 → 사령탑**: 사용자가 코드 세션에서 **"정보 넘겨"**라고 하면, 코드 세션은 4절 "회신"에 아래 형식으로 **덧붙인다**(지우지 않음)
  ```
  ### R-n (Q 번호) 제목 — MM-DD HH:MM
  - 결론 한 줄
  - 숫자 (표)
  - 그림 경로
  - 사용자가 보며 한 말·새 아이디어 (그대로 옮김)
  - 해석 주의 (라벨 사용 여부, 사후 여부, 확인 못 한 것)
  - 사령탑이 판단할 질문
  ```
  그 뒤 가능하면 `ListAgents`로 사령탑 세션을 찾아 `SendMessage`로 "회신 R-n 추가"라고 알린다(안 되면 파일만으로 충분, 사용자가 사령탑에 전달)
- **사령탑**은 회신을 읽고 판단·결정을 2절에 반영하고, 새 Q를 3절에 낸다

## 2. 지금까지 합의 (사령탑이 갱신)
**뼈대 (11-21 합의)**
- 고주파 블록 H(지도학습, ET) + 저주파 블록 L(정상만으로 기준을 잡는 이상 점수) → 결합. 규칙은 피처로 겨룬 뒤 남는 오류에만, 문턱은 라벨이 아니라 "정상 분포 고정 분위수(예: 99%)"
- 비교 목록(실행 전 고정): 1단계 A 기준(EXP-034 c 재측정) / B ET 하나에 H+L 작은 세트, 규칙 없음 / C H + L 결합 → 2단계(C 위) 결합 방식 로지스틱 · max(ㄱ자) · RBF SVM(C=1, gamma=scale 고정) → 3단계 D 정상 기준 전문가. sd 안이면 단순한 쪽
- **AE는 새 구조에서 제외 (사용자 결정 11-21)**: 스펙트럼 모양은 ET의 옥타브별 스펙트럼 몫으로. 기준 A보다 sd 넘게 나쁘면 재검토. (Q4는 우선순위 낮춤) AE × ET(D+) 상관 0.81(정상만 0.67, 고장만 0.49)
- 모델 구상(사용자 확인 11-21): 질문 두 개 — "아는 고장과 닮았나"(ET, 지도) + "정상에서 벗어났나"(정상 기준 점수, **저주파 위주**). 울림은 별도 전문가 없이 ET 피처로(충격 0개는 −1 표시값, ET가 판단). B(ET 하나) vs C(ET + 정상 기준 점수)는 중첩 CV로
- **고주파 대역 경계 (사령탑 판단·사용자 위임 11-21, 결정.md)**: 옥타브 4칸 1–2 · 2–4 · 4–8 · 8–12.5 kHz + "정상보다 가장 솟은 좁은 봉우리 높이·폭" 1쌍. 예전 사후 경계는 안 씀
- **충격 확인 7a+·7g 완료 (11-21, `3_단계/4_피처/4-6_1121_충격재정의/사령탑_7a+_7g/`)**: ① 포락선 500 Hz 다듬기는 꺼짐 1 ms 울림을 약 60%로 깎음(022 2 kHz 0.59 ≈ 정상 7 kHz 0.62 → 022만 불리하지 않음). 꺼짐 0.5 ms 미만(ζ 0.16–0.3)은 약 30%로 깎여 놓침. 6배 문턱은 너무 엄격(처음 8배 울림도 500 Hz 다듬기 후 0–10%만 검출), 4배면 τ ≥ 1 ms 모두 검출·백색잡음 가짜 0(실제 바탕은 미확인). ② 022에서 A로만 잡힌 5개 = 문턱 미달 4 + 둔한 충돌 1. 전체로도 A만 사건의 80%+가 문턱 미달 → **놓침의 주원인은 6배 문턱**. ③ 둔한 충돌(200–1000 Hz 몫 ≥ 0.5)은 정상 16.7% · val 17.5% 파일에 있음(고장 26.7%, 보고만) → 고장 특유 신호 아님 → **200–1000 Hz 둔한 충돌 피처는 만들지 않음(사령탑 판단)**
- **충격 정의 확정 (11-21, 결정.md, `4-6_1121_충격재정의/사령탑_7b-7e/`의 `detect_impacts`)**: 1 kHz 고역 → 포락선 → 1000 Hz 다듬기 → 100 ms 이동 중앙값 바탕 → 4.5배 이상 봉우리, 간격 ≥ 6.75 ms. 파일당 충격 평균 정상 7.2 · val 6.2 · 고장 13.5. 015 = 36개. 새 시점 S: 022 0.963 유지, 정상 최대 0.449(nor_092), 014 0.546(정상 최대 위로 올라옴), 001·014·022가 정상 최대 초과. 모양 거르기 안 함(사용자 결정). 015 점검 후: 앞뒤 10 ms 제외 추가, 누설·작은 봉우리 거르기 안 함, 35–44 Hz 위상 잠금 R 제외 → 박자 블록 = S 하나 (사용자 결정 11-21). 계획 초안 `3_단계/5_모델비교/검토문서/모델구성_계획_1121.md`. 결합 동률 순서 max → 로지스틱 → SVM, L 문턱 정상 99% (사용자 결정 11-21)
- 예전 수치는 "가설·출발점"으로만. 새 파이프라인에서 다시 잰다

**전처리**
- 고주파 차단 주파수: 3-2(`3_단계/3_전처리/3-2_1121_고역차단주파수/`) 결과 — 길 끌림 ρ(정상 RMS)는 fc를 올려도 0.40 → 0.26으로 완만히 줄 뿐 평탄점 없음(사전 규칙 퇴화). quick_cv 8피처: 1000 Hz 0.888 ± 0.016, 1500 Hz 0.875 ± 0.019(sd 안), 500 Hz 0.789(sd 밖 하락). 1500은 정상 1.3 kHz 모드 24%·017 1.6 kHz 63%만 통과. **1 kHz 유지 (사용자 결정 11-21, 결정.md)**. 결론: 필터만으로 길 끌림은 안 없어짐 → 고주파 크기 피처도 비율·모양으로
- Welch 창: 대상별로 물리 기준 고정 — 저주파 8192점(3 Hz, 조각 11), AE 2048점(12 Hz, 조각 47), 충격 8 ms(125 Hz), 포락선 1 s(1 Hz). 겹침 50%·Hann, 저주파는 detrend 끔
- 저주파 피처는 크기 말고 시간 구조·비율·모양으로(크기는 길 상태를 잼, AUC 0.43–0.58)

**val**
- 경진대회 방식(사용자 11-21): 목표는 test. 라벨 없는 val·test로 문턱·하이퍼파라미터 맞추기 허용. 피할 것은 대량 오판(참사). 결정.md 문구는 계획 확정 때 수정
- 참사 후보 = AE 점수 이동: EXP-025 최종 모델 val AE z 평균 1.77(ET 1.05), 고장 판정 10/40, 문턱 ±0.5 안에 16개 밀집 (`3_단계/4_피처/4-4_…/17_AE_ET_D/README.md`)
- val 제출 모델: 미정

**알게 된 것**
- 022는 정보가 없어서가 아니라 주기 잠금 S(0.963 vs 정상 최대 0.389)를 사후 규칙이라 뺀 것. 014도 같은 기전(약함). 일반 포락선 스펙트럼으로는 1 Hz 박자(2초에 2번)를 못 잡음
- 충격 감쇠비 ζ 사전은 0.01·0.02·0.04·0.08 네 칸 → 0.08 = "0.08 이상 또는 깨끗한 울림 아님". 022 충격: 2 kHz 3개 ζ 0.08, 5.5 kHz 2개 ζ 0.02. 002: 8.25 kHz ζ 0.01
- 2 kHz 음 자체는 정상에도 있음(정상 중앙 PSD 1.88 kHz 봉우리). 가르는 것은 "충격이 어느 음으로 울렸나"(7 kHz 몫 정상 92% vs 고장 9%)
- 뷰어(`3_단계/2_EDA/EDA뷰어/`) 3탭 + val 40개(기준은 train만, 채점 안 함) + 5개 보기 + 산점도(추천 쌍·ρ·AUC) 완료 (11-21)
- val 사실(라벨 없음): 평균 < −0.5 g 파일 0개(C1 위험 낮음). 주기 잠금 S가 train 정상 최대 0.389를 넘는 val 0개(최대 val_031 0.174) → val에는 022형이 안 보임
- 축 상관(train, 정상만 ρ) · AUC: 고주파 첨도(입력) × 7 kHz 울림 몫(구조) ρ −0.07, AUC 0.76 / 0.83(낮을수록 고장) → 입력·구조 축은 독립. 2–4 kHz 몫 0.78, 충격 수 0.77, 빨리 꺼지는 비율 0.72, S 0.69, 하중 대비 고주파 0.60. 200 Hz 고역 RMS는 0–20 Hz 에너지와 ρ 0.47 → 고역 크기도 길에 끌림. 울림 몫은 충격 있는 파일만(n=128, 22개 null)
- **L 블록 = 박자 블록 (사용자 결정 11-21, R-2 반영)**: 주기 잠금 S·r·hit(새 충격 시점) + 확인되면 35–44 Hz 위상 잠금 R. HFL은 ET 맥락 피처로, SHP 뺌. 크기는 뺌(028 포기). H 블록도 크기보다 비율·모양 우선(R-1: 옥타브별 스펙트럼 몫 추가 후보, R-3: ET도 크기에 끌림)

- **실행 중 (11-21, 사령탑 에이전트)**: `src/impacts.py`·`src/features2.py` 구현, 4-7 라벨 없는 피처 점검, **EXP-040**(A · B · C 중첩 CV + val), 뷰어 새 충격 정의 반영. H11 제외(결정.md) → H 블록 17개. **코드 세션은 src/·EXP-040·뷰어를 건드리지 말 것**
