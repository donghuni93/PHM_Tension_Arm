# 6-9 val 분포 이동 점검 (11-22, 라벨 없는 진단) (옛 6-10)

**결론: val은 train과 확실히 다른 분포다. 분류기가 train 정상과 val을 AUC 0.95로 가른다(train 정상 대 고장 0.97–0.98과 거의 같다). 이동의 대부분은 AE(스펙트럼 배경)이고, 모델 H 피처만 쓰면 0.79–0.85로 줄어든다.** J-축소가 "확실 정상"으로 본 val 23개만 써도 AE로 0.93이 나온다 → 고장이 섞여서가 아니라 측정 조건 차이 쪽(2-8의 3–5 kHz +10.9 dB와 같은 결론).

| 비교 | H + AE | H만 | AE만 |
|---|---|---|---|
| train 정상 vs val | 0.95 (ET) · 0.95 (LR) | 0.85 · 0.79 | 0.94 · 0.93 |
| train 전체 vs val | 0.91 · 0.87 | 0.82 · 0.74 | 0.86 · 0.79 |
| train 정상 vs val 확실 정상 23 | 0.94 · 0.91 | 0.80 · 0.63 | (AE 열 중앙 백분위 83–95) |
| 참고: train 정상 vs train 고장 | 0.98 · 0.97 | | |

- 방법: 기본 t-SNE 공간(모델 H 열 + AE 5열, `map_scale`) 그대로, ExtraTrees(300, 잎 3) · 로지스틱(C 0.3)으로 "train이냐 val이냐"를 5겹 교차검증, seed 5개 평균. 0.5면 같은 분포
- 열별: val 중앙이 학습 정상 몇 % 자리인지 → AE 5열 90–97 %, H16 · H17(봉우리) 76–81 %, H8 2–4k 울림 비율은 15 %(오히려 낮음)
