# 6단계 오류 분석

상태: **11-25 정리.** 최종 모델 계열(J · J-축소)의 오류 · val 경계 진단. 번호에서 날짜를 빼고 6-1부터 다시 매겼다(옛 번호는 괄호). 조각 폴더 = `README.md` + `자료/`. 발표에 쓰는 것 = [6-4 val 확실도](6-4_val확실도/README.md)(슬라이드 11) · [6-1 J 판정 t-SNE](6-1_J판정_tSNE/README.md). `아카이브/` = 예전 구성(6-1 옛, EXP-030 시절) · `_임시_1122`

## 목적

- [6-12 (11-23) V025 판정 근거](../아카이브/J축소이후/6_오류분석/6-12_1123_V025판정근거/README.md): train에서 닮은 파일(물리 특징 7개) 가까운 5개 모두 정상, "공유 모드 + 작음 + 충격 3–8개" 11개 중 고장 1. 규칙적 쌍 충격은 train에 비교 파일 2개(A023 · N074)뿐 → 정상 쪽 우세, 확정 불가
- [6-11 (11-23) V025 재진단 (EXP-056 추가)](../아카이브/J축소이후/6_오류분석/6-11_1123_V025_056/README.md): 여유 −0.02. 6-6의 H8(2 kHz를 2–4k로 셈)에 더해 RM_n_joint(1.6–4.5k 충격 수)가 1.9k 공유 모드 울림 6개를 세서 +0.82. 2.2k부터 세면 −1.31이지만 train 분리도 0.77 → 0.62
