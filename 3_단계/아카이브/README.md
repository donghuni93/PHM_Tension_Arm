# 아카이브 (단계를 가로지르는 묶음)

최종 모델 줄기에 들어가지 않은 작업 묶음. 지우지 않고 원래 내부 구조 그대로 둔다(폴더 안은 예전 형식, `자료/` 없음).

| 폴더 | 무엇 | 언제 |
|---|---|---|
| [J축소이후/](J축소이후/README.md) | J-축소 이후 탐색: 울림 모드 경계 · 대역 경계 지도 · 팀원 피처 비교 · ET 진단 · EXP-056 – 061 (옛 `3_단계/아카이브_J축소이후/`) | 11-23 – 24 |
| [new_단계/](new_단계/README.md) | "처음부터 다시" 재시작 폴더(옛 프로젝트 맨 위 `new_단계/`). 최종 모델에 쓰인 두 조각(전체 PSD → 11 kHz 상한, 검출기 1–11 kHz)은 [3_전처리 3-3 · 3-4](../3_전처리/README.md)로 옮겼다 | 11-24 – 25 |

각 단계 폴더 안의 `아카이브/`(2_EDA · 4_피처 · 5_모델실험 · 6_오류분석)는 그 단계에서 내린 조각이다.
