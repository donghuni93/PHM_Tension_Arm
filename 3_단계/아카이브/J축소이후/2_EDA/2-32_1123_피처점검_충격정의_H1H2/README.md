## 추가: H1 설계 변형 비교 (추가_H1_설계.py · 결과_H1_설계.md, 11-23)
기준 ET(고정 H 13열 + 박자)에서 H1 열만 교체해 quick_cv PR-AUC(5겹 × seed 5)로 비교. 기준 0.968 ± 0.012, H1 제거 0.958 ± 0.011.
- 문턱 K 격자: K=4~4.5가 최고(0.967~0.968), K=3 0.962 · K=6~8 0.959~0.960 · K=2 0.953. 현재 4.5가 이미 평평한 구간의 중심
- 시그마(MAD) 문턱: 최고 σ=6 0.963, val 이동도 0.15 → 국소 바탕 비율 정의보다 못함
- 잔향 꼬리 제거 · 병합: 0.965~0.976(최고 K=4.5 · 100 ms 병합 0.976 ± 0.014). 기준 대비 +0.008 이내로 sd 안
- 크기 반영(로그 높이 합 · 최댓값): 0.956~0.967, 개선 없음

## 추가: H2 재설계 후보 (추가_H2_설계.py · 결과_H2_설계.md, 11-23)
독립 충격(30 ms 안 뒤 봉우리 병합) 기준. 기준 ET에서 H2 열만 교체한 quick_cv PR-AUC: 기준 0.968 ± 0.012, H2 제거 0.961.
C1 큰 충격 개수 0.962 · C2 2위÷1위 0.969 · **C3 상위3 크기 균일도(3위÷1위) 0.981 ± 0.004** · C4 포락선 자기상관 최대 0.971(단독 분리도 0.53, n≥2 파일만 0.41) · C5 0.973. 5개 중 고른 값이고 같은 150개라 낙관적.
