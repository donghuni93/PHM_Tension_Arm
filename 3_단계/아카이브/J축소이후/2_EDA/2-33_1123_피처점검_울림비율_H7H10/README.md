# 2-33 피처 점검 ② 울림 비율 H7~H10 (11-23)

점검만 하고 피처는 고치지 않는다. 판정은 후보이며 사용자가 정한다. 수치 전체 = [결과.md](결과.md), 코드 = run.py · 추가_울림주파수_이동.py

- 정의: 충격 뒤 8 ms를 감쇠 사인파 사전(1–12 kHz 250 Hz 격자 × ζ 4개)에 맞춰 충격마다 울림 주파수를 정하고, 파일마다 옥타브(1–2 · 2–4 · 4–8 · 8–12.5 kHz) 비율. 충격 0개 = −1. 모델 H7~H10과 최대 차이 1e-16
- 충격 단위: 정상은 7.0–7.5 kHz에 모이고 고장은 1–3 kHz와 8–11 kHz로 퍼진다(신효섭 그림 3 재현). 맞춤도 fit 중앙 0.60~0.64, fit < 0.5인 충격이 15~28%
- val 이동: H9(4–8k) 원값 이동도 0.30, 충격 ≥ 1개만 0.44. 충격 수 층별로 보면 n ≥ 2 모든 층에서 val H9가 낮다(0.25~0.63 대 정상 0.92~1.0)
- 2 kHz 군집이 옥타브 경계(2000 Hz)에 걸친다: val 충격의 25.5%가 정확히 2000 Hz(정상 2.9%, 고장 11.9%), 1750 Hz는 H7, 2000 Hz는 H8로 갈린다
