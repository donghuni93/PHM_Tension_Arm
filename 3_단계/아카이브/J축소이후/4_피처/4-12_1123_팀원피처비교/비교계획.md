# J-축소 대 팀원 모델(소린 32 피처 계열) 비교 계획 (11-23, 결과 보기 전에 고정)

## 끝에 답할 질문
1. **왜 갈렸나**: val 판정 차이(팀원만 고장 7 · J만 고장 3, 효섭 기준)가 피처 · 모델 구조 · 규칙 중 무엇에서 오나
2. **J가 잘못 잡은 점**: J가 놓치거나 과하게 잡는 고장 유형은 무엇인가
3. **팀원이 잘못 잡은 점**: 팀원 모델이 놓치거나 과하게 잡는 유형은 무엇인가
4. **최종 모델**: J-축소 유지 / 팀원 모델 / 둘의 결합 중 무엇을 제출하나 (판단은 사용자)

라벨이 없으므로 한 가지 증거로 정하지 않는다. **세 갈래 증거(학습 오류 · 이동 민감도 · 파일별 물리 근거)가 같은 방향을 가리킬 때만** "잘못 잡았다"고 쓴다. 엇갈리면 "판단 불가"로 남긴다.

## 비교 대상 (구성)
| 이름 | 내용 | 역할 |
|---|---|---|
| A | 팀원 모델 그대로 (효섭 RF 배깅 + 8.3k 스펙트럼) | 팀원 대표 |
| A′ | 소린 M1 (RF + ET, 0.41) | 팀원 변형 (A와 임계값 차이만 보는 용도) |
| B | J-축소 | 우리 |
| C | J 구조 + ET 입력을 소린 10개로 교체 | 피처 효과 분리 |
| D | J 구조 + H 15열 + 소린 10개 | 정보 추가 효과 |
| E | A의 확률을 J 로지스틱에 한 축으로 넣거나 J OR A | 결합 후보 |

## 단계
### 0. 재현 (통과해야 다음)
- 소린 피처 150개 선택 = F10 (`run_소린.py`)
- 효섭 `최종모델.py`로 val 판정 14개 · 확률이 같게 나오는가
- 통과 기준: 피처 목록 일치, val 판정 40/40 일치(확률 차이 ≤ 0.01)

### 1. 같은 조건 학습 비교 — 질문 2 · 3의 주 근거 (라벨 있음)
- 우리 중첩 CV, 같은 분할, 이상치 3개 학습 제외 · 평가 포함. 기록은 full
- A · B · C · D · E의 F2 · 재현율 · 오경보
- **파일별 오류 표**: 둘 다 틀림 / J만 틀림 / 팀원만 틀림. 틀린 파일을 2-1 고장 유형(L1–L4) · 오경보 유형(끝 충격 · 단발 충격 · 조용함 · 상태 전환)으로 나눔 → "J가 못 보는 유형", "팀원이 못 보는 유형"
- 차이 판단 잣대: full sd 0.010

### 2. 부품 교체 — 질문 1의 주 근거
- C · D의 val 판정을 A · B와 비교(40개 중 일치 수)
- 읽는 법: C가 A 쪽이면 원인 = 피처, B 쪽이면 원인 = 구조(AE · 로지스틱 · E2 · 8.3k 정의)
- 갈린 10개 각각에 대해 "어느 부품을 바꾸면 판정이 넘어가나"를 표로

### 3. val 이동 민감도 — 질문 2 · 3의 val 쪽 근거 (라벨 없음)
- (a) 피처별 이동: H 15열 · 소린 32개의 val 중앙값이 학습 정상 몇 백분위인지
- (b) 인공 이동: 학습 파일에 val의 3–5 kHz 배경 차이(2-8에서 잰 값, 바꾸지 않음)를 대역 잡음으로 얹고 fold 안 모델로 판정 → 정상 오경보 증가 · 고장 놓침 증가를 A · B · C 각각 셈
- (c) 이동 맞춘 재학습(진단용, 제출 아님): 학습 150개 전부에 같은 이동을 얹어 재학습 → val 판정. 이동을 맞춰도 고장으로 남는 val은 이동 탓이 아님
- 판단: (b)에서 오경보가 크게 느는 모델의 "혼자만 고장" 판정은 이동 탓 의심. (c)에서 넘어가는 파일을 표시

### 4. 갈린 파일 해부 (10개, 소린 기준이면 13개)
파일마다 한 줄:
| val | 누가 고장 | 판정을 만든 피처 (기여 상위) | 그 피처가 이동에 흔들리나 (3) | 이동 맞춘 재학습 후 (3c) | 학습 이웃 5개 라벨 (H · 소린 공간 각각) | 물리 근거 (충격 반복 · 울림 주파수 · 지속음) | 결론 |
- 결론 = "고장 쪽 근거 우세 / 정상 쪽 우세 / 판단 불가" (세 갈래가 같은 방향일 때만 우세)

### 5. 결정 표
- 판정 시나리오별 val F2: 갈린 파일의 진짜 라벨을 (i) 팀원이 맞음 (ii) J가 맞음 (iii) 4단계 결론대로 (iv) 판단 불가 파일 반반으로 두고 B · A · E(J OR A 등)의 F2를 계산
- F2는 놓침을 4배 무겁게 치므로, 애매한 파일을 고장으로 두는 손해와 정상으로 두는 손해를 숫자로 비교
- 최종 선택 기준(미리 고정): ① 학습 중첩 F2가 최선에서 sd 안 ② 이동 시험 오경보 증가가 작은 쪽 ③ 시나리오 F2의 최악값이 높은 쪽(안전). 셋이 엇갈리면 사용자 판단

## 지키는 것

- 결과를 본 뒤 기준 · 이동 크기 · 구성을 바꾸지 않는다. 바꾸면 이유를 적고 새 번호로
