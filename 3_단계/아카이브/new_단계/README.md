# new_단계 — 처음부터 다시 (11-24 시작)

기존 `3_단계/`는 그대로 두고, 정식 순서(문제·평가 → EDA → 전처리 → 피처 → 모델 비교 → 오류 분석 → 최종·val)를 이 폴더에서 다시 밟는다.

## 왜 다시 하나 (사용자 11-24)
- 지금까지 만든 모델의 **정합성을 설명**해야 하고, 그러려면 **더 일반화된 피처**가 필요하다.
- 과정마다 라벨을 본 판단 · 과적합 근거가 없는지 확인하면서, 물리적으로 절대적인 피처를 쓴다.
- val 라벨이 없으니 평가는 둘로 나눈다. **성능** = 학습 150개 중첩 CV(라벨을 본 선택은 모두 폴드 안에서). **위험** = 학습 + val 190개를 라벨 없이 넣어 본 이동 진단([판단차이 A13](../../1_기준·기록/판단차이.md)).

## 이어서 할 곳
- 멈춘 지점: [`3_단계/4_피처/4-16_1124_라벨없는지도·val이동`](../3_단계/4_피처/4-16_1124_라벨없는지도·val이동/README.md). 라벨 없는 지도와 val 이동 진단까지 끝났고, 다음은 아래와 같다.
  1. 학습 라벨로 "고장만 우는 대역"을 고르되, 폴드마다 다시 골라도 같은 대역이 나오는지 확인
  2. 18열 · 규칙을 라벨 사용 등급(D/L/P)과 val 이동 여부로 다시 분류(H7 · H13 빼기 후보, H2 vs C4/C5)
  3. 1.6–5.5 kHz 에너지 열을 "충격 대 같은 대역 배경 비"로 바꾸는 EDA
- 라벨이나 val을 본 지점 목록(8.3k 규칙, K83 게이트, 이상치 정상 3개, RM 대역 선택, 65개 구성 비교, A11 val 흔들림, AE val 이동)은 11-24 세션 대화에 정리했다. 이 폴더의 첫 단계 문서로 옮긴다.
