# NEXP-01 이벤트 5피처 기준 ExtraTrees (11-25)

new_단계 첫 실험이다. 번호는 이전 프로젝트의 `EXP-nnn`과 겹치지 않게 `NEXP`로 시작한다(실험 폴더 규칙은 아직 미정이라 임시).

| 항목 | 값 |
|---|---|
| 모델 | ExtraTrees 300, max_depth 3–4, min_samples_leaf 3–5, class_weight=balanced |
| 입력 | 이벤트 5피처 (cnt_low · cnt_high · cnt_total · ratio_off · off_max_amp), 4.5 kHz 기본안 |
| 평가 | 중첩 CV: 바깥 5-fold StratifiedGroupKFold × 5회, 안쪽 4-fold로 문턱 선택(0.05 격자), 그룹 = 097·101·120 묶음 |
| 결과 | ET 단독 F2 **0.78–0.84** (최고 0.841 ± 0.013), OR 8.3k [사후 값]은 같은 값 |
| 변경점 | 새 실험(기준선). 입력 정의는 [2-6](../../2_EDA/2-6_바닥보정·이동·기준ET/README.md) |
| 메모 | 라벨을 본 설계의 낙관적 값. 059 · 065 · 116 학습 포함 |

코드 [run.py](run.py)(2-6과 같은 코드, 캐시 `figs/events_190.csv` 사용) · 수치 [figs/계산_수치.txt](figs/계산_수치.txt)

## 해석
- 5개 피처만으로는 F2 약 0.84에서 멈춘다. 이전 프로젝트의 0.978은 AE · 스펙트럼 정보를 포함한 낙관적 값이라 직접 비교할 수 없지만, 격차는 크다.
- OR 8.3k를 붙여도 점수가 같다. ET가 규칙이 잡는 고장 6개를 이미 잡는다(규칙 단독 F2 0.238).
- 바닥 보정은 같은 설정끼리 0.01–0.03 낮다(sd 안). 넣을 근거가 없다.
- 설정 4개 사이의 차이는 대부분 sd 안이다. 설정을 고르지 않았다.

## 아직 안 한 것
- 폴드 안 4.5 vs 5.5 kHz 선택, 피처 추가, AE 같은 정상 기준 점수 결합.
- 이 값을 `3_단계/1_기준·기록/실험로그.md`에 올리는 일(new_단계는 아직 기록 이관 전).
