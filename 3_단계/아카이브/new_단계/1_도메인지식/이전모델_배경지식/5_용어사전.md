# 5. 낯선 용어 · 기록 해설 (배경지식)

이전 프로젝트 기록과 이번 대화에서 나온 용어를 쉬운 말로 풀었다.

## 신호 · 검출
| 용어 | 뜻 |
|---|---|
| **충격 검출기** (`src/impacts.py`) | 작업 폴더에 원래 있던 분석 코드. 파형에 껍데기(힐베르트 포락선)를 씌우고, 평소 배경 진동(100 ms 이동 중앙값)보다 4.5배 이상 갑자기 튀는 순간을 찾는다. 그 직후 8 ms 동안 몇 kHz로 울리는지 계산한다. |
| **힐베르트 포락선** | 진동 파형의 위쪽 윤곽선(진폭이 커지고 작아지는 모양). 빠른 떨림은 지우고 "얼마나 센가"만 남긴다. |
| **이벤트** | 충격 하나. 25 ms 안에 연달아 잡힌 검출은 한 이벤트로 묶어 센다. |
| **울림 (ring-down)** | 충격 직후 구조물이 일정한 주파수로 윙 하고 우는 것. |
| **감쇠비 ζ · 맞춤도 fit** | ζ = 울림이 얼마나 빨리 잦아드나. fit = 울림이 이상적인 감쇠 사인파와 얼마나 닮았나(1이면 완전히 같음). **측정이 들쭉날쭉해서(두 방법 순위 상관 0.475) 피처에서 뺐다.** |
| **모드 봉우리 · 골짜기** | 전체 데이터의 울림 주파수를 모았을 때 자주 몰리는 지점(봉우리)과 비어 있는 경계(골짜기). 대역을 감으로 자르지 않고 이 빈틈을 기준으로 나누는 근거다. |
| **연결부 · 본체 · 고주파 모드** | 1.6–4.5 kHz(고장 쪽) · 5.5–8 kHz(정상 쪽) · 8–12.5 kHz(고장 쪽 + 이상치 정상)로 이름 붙인 울림 대역. 구조의 어느 부분이 우는지에 대한 해석이다. |
| **소린 비율** | 충격 직후 12 ms 스펙트럼에서 √(연결부 에너지 ÷ 본체 에너지)를 큰 충격 20개에 대해 중앙값으로 낸 값. 같은 충격이 연결부를 더 울렸는지 본체를 더 울렸는지 본다. (제안자 소린님의 이름) |
| **옥타브 몫 · 울림 비율(H7–H10)** | 충격이 1–2 · 2–4 · 4–8 · 8–12.5 kHz 중 어디로 울렸는지의 비율 · 에너지 몫. 비율은 충격 하나를 주파수 하나로 판정해 세고, 소린 비율은 에너지로 나눠 연속적이다. |
| **K1 · D_K1 · H2_ratio21** | 두 번째로 큰 충격의 높이 ÷ 바탕(또는 1위 충격). 유격 타격은 고른 크기로 반복한다(H1′)는 가설을 잰다. |
| **박자 · 주기 잠금 S** | 저주파 흔들림의 주기에 맞춰 충격이 반복되는 정도. 022에서만 잡혀 규칙으로는 채택하지 않았다. |
| **DC 평균(오프셋)** | 신호 전체의 평균값. 센서 방향 · 중력 성분이라 고장 정보가 아니다. 평균 제거가 기본이다. |
| **PSD · Welch** | 주파수별 에너지 분포. Welch는 신호를 겹치는 창으로 나눠 평균 내는 방법. |

## 8.3 kHz 규칙
| 용어 | 뜻 |
|---|---|
| **8.3 kHz 규칙** | 이전 기록(결정.md)에 남은 수제(하드코딩) 조건식. 8.3 kHz 부근의 에너지 · 폭 · 뾰족함을 따져 고장 6개를 오경보 0으로 집어낸다. 기준 숫자를 사후에 맞춘 흔적이 있어 **메인 모델에 섞지 않고 보조 보험으로 쓸지만 나중에 테스트**할 예정이다. |
| **P83** | 8.20–8.45 kHz 봉우리의 돌출(dec = 주변 대비 10배 단위). 문턱 ≥ 0.75. |
| **W83** | 그 봉우리의 반높이 폭(Hz). 문턱 ≥ 150. 고정된 좁은 음은 폭에서 걸러진다. |
| **K83** | 8.20–8.45 kHz 대역 포락선의 첨도. 순수 지속음 1 · 가우스 잡음 2 · 충격 울림 ≫ 2. 문턱 > 3으로 미끄러지는 지속음(val_001)을 뺀다. |
| **공진 규칙** | 8.0–8.7 kHz로 울린 충격 중 ζ ≤ 0.02이고 fit ≥ 0.7인 것이 하나라도 있으면 고장. 스펙트럼 규칙과 OR. |

## 모델 · 평가
| 용어 | 뜻 |
|---|---|
| **ET (ExtraTrees)** | 무작위로 자른 결정 트리 앙상블. 이전 모델의 중심. |
| **AE (오토인코더) · AE z** | 정상만으로 학습해 스펙트럼 모양을 복원하게 한 신경망. 복원 오차가 크면 "정상과 다르다"고 본다. AE z = 정상 기준 표준화 값. |
| **J · J-축소** | 이전 모델의 이름. J = ET 피처 + 박자 + AE를 로지스틱으로 결합. J-축소 = 울림 비율을 충격 수로 축소한 판. |
| **로지스틱 결합** | 서로 다른 전문가(ET · AE · 박자)의 점수를 하나로 합치는 선형 모델. |
| **quick_cv / 중첩 CV** | quick_cv = 임계값 없는 5-fold PR-AUC(탐색용). 중첩 CV = 안쪽에서 문턱을 고르고 바깥에서 평가하는 F2(최종 확인용). |
| **PR-AUC · ROC-AUC · AUC** | 순위로 정상과 고장을 얼마나 가르는지. AUC 0.5 = 무작위, 1 = 완전 분리. 분리도 = |AUC − 0.5| × 2. |
| **F2** | 재현율을 정밀도보다 중시한 점수. 미탐 1건 = 오경보 4건. |
| **사후 값 (post-hoc)** | 정답 라벨을 눈으로 보고 정한 대역 · 문턱. 그 데이터에서는 잘 맞아 보이지만 새 데이터에서는 틀릴 수 있다. 검증 점수가 부풀지 않도록 **교차검증 안에서(폴드 안 재선택) 다시 확인해야** 한다. |
| **폴드 안 재선택** | 학습용 일부만 보고 선택하고 나머지로 시험하는 것. 라벨을 본 선택의 점수가 부풀지 않게 한다. |
| **공변량 이동(shift)** | val처럼 새 데이터에서 피처 값 분포 자체가 학습과 다른 현상. 라벨 없이 볼 수 있다. |
| **이상치 정상 059 · 065 · 116** | 데이터로 정상 · 고장을 가를 수 없다고 본 정상 3개. 학습에서만 빼고 평가에는 포함했다(사후 선택). |
| **D · L · P · X** | 근거 등급. 도메인 / 라벨 확인 / 사후 맞춤 / 이상한 실험. 4번 파일 참고. |

## 파일 이름 접두사
- `EXP-nnn`: 이전 프로젝트 실험 번호. `PHO-nnn`: 휴대폰(클라우드) 세션 실험. `2-n`: 2단계 EDA 조각, `4-n`: 4단계 피처 조각.
- `nor_nnn` · `abn_nnn` · `val_nnn`: 정상 · 고장 · val 파일. 기록에서는 N059 · A022 · V025처럼 줄여 쓴다.
