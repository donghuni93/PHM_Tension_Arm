# 3. 모델 · 평가에서 알게 된 것 (배경지식)

출처: 결정.md · 판단기준.md · 1단계 평가 논의 · 5단계 실험 README. 숫자는 이전 프로젝트의 값이며 사후 선택이 섞여 낙관적이다.

## 1. 평가의 교훈
- **F2는 미탐 1건 = 오경보 4건**이다(F2 = 5TP / (5TP + 4FN + FP)). 고장을 놓치지 않는 것이 중심이다.
- **같은 폴드로 임계값을 고르면 F2가 +0.03–0.045 부풀고 순위까지 뒤집힌다**(ET 0.856 → 0.827, SVM 0.863 → 0.818). 그래서 탐색은 임계값 없는 PR-AUC(quick_cv), 최종 후보만 중첩 CV(바깥 5 × 안쪽 4)로 F2를 봤다.
- quick 모드의 sd(seed 2개)는 믿지 않는다. EXP-056 추가는 quick 0.944가 full 0.978이었다.
- **val 40개는 표본 하나**다(같은 20 %여도 sd 약 0.09, 5–95 % 0.64–0.95). val만 보고 고치지 않는다. (val 고장 비율은 비공개라 20 %라는 가정이다.)
- **사후 문턱이 낙관 편향을 만든다**: 8.3 kHz 규칙 · 유격 규칙을 더하면 quick_cv +0.021 부풀었고, 규칙의 문턱은 ±20 % 여유(C3)에 못 미쳤다.
- **CV 오류를 본 뒤 정한 선택은 사후다**: 이상치 정상 3개(059 · 065 · 116) 학습 제외는 사후 선택이고, 비슷한 시도(EXP-028 · 038: 못 가르는 정상을 학습에서 빼기)는 기준 아래로 기각된 적이 있다.
- **다른 데이터의 방법은 안 맞는다**: 25년 3조 방식(0.93)은 다른 데이터 + CV 누수였고 우리 데이터에서 0.538(EXP-003).
- 그룹: 수리 전 · 후 짝 구조는 근거가 없어 파일 1개 = 그룹 1개로 봤다(1-1). new_단계는 097 · 101 · 120이 같은 세션일 가능성을 새로 얻었다(2-1).

## 2. 닫힌 질문 (이전 프로젝트에서 시도하지 않기로 한 것)
| 질문 | 이전 결론 | 근거 |
|---|---|---|
| 분류기를 바꾸면 오르나 | 안 오른다. 병목은 모델이 아니라 입력 정보 | EXP-004 · 015 · 019 · 037, PHO-005 |
| 결합기를 비선형으로 | 로지스틱이 최선(비선형 7종 × 용량 52칸 중 sd 넘는 칸 0) | EXP-045 · 052 |
| 피처를 줄이거나 고르면 | 하락. 정보가 충격 · 스펙트럼 모양 두 덩어리에 나뉨 | EXP-007 · 011 · 027 |
| 하이퍼파라미터 튜닝 | 기본값이 최선, 안쪽 CV 선택이 잡음에 맞춰짐 | EXP-013 · 018 · 026 |
| 못 가르는 정상을 학습에서 빼면 | 하락(원래 특이한 파일) | EXP-028 · 038 · 046 |
| 오경보 059 · 065 · 116을 새 피처로 | 어떤 피처로도 안 내려감 = 정보 한계 | PHO-001–004 · 006 · 008 · 009, 4-9 |
| 한두 파일만 겨냥한 규칙 | 쓰지 않는다(주기 잠금 · 본체 모드 내림 · 9.5 kHz 내림) | EXP-029 · 030 · 034 · 036 |

주의: 이 결론들은 이전 피처 · 평가 틀에서 나온 것이다. new_단계에서 틀이 바뀌면 일부는 다시 열릴 수 있다. 다만 "분류기를 바꿔도 안 오른다"와 "피처를 줄이면 하락"은 여러 실험에서 반복됐다.

## 3. 이전 모델을 만든 이유
- **AE(정상만 학습한 스펙트럼 오토인코더)**: "정상과 다른가"를 본다. 주로 오경보를 줄인다(EXP-044에서 정상 037 · 110 · 095 등 오경보 감소). AE와 ET는 **서로 다른 고장을 잡는다**(AE: 002 · 029, ET: 005 · 014 · 017 · 028). 단 val에서 AE z가 통째로 이동한다(+1.1~+1.7).
- **ET(ExtraTrees)**: "아는 고장과 닮았나"를 본다. 충격 수 · 울림 비율 · 옥타브 몫 · 하중 대비 고주파 등 H 피처.
- **로지스틱 결합**: 3입력(ET z, 박자 z, AE z) 경계가 거의 대각선이라 유연한 모델은 폴드마다 경계를 흔든다.
- **규칙(OR)**: 8.3k 규칙 · E2는 높은 특이도를 위해 둔다. 규칙으로만 잡히는 고장이 있었다(002 · 029 · 014 · 017).
- **울림 비율 축소**: 충격이 적은 파일의 비율은 흔들리므로 정상 비율 쪽으로 (k + 3·p₀)/(n + 3)으로 줄였다. 점수는 같았고 val 판정의 흔들림이 줄었다.
- **옥타브에 울림 모드 열을 "더하기"**: 같은 점수에서 오경보율 0.030 → 0.022. "바꾸기"는 하락.

## 4. 규칙보다 연속 열이라는 교훈 (지식장부 D13 · D14)
- 규칙이 쓰던 **"양"**(울림 fit · 하중 대비 고주파 · 2위/1위 사건 높이)이 규칙의 **"문턱"**보다 근거가 강했다.
- 단일 타격 감점(정상으로 내리는 if문)은 틀리면 미탐이라 쓰지 않았다. 올리는 규칙이 틀리면 오경보, 내리는 규칙이 틀리면 미탐이다.
- 규칙 채택 기준(C1–C4): ① 기전 ② 겨냥한 학습 고장 ≥ 3개 ③ 문턱 ±20 % ④ 오류 방향(정상으로 내리는 규칙은 측정 구간을 바꿔도 고장이 조건에 들지 않아야 함).
- 지식 감사의 원칙: 라벨을 보고 설계하는 것은 허용하되 ① 기전이 있고 ② 겨냥 고장이 3개 이상이며 ③ 폴드 안 재선택에서도 안정할 때만 "L"로 인정했다.

## 5. 점수 이력 (참고용, 모두 낙관적)
| 구성 | 중첩 CV F2 |
|---|---|
| ext150 + ET (기준선) | 약 0.83–0.86 |
| + 규칙(8.3k · 유격) | 0.892 → 0.942 |
| EXP-034 c(AE + ET + 규칙) | 0.955 ± 0.007 |
| J(AE z + 박자 z, 로지스틱 + 규칙) | 0.977 ± 0.010 |
| J-축소(울림 비율 축소) | 0.977 ± 0.010 |
| + 울림 모드 RM 3열 | 0.978 ± 0.013 (오경보율 0.022) |
- 각 단계의 개선 폭은 대부분 sd 안이었다. 차이가 sd 안이면 같은 수준으로 봤다.
