# 4. 지식 61개의 근거 등급 D · L · P · X (배경지식)

출처: `3_단계/5_모델비교/검토문서/협의_1121/지식장부.md`(11-22, 3인 협의 감사: F 피처 · R 규칙 → 피처 · D 진단). 원 장부 153행을 같은 주장끼리 합친 61행이다. 숫자는 이전 프로젝트의 것이다.

| 등급 | 개수 | 뜻 | 이 배경지식에서의 쓰임 |
|---|---|---|---|
| D 도메인 | 17 | 구조 · 기전 사실, 음성 결과 포함 | 믿고 참고 |
| L 라벨 확인 | 19 | 기전 + 겨냥 고장 ≥ 3 + 폴드 안 재선택 안정 | 가설 후보. 연속 열 · 폴드 안 재선택 형태로만 |
| P 사후 맞춤 | 12 | 라벨을 보고 문턱을 맞춤 | 쓰지 않음 |
| X 이상한 실험 | 13 | 설계나 정의가 잘못됨 | **근거로 쓰지 않음** |

| X3 | 감쇠 ζ 기반 주장 전부 | 두 방법 ζ 순위 상관 0.475, 정렬 평균 신뢰 0.43, 추정법에 따라 3–4배 값 차이 |
| X4 | 잔향 비 | 사후 정의, 선형 항으로 넣으면 PR-AUC 0.929 → 0.900 |
| X5 | "9.5–10 kHz는 고장 근거가 아니다" | 옛 충격 정의 결론, 새 정의에서 9.5–9.75 kHz 고장 3 · 정상 1로 뒤집힘 |

| X12 | 0.949와 규칙 단계별 기여, 고정 임계 0.85 · 1.0, val_001 규칙 판정 | 사후 문턱 + 비교 틀 혼재 |
| X13 | 라벨로 고른 울림 열을 기준 공간에 더하면 개선 | 재계산이 반증: 0.968 → 0.930–0.961 |

## L: 라벨 확인 19개 중 핵심 (사용 형태 포함)
| # | 주장 | 사용 |
|---|---|---|
| L1 | 충격 ≥ 8.0 kHz 있는 파일: 고장 20 · 정상 6(019 043 059 065 092 116) | 제외(H10 칸에 이미 담김, 위험 정상 악화) |
| L2 | 8.25–8.75 kHz 깨끗한 울림: 고장 6 · 정상 0, 폴드 안 선택 78 % | 연속 열 u_ring(조건부) |
| L3 | 2.0–3.4 kHz 창 충격(유격): 고장 21 · 정상 9, AUC 0.907 | 제외(H8과 ρ 0.91 중복, val 이동) |
| L4 | 본체 모드 몫이 크면 정상(충격 ≥ 3 & 몫 ≥ 0.9: 정상 41 · 고장 0) | 연속 열 H14로만. 별도 축 · 내림 금지 |
| L5 | 충격 0개 → 정상(정상 17 · 고장 0) | H1_nimp 열 |
| L6 | 사건 수 ≤ 1 → 정상(정상 36 · 고장 0, 컷 안정 96 %) | log1p(n_ev) 열 |
| L7 | 지배 사건 몫 dom이 낮으면 고장 | ET 열로만. 축으로 쓰면 정상 순도 악화 |
| L8 | 하중 대비 고주파 H18: 017형 4개 + 024 | H18_hfl 열 그대로 |
| L9 | 2위/1위 높이 K1n 단변량 AUC 0.87 | H2_ratio21 열 |
| L10 | 두 정보 영역: 1.25–3.75 kHz 충격(H1) · 8.25–9.5 kHz 모양(H3) | 피처 구성의 근거 |
| L16 | 결합은 로지스틱이 max · svm · OR보다 낫다(0.907 vs 0.887 vs 0.883) | 결합은 로지스틱 |
| L18 | AE를 빼면 중첩 F2 −0.042 ~ −0.059 | AE 유지 |

## D: 도메인 17개 중 핵심
| # | 주장 |
|---|---|
| D1 | 평균(DC)은 센서 방향이라 고장 정보 없음. 단 고장 016도 DC −1.04 g라서 "평균 −1 g = 정상 증거"는 아님 |
| D2 | 크기 계열은 20 Hz 아래에 끌린다 → 200 Hz 고역통과 후 크기 |
| D3 | 새 충격 정의(1 kHz 고역 · Hilbert · 100 ms 바탕 · 4.5배 · 간격 6.75 ms), 가짜 충격 ≤ 0.05/파일 |
| D4 | 모드 위치는 구조 성질. 8.3 kHz는 "이동"이 아니라 "크게 들뜸"(H2′) |
| D5 | 정상 충격은 본체 모드(약 7 kHz)로 울림 |
| D6 | AE와 ET는 서로 다른 고장을 잡는다 |
| D7 | 피처를 줄이거나 고르면 순도 · PR-AUC 개선이 없음 |
| D8 | 낮은 음 봉우리 · H4 · B1–B5 · AR 잔차 · P02 peak는 구분 정보가 없다(순열 ≈ 0) |
| D10 | 오경보 정상 11개는 어느 피처 공간에서도 정상 무리 가장자리 |
| D11 | val 이동은 사실(AE z +1.1, ET z +0.63, 2–4 kHz 창 충격 0.20 → 0.475). AE 이동은 충격 수 · 게인과 무관 |
| D12 | 같은 기전도 정의에 따라 val 이동량이 다르다(연속 본체 몫 vs 문턱형) |
| D13 | 유격 타격은 하중과 무관하게 같은 간극을 반복해 침(H1′) → 연속값, 문턱 규칙 금지 |
| D14 | 규칙이 보던 "양"이 규칙의 "문턱"보다 근거가 강함. 내림 장치는 틀리면 미탐 |
| D17 | 규칙 문턱은 ±20 % 여유 미달. 규칙 점수는 낙관적(+0.021 quick_cv) |

## 이 등급이 new_단계에 주는 규칙
- **연속 열 · 폴드 안 재선택 · 내림 if문 금지**: 이전 감사의 결론이고, Gemini 수정안의 방향과 같다.
- **X · P는 근거가 아니다.** 특히 ζ, "한 사건 몰림 → 정상", 9.5 kHz를 정상 전용으로 보는 것은 쓰지 않는다.
- L과 D는 "참고"다. new_단계에서 같은 결론이 다시 나오기 전에는 확정으로 쓰지 않는다.
