## 정리
1. **1–5 kHz를 새로 맡는 열은 거의 없다.** 고장을 잘 가르는 열은 대부분 이미 있는 H3(첨도) · H8(울림 2–4 kHz) · H1(충격 수) 정보를 다시 잰다.
2. **넣어 볼 것은 cnt_low 하나다.** 다음 실험은 EXP-062 구성 3 + cnt_low를 같은 분할로 돌린다. 021 · 022를 되찾는지와 037 · 016 오경보가 늘지 않는지를 본다.
3. **반쪽 관문은 사용자 판단 대기.** 정상 파일은 1초 안에 충격이 0–2개뿐이라, 충격 기반 열은 이미 J에 있는 H4 수준(0.17)도 통과하지 못한다. "두 반쪽에서 효과 방향 유지"로 완화하면 C4와 cnt_low가 관문을 넘는다.
4. **abn_028**은 어느 후보로도 따로 서지 못한다(최대 81–99 %이지만 정상 이상치와 겹침). 지금 EXP-062에서 1/5만 놓치므로 유지하고 여유를 지켜본다.

## 공통 방법 (두 조각 같음)
관문은 계산 전에 고정했다.
1. AUC 95 % CI 하한 > 0.6
2. J 열과 max |ρ| < 0.8
3. val 이동이 "학습 정상 + 고장 0–40 % 섞음" 범위 안
4. 오경보 · 이상치 정상이 정상 99 % 위로 가지 않음
5. 앞 1초 vs 뒤 1초 반쪽 ρ(정상) ≥ 0.5

4-21은 여기에 ⑥ EXP-062 OOF 여유를 통제한 증분(LOO 로그손실 · 부분 ρ)을 더 봤다. 라벨을 본 탐색이라 AUC는 설명용이다.
