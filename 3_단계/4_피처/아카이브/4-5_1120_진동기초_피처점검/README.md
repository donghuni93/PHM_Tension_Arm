# 4-5 진동 기초 공부로 본 피처 점검 (11-20 ~)

## 목적
진동 기초(Stage 1–7, 뷰어 `1_참고자료/진동공부/`, 포트 8770)를 공부하면서 우리 피처가 물리적으로 맞는 양을 재는지 점검한다. 바꿀 것은 여기에 모아 두고 **한 번에 하나의 EXP로 비교**한다(사용자 결정 11-20). 그 전에는 코드를 바꾸지 않는다.

## 첨도는 어디서 오나 (11-20 확인, 150개 파일)
- 첨도(1 kHz 고역통과 신호) 중앙값: 정상 31.5 · 고장 174. 원신호: 정상 4.6 · 고장 19.5
- 첨도 ↔ 충격 수 순위상관 0.61, 첨도 ↔ 충격 감쇠비 0.12(정상 안 0.01, 고장 안 0.01) → **첨도는 충격이 생겼나(입력 쪽)를 재고, 울림 길이(구조 쪽)와는 거의 무관**. "감쇠가 크면 충격이 짧아져 첨도↑" 경로는 우리 데이터에서 안 보임
- abn_002는 첨도가 낮음(원신호 2.7 = 정상 중 하위 11%, 고역통과 6.8 = 22%), 충격 1개 · ζ 0.01 · 8.25 kHz → 첨도 계열로는 못 잡고 구조 쪽(8.3 kHz 공진) 피처로 잡힘. 두 무리 피처가 서로 다른 고장을 잡는 예
- 시사: 첨도·파고율·충격 수는 같은 것(충격 유무)을 여러 번 재는 중복 후보 → 교수님 조언(피처 과적합) 점검 때 한 묶음으로 본다

## 피처 분류: 입력(가진) 쪽 vs 구조(전달함수) 쪽 (Stage 3, 11-20)
- 입력 쪽 = 충격이 생겼나·얼마나 단단한가: 충격 수, K1 두 번째 타격/σ, 첨도·파고율(P02), 큰 타격 수
- 구조 쪽 = 부품의 k·ζ가 바뀌었나: 울림 주파수 비율(RING), 8.3 kHz 공진 충격(RES), 8.3 kHz 폭(W83), AE 스펙트럼 모양
- 주의: 8.3 kHz는 2-9·2-10·2-16에서 "모드 이동이 아니라 타격이 그 모드를 울림" → 입력 쪽(단단한 충격) 변화가 구조 공진으로 드러난 것. W83(폭) 넓음은 감쇠↑ 또는 충격마다 울림 주파수가 흩어짐, 둘 중 무엇인지 미확인

## 200 Hz 아래 정보의 역할 (11-20 정리)
- **크기 자체**: 운전 조건(차량 출렁임)이 지배, 평균적으로 구분력 없음(AUC 0.43–0.58, 3-1)
- **분모·맥락**: 충격 ÷ 하중(K2). 017은 하중이 150개 중 최소인데 충격이 남 → 비율로만 보임(2-17)
- **시간 기준**: 하중 반전 시점(H4 주기 잠금, 022)
- **모양**: 미검증(C3)
- 결론: 원신호 피처에서는 빼고(C2), 저주파는 별도 그룹으로 **비율·모양·시점** 형태로만 쓴다
