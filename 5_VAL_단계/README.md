# 5_VAL_단계 — val 점수(0.513) 이후 EDA · 실험 (11-27~, 옛 VAL_EDA)

val F2 0.513(고장 17/40, TP 8 · 오경보 2 · 미탐 9)의 원인을 찾고 test 전략을 정하는 작업 공간. **11-27 이후 만드는 EDA · 실험은 모두 이 폴더 안에 둔다**(사용자 11-27).

## 규칙
- 새 EDA 조각 = `V-n_이름/` (README.md + `자료/`). 진행 중에는 이 폴더 바로 아래에 둔다
- **새 실험 = `실험/EXP-nnn_이름/`** (README.md + `자료/run.py`, 번호는 3_단계 실험에 이어서, EXP-068부터). `src.exp.find_exp`가 여기도 찾는다. 실험로그는 그대로 `3_단계/1_기준·기록/실험로그.md`
- 결론이 나면 옮긴다: 유의미 → `유의미한_EDA/`, 아니면 → `아카이브/`
- `유의미한_EDA/`의 결과 중 모델에 반영할 것은 정식 단계(`2_EDA` · `4_피처` · `5_모델실험`)로 승격한다
- val 그룹(둘다고장 · 8조만 · 우리만 · 둘다정상)은 다른 조 결과로 추론한 것이다. **원인 진단에만 쓰고, 모델 · 문턱 튜닝에 직접 쓰지 않는다**
