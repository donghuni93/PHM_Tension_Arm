# 08 평가·임계값: F2와 누수 없는 검증

← [[07_모델링]] · [[00_지도]]

## 한 줄 정의
고장을 놓치면(FN) 안전과 직결되므로 재현율에 2배 가중한 F2로 평가하고, 임계값과 보고 점수는 서로 다른 데이터에서 정한다.

## F2

$$F_\beta=(1+\beta^2)\frac{P\cdot R}{\beta^2P+R},\qquad F_2=\frac{5PR}{4P+R}$$

- 재현율 R을 정밀도 P보다 2배 중시 → 임계값을 보수적으로 낮춰 미탐 최소화, 오탐 일부 감수
- 일반 정형 분석(F1·ROC-AUC)과의 차이 (원문 비교표)
- F2 근거는 지표 정의로 설명한다. 노션 DB의 "F2 우선 논문"은 서지 확인 실패라 인용 금지 ([[20_논문/00_논문DB]])

## 검증 분할 (원문)
- 파일 단위 그룹 분할 (`StratifiedGroupKFold`). 증강 조각도 원본 파일 그룹으로
- 모든 실험은 같은 분할 사용
- 변환 학습·특징 선택·하이퍼파라미터·임계값 선택은 모두 학습 fold 안에서

## 임계값 (원문)
- 기본값(확률 0.5, 결정함수 0.0) 금지
- OOF 예측에서 F2 최대 지점
- 확률이 아닌 출력(Ridge 결정 점수, IF 점수)도 내부 검증에서 임계값

## 임계값과 점수의 분리 (정리자)
- OOF에서 고른 임계값으로 같은 OOF의 F2를 보고하면 낙관적
- 보고용 F2는 임계값 선택에 쓰지 않은 바깥 fold(중첩 CV)에서
- RBF-SVM C·gamma 튜닝도 내부 CV에서

## 기록 규칙 (원문)
- F2와 함께 **미탐·오탐 파일 목록** 기록. F2가 낮아도 다른 모델이 놓친 고장을 찾으면 결합 후보
- CV 점수와 val 제출 점수 비교 (과적합 확인)

## 확인 질문
1. 전부 고장으로 찍었을 때 F2가 0.556이 되는 계산을 직접 해 보라
2. 임계값을 같은 OOF로 고르고 보고하면 왜 점수가 오르는가
3. 증강 조각을 쓸 때 그룹 분할을 파일 단위로 하지 않으면 무엇이 새는가
