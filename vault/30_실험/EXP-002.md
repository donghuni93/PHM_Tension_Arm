# EXP-002 천장 확인: 확장 피처 150개 × 모델 4개

## 목적 (무엇을 확인하려 했나)
- [[30_실험/EXP-001]]의 core 13개는 바닥 점수보다 +0.05. 후보를 하나씩 추가하면 실험당 개선폭이 잡음(±0.055)과 구분되지 않음
- 후보를 한꺼번에 넣어 "이 방향의 피처로 어디까지 가나"를 먼저 확인하고 다음 갈래를 고름
  - ≥ 0.90: 하나씩 빼며 설명 / 0.70–0.90: 도메인 개선 방법 / < 0.70: 원신호 직접 분석

## 설정
- 특징셋: core 13 + 후보 137 = 150개 (`src/features.py` `extract_features_ext`, [[features]] 상태 `확장`)
  - 대역은 데이터를 보기 전에 정한 균등 분할만 사용 (B04 625 Hz 20칸, P02·E01·S01 1,250 Hz 10칸). EDA 대역 미사용 → 누수 없음 (D4)
  - 생략: T05(RMS와 같음), F06(P02 대역별 첨도가 대신함)
- 모델 (하이퍼파라미터는 미리 정한 값 하나, 튜닝 없음)
  - core13 · 로지스틱 회귀: EXP-001 설정 그대로 (기준 재현용)
  - L1 로지스틱 회귀: `RobustScaler` → `l1_ratio=1, solver='liblinear', class_weight='balanced'` (전체 학습 시 0이 아닌 계수 30/150)
  - RandomForest·ExtraTrees: 500그루, `class_weight='balanced_subsample'`, `min_samples_leaf=2`
  - HistGradientBoosting: `max_depth=3`, `learning_rate=0.05`, `max_iter=200`, `class_weight='balanced'`
- 검증 방식: EXP-001과 같은 중첩 CV (바깥 StratifiedGroupKFold 5 × 안쪽 4, seed 0–4)
- 임계값: 안쪽 OOF에서 F₂ 최대(같으면 가장 낮은 값)
- 코드: `notebooks/05_천장확인.ipynb`

- 트리 모델과 L1 로지스틱이 놓치는 고장이 거의 겹치지 않음. abn_022만 모든 모델이 놓침

피처 중요도 (RandomForest를 150개 전체로 한 번 학습, 해석용. 점수 계산에는 쓰지 않음)

- 상위: `P02_kurtosis_012`, `P02_peak_075`, `S01_cv_012`, `P02_crest_012`, `P02_peak_025`, `S01_max_to_mean_012`, `E01_env_kurtosis_000`
- 1,250–2,500 Hz 대역(`012`)의 첨도·파고율·시간 변동이 반복해서 상위에 옴. EDA에서 에너지 비율 차이가 가장 컸던 8–12.5 kHz와는 다른 대역

## 결론
- 최고 0.819(ExtraTrees). 판정 구간 0.70–0.90 → 도메인 개선 방법 갈래
- 개선의 대부분은 대역 필터 후 국소 충격 피처(P02·E01·S01, 중요도 합 0.71)에서 옴. 파일 전체 통계에 묻혀 있던 국소 사건 정보가 대역을 나누면 드러남
- 정밀도가 크게 오름(0.348 → 0.707). 오경보가 43 → 11개
- 주의: 같은 CV로 모델 4개 중 최고를 골랐으므로 0.819에는 약간의 선택 편향이 있음. 표준편차 0.03
- 0.90까지 남은 차이는 주로 재현율(놓친 고장 4.4개). 트리 모델이 abn_002·029를, L1 로지스틱이 다른 고장을 놓치므로 두 모델이 서로 보완할 가능성이 있음
