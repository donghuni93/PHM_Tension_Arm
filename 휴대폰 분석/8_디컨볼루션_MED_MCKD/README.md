# 8. 디컨볼루션: MED · MCKD

## 원리
측정 신호 = (충격 열) ∗ (구조 전달 경로 응답) + 잡음. 전달 경로가 충격을 뭉개고 퍼뜨려 충격이 잘 안 보인다. **역필터**를 학습해 충격 열을 복원한다.
- **MED(최소 엔트로피 디컨볼루션)**: 출력 신호의 **첨도(또는 엔트로피)를 최대화**하는 FIR 필터를 반복 계산. 날카로운 충격 하나하나를 복원.
- **MCKD(최대 상관 첨도 디컨볼루션)**: 첨도 대신 **주기 T의 상관 첨도**를 최대화. 주기적 충격 열을 복원(주기 T를 알아야 함).

## 우리 데이터에서 볼 것
- MED로 울림을 줄이면 정상의 7 kHz 본체 울림과 고장의 2–4 kHz 유격 울림이 충격 단위로 더 분명히 갈리는지.
- 저에너지 고장(022)의 약한 충격이 복원되는지, 경계 정상에서 큰 충격 하나가 과복원되는지.

## 구현 현황
- 없음 (논문 조사 노트에 Endo & Randall 2007, McDonald 2012 정리).

## 한계 · 주의
- MED는 **큰 충격 하나에 맞춰 과적합**하기 쉽다(첨도 최대화 특성). 필터 길이·반복 횟수에 민감.
- MCKD는 주기 T 가정이 필요한데 우리는 비주기 → MED 위주로, MCKD는 주기가 확인될 때만.
- 파일별로 필터를 따로 학습하므로, 피처화하면 필터 계수·복원 후 첨도 중 무엇을 쓸지 설계 필요.

## 상위 개념
AR+MED(Endo & Randall), OMEDA, 블라인드 디컨볼루션 일반.
