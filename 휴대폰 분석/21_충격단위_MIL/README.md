# 21. 충격 단위 다중 인스턴스(MIL) — 파일 평균에 묻히던 022 · 017이 충격 단위로 보이는가

## 방법
14번이 뽑은 충격 1497개(파일 128개에 충격 있음, 22개 정상 파일은 충격 0개)를 샘플로, 입력 = (울림 f, ζ, fit, 높이, 파일 RMS 대비 상대 높이), 라벨 = 파일 라벨(MIL 가정)로 ExtraTrees를 학습한다. 파일 점수 = 충격 로짓 상위 k개 평균(충격 없는 파일 = −3). 폴드는 파일 단위. (1부) 5겹 × 3회 OOF에서 파일 AUC · 정상 대비 백분위, (2부) AE + ET(D+) + MIL 스택을 EXP-036과 같은 중첩 CV(seed 5 × 바깥 5 × 안쪽 4)로 비교.

## 결과 (11-19 실행)
**1부: 정상 대비 백분위 (상위 3개 집계, 정상 중 이 파일보다 덜 이상한 비율)**
| 파일 | 파일 단위 LOF(20번) | 충격 단위 MIL |
|---|---|---|
| **abn_022** | 0.49 | **0.84** |
| abn_017 | 1.00 | 0.62 |
| abn_002 · 014 · 029 | 0.82 · 0.71 · 0.93 | 0.83 · 0.82 · 0.71 |
| nor_116 · 055 (오경보) | 0.99 · 0.85 | 0.91 · 0.89 |
- 파일 AUC 0.916(상위 1) · 0.927(상위 3). **022가 처음으로 정상 중앙(0.35–0.49)을 벗어났지만(0.82–0.84) 오경보 116(0.91) · 055(0.89)가 더 높아** 가려지지 않는다. 017은 오히려 낮아졌다(1.00 → 0.62).

**2부: 스택 (seed 5, 중첩 CV)**
| 구성 | F₂ | 재현율 | 오경보율 | 놓침 | 오경보 3회+ |
|---|---|---|---|---|---|
| AE+ET(D+) 규칙 없음 [EXP-036] | 0.869 ± 0.055 | 0.887 | 0.053 | 017 5/5 · 022 5/5 · 002 2/5 | 025 055 106 116 |
| + MIL, 규칙 없음 | 0.865 ± 0.026 | 0.887 | 0.060 | 017 5/5 · 022 5/5 · 002 2/5 | 6개 |
| AE+ET(D+) + 규칙 [EXP-036] | 0.935 ± 0.025 | 0.940 | 0.022 | 022 5/5 · 015 3/5 | 019 |
| **+ MIL + 규칙** | **0.950 ± 0.021** | **0.960** | 0.023 | **022 5/5** · 015 1/5 | 019 116 |
(기준 EXP-025 재현 0.939 ± 0.013, EXP-036 D 76열 + 규칙 0.944 ± 0.015)
- **MIL + 규칙이 이 프로토콜의 최고 점수(0.950)이나 기준 대비 +0.011로 sd(0.013–0.021) 안쪽이다.** 개선의 실체는 015 미탐이 3/5 → 1/5로 줄어든 것 하나.
- 규칙 없는 쪽은 MIL을 더해도 그대로(0.869 → 0.865). 022는 모든 구성에서 5/5 미탐이다.

## 판정
**B (소폭 유망, 미채택).** 충격 단위 정보가 파일 단위 정보에 없던 것을 일부 준다(022 백분위 0.49 → 0.84, 015 미탐 감소). 그러나 022를 오경보 정상과 가르는 데는 부족하고 F₂ 개선은 잡음 수준이다. 022는 파일 단위 8방법에서 정상 중앙, 충격 단위에서도 상위 16%에 그쳐서 **이 데이터에서 가능한 최대 분리는 거의 확인됐다**고 본다(충격 단위 방식은 충격 5개 이하인 파일에서는 표본이 적어 한계).
