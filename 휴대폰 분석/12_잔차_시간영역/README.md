# 12. 시간 영역 잔차 (AR 백색화)

## 원리
외부 가진·구조 공진처럼 **예측 가능한 규칙 성분**이 에너지 대부분을 차지해 결함 충격이 안 보인다. 정상 파일로 AR(32) 선형 예측기(과거 32점 → 다음 값)를 맞추고, 실제 − 예측 = **잔차**를 보면 규칙 성분은 지워지고 예측 불가능한 충격만 남는다. 즉 신호를 정상 기준으로 "백색화"하는 것.
상위 개념: AR + MED(Endo & Randall 2007), 8번 디컨볼루션으로 이어짐.

## 우리 구현 현황
- 있음(EXP-019, 탈락): AR(32) → 잔차 요약 5개(첨도·RMS 비 등) → 로지스틱. 단독 0.608 ± 0.014, 기준에 더하면 0.907(기준 0.929)로 탈락. 다만 EXP-023 표에서 **017 한 파일은 0.92**로 잘 잡았다(같은 표의 AE는 0.44). 이 0.92는 파일 단위 점수이고, AR 단독 전체 성능이 아니다.
- 빈틈: 잔차를 **파형으로 본 적이 없고**, 5개 스칼라로 줄여서 충격의 시각·간격·주파수·원신호 대비 크기를 버렸다. AR 계수도 정상 앞 10,000점만으로 맞췄다.

## 방법 (`run.py`)
200 Hz 고역통과 → 파일별 표준편차 정규화 → **오탐 경계 정상 4개를 뺀 일반 정상**으로 AR(32) 최소제곱 → 150개 전체 잔차. 보기용이라 폴드 밖에서 맞췄다(피처로 쓰면 폴드 안에서 재학습).
| 그림 | 내용 |
|---|---|
| `residual_time.png` | 8개 파일의 잔차·원신호 로컬 RMS(2 ms), **정규화 잔차 비율**(잔차/원신호) |
| `residual_stft.png` | 잔차 STFT (같은 색 범위 = 일반 정상 10개 표본) |
| `residual_acf.png` | 잔차 로컬 RMS 자기상관(5–200 ms). 일정 지연에 피크 = 충격이 규칙 간격으로 반복 |
| `residual_scatter.png` | 150개 전체, 코호트 색(회색 정상 / 파랑 오탐 정상 / 빨강 미탐 고장 / 주황 일반 고장) |
| `residual_all.png` | 위 4장 합본(휴대폰용) · 표 `residual_summary.csv` |

## 사전 가설 (결과 보기 전에 적음)
- **H-a (본체 모드 연동형)**: 오탐 경계 정상(116·059·055·106)의 잔차 충격은 원신호 포락선이 클 때 같이 커지고, 정규화 잔차 비율은 낮게 유지된다. 잔차 STFT에서 7 kHz 본체 모드 부근에 몰린다.
- **H-b (틱 충격형)**: 미탐 고장(022·014·017·002)은 원신호가 작은 구간에서도 잔차 비율이 튀고(국소 충격), 자기상관에서 일정 지연 피크가 보이거나(022의 주기잠금은 2-13 기록), 잔차 STFT에서 2–4 kHz 또는 8.25 kHz 줄무늬가 나온다.
- 반증: 두 그룹의 정규화 잔차 비율·간격 CV·자기상관 피크가 일반 정상과 같은 범위이면 시간 영역 잔차는 둘을 갈라주지 못한다(등급 C).
- 한계: 002는 충격 1개라 간격·자기상관 지표가 의미 없다. 017만 AR에서 높게 나왔던 이유(짧은 임펄스성 충격 추정)는 가설이며 이 그림으로 확인한다.
