# 15. 피처 정리 → t-SNE (고장과 정상이 잘 갈리게)

## 목적
ext150 피처를 정리해서 t-SNE에서 고장이 정상과 가장 잘 갈리는 구성을 찾는다. 피처 순위·가중치·k는 **항상 학습 폴드 안에서만** 정하고, 폴드 밖(OOF) 점수로 비교한다(전체 150개로 고른 뒤 그린 그림은 분리가 과장된다). val 40개는 라벨 없이 임베딩에 함께 넣어 보라색으로 표시한다.

## 방법 (`run.py`)
1. 분위수 변환(학습 150개로 fit) → 라벨 없는 상관 군집(|ρ| ≥ 0.85)당 대표 1개: 150열 → **62열**
2. 울림 4열(`src.final.ring_table`: ring24, ring_body, res83, nimp)을 더한 **66열**
3. 폴드 안 단변량 AUC로 열 가중(문턱 t 이하 AUC는 0): `weight = clip(|AUC−0.5| − t, 0) / max`
4. 평가 = (a) 로지스틱 PR-AUC · AUC(5회×5겹), (b) t-SNE **OOF 이웃 순도**(시험 고장의 2차원 이웃 5개 중 고장 비율, 이웃은 학습 파일만, 무작위 0.20)

## 결과 (11-17 실행)
| 구성 | 로지스틱 PR-AUC | t-SNE OOF 순도 |
|---|---|---|
| A ext150 전체 | 0.817 ± 0.124 | 0.52 |
| B 대표만 (62열, 라벨 없음) | 0.807 ± 0.126 | 0.57 |
| C B + 울림4 (66열) | **0.841 ± 0.112** | 0.53 (균등 가중) |
| C + 상위 12개 자르기 | 0.733 ± 0.152 | 0.54–0.59 |
| **C + AUC 소프트 가중 (t = 0.10, 49열, perplexity 15)** | — | **0.66 ± 0.04** (소격자 9개 중 최고) |
- **상위 k개로 자르는 방식은 오히려 나빠진다**(PR-AUC 0.73 < 전체 0.84): 고장이 여러 유형이라 한 피처가 한 유형만 가르고, 잘라내면 다른 유형 정보가 사라진다. 자르기 대신 **가중**이 t-SNE에서는 더 낫다(균등 0.53 → 0.64–0.66).
- 라벨 없는 상관 정리(150 → 62열)만으로도 로지스틱 성능은 같다(0.807 vs 0.817). 피처의 약 60%는 중복이다.
- 울림 4열을 더하면 로지스틱이 소폭 오른다(0.807 → 0.841, sd 0.11 안쪽이라 유의 여부는 불확실).
- 가중치 상위: P02_kurtosis_012, P02_peak_025/012, P02_kurtosis_025, P02_crest_000, W03_win_kurtosis_max, **ring24**, P02_rms_087/037, T12_clearance, T03_peak_to_peak (전체: `feature_weights.csv`).

## 그림에서 읽은 것
- 고장(주황)은 한쪽 군집으로 모이지만 **정상과 섞이는 영역이 남는다.** 오경보 정상 116 · 055 · 025는 고장 군집 가장자리에, 059는 정상 쪽에 놓인다. 미탐 고장 022 · 017 · 002는 정상 쪽 군집 안(또는 가장자리)에 놓인다 → 이 피처 공간으로도 022 · 017은 따로 갈리지 않는다.
- **val(보라)**은 train 분포 밖으로 벗어나지 않고 정상 군집 · 고장 군집 양쪽에 섞여 들어간다. 최종 임베딩에서 val 40개의 train 이웃 5개 중 고장 비율은 0/5이 20개, 4–5/5가 5개다(AE z가 전부 양수였던 점과는 다른 그림: ext 피처 공간에서는 분포 이동이 두드러지지 않음).

## 한계
- 이웃 순도는 고장 30개 기준이라 표준오차가 0.03–0.04이고, 가중 방식과 (t, perplexity)를 같은 폴드로 골라 약간 낙관적이다. in-sample 순도(0.59)가 OOF(0.66)보다 낮은 것은 임베딩 seed·perplexity 차이 때문이다.
- t-SNE는 시각화 도구이며 판정 규칙이 아니다. 가중 피처를 모델에 쓰려면 새 EXP에서 폴드 안으로 중첩 CV 비교해야 한다.

## 15-2. 지도 임베딩 + 새 물리 피처 (`run2.py`, train 150개만, val 안 씀)
폴드 안에서 거리를 학습하고 시험 점은 변환만 하는 방식 4가지를 두 피처 집합(C = 66열, D = C + 파일 단위 물리 10개)에서 비교했다. 물리 10개 = 정렬 평균 울림(f · ζ · 피크/RMS), 스펙트럼 첨도 4대역, PSD 기울기 2, log RMS(모두 라벨 없이 계산).

| 피처 집합 | S0 균등 t-SNE | S1 AUC 가중 | S2 NCA → t-SNE | **S3 ExtraTrees 근접도 → t-SNE** |
|---|---|---|---|---|
| C (66열) | 0.571 ± 0.027 | 0.658 ± 0.038 | 0.684 ± 0.042 | 0.747 ± 0.047 |
| D (76열) | 0.584 ± 0.032 | 0.638 ± 0.031 | 0.629 ± 0.037 | **0.798 ± 0.039** |
(OOF 이웃 순도, 무작위 0.20, 3회 × 5겹. 같은 폴드로 방식을 골랐으므로 약간 낙관적)

파일 단위로 본 OOF(이웃 5개의 고장 비율, 3회 평균):
| 지표 | 기준 C·S0 | **최고 D·S3** |
|---|---|---|
| 이웃 고장 비율로 본 AUC | 0.899 | **0.921** |
| 고장 중 비율 ≥ 0.5 | 19/30 | **25/30** |
| 정상 중 비율 ≥ 0.5 | 7/120 | **3/120** |

- **ET 근접도가 가장 잘 가른다**(고장이 한쪽 군집으로 모이고 정상과 분리). 단, 그림의 in-sample 순도(0.97)는 라벨로 학습한 거리라 과장이며 **정직한 수치는 OOF 0.80**이다.
- 새 물리 피처 10개의 추가 효과는 작다(C→D, S3에서 0.747 → 0.798로 표준오차 1배 안쪽, 균등 t-SNE에서는 0.571 → 0.584). 10개 중 ET 중요도 4위로 높은 것은 `ring_peak_rms`뿐이고 SK 2–4k(15위), log_rms(33위) 등은 중하위다. 효과가 있다면 상당 부분은 `ring_peak_rms` 하나에서 나온다.
- **개별 파일 변화(OOF 이웃 고장 비율, 기준 → 최고)**: 오탐 106 0.53 → 0.00, 116 0.40 → 0.20, 055 0.33 → 0.20(감소 = 개선), 025 · 059는 0.00 유지. 미탐 014 0.73 → 0.53(소폭 악화), **002 0.87 → 0.00(악화)**, **017 · 022는 0.00 그대로**. 즉 정상 쪽 오경보 후보는 줄었지만, 고장 유형이 유일한 002 · 017 · 022는 학습 폴드에 닮은 고장이 없어 **폴드 밖에서는 정상 이웃에 둘러싸인다.**
- 판정: **B (설명용, 유망)**. 전체 분리는 개선되었으나(0.57 → 0.80) 남은 한계는 피처가 아니라 **희소 고장 유형(002 · 017 · 022)**이다. 이들은 정상과 가장 닮은 이웃을 가져서, 규칙 없이 t-SNE·이웃 방식만으로는 잡히지 않는다. 같은 구조적 이유로 이후 모델 개선의 상한도 이 3개가 정한다.
