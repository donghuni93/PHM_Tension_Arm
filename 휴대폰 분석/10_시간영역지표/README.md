# 10. 시간 영역 통계 지표

## 원리
시간 파형에서 직접 계산하는 요약값: **RMS**(에너지), **첨도**(충격성), **왜도**, **파고율**(peak/RMS), **형상 인자**, **구간별 RMS**(정상성). 계산이 가장 단순하고 해석이 직관적이라 첫 방어선으로 쓴다.

## 우리 데이터에서 볼 것
- 구간별 RMS 궤적이 평탄한지(정상 상태) 또는 시작 과도/중간 사건이 있는지.
- 첨도·파고율이 충격 개수와 어떻게 얽히는지(충격 많으면 첨도 낮아지는 역설).

## 구현 현황
- 있음: `src/features.py` 기본 피처에 포함(전체 파일 단위). 정상 띠폭 확인은 `2-7`.
- 없음: 구간별(시간에 따른) 지표 궤적 비교.

## 한계 · 주의
- 에너지 큰 저주파가 지배하면 미세 충격이 가려짐 → 고역통과 후 계산해야 의미.
- 센서 방향·DC 오프셋(평균 −1 g 파일 4개) 영향 → 계산 전 평균 제거, 평균은 따로 기록.

## 상위 개념
고차 모멘트, 엔트로피 지표, Gini 지수.
