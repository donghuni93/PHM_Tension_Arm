# 13. 주파수 영역 잔차 (ΔPSD · AE bin 오차)

## 원리
정상 파일들의 PSD(중앙값)를 기준선으로 삼고 파일의 PSD에서 뺀 **ΔPSD**를 보면, 거대한 기본 피크에 가려진 특정 대역의 미세한 에너지 상승이 드러난다. 학습형 기준선이 AE다: 정상 스펙트럼으로 학습한 오토인코더가 복원 못 하는 정도(복원 오차)를 **주파수 bin별**로 보면 어디가 정상에서 벗어났는지 보인다.
핵심 구분: ΔPSD가 크게 나온 이유가 ① 파일 전체가 센 것(게인, 본체 모드 가진 세기)인지, ② 특정 대역만 이탈한 것인지. 그래서 **에너지 정규화**(전체 파워 또는 본체 대역 5.5–7.75 kHz 파워로 나눔)를 병행한다.

## 우리 구현 현황
- 있음: AE(`src/experts.py` `ae_segerr`, 구간별 log PSD 1025칸 MLP AE, 정상만 학습)가 최종 모델의 한 축(AE z). `ae_bins`(bin별 복원 오차)와 `shape=True`(구간 평균 log PSD를 빼서 게인 제거, H3)도 이미 구현. 정상 5–95% 띠 비교는 매 EXP의 `psd_focus`.
- 빈틈: AE 점수는 한 숫자라 **어느 대역이 이탈인지** 파일별로 읽지 못하고, 정상 중앙값을 직접 뺀 ΔPSD 그림이 없다.

## 방법 (`run.py`)
4개 코호트: **일반 정상**(회색 5–95% 띠 · 중앙값) / **오탐 경계 정상** 116·059·055·106(파랑) / **미탐 경계 고장** 022·014·017·002(빨강) / **일반 고장 중앙값**(주황). 사전 고정 대역 3개(2–4, 5.5–7.75, 8.0–8.7 kHz, 2-16 울림 기록)를 노란 띠로 표시.
| 행 | 내용 |
|---|---|
| 1 | ΔPSD 원본(dB) |
| 2 | ΔPSD 전체 파워 정규화 |
| 3 | ΔPSD 본체 대역 정규화 |
| 4 | AE bin 복원 오차(5-fold OOF) |
| 5 | AE bin 복원 오차 모양 AE(게인 제거) |
산출: `cohort_overlay.png`, `band_zscore_heatmap.png`(파일 × 측정·대역 z, 일반 정상 분포 기준), `band_zscore.csv`, `freq_residual_all.png`(합본).

## 사전 가설 (결과 보기 전에 적음)
- **H-c (게인 때문에 튐)**: 오탐 정상 4개는 원본 ΔPSD·AE에서는 정상 띠 밖이지만 **정규화하면 띠 안으로 돌아온다**(z가 0 근처). 그렇다면 AE z를 전 대역 합산이 아니라 대역별(본체 vs 결함 대역)로 쪼개는 것이 해법 후보.
- **H-d (고장은 정규화해도 남음)**: 미탐 고장은 정규화 후에도 2–4 kHz(유격 H1) 또는 8.0–8.7 kHz(H2′)에서 z가 크게 남는다. 022는 에너지가 작아(2.6 kHz 돌출이 104위) 정규화해도 안 남을 수 있으며, 이 경우 주파수 영역 잔차로는 한계(등급 B/C).
- 반증: 정규화 후에도 오탐 정상이 계속 튀면 원인은 게인이 아니라 대역 이탈(본체 모드 자체의 모양 차이)이다.
- 한계: ΔPSD 기준선에 일반 정상이 자기 자신으로 들어간다(보기용, 폴드 밖). AE만 OOF.

## 결과 · 해석 (PC 실행 후 채움)
(11-17 실행. 9–10 kHz 대역은 첫 실행 그림을 본 뒤 **사후 추가한 탐색용** 대역이다. 이유: 2-16에서 9.5–10 kHz 울림은 고장 근거가 아니라고 이미 기록됨)
- **H-c(게인 때문에 튐) 기각(AE 쪽)**: 오탐 정상 4개의 AE z(OOF)는 5개 대역 모두 +1~+3.8σ로 **일반 고장 중앙값(1.8–2.7)과 같은 크기**이고, 게인을 제거한 모양 AE에서도 그대로다(1.0–3.4). 전체 세기 때문이 아니라 bin 모양 이탈이다.
- **ΔPSD는 정규화하면 상당히 줄어든다**: 116 · 055 · 106은 전체/본체 정규화 후 대부분 |z| < 2. 059는 정규화 후에도 이탈(5.5–7.75 kHz 전체정규화 −2.3, 2–4 kHz 본체정규화 +3.3).
- **오탐 정상의 가장 큰 이탈은 9–10 kHz**: ΔPSD 원본 z = 116 3.95 · 059 1.95 · 055 4.63 · 106 1.77 (일반 고장 중앙값 2.3). 기존 세 대역(2–4, 5.5–7.75, 8.0–8.7)에서는 경계 정상이 고장과 분리되지 않는다.
- **미탐 고장**: 022 · 017은 AE z가 0 이하(022 −0.1~−1.25, 017 −0.9~+0.4), ΔPSD도 대부분 |z| < 2 → **주파수 영역 잔차로는 분리되지 않는다**(H-d 기각, 에너지가 작아 정규화해도 안 남음). 002는 8.0–8.7 kHz에서 본체정규화 ΔPSD z 3.2, AE 2.6–3.7로 분명(기존 8.3k 규칙과 일치). 014는 약함(AE 2–4 kHz 1.9).
- 판정: **B (설명용)**. 경계 정상이 오탐되는 이유가 9–10 kHz 울림과 AE의 bin 모양 이탈이라는 것은 설명되지만, 022 · 017을 잡을 단서는 이 방법에 없다.
