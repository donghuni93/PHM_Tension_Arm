# 18. 규칙을 피처로 — 8.3 kHz · 유격 규칙의 기반 수치를 ET 입력에 넣어 규칙 없이 가르기

## 동기
8.3 kHz 규칙과 유격 반복 규칙은 문턱을 라벨 본 뒤 정한 사후 값이라 과적합 위험이 있다. 규칙이 쓰던 연속 수치를 피처로 주면 문턱은 트리가 폴드 안에서 학습한다. 규칙 기반 수치 = P83 · W83(8.20–8.45 kHz 봉우리의 돌출 · 반높이 폭), K1 · K2 · K3(유격 반복: 두 번째 타격/σ, 저주파 RMS/σ, 2위/1위). 이 5열을 분위수 변환해 D 76열에 더한 것이 **D+ (81열)**.

- **규칙 기반 수치 5열만으로 002 · 014가 규칙 없이 잡힌다**(놓침 3·1회 → 0·0회). 8.3 kHz 스펙트럼 규칙(002 · 003 · 006 · 010 · 029)과 유격 규칙의 정보는 연속 피처로도 모델이 쓸 수 있다. F₂ +0.029(0.868 → 0.897).
- **017 · 022는 그대로 3/3 놓친다.** 이 둘은 규칙으로도 022만 못 잡고(P3 기준 017은 유격 규칙으로 잡힘), 피처로 주면 017도 다시 놓친다 → 유격 규칙이 017을 잡는 힘은 K 수치가 아니라 **문턱을 라벨로 정한 효과**가 섞여 있다는 뜻일 수 있다.
- **규칙이 있는 쪽(P3, 0.950)이 여전히 높다.** 규칙 없는 Q0는 오경보율이 0.056으로 높다(규칙이 확정 고장을 먼저 빼고 나면 임계값을 보수적으로 둘 수 있기 때문). 규칙 + D+(Q1)는 재현율이 약간 낮아져 0.940으로 P3와 같은 수준(sd 안).
- 한계: 5열의 정의(8.20–8.45 kHz 대역, K1–K3)가 002 등을 본 뒤 설계된 것이라 이 이득에는 규칙과 같은 종류의 낙관 편향이 있다. 절대 비교 시 주의.

## val
- Q0(규칙 없음, 임계값 0.11)이 **025 모델의 규칙 켜진 val 파일 4개(001 · 027 · 035 · 039)를 규칙 없이 모두** 고장으로 잡는다. 025의 고장 판정 10개를 전부 포함하면서 추가 6개(009 012 018 021 022 034)가 나온다(총 16/40). 추가분은 규칙 없는 P1이 많이 잡던 경계 파일 군집과 같고 018 · 022는 앞서 세 방법이 가리킨 파일이다.
- train OOF(5겹): 재현율 28/30, 오경보 10/120(009 025 037 039 045 055 059 060 106 116) → 오경보가 많아 val의 추가 6개 중 일부는 오경보일 수 있다.

## 판정
**B (유망).** 규칙을 피처로 바꾸면 규칙 없이도 002 · 014를 포함한 규칙 유형을 모델 안에서 잡을 수 있고(F₂ +0.029), 규칙의 사후 문턱 의존을 줄이는 방향의 근거가 된다. 단, 규칙 포함 구성(P3 0.950)을 넘지는 못하고 오경보가 많아 지금 채택하기는 이르다. EXP-036에서 5 seed · 고정 임계값과 함께 Q0 · P3를 기준 EXP-025 대비 비교한다.
