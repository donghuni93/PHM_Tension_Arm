# 휴대폰 분석 — 원시 진동 신호를 물리량 하나씩 해부

목적: 모델·규칙을 더하지 않고, 오탐 경계 파일(정상인데 고장처럼 보이는 파일)이 **주변 고장과 닮았는지, 다르다면 어디가 다른지**를 원시 신호 분석으로 설명한다.
방식: 기법 하나당 폴더 하나. 폴더마다 `run.py`(`# %%` 셀) + `README.md`(원리 · 우리 데이터에서 볼 것 · 결과 · 해석). 결과를 보고 다음 기법으로 간다.

| 순서 | 폴더 | 기법 | 상태 |
|---|---|---|---|
| 1 | [1_STFT](1_STFT/README.md) | STFT 스펙트로그램 비교 | 코드 작성, PC 실행 대기 |
| 2 | 2_포락선 | 고정 대역 포락선 스펙트럼 | 예정 |
| 3 | 3_커토그램 | fast kurtogram (파일별 최적 대역) | 예정 |
| 4 | 4_켑스트럼 | 파워 켑스트럼 | 예정 (비주기 충격이라 음성 결과 가능성 높음) |
| 5 | 5_시간주파수 | 웨이블릿 · HHT | 앞 단계에서 단서가 나오면 |
| 6 | 6_사이클로·디컨볼루션 | 사이클로스테이셔너리 · MED/MCKD | 앞 단계에서 단서가 나오면 |

이미 구현된 것(정리용): STFT는 피처·딥러닝 입력으로만(`src/features.py:184`, `src/candidates.py`), 포락선은 충격 검출(`src/final.py:71`)과 `2-7_정상띠폭`의 1–300 Hz 구간, 스펙트럼 첨도는 `2-7`의 고정 격자뿐이다. 켑스트럼·웨이블릿·HHT·사이클로스테이셔너리·MED/MCKD는 구현된 적이 없다.

## 작업 원칙
- 대역·주파수를 라벨 본 뒤 손으로 고르지 않는다. 그림은 **보기용**이고, 피처로 쓰려면 새 EXP로 중첩 CV 비교한다.
- 실행은 PC(conda `qe-phm`)에서. 이 폴더의 스크립트는 `data/TeamProject_train_변경/`가 있어야 돈다.
