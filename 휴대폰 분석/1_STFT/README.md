# 1. STFT 스펙트로그램 비교

## 목적 · 답할 질문
1. 오탐 경계 정상(116 · 059 · 055 · 106)의 시간-주파수 구조가 대표 정상과 닮았는가, 놓친·저에너지 고장(022 · 014 · 017 · 002)과 닮았는가?
2. 다르다면 **언제**(충격 시각·간격), **어느 주파수**(울림 대역), **얼마나 오래**(감쇠) 다른가?

## 원리 (기초)
- FFT는 2초 전체를 한 번에 보므로 "언제"를 잃는다. STFT는 짧은 창을 밀며 FFT를 반복해 시간×주파수 지도를 만든다.
- 읽는 법: **세로 줄무늬 = 충격**(모든 주파수에 동시에), **가로 띠 = 지속 공진/가진 성분**, **줄무늬가 위(고주파)는 짧고 아래(저주파)는 길게 늘어짐 = 울림(ring-down)**. 줄무늬가 가로로 얼마나 번지는지가 감쇠 시간이다.
- 불확정성 트레이드오프: 창 256점(10 ms)은 충격 시각이 선명하나 주파수 해상도 98 Hz, 창 1024점(41 ms)은 24 Hz로 선명하나 충격이 번진다. 그래서 두 장을 만든다.
- 상위 개념: STFT는 해상도가 고정이다. 주파수마다 창을 바꾸면 웨이블릿(5단계), 데이터 스스로 분해하면 HHT/EMD다.

## 방법
`run.py` 한 번 실행으로 `figs/`에 4장.
| 그림 | 내용 |
|---|---|
| `stft_256.png` · `stft_1024.png` | 행 = 대표 정상 3 / 오탐 경계 정상 4 / 놓친 고장 4. 모든 패널 같은 색 범위(대표 정상 1–99.5%) |
| `stft_512_diff.png` | 파일 − 정상 중앙 스펙트로그램(dB). 빨강 = 정상보다 센 곳 |
| `stft_profile.png` | 주파수별 프레임 평균(지속 에너지) · 최댓값(순간 충격)을 정상 5–95% 띠 위에 겹침 |

대표 정상은 총 RMS가 정상 중앙값에 가장 가까운 3개로 자동 선택(손으로 고르지 않음). 파일 번호는 EXP-034 · 2-16 기록에서 가져왔다.

## 볼 것 (사전 가설, 결과 전에 적어 둠)
- 정상 충격은 7 kHz 부근 본체 모드로 울리고, 고장은 2–4 kHz(유격, H1) 또는 8.25 kHz(H2′) 울림이 나온다고 알려져 있다. 경계 정상 4개가 이 둘 중 어느 쪽 줄무늬를 닮는지 본다.
- 충격 **간격과 개수**가 대표 정상과 같은지(규칙성), 큰 충격 하나만 튀는지(116은 큰 타격 하나가 9.5 kHz로 울린다고 기록됨).
- 022(저에너지)는 전체 에너지가 작아서 색 범위 공통 스케일에서는 안 보일 수 있다 → diff 그림과 profile 그림으로 확인.

## 결과 · 해석 (PC 실행 후 채움)
(11-17 실행, 컨테이너 Python 3.13, 파일명 `nor_###`/`abn_###`)
- **오탐 경계 정상**: 116 · 055는 **큰 광대역 충격 1개**(116은 1.53 s, 055는 1.2 s)와 **약 9.5 kHz 지속선**, 나머지 구간은 조용하다. 059는 짧은 충격 여러 개(0.3 s, 1.09 s 등). **106은 앞 0.8 s가 매우 조용하다가 갑자기 시작하고, 이후 주파수가 변하는 대각선 줄무늬**가 보인다. 다른 표본에는 없는 모양(충격이 아니라 스윕형).
- **미탐 고장**: 017은 RMS 0.002 g로 대표 정상(0.029)의 약 1/15이라 거의 노이즈 바닥이다. 022는 6 kHz 이하에 에너지가 있고 충격이 몇 개(0.05–0.2 s, 1.0 s, 1.95 s 부근). 002는 **8.3 kHz 지속선**이 뚜렷하다(스펙트럼 8.3k 규칙이 잡는 근거를 그림으로 확인). 014는 충격 몇 개와 8.5 · 10.5 kHz 선.
- **프로파일(최댓값)**: 오탐 경계 정상 4개가 5–6.5 kHz와 9–10 kHz에서 정상 띠 위로 약 +20–30 dB 튀어 오른다(큰 충격 + 9.5 kHz 울림). 반대로 미탐 고장은 대부분 정상 띠 안이거나 아래다 → **미탐 고장의 충격이 정상의 큰 충격보다 작다**는 것이 시각적으로 확인된다.
- 판정: **B (설명용)**. 정상 경계가 튀는 원인(큰 충격 + 9.5 kHz)과 고장이 묻히는 원인(저에너지)은 보이지만, 새 피처 근거로는 아직 부족.

## 다음
- 줄무늬가 닮는/다른 대역이 보이면 → 2단계 포락선 스펙트럼의 **대역을 그 결과가 아니라 물리 근거(울림 대역 표)로** 고정.
- 충격 시각이 어긋나서 diff가 흐리면 → 충격 정렬 평균(시간 동기 평균)을 별도 조각으로.
