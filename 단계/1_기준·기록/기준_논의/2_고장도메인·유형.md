# 2 고장 도메인 · 유형 분류 · 물리 가설

텐션암이 어떻게 고장 나고, 그것이 신호에 어떻게 보이며, 우리 데이터에서 무엇이 확인됐나. 예전 개념(노션 원문)·1-3 고장 유형·물리가설을 합친 것 (11-16). 피처·모델을 추가할 때는 아래 가설(H1…)에 연결하고, 실험 후 "우리 데이터" 칸을 갱신한다.

## 부품과 고장 기전 (노션 원문 요약 = 선택지, 정답 아님)
- 텐션암 = 휠의 전후 움직임을 잡는 **비회전** 현가 부품. 결함은 대개 양 끝 고무 부싱에서 시작
- 1자유도 모델 Mẍ + Cẋ + Kx = F, ω = √(K/M). 결함 → 강성 K·감쇠 C 변화 → 공진 위치·충격·고조파

| 결함 | 물리 변화 | 예상 신호 |
|---|---|---|
| 부싱 경화 | K↑, 감쇠↓ | 공진 오른쪽 이동, 피크 날카로움, RMS↑ |
| 부싱 박리·파단 | K↓, 유격 | 금속 타격(clunk) → 짧은 충격, 첨도↑, 광대역 고주파 |
| 볼조인트 마모·유격 | 하중 반전 때 틈에서 부딪힘 | 반전 순간 짧은 고주파 충격이 간헐 |
| 체결 이완 | 구속력 약화 | 특정 주파수에서 암 전체 떨림 |
| 본체 호흡 균열 | 이선형 강성 | 가진 주파수 정수배 고조파 (드묾, 보조) |

- 회전체와 달리 결함 주파수 공식(BPFO 등)이 없다 → 비주기 충격 + **정상에서 얼마나 벗어났나**로 잡는다
- 주의: 원인이 부싱인지 볼조인트인지 PDF로는 모름(수리 그림이 부싱 압입이라 부싱 추정) · 센서 1축이라 축간 지표 불가 · 가진 방식 미상

## 열화 단계 L1–L4 (가설) → 실제 분류 결과
라벨은 정상/고장뿐이다. 아래 단계는 **해석**이고 순서도 가정(시간 정보 없음) → 발표에서는 "신호 유형"으로 말한다. 분류는 설명용이며 모델 입력·선택에 쓰지 않는다. 분류 규칙·파일 목록은 [2-1](../../2_EDA/2-1_고장유형분류/README.md), 유형별 오류는 [6-1](../../6_오류분석/6-1_1116_유형별_정상고장_구분/6-1_유형별_정상고장_구분.md).

| 단계 | 물리 상태 | 신호 징후 | 고장 수 (2-0) | 같은 규칙에 걸리는 정상 |
|---|---|---|---|---|
| L1 초기 미세 열화 | 극소 유격, 큰 외력에서만 "틱" | 에너지는 정상 수준, 짧은 마찰·고주파 링잉 | 5 | |
| L2 부싱 유격 확대 | 저주파로 크게 출렁이고 끝단에서 타격 | 0–20 Hz 요동 + 고역통과 후 충격 | 9 | 33 (놓친 022가 여기) |
| L3 금속 타격 | 볼스터드–하우징 연속 충돌 | 연발 충격, 광대역·2–3.5 kHz | 12 | 연발 0 · 강타 6 (= EXP-025 오경보 전부) |
| L4 체결 이완·공진 | 암 전체 저주파 떨림 | 충격 0, 10–200 Hz 대진폭 | 1 | |
| 미분류 | | | 3 | |

- 고장은 한 덩어리가 아니다: 고장끼리 거리(22.8)가 고장–정상(18.5)보다 멀다 → 정상 둘레에 흩어짐

## 물리 가설 H1–H6 → 우리 데이터

| id | 가설 | 우리 데이터에서 | 상태 · 쓰인 곳 |
|---|---|---|---|
| **H1 / H1′** | 유격 → 금속 타격. H1′: 타격은 하중과 무관하게 **고른 크기로 반복** | P02 대역(1.25–3.75 kHz) 충격 피처가 가장 강함(EXP-002·027). 정상 중심 거리 r ≥ 2 & 2위/1위 사건 ≥ 0.7 → 고장 10개만 켬(014·017 해결). 큰 타격(≥ 20σ) 딱 1개 = 정상 38 · 고장 0 | **지지 · 최종 유격 규칙** (0.892 → 0.942). 단일 타격 감점은 관찰 열만 |

## 1단계 합의(11-13)에서 바뀐 것
- **유형 분류 안 함 → 설명용으로 분류(11-16).** 남은 오류가 어느 유형에 몰리는지 보려고. 1-3의 L1 예시 014·017·021은 실제 지표로 L1이 아니었다(014 = L2, 017·021 = 미분류)
- **공진 왼쪽 이동(노션 원문) → H2′.** 002·029가 두 봉우리를 다 가지고, 봉우리 모양이 라벨이 아니라 위치를 따른다. 정상에도 8.3 kHz 봉우리가 22개 → 원래 있던 모드가 더 크게 들뜬 것

## 열린 질문
- 1.25–2.5 kHz 충격이 가장 강하다 → 유격 충격이 조립부 고차 모드(1–3 kHz)를 때리는가 (H1)
- 8.3 kHz 모드의 정체 (H2) · 정상에 공통 가진 피크가 없음 → 랜덤 가진? (H6, 조교 질문 후보)
- 평균 −1 g 파일 4개(nor_097·101·120, abn_016): 센서 방향?
