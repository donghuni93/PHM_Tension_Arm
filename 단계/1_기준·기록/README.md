# 1단계 기준·기록 — 문제·평가 + 프로젝트 기록

상태: 11-16 `notes/`와 `단계/1_문제·평가/`를 이 폴더 하나로 합침. 두 곳이 다르게 판단한 지점은 [판단차이](판단차이.md)

## 이 폴더의 역할
모든 단계가 따르는 **기준**(무엇을 맞히나, 점수를 어떻게 정직하게 매기나, 어떤 물리 가설로 개발하나)과, 그 기준이 실험을 거치며 어떻게 바뀌었는지의 **기록**을 한곳에 둔다. 발표 제출물 01(데이터·취득 과정)과 04(성능 평가)의 근거.

## 기록 규칙
- 1-1·1-2·1-3은 **11-13 당시의 논의 기록**이다. 뒤에 바뀐 합의는 본문을 지우지 않고 ⚠ 표시와 판단차이 링크만 단다 (왜 바뀌었는지 발표에서 설명할 수 있게)
- 지금 유효한 규칙은 [결정](결정.md) 한 곳. 새 결정이 1단계 합의를 뒤집으면 [판단차이](판단차이.md)에도 한 줄
- 실험 = 실험로그 한 줄, 가설 검증 = 물리가설 검증 열, 상태 = 00_NOW
- 형식: 1-n 문서는 **사실 / 논의 / 합의·미정**으로 나눈다

## 요약 — 지금의 평가 틀
- 판정 단위 = 파일, 고장이 양성. F2 = 5TP / (5TP + 4FN + FP) → 미탐 1 = 오경보 4
- 분할 = `StratifiedGroupKFold`, 파일 1개 = 그룹 1개
- 탐색 = `quick_cv`(5-fold × seed 3, 임계값 없는 PR-AUC) / 유의미 판정·최종 = 중첩 CV(바깥 5 × 안쪽 4, seed 5) F2 ± sd. 차이 < sd면 같은 수준
- 고장 비율에 맞추지 않고 재현율↑·오경보율↓. val은 확인용, 보고 고치지 않음
- 라벨을 보고 고른 대역·문턱 금지, 예외는 8.3 kHz 모드 규칙·유격 반복 규칙 둘뿐 (점수 낙관적 표시)
