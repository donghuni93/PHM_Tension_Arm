- **성능 (학습 150개, 중첩 교차검증 F2)**: **0.942 ± 0.012** (재현율 0.960 · 오경보율 0.033). 단, 규칙 문턱을 라벨을 보고 정했기 때문에 실제보다 높게 나온 값이다. 새 데이터에서는 0.86–0.94 사이를 예상한다
- **11/19 val 공개 날**: 스크립트 하나(`7_최종·제출/2_예측.py`)만 돌리면 제출 CSV가 나오도록 준비해 두었다. val 점수를 보고 모델을 고치지 않는다
- **남은 오류**: 고장 022(주기적으로 반복되는 충격형) 하나를 자주 놓치고, 정상 025처럼 "큰 타격이 한 번 있는 정상"을 고장으로 잘못 판정한다

| 구성 | F2 | 의미 |
|---|---|---|
| RMS 관리도 (평균 + 3σ) | 0.080 | 진동 **크기**로는 거의 못 가른다 (고장 30개 중 28개가 정상 범위 안) |
| AE 단독 / ET 단독 | 0.845 / 0.823 | 각각 스펙트럼 모양 · 충격 피처로 판정 |
| AE + ET 결합 | 0.857 | 서로 놓치는 고장이 달라 합치면 나아진다 |
| + 8.3 kHz 규칙 | 0.892 | 조용한 고장 002 해결 |
| **+ 유격 반복 규칙 (최종)** | **0.942** | 신호가 작은 고장 014 · 017 해결 |

F2 = 5·TP / (5·TP + 4·FN + FP). 고장을 1개 놓치는 것(미탐)이 정상을 4개 잘못 잡는 것(오경보)과 같은 무게다.

## 단계별 핵심

### 1단계 문제·평가 — 점수를 정직하게 매기는 틀
- 판정 단위 = 파일 1개, 고장이 양성. 미탐 1건 = 오경보 4건의 무게라 **재현율을 우선**한다
- 성능은 **중첩 교차검증**(바깥 5-fold로 점수, 안쪽 4-fold로 임계값, seed 5번)으로 잰다. 같은 데이터로 임계값까지 고르면 F2가 0.03–0.045 부풀어서다
- val(40개)은 표본이 작아 같은 모델이어도 F2가 ±0.09 흔들린다 → **확인용으로만 쓰고 보고 고치지 않는다**
- 근거: [1-2 평가 설계](기준_논의/1-2_평가설계.md) · 현재 규칙 전체: [결정.md](결정.md)

### 2단계 EDA — 정상과 고장은 "크기"가 아니라 "형태"가 다르다
최종 모델의 규칙 2개가 모두 여기서 나왔다. 발표 "02 정상·고장 비교 분석"의 근거.

1. **8.3 kHz 봉우리** ([2-11 README2](../2_EDA/아카이브/8kHz공진/2-11_1114_경계파일특징_8.25khz/README2.md)): 가장 큰 봉우리가 8.2–8.45 kHz에 **넓게**(198–275 Hz) 솟으면 고장, 8.45–8.75 kHz이거나 좁은 순음(92 Hz)이면 정상. 진동은 작지만 이미 고장 난 002 · 029를 이것으로 잡는다
2. **큰 타격의 반복** ([2-4](../2_EDA/2-5_하중대비고주파/README.md) · [2-5](../2_EDA/2-2_큰타격반복/README.md)): 부싱·볼조인트에 틈(유격)이 생기면 하중과 상관없이 비슷한 크기의 타격이 **여러 번** 난다. 정상도 노면 때문에 큰 타격이 있지만 대개 **한 번**이다. 큰 타격이 딱 1개인 파일 = 정상 38개 · 고장 0개
3. **주기에 잠긴 충격** ([2-6](../2_EDA/2-4_주기잠금_022/README.md)): 고장 022는 0.94초마다 반복되는 하중 주기에 충격이 맞춰 난다. 이런 파일이 022 하나뿐이라 규칙으로는 쓰지 않았다 (과적합 위험)
4. **고장은 한 덩어리가 아니다**: 고장끼리의 거리가 고장–정상 거리보다 멀다. 고장 방식이 제각각이라 "고장을 닮았나"보다 **"정상에서 얼마나 벗어났나"**를 재는 구조가 맞다
5. **고장 유형 분류** ([2-1](../2_EDA/2-1_고장유형분류/README.md)): 고장 30개를 열화 단계 L1–L4로 나눈 설명용 분류 (모델 입력 아님)
- 물리 해석 묶음: [2-11~14 물리검증자료.pdf](../2_EDA/물리검증자료_충격패턴.pdf) — 발표 자료로 가장 바로 쓸 수 있는 파일
- 개관·기각된 가설은 [2_EDA/아카이브/개관/](../2_EDA/아카이브/개관/)에 있다. 필요할 때만 보면 된다

### 3단계 전처리 — 평균 제거 + 200 Hz 고역통과
- **평균 제거**: 평균이 −1 g인 파일 4개(정상 097 · 101 · 120, 고장 016)가 있다. 센서 설치 방향(중력) 때문으로 보이며, 빼지 않으면 진폭 피처가 진동이 아니라 설치 자세를 잰다
- **200 Hz 고역통과**: 정상 에너지의 약 74%가 200 Hz 아래 차량 흔들림이고 정상·고장 구분력이 없다. 걷어내면 숨어 있던 충격이 보인다. 스펙트럼 AE 입력과 충격 검출에 쓴다
- 이동평균(MA)은 쓰지 않는다 (충격 피크를 뭉갬)
- 근거: [3-1](../3_전처리/3-1_평균제거·고역통과/README.md)

### 4단계 피처 — 유의미한 정보는 두 덩어리
- 피처 229개 중 정상·고장 분포가 다른 것은 많지만, 실제로 쓸모 있는 정보는 **두 가지**다
  - **1.25–3.75 kHz 대역의 충격 크기·뾰족함** (첨도, Peak) → 유격 타격 (가설 H1)
  - **8.25–9.5 kHz 근처 스펙트럼 모양** → 공진 모드 변화 (가설 H2)
- 둘 중 하나를 망가뜨리면 성능이 크게 떨어지고, 나머지 그룹은 거의 영향이 없다. 상위 몇 개만 남기면 오히려 떨어져서 **피처 선택은 하지 않는다**
- 근거: [4-1 피처 중요도](../4_피처/아카이브/4-1_피처중요도/4-1_피처중요도.md) · 피처 목록 [4-2](../4_피처/아카이브/4-2_피처목록/4-2_피처목록.md)

### 5단계 모델 비교 — 모델보다 입력 정보가 병목
- SVM, 튜닝, 모델 8종 스크리닝, 신경망(MLP)까지 바꿔 봤지만 같은 고장을 놓쳤다 → **문제는 경계 모양이 아니라 정보 부족**이었고, 점수를 올린 것은 EDA에서 찾은 물리 규칙이었다
- 점수를 올린 실험(유의미)만 보면 된다

| 실험 | F2 | 한 줄 |
|---|---|---|
| [EXP-012 스펙트럼 AE](../5_모델실험/1_첫베이스/EXP-012_스펙트럼AE_tSNE/README.md) | 0.832 | 정상만 학습해 "정상 스펙트럼에서 벗어난 정도"를 잰다 |
| [EXP-014 AE + ET 결합](../5_모델실험/1_첫베이스/EXP-014_ET·AE결합/README.md) | 0.857 | 두 점수를 정상 기준 z로 바꿔 로지스틱으로 합침 |
| [EXP-021 8.3 kHz 규칙](../5_모델실험/2_규칙발견/EXP-021_8k모드규칙/README.md) | 0.892 | 2단계 발견 1을 규칙으로 |
| [EXP-025 유격 반복 규칙](../5_모델실험/2_규칙발견/EXP-025_유격반복규칙/README.md) | **0.942** | 2단계 발견 2를 규칙으로 → **최종 구성** |
| [EXP-030 최종 고정 · 규칙 감사](../5_모델실험/아카이브/EXP-030_1116_최종후보고정_규칙감사/README.md) | 0.942 | 규칙을 더 넣으면 0.978까지 오르지만 이득이 파일 3개에 몰려 있어 넣지 않음 |

### 6단계 오류 분석 — 왜 틀리나
- 고장 30개 중 **20개는 쉽다** (두 모델 모두 정상 범위 밖). 나머지 10개가 정상과 겹친다
- 정상을 고장으로 잘못 보는 원인은 5유형인데, 최종 모델의 오경보는 대부분 **"큰 타격이 한 번 있는 정상"**(025 · 116 · 055)이다
- 두 모델이 재지 못하는 것 = 타격의 **반복성 · 울리는 주파수 · 발생 시점**. 남은 오류는 모두 여기서 나온다 → 발표 "05 한계"의 근거
- 근거: [6-1 유형별 정상·고장 구분](../6_오류분석/아카이브/6-1_1116_유형별_정상고장_구분/6-1_유형별_정상고장_구분.md) (텐션암 부품·하중 경로 설명도 1절에 있다)
