# 4-8 모드지도 (라벨 없이): 옛 대역 경계는 구조인가, 라벨 맞춤인가

## 목적
옛 경계(2–4k · 5.5–7.75k 본체 · 8.0–8.6k 고장 모드 · 9.25–10k)가 라벨 없는 데이터에서 복원되는 구조(도메인 지식)인지, 라벨에 맞춰 고른 것(사후 조정)인지 가른다.

## 답할 질문
1. 충격 울림 주파수 분포(train 150 + val 40, 1503개)에서 라벨 없이 모드 봉우리·골짜기가 보이는가?
2. 8.0–8.6k(고장 abn_002 8.25k)와 9.4k(정상 nor_116)는 서로 다른 대역인가?
3. 새 충격 정의의 충격 정렬 평균(f, ζ)은 신뢰할 만한가 (홀/짝 분할)?

## 방법
- 충격 = `src/impacts.py` (합계 정상 854 · val 247 · 고장 402 확인). 울림 f = `impact_rings_v2`(250 Hz 격자).
- **사전 규칙(라벨 보기 전 고정)**: 가우시안 KDE, 폭 Scott(0.5·2배 민감도), 봉우리 = 최대 밀도의 10% 이상 prominence, 경계 = 인접 봉우리 사이 최저점. 균등/fit 가중 둘 다.
- **탐색 규칙(사전 규칙 밖, 별도 표기)**: 폭 0.3×Scott · prominence 0.03 (및 0.015). 이 규칙은 사전 규칙이 약해서 추가했고, 이미 abn_002·nor_116 위치를 본 뒤에 만든 것이다. 확인용이지 증거가 아니다.
- 정렬 평균: 새 충격 idx를 ±1 ms 미세 정렬 → 극성 맞춤 → −2…+20 ms 평균 → 감쇠 사인 f·ζ. 대용 = 위상 무작위(5회), 새 정의는 대용에서 충격을 못 찾으므로 같은 개수의 상위 봉우리를 강제로 뽑아 R = 실제/대용 p2p.
- 라벨은 대역 확정 뒤 보고에만 사용.

## 결과
| 구분 | 경계 / 봉우리 (kHz) |
|---|---|
| 사전 규칙 (6개 설정 모두) | 봉우리 1.8–1.9 · 6.9–7.1 / **골짜기 3.6–3.9 하나뿐** |
| 탐색 (0.3×, prom 0.03) | 봉우리 1.25 · 1.96 · 5.0 · 7.14 · 8.26 / 골짜기 1.52 · 3.51 · 5.41 · **7.96** |
| 탐색 (0.3×, prom 0.015) | 봉우리 …8.26 · 9.46 · 10.25 / 골짜기 …7.96 · **8.68** · 9.89 |
| 옛 경계 | 2–4 · 5.5–7.75 · 8.0–8.6 · 9.25–10 |

- 사전 규칙은 옛 경계 중 **약 3.8k(옛 2–4k의 위쪽 경계 4.0k와 0.2k 차)만 복원**한다. 5.5–7.75k는 봉우리가 6.9–7.1k 하나로 넓게 보이고(단일 골짜기 없음) 8k 이상은 봉우리 규칙을 통과하지 못한다.
- 250 Hz 격자 히스토그램: 7.0–7.5k 폭발(413), 8.25k 28개(이웃 4·6), 9.5k 15개(이웃 7·4). 탐색 규칙의 7.96k 골짜기는 옛 8.0k와 일치, 5.41k는 옛 5.5k와 0.1k 차, 8.68k는 옛 8.6k와 0.08k 차, 9.89k는 옛 10k와 0.1k 차.
- 8.28k 대 9.4k: 사전 규칙에서는 **같은 대역**(둘 다 3.8k 이상). 탐색 prom 0.015에서만 8.68k 골짜기로 분리. 모든 설정 6개에서 사전 규칙은 분리하지 못함.
- 라벨(보고용): 8.0–8.5k 충격이 있는 파일 9개 = 고장 7·정상 2(nor_019, nor_092, val 0), 9.25–9.75k 10개 = 고장 8·정상 2(nor_043, nor_116, val 0). 즉 두 대역 모두 대부분 고장. nor_055는 9.4k가 아니라 6.0k다 (질문 전제와 다름).
- 정렬 평균 분할 신뢰도 (충격 ≥4, 104파일): f Spearman **0.78**, ζ **0.43** (충격 ≥6: 0.81/0.46, ≥8: 0.81/0.46). 정렬 f와 개별 충격 f 중앙값 0.83. R 중앙값 정상 2.8 · 고장 3.1 · val 3.3.
- 충격 1개 파일: 정상 12, 고장 0, val 7 (0개: 정상 17, val 4). 평균 이득 없음.
- val 이동: 본체 대역(5.41–7.96k) 울림 비율 val 중앙값 0.31 vs 정상 1.0, 최대 fit 0 vs 0.65 (약 −1.7 sd). 7.96k 이상 val 충격은 2개뿐.

## 해석
- 라벨 없이 **안정적으로 복원되는 구조는 두 군집(약 2 kHz 낮은 모드, 약 7 kHz 본체 모드)과 경계 3.5–3.9k**다. 8.3k와 9.5k 대역은 소수 파일의 좁은 스파이크라서 사전 규칙으로는 나오지 않는다. 폭을 격자 수준(174 Hz)으로 줄이면 8.26k 봉우리와 7.96k 골짜기가 보이지만 이 격자가 250 Hz 불연속이라 히스토그램 자체와 다르지 않다.
- 결론: 3.8k · (5.4k) · 8.0k 경계는 구조와 맞지만, 8.0–8.6k를 "고장 모드"라 부르는 것과 9.25–10k를 별도 대역으로 두는 것은 라벨 없는 증거로 지지되지 않는다(표본이 적고 대부분 고장 파일에서 나옴 = 라벨과 겹친 관찰). 8.3k와 9.4k를 가르는 근거는 약하다(8.68k 골짜기, 가장 약한 규칙에서만).
- 정렬 평균 f는 쓸 만하지만(0.78) ζ는 약하다(0.43). 충격이 적은 파일에서는 효과 없음.

## 개념
- KDE(커널 밀도 추정): 점을 가우시안 언덕으로 겹쳐 연속 분포를 만든다. 폭이 좁을수록 봉우리가 많아지지만 우연도 늘어난다.
- Scott 폭: 표본 수만으로 정하는 기본 폭. 라벨 없이 쓸 수 있는 객관적 기준.
- 정렬 평균(TSA): 충격 시점을 맞춰 평균하면 비동기 잡음이 줄고 반복되는 울림만 남는다.
- 분할 신뢰도: 홀수/짝수 충격으로 따로 구한 값이 일치하면 측정이 안정적.
