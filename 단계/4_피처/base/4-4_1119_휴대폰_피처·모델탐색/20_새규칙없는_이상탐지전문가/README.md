# 20. 정상만 학습하는 이상 탐지(LOF · kNN) 전문가 — 017 · 022를 가를 새 정보원이 되는가

## 동기
EXP-023 기록: 017은 정상만 학습한 MiniRocket LOF 0.99 · iforest 0.99 · kNN 0.98로 잘 갈리나 AE는 0.44였다. 정상 기준 거리(novelty)는 AE(스펙트럼 모양)와 다른 정보를 줄 수 있다고 보고, D+ 81열 공간에서 폴드 안(학습 정상만)으로 LOF · kNN 이상 점수를 만들어 (1) 파일별 백분위, (2) 세 번째 전문가로 스택에 넣은 중첩 CV를 확인했다.

## 해석 · 판정
**C (기각).** 017만을 가르는 정보원(LOF)은 존재하지만 오경보 정상(116 등)과 구별되지 않아 순효과가 음이다. 그리고 **022는 지금까지 만든 모든 파일 단위 전문가에서 정상 분포 안에 있다**: AE z 0.3, ET · LR 점수 평범, LOF · kNN 백분위 0.35–0.49, t-SNE 이웃 고장 비율 0.00, ΔPSD · 스펙트럼 첨도 · PSD 기울기 · 잔차에서 정상 범위. 이는 "022를 가를 파일 단위 정보가 이 피처들에는 없다"는 강한 정황 증거다(충격 단위 구조(2.0 kHz 울림)는 정상 14%와도 겹침).
