## 목적
new_단계에서 확정한 이벤트 5피처([2-6](../../../아카이브/new_단계/2_EDA/2-6_바닥보정·이동·기준ET/README.md) 정의)를 최종 모델 **EXP-062 구성 3**(J-축소 + K83 + 11 kHz 상한, 중첩 F2 0.971 ± 0.022)에 더하면 도움이 될 가능성이 있는지 본다. **실험(중첩 CV)은 하지 않았다.** 판단 자료만 만든다.

## 방법
- 피처 값: [3-4](../../../3_전처리/3-4_검출기대역통과/README.md)의 1–11 kHz 대역통과 검출기 입력 버전(`events_190_bp11k.csv`, EXP-062와 같은 상한). `feats_bp11k.csv`와 값이 같은지 확인했다(같음). F5는 이름대로 하한 보정: 바탕 = max(바탕, b_floor), b_floor = Train 150 파일 바탕 중앙값의 하위 20 %(0.0044 g, 라벨 없이).
- EXP-062 결합 여유: result.json에 파일별 점수가 없어, 같은 모델(`JShrink`, `jtab_train_11k` 캐시)을 **단일 바깥 5겹**(StratifiedGroupKFold seed 0, 097 · 101 · 120 한 그룹)으로 한 번 돌려 OOF 여유를 얻었다. 중첩 CV가 아니다. 이 분할의 F2 0.927, 놓친 고장 abn_021 · 028, 오경보 nor_055 · 059 · 116(EXP-062 오류 표와 같은 파일들). val 여유는 Train 150 전체 학습 모델.
- 관문 ①–⑤는 4-20과 같은 값으로 계산 전에 정했다. ⑥ 증분 가치 기준도 계산 전에 run.py 머리에 적었다: 여유만 쓴 로지스틱 대비 (여유 + 피처)의 LOO 로그손실 변화 ΔLL을 전체 150과 규칙(E2/8.3k) 켜진 10개를 뺀 140에서 보고, **둘 다 < −0.005이고 부분 Spearman ρ(여유 통제) > 0.1이면 "있음"**, 하나만이면 "약함".
- 라벨을 본 탐색이다. 대역 · 문턱은 여기서 고르지 않았다(대역은 2-6에서 이미 고정).

## 해석과 판정
- **cnt_low만 증분 기준을 넘는다.** 여유가 0 근처인 고장(021 · 022 · 009)에서 정상 96–98 %이고, 오경보 정상 ◆ 059 · 065 · 116 · 055는 값이 0(1.6–4.5 kHz 이벤트 없음)이라 오히려 정상 쪽으로 당긴다. 위험은 경계 정상 nor_037(96 %)과 nor_016(81 %). 관문 ⑤ 미통과는 남는다.
- ratio_off · off_max는 단독 AUC는 가장 높지만, off에 8–11 kHz 이벤트가 섞여 오경보 정상 059 · 065 · 116을 같이 끌어올린다. 여유를 통제하면 규칙 뺀 집합에서 증분이 사라진다(이미 모델이 가진 정보).
- cnt_high는 8–11 kHz 신호가 이미 H10 · E2 · 8.3k 규칙과 4-19 max_8_11k에 있고, 이상치 059가 정상 99 % 위다.
- cnt_total은 H1_nimp(충격 수)와 사실상 같은 열이다(ρ 0.96). 증분 수치가 나왔지만 새 정보가 아니라 같은 양의 다른 검출 방식이라 중복으로 둔다.
- **EXP-062에 넣어 볼 후보 = F1 cnt_low 하나.** 다음 실험: JShrink `cols = J_FIXED + cnt_low`(2-7 방식 25 ms 이벤트 · 50 Hz 사전, 1–11 kHz 입력)를 구성 3과 같은 분할 quick 중첩 CV로 비교. 오류 표에서 abn_021 · 022 회수와 nor_037 · 016 오경보 증가를 같이 본다. 차선으로 ratio_off를 같은 방식으로 따로.

## 한계
- 라벨을 본 탐색이고, 같은 150개에서 증분을 쟀다. 증분 기준 −0.005 · 0.1은 계산 전에 정한 값이지만 근거 있는 표준값은 아니다.
- OOF 여유는 단일 분할 · seed 0이다(중첩 5 seed가 아님). EXP-062 F2 0.971과 이 분할 0.927은 다르다.
- 이벤트 검출(2-7: 25 ms 묶음 · 50 Hz 사전)은 EXP-062 J 표의 충격 검출(`all_impacts`, 250 Hz 사전, 하나씩)과 다르다. 넣는다면 제출 파이프라인에도 이 검출을 그대로 옮겨야 한다.
