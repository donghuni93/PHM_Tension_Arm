# 4-20 1–5 kHz(연결부 대역) 피처 후보 C1–C4 EDA (11-25)

동기: 최종 모델(EXP-062 구성 3) 입력에 1–5 kHz를 맡는 열이 적다([피처후보_목록](../../후보/README.md) P1–P3, 요약 [4-6](../README.md)). 고장 충격은 연결부(1.6–4.5 kHz)로 울고 정상 충격은 본체(5.5–8 kHz)로 운다(H1, 2-7).
- 정의는 라벨을 보기 전에 고정했다: `src/features2.py band15_table` (대역 = 모드 경계 1.6–4.5 · 5.5–8 kHz, 옥타브 2–4 kHz, WPD 3단계 경계 1.5625 kHz). 모두 무차원.
- 충격 = 최종 모델과 같은 `all_impacts(fmax=11000)`. 충격 없는 파일: 정상 17 · 고장 0 · val 4 → 충격 구간 몫(C3_imp) = −1, 충격 대 배경 비(C4) = 0(대비 없음).
- PyWavelets가 설치되어 있지 않아 C3은 **같은 경계의 FFT 대역 분할**로 계산했다(WPD 필터의 대역 누설은 없다).
- 코드 [run.py](자료/run.py) (하위 폴더 넷에 결과를 쓴다) · 요약 [figs/관문.csv](자료/figs/관문.csv) · [figs/관문.txt](자료/figs/관문.txt) · 후보끼리 ρ [figs/후보끼리_rho.csv](자료/figs/후보끼리_rho.csv)

## 공통 방법
- AUC(고장 > 정상, 방향은 가설로 미리 고정) + 2000번 부트스트랩 95 % CI. 꼬리 = 정상 99 %를 넘는 고장 · 고장 10 % 선을 넘는 정상.
- val 이동 = AUC(val vs 학습 정상)를 "학습 정상 + 고장 0 · 20 · 40 % 섞어 n = 40으로 재추출"한 AUC 90 % 범위와 비교(4-19와 같음).
- 하중 ρ = 정상에서 Spearman(피처, 0–20 Hz RMS). 중복 = 학습 150에서 J 입력(`j_tables(fmax=11000)` H 13열 + 봉우리 H16 · H17 + L1_lock)과의 최대 |ρ|.
- 반쪽 안정성 = 앞 1초 vs 뒤 1초로 따로 계산(충격은 전체 파일 검출을 나눠 씀), 정상 120에서 Spearman ρ.

## 관문 (계산 전에 고정)
1. AUC 95 % CI 하한 > 0.6
2. 기존 J 열과 max |ρ| < 0.8
3. val 이동 AUC가 고장 0–40 % 섞음 기준 범위 안
4. 오경보 정상 059 · 065 · 116 · 095 · 110이 정상 99 % 위로 가지 않음
5. 반쪽 ρ(정상) ≥ 0.5

## 해석
1. **분리력이 있는 열은 모두 H3(첨도 1–2k)와 같은 "뾰족함" 축이다.** C1 첨도 · H4 · C2 TKEO · C4 충격 대 배경 비는 서로 ρ 0.55–0.97, H3과 0.69–0.88. 1–5 kHz를 새로 맡는다기보다 이미 있는 H3 정보를 다른 대역에서 다시 잰다.
2. **반쪽 안정성(관문 5)에서 거의 다 떨어진다.** 정상은 충격이 드물어(17개는 0개) 1초 안에 충격이 있느냐에 따라 값이 바뀐다. 이미 J에 있는 같은 종류 열(H4, H3과 같은 식)도 0.17이라, 이 관문은 충격 기반 열에 엄격하다. 통과한 것은 전체 파일 몫(C3_all)뿐이고, 그것은 분리력이 없거나(w1) val에서 넘친다(w2, 3–5 kHz 배경 +6 dB 그대로).
3. **대비(연결부 ÷ 본체)는 기대보다 약하다**(AUC 0.64–0.68). 본체 첨도가 정상에서도 낮지 않다(강타형 정상은 두 대역 다 높음).
4. **C4(충격 대 배경 비)는 설계대로 val 이동이 없다**(0.55–0.56, 0 % 범위 안). 꼬리 증거도 가장 넓다(고장 8–10개가 정상 99 % 위, 021 포함). 다만 반쪽 ρ ≈ 0, H3과 0.73.
5. abn_021은 C2 · C3_w2 · C4에서 98 백분위, abn_028은 C1_kenv 100 · H4 98 백분위. 오경보 정상 065 · 116은 C1 · H4 · C4에서 90–96 백분위로 같이 올라간다.
