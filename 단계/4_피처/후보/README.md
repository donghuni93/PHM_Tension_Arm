# 추가할 피처 후보 목록 (11-25 시작)

기준 모델 J-축소 + K83에 **더할** 물리 피처 후보를 모아 두고, 하나씩 검토 → EDA → 추가 여부를 정한다. EXP-064(H2 → D_K1, H16 · H17 · H13 · H7 빼기)는 이 검토 뒤로 **보류**(사용자 11-25).
- 동기: 지금 입력에서 **1–5 kHz(연결부 대역)를 맡는 열이 적다**. 있는 것은 H3 첨도 1–2k · H7 울림 1–2k(약함) · H8 울림 2–4k · H12 · H13 몫(H13은 val 넘침). 2–4 kHz 첨도 H4는 계산은 되지만 J에 안 들어 있다.
- 관문(결정.md 11-23 · 24): 더하기만 · 물리가설 H 번호 · 크기 무관 · 라벨로 대역 · 문턱을 고르지 않음 · val 이동 점검(특히 val 3–5 kHz 배경 +6 dB, [new 2-8](../../아카이브/new_단계/2_EDA/2-8_val배경이동_원인/README.md)) · 기존 열과 |ρ| < 0.8 · 헷갈리는 파일 기여.
- AE: 있으면 좋지만 최종 목표는 AE 없이 구분. AE 검증은 후순위(AE가 경계를 바꾸는 경우만 먼저 본다).

## 검토 (EDA 전)
### P1 대역 포락선 첨도 대비
- 원리: 정상 충격은 본체 모드(5.5–8 kHz)로 울리고 고장 충격은 연결부(1.6–4.5) · 고주파(8–11)로 운다(2-7 · new 2-2). 대역 포락선 첨도를 "비정상 대역"과 "본체 대역"에서 같이 재면, 정상 충격 파일(055 · 116)은 둘 다 높고 고장은 비정상 대역만 높다.
- 장점: 검출기 문턱(4.5배)을 쓰지 않는 연속값, 무차원. 1–5 kHz를 직접 맡는다.
- 주의
  - 대역 경계 1.6 · 4.5 · 5.5 · 8 kHz는 2-14 모드 골짜기(라벨 없이)에서 왔지만 **4.5 kHz 골짜기는 new 2-4에서 재현되지 않았다**(3.75 · 5.35 kHz). 옥타브(2–4 kHz, H4)나 WPD 경계(P3)와 같이 비교한다.
  - 이름: Antoni의 "스펙트럼 첨도(SK)"는 주파수별 첨도 곡선이고, 여기 제안은 "대역 포락선 첨도"다. 이전 시도 PHO-002(커토그램, 0.968 → 0.965)는 개선 없음 — 그때는 대비(비율)가 아니라 최대 첨도 대역을 썼다.
  - 기존 H3 · H5(옥타브 첨도), H8(울림 비율)과 겹칠 수 있다(|ρ| 확인).
  - val 배경 +6 dB(3–5 kHz)는 첨도의 분모(바탕)를 키워 연결부 첨도를 낮춘다 → val 이동 확인 필수.
### P2 TKEO 파고율
- 원리: Ψ[x] = x(n)² − x(n−1)x(n+1) ≈ A²ω². 저주파를 누르고 순간 울림을 키운다. 대역별 Ψ의 P99/P50은 약한 충격(문턱 미달)도 연속값으로 잡는다.
- 주의
  - 대역통과 뒤 TKEO를 쓰면 ω 가중은 대역 안에서만 작다 → 사실상 "대역 순간 에너지의 꼬리 비"이고 P1(포락선 첨도)과 같은 정보일 가능성이 크다. EDA에서 P1과의 ρ를 먼저 본다.
  - 2-21(아카이브, 뾰족함 지표 중복): 첨도 · 파고율 · 충격계수류는 서로 중복이었다.
  - "abn_016 · 028 같은 약한 고장을 잡는다"는 가정이다. 028은 저주파형(0–200 Hz 몫 0.98)이라 고주파 TKEO로 잡힐지 의문, 016은 11 kHz 위 성분이 바탕을 끌어올린 파일(new 2-7)이라 11 kHz 상한 뒤 다시 봐야 한다.
### P3 WPD 3단계 상대 에너지
- 원리: 0–12.5 kHz를 1.5625 kHz 폭 8칸으로 나눈다. 경계가 수학적(2의 거듭제곱)이라 라벨 누수 논란이 없다. Band 1–2(1.56–4.69 kHz)가 연결부, Band 4(6.25–7.81)가 본체, Band 5–6(7.81–10.94)이 고주파와 맞는다.
- 주의
  - WPD 노드 순서는 주파수 순서가 아니다(Paley 순서 → 그레이 코드로 다시 정렬해야 함). db4 · sym4 필터는 대역 경계에서 새는 양이 커서, 실제 대역은 FFT 대역 분할보다 흐리다. 같은 경계의 FFT(Welch) 대역 몫과 비교해 이득이 있는지 본다.
  - **상대 에너지(몫)는 지금 H12–H15(옥타브 몫)와 같은 종류**다. 4-18에서 몫 열은 val 3–5 kHz 배경 이동에 흔들렸다(H13 넘침). 파일 전체 에너지 대신 **충격 구간(이벤트 전후)만의 몫**으로 계산하는 변형을 같이 본다.
  - Band 7(10.94–12.5)은 11 kHz 상한으로 버린다. Band 0(0–1.56)도 1 kHz 하한과 맞지 않아 뺀다.
### P4 스펙트럼 엔트로피 · 중심
- 원리: 정상은 본체 모드 한곳에 에너지가 모여 엔트로피가 낮고, 고장은 흩어져 높다. 중심(centroid)은 이동한다.
- 주의
  - 제안의 "검출 문턱을 안 쓰니 val에서 흔들리지 않는다"는 **맞지 않는다**. 엔트로피 · 중심은 파일 전체 PSD 모양이라 val 3–5 kHz +6 dB · 6.5–7.5 kHz −3.8 dB 배경 재분배를 그대로 받는다(중심은 낮아지고 엔트로피는 오른다 → 고장 쪽으로 이동할 위험).
  - 충격 구간 PSD로 계산하는 변형만 의미가 있다. 그러면 H7–H10(울림 비율)과 겹칠 가능성이 크다.
  - 1–5 kHz를 직접 맡지는 않는다.

## EDA 순서 제안
P1(+ H4) → P2(P1과 중복 확인) → P3(전체 vs 충격 구간 몫) → P4(충격 구간 변형만). 각 EDA = 분포(정상 · 고장 · val) · 분리도(AUC, CI) · val 이동(고장 섞음 기준) · 하중 ρ · 기존 열과 |ρ| · 헷갈리는 파일(059 · 065 · 116 · 025 / 002 · 014 · 016 · 017 · 028) · 1–5 kHz 기여. 결과에 따라 이 표의 상태를 "추가 후보 확정 / 기각"으로 바꾼다.
