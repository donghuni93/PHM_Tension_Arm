## 개념 (예전 notes/개념/에서 옮김)

### 신호 변환: FFT · 대역 분할 · Bandpass · 포락선 · STFT · 웨이블릿


#### 한 줄 정의
특징을 뽑기 전에 신호를 "어느 주파수에 에너지가 있는가(FFT)", "그 대역만 남기면 어떤가(Bandpass)", "언제 튀었는가(STFT·포락선)"의 공간으로 바꾸는 단계다.

#### FFT 기본값 (이 데이터)
- $f_s$ = 25,000 Hz → 나이퀴스트 12,500 Hz
- 2초 전체 FFT 분해능 $\Delta f = 1/T$ = 0.5 Hz
- 공진 피크 이동 측정은 해상도가 가장 높은 전체 FFT가 맞다

#### 대역 분할 (원문 4.3)
| 방식 | 방법 | 언제 |
|---|---|---|
| 균등 분할 | 0–12.5 kHz를 10개(1.25 kHz) 또는 20개(625 Hz)로 등분, 구간 에너지 = 진폭 제곱합 | 도메인 지식이 불확실할 때 베이스라인 |
| 물리적 분할 | 저주파(본체 거동) / 중주파(부싱 고유 진동) / 고주파(유격 금속 타격). 예 0–2k / 2k–5k / 5k–12.5k | 물리 의미를 담고 싶을 때 |
- 둘 다 피처로 함께 쓸 수 있음. 경계는 예시, 실제 경계는 정상 vs 고장 FFT로 정함

#### Bandpass 필터와 필터 후 특징 (원문 4.4)
- 배경: 저주파에 가진기 자체 진동처럼 큰 에너지가 섞이면 원본 전체 첨도·Peak가 거기 묻혀 고주파 충격을 반영하지 못함
- 절차: 정상·고장 FFT 비교 → 고장에서 솟는 대역(예 3–5 kHz) → `scipy.signal.butter`로 그 대역만 통과
- 필터 후 피처: 대역 내 총 에너지, Filtered RMS·Peak·첨도·파고율
- 핵심: 다른 대역의 큰 진동을 걷어내면 숨은 충격 펄스가 뚜렷해짐. 정보를 버리는 것이 아니라 열을 **추가**

#### 스펙트럼 첨도와 커토그램 (원문 2.2, 논문 Antoni 2006·2007)
- 스펙트럼 첨도(SK): 주파수별로 시간 축 첨도를 계산 → 과도 충격이 **어느 주파수에** 있는지 알려줌. PSD는 비정상성 정보를 지우지만 SK는 남김
- 커토그램: (중심 주파수, 대역폭) 격자에서 첨도가 최대인 대역을 찾음 → 그 대역 Bandpass → 힐베르트 포락선
- 이 프로젝트 의미: Bandpass 대역을 사람이 아닌 데이터 규칙으로 고름. 단 **폴드 안에서** 골라야 누수 없음 (옛 결정 D4)

#### 고급 신호처리 (원문 4.5)
| 기법 | 원리 | 효과 |
|---|---|---|
| 포락선 (Hilbert) | 고주파 반송파는 무시하고 충격 윤곽선만 추출 | 노이즈에 묻힌 간헐 충격('찌그덕')을 저주파 윤곽으로 분리 |
| 웨이블릿 디노이징 | 다해상도로 쪼개 백색 잡음 계수를 임계값으로 깎음 | 일시적 충격만 복원. FFT가 잃는 "언제"를 유지 |
| 웨이블릿 패킷 분해(WPD) | 고·저주파를 반복 분할하는 필터 뱅크, 노드 에너지 = 피처 | Bandpass보다 정교한 분리 (원문 주장) |
| 교차 상관 | 좌/우 센서 위상차·유사도 | 단일 센서라 적용 불가 |
| EMD | 데이터 스스로 IMF로 분해, 컷오프 지정 불필요 | 저주파 꿀렁임과 고주파 타격을 분리 |
| 켑스트럼 | 스펙트럼의 스펙트럼 | 등간격 고조파를 하나의 피크로 압축 |

#### 시간-주파수 이미지 (원문 4.6)
**STFT 스펙트로그램**: 짧은 창마다 FFT → 시간(x)·주파수(y)·에너지(색)

$$\Delta f=\frac{f_s}{N_w},\qquad \Delta t=\frac{N_w}{f_s}$$

- $N_w$ = 1,024 → Δf ≈ 24.4 Hz, Δt ≈ 41 ms / $N_w$ = 1,250 (0.05초) → 20 Hz, 50 ms
- 창을 키우면 주파수 정밀·시간 뭉개짐, 줄이면 반대

| 경로 | 스펙트로그램 이후 | 단계 |
|---|---|---|
| A 탐색 | 정상 vs 고장 이미지 비교 → 결함 대역·시점 | EDA |
| B 특징 | 시간 축 요약(대역별 에너지의 최댓값·표준편차·첨도) | 특징 추출 |
| C 이미지 입력 | CNN에 투입 | 모델링 |

| 다른 이미지 변환 | 방식 | 비고 |
|---|---|---|
| CWT 스캘로그램 | 고주파는 좁게, 저주파는 넓게 보는 가변 창 | 불규칙 충격에 더 정밀 |
| GAF | 극좌표로 옮겨 시간 상관을 2D 행렬로 | 50,000점이면 25억 칸 → PAA·다운샘플 필수 |

- 권장(원문): A로 대역·시점 확인 → 4.3·4.4 기준으로 사용, B는 필요 시. C는 150개로는 과적합 위험, 발표 「개선 방향」 정도

#### 주의 (정리자)
- Bandpass 대역은 EDA 이후에 정함. 그 전엔 균등 분할 베이스라인
- **EDA로 고른 대역을 전체 데이터 CV에 쓰면 누수**: 대역 선택도 학습 폴드 안에서
- EMD: 모드 혼합, 파일마다 IMF 개수가 달라 앞쪽 몇 개만 쓰는 규칙 필요
- WPD: 웨이블릿 종류·레벨 결정 부담, 노드 수만큼 피처 증가
- 켑스트럼: 호흡 균열 고조파($2f_0, 3f_0$)가 하나의 피크로 모일 수 있음. 단 $f_0$ 미상 (D1)

#### 확인 질문
1. 전체 첨도는 평범한데 1.25–2.5 kHz Bandpass 후 첨도가 크게 튀는 상황을 파형으로 그려 설명하라
2. 포락선 분석이 "고주파 반송파 + 저주파 충격 변조" 구조를 가정하는 이유는
3. STFT 창 1024에서 1.25 kHz 대역 1칸에는 주파수 빈이 몇 개 들어가는가

### 특징 추출: 50,000점 → 피처 벡터


#### 한 줄 정의
1차원 진동 50,000점을 물리 의미가 있는 숫자 N개로 압축해 **150행 × N열** 표로 만드는 단계. PHM에서는 이 압축 과정 자체가 피처 엔지니어링의 핵심이다 (원문 3장).

피처 id·구현 상태(core/확장/후보/제외)는 `src/features.py`가 원본이다. 이 노트는 **각 피처가 물리적으로 무엇을 잡는가**를 정리한다.

#### 시간 영역 (원문 2.1)
| 특징 | 식 | 물리 의미 | 결함 매핑 |
|---|---|---|---|
| RMS | $\sqrt{\sum x_i^2/N}$ | 전체 진동 에너지 | 감쇠 저하 → 상승(경화·노후). 간헐 충격에는 둔감 |
| Peak | $\max\lvert x_i\rvert$ | 순간 최대 가속도 | 금속 타격, 구조 간섭 |
| 첨도 | $E[(x-\mu)^4]/\sigma^4$ | 분포 꼬리 두께, 충격성 | 박리·초기 균열의 간헐 충격 |
| 파고율 | Peak / RMS | 기본 진동 대비 충격이 얼마나 튀었나 | 초기 미세 결함. 무차원이라 가진 크기에 덜 민감 |
| 왜도 | 3차 모멘트 | 비대칭. 정상 ≈ 0 | 한쪽으로 쏠린 마찰·충격 |
| Hjorth Mobility / Complexity | $\sqrt{\mathrm{var}(x')/\mathrm{var}(x)}$, $\mathrm{Mob}(x')/\mathrm{Mob}(x)$ | 정현파에서 벗어난 정도 | 비선형 거동, FFT 없이 포착 |
| TKEO | $\Psi[x(n)]=x(n)^2-x(n-1)x(n+1)$ | 순간 에너지(진폭² × 주파수²에 비례) | 미세한 금속성 타격 강조 |
| ZCR | 부호가 바뀌는 비율 | 주파수가 높고 불규칙할수록 증가 | 고주파 마찰 |

**형상 지표 (서로 정의로 얽혀 있음)**

| 지표 | 식 |
|---|---|
| 파고율 Crest | Peak / RMS |
| 충격 계수 Impulse | Peak / MAV |
| 형상 계수 Shape | RMS / MAV |
| 여유 계수 Clearance | $\text{Peak}\big/\left(\frac{1}{N}\sum\sqrt{\lvert x_i\rvert}\right)^2$ |

- 첨도 기준: 가우시안 = 3. 결함 시 7–10 이상은 경험적 예시일 뿐. **순수 정현파의 첨도는 1.5** (원문의 "≈ 3"은 오류)

#### 주파수 영역 (원문 2.2)
| 특징 | 물리 의미 | 결함 매핑 |
|---|---|---|
| 공진 이동 $f_{shift}=f_{peak,sample}-f_{peak,baseline}$ | 유효 강성 변화. 기준선 = 정상 평균 스펙트럼 | + 경화, − 박리·균열 |
| 고조파 에너지 비율 $(E(2f_0)+E(3f_0))/E_{total}$ | 이선형 비선형 왜곡 | 본체 호흡 균열. $f_0$ 필요 |
| 대역 에너지 | 구간별 진폭 제곱합 | 고장 시 고주파 특정 구간 상승 |
| 대표 주파수 상위 3–5개와 진폭 | 공진 위치 자체 | 강성 변화로 인한 이동 |
| 스펙트럼 중심 $f_c=\sum f_k\lvert X_k\rvert/\sum\lvert X_k\rvert$ | 스펙트럼 무게중심 | 유격 마찰음 → 고주파로 쏠림 |
| Bandwidth $\sqrt{\sum(f_k-f_c)^2P_k/\sum P_k}$ | 중심 주변 퍼짐 | |
| Roll-off 85%·95% | 누적 에너지 도달 주파수 | 고주파로 퍼진 정도 |
| 스펙트럼 엔트로피 | 스펙트럼의 평탄함 | 광대역 노이즈 증가 |
| 스펙트럼 첨도·커토그램 | 충격이 몰린 대역 | → 4단계 신호 변환 |

- 고조파: 선형 시스템은 가진 주파수에만 응답. 균열·유격 같은 비선형이 있으면 파형이 찌그러져 정수배 성분이 생김

#### 윈도우(구간) 통계 (원문 2.6, 특화 설계안)
- 고장(유격)은 특정 순간에만 진폭이 커지는 **비정상(non-stationary)** 신호 → 2초 전체 통계에 묻힘
- 5–10개 서브윈도우(0.1–0.5초)로 나눈 뒤 파일당 1행을 유지하며 요약: 윈도우 RMS의 표준편차, Max-to-Mean RMS, 윈도우 첨도 최댓값, ZCR 변동성
- 증강 슬라이싱(조각을 별도 샘플로)과 다르다 → 3단계 증강

#### 자기상관(ACF) 피처 (원문 2.6)
- 특정 지연의 ACF 값, 처음 0이 되는 지연, 감쇠율 등
- 주의 (정리자): ACF와 PSD는 푸리에 변환 쌍(Wiener–Khinchin)이라 주파수 피처와 정보가 상당히 겹침

#### 후보 피처 그룹 (원문 5장)
| 그룹 | 예시 | 잡는 결함 특성 |
|---|---|---|
| 시간 기본 통계 | Mean, Std, RMS, Peak, P2P, MAV | 전반적 에너지 증가, 헐거움 |
| 시간 형상 지표 | 첨도, 왜도, 파고율, 충격·형상·여유 계수 | 짧고 날카로운 충격 |
| 주파수 | 중심, 엔트로피, 스펙트럼 첨도, 상위 N개 피크 | 공진, 주기적 결함 성분 |
| 대역 에너지 | 8–16개 등분 대역 에너지 비율 | 결함 진행에 따른 에너지 분포 이동 |
| 포락선 | 힐베르트 후 RMS·첨도·피크 | 고주파 공진에 실린 반복 충격 |
| TKEO | Mean, Max, Kurtosis, Energy | 금속성 타격(Rattle) |
| 비정상성 | 윈도우 통계 6–8개 | 순간 '딱' 치는 유격 |
| 다축 | 축별 에너지 비율, 축간 상관 | 3축일 때만 → **이 데이터 제외** |

#### 주의 (정리자)
- 평균 제거 후 Mean ≈ 0, Std = RMS → Mean은 원본에서 따로, Std는 제외 (D7)
- RMS·MAV·Peak·P2P와 형상 지표는 정의로 얽혀 상관이 높음 → 4단계 특징 선택
- 에너지 **비율**은 합이 1이라 절대 크기 정보가 사라짐 → 절대 에너지도 함께 비교 (D6)
- 포락선은 보통 공진 대역을 Bandpass로 거른 뒤 만든다
- TKEO는 고주파에 민감해 MA가 강하면 약해짐 (MA 미적용으로 해결, 3단계 전처리)
- val·test에도 같은 조건으로 추출

### 특징 선택: 상관 · VIF · 폴드 안 선택


#### 한 줄 정의
특징 추출과 모델 학습 사이에서, 중복되거나 쓸모없는 열을 줄여 150행에 맞는 크기로 만드는 단계. 절대 필수는 아니지만 과적합 방지와 해석에 유효 (원문).

#### 진동 피처는 태생적으로 상관이 높다 (원문)
| 영역 | 상관 높은 피처 | 이유 |
|---|---|---|
| 시간 | Peak, RMS, 파고율 | 파고율 = Peak/RMS. 결함으로 Peak가 크면 RMS도 보통 큼 |
| 주파수 | 인접 대역 에너지 (3 kHz, 4 kHz) | 충격파가 인접 대역을 같이 올림 |
| 시간·주파수 (정리자) | 필터 전·후 같은 지표 | 같은 신호에서 파생, 대역 겹침 |

#### 모델별 처리 필요성
| 모델 | 다중공선성 영향 | 처리 |
|---|---|---|
| 선형·로지스틱 회귀 | 계수 왜곡 | 필수 (원문) |
| 트리 (RF, XGBoost) | 분기마다 한 변수만 선택, F2 영향 작음 | 선택 (원문) |
| Mahalanobis | 공분산 역행렬 불안정. 피처 수 > 정상 120이면 역행렬 없음 | 사실상 필수 (정리자) |
| One-Class SVM 등 거리 기반 | 같은 정보가 거리에 중복 반영 | 권장, 표준화와 함께 (정리자) |
| Isolation Forest, Autoencoder | 영향 작지만 노이즈 학습 | 선택 (정리자) |

#### 그래도 처리하는 이유: 차원의 저주
- 150행에 피처를 50·100개씩 늘리면 노이즈까지 외움
- |r| ≥ 0.9 쌍 중 하나만 남기거나 PCA로 축소하면 가볍고 val·test에서 안정적

#### 실무 절차 (원문)
1. `df.corr()` 히트맵
2. |r| ≥ 0.85 쌍은 물리 의미가 뚜렷한 쪽만 남김 (예: Peak보다 첨도)
3. 필요하면 PCA
4. VIF로 확인, 5–10 이상이면 공선성 의심

$$\mathrm{VIF}_j=\frac{1}{1-R_j^2}$$

- 지도 선택: 학습 폴드에서 Mann–Whitney U 또는 Mutual Information 상위 12–15개 (원문 실전 포인트)

#### 주의 (정리자)
- **누수 방지**: 상관·PCA·표준화·선택은 train(학습 폴드)에서 fit, 검증·val·test는 transform만
- **클래스 차이로 생긴 상관**: 정상+고장으로 상관을 보면 "고장에서 Peak와 RMS가 같이 큼"이 상관으로 섞여 쓸모 있는 피처를 지울 수 있음 → 정상 120개만의 상관표 병행 (D9)
- **해석성**: 상관 피처가 남으면 트리 중요도가 나뉘어 해석이 흐려짐. 과제가 판단 근거 제시를 요구하므로 중복 제거가 유리
- **PCA 한계**: 주성분은 물리 의미가 사라짐 → 상관 기반 드롭이 먼저, PCA는 보조
- 위 상관 쌍은 가설. 실제 중복은 추출 후 확인
- MWU·MI는 고장 라벨이 필요 → One-Class 경로에서는 못 씀
