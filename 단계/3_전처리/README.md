## 개념 (예전 notes/개념/에서 옮김)

### 전처리: 평균 제거와 이동평균


#### 한 줄 정의
원신호 = 편향 + 진동 + 잡음. 전처리는 편향(영점)을 없애고, 필요하면 센서 잡음을 누르는 단계다. 원본 정보를 버리는 단계가 아니다.

#### 전체 흐름 (원문)
평균값 제거 → 이동평균(MA) → 대역 분할·필터 → 특징 추출

| 순서 | 단계 | 목적 | 필수 여부 |
|---|---|---|---|
| 1 | 평균값 제거 | 센서 영점 편향 제거 | 필수 (데이터 소개 PDF) |
| 2 | 이동평균(MA) | 센서 고주파 전기 잡음 완화 (저역통과) | 권장, 윈도우 M 조정 |
| 3 | 대역 분할 / Bandpass | 대역별 에너지, 결함 대역 증폭 | 균등 분할은 베이스라인, Bandpass는 EDA 이후 → 4단계 신호 변환 |
| 4 | 포락선·웨이블릿 | 노이즈 속 간헐 충격 분리 | 선택 → 4단계 신호 변환 |
| 4 (병렬) | 스펙트로그램(STFT) | 시간-주파수 변환 | 선택 → 4단계 신호 변환 |
| 4 (선택) | 증강 (train만) | 데이터 수·불균형 | 선택 → 3단계 증강 |
| 5 | 특징 추출 | 150행 × N열 | → 4단계 특징 추출 |

- 원칙: 전처리·대역 분할은 원본에서 뽑은 전체 RMS·첨도 **옆에** 대역 특징을 열로 **추가**하는 돋보기다

#### 평균값 제거

$$x_1(t)=x(t)-\mu$$

- 센서가 0을 못 잡아 파형 전체가 들려 있는 영점 편향을 제거. PDF 예시: 평균 +0.7 g → 약 0 g

#### 이동평균(MA)

$$x_2[n]=\mathrm{MA}_M\{x_1[n]\}=\frac{1}{M}\sum_{k=0}^{M-1}x_1[n-k]$$

- 인접 M개 평균 → 빠른 변동 완화 = 저역통과 필터
- 트레이드오프: M이 크면 짧고 강한 Peak도 뭉개짐
- 원문 주장: 기계 잡음이 Peak를 높여 오탐을 만들 수 있으니 MA가 핵심 전처리

#### 순서: 왜 노이즈 제거가 먼저인가 (원문)
1. 평균 제거 + MA로 정돈된 시계열
2. FFT·대역 분할·필터링
3. 특징 추출
- 정돈 전에 FFT를 하면 기계 노이즈가 유의미한 피크로 둔갑
- 결함 주파수가 확실하지 않은데 Bandpass부터 걸면 저주파 유격 흔들림·예상 밖 고주파 충격까지 날아감

#### 주의 (정리자)
- **MA와 고주파 피처의 충돌**: MA는 저역통과라 5–10 kHz 대역 에너지, Peak, 첨도, TKEO를 약하게 만든다. 평균만 뺀 신호와 MA 신호 양쪽을 비교해 정한다
- val·test에도 train과 같은 전처리를 적용

#### 확인 질문

2. 고장 정보가 고주파 충격에 있다면 MA를 쓸 때 F2는 어느 방향으로 움직일 것으로 예상하는가
3. 평균 제거 후 Std와 RMS가 같아지는 이유는

### 증강: 슬라이싱 · 노이즈 · 스케일 · SMOTE


#### 한 줄 정의
정상 120 vs 고장 30의 데이터 부족·불균형을, 물리 특성을 해치지 않는 방법으로 train 안에서만 늘리는 단계.

#### 위치 규칙 (원문)
- 원신호 증강(슬라이싱·노이즈·스케일·시프트)은 특징 추출 **전**
- SMOTE는 특징 추출·선택 **후**
- 모두 **train에만**, val·test는 원본 그대로

#### 기법 (원문)
| 기법 | 시점 | 원리 | 효과 / 원문 주의 |
|---|---|---|---|
| 윈도우 슬라이싱 + 오버랩 | 추출 전 | 0.5초(12,500점) 창, 50% 오버랩 → 파일당 7조각 | 데이터 수 증가. 원문 최우선 추천 |
| 가우시안 노이즈 (Jittering) | 추출 전 | 작은 백색 잡음 추가 | 센서 미세 떨림 과적합 방지 |
| 크기 변환 (Scaling) | 추출 전 | 진폭에 0.9–1.1 곱 | 가진력 차이 모사. RMS가 직접 영향받아 경계가 무너질 수 있음 |
| 시간 이동 (Shifting) | 추출 전 | 좌우로 밀고 빈칸 채움 | 충격 시점 과적합 방지 |
| SMOTE | 추출 후 | 고장 행 사이 선분 위에 가상 고장 생성 | 트리 모델과 결합 시 재현율 상승 (원문) |

**조각 수**

$$\left\lfloor\frac{50{,}000-12{,}500}{6{,}250}\right\rfloor+1=7$$

#### 주의 (정리자)
- **파일 단위 분할**: 같은 파일의 조각이 train·검증에 섞이면 누수로 F2가 부풀려짐 → 그룹(파일) 단위 CV
- **정상·고장 같은 창으로**: 고장만 자르면 창 길이 자체가 단서가 됨(구간이 길수록 Peak 큼). 둘 다 자르면 840 vs 210으로 비율은 4:1 그대로 → 불균형은 가중치·임계값·SMOTE로 따로
- **라벨 노이즈**: 간헐 충격이면 충격 없는 조각에도 고장(1) 라벨이 붙음
- **추론도 같은 방식**: 조각 예측을 파일 단위로 합침 (예: 하나라도 고장이면 고장 = F2에 맞는 보수적 방향). 0.5초 창이면 Δf = 2 Hz로 거칠어짐
- **효과적 표본 수**: 30개에서 나온 210조각은 독립 210개가 아님. 같은 고장을 여러 번 보는 것에 가까움
- **노이즈 주입**: 모든 대역(특히 고주파 에너지)과 첨도를 건드림 → 작게 시작
- **Scaling**: 부싱은 진폭 의존 비선형(Payne/Fletcher-Gent)이라 곱셈이 실제 가진 차이를 재현 못함 → ±5%부터 (1단계 도메인)
- **Shifting**: 전체 통계 피처(RMS·첨도·FFT 크기)는 순환 이동에 불변이라 효과 없음. 0 채우기는 인공 충격 → CNN·스펙트로그램 입력에서만 의미
- **SMOTE 순서**: 폴드를 나눈 뒤 train 쪽에서만. 분할 전 적용하면 가상 데이터가 검증에 섞임
- **One-Class 경로**: 고장 증강 불필요, 정상 슬라이싱은 오토인코더 샘플 확보에 도움
