# 3-2. 고주파 블록의 고역통과 차단 주파수(fc) 정하기 (11-21)

상태: 분석 완료. **고정 규칙의 결과는 fc = 500 Hz지만 규칙이 사실상 작동하지 않았다(아래 해석). 결정은 사용자에게 넘긴다.**

## 목적
고주파 블록(충격 검출·울림 분석·고역 RMS/첨도)의 고역통과 차단 주파수를 정한다. 지금은 1 kHz(충격·울림), AE는 200 Hz. 1.5 kHz로 올리자는 안이 나왔으나 정상도 1–2 kHz 모드를 쓰므로 최적값을 구해 본다.
원칙: **선택은 라벨 없는 기준(A)으로, 라벨을 쓰는 결과(B)는 민감도로만 보고.** 격자·규칙은 실행 전에 고정했다.

## 답할 질문
1. 고역 신호가 길 상태(출렁임)를 덜 따라가려면 fc를 어디까지 올려야 하나 (A1)
2. fc를 올리면 정상 모드(0.73–1.9 kHz)가 얼마나 잘리나 (A2)
3. fc에 따라 충격 검출이 급변하나 (A3)
4. 라벨을 쓰는 지표(AUC·quick_cv)는 fc에 얼마나 민감한가 — 선택에는 안 쓴다 (B)

## 방법
- 격자 fc ∈ {500, 750, 1000, 1250, 1500, 1750, 2000, 2500} Hz, 4차 Butterworth `sosfiltfilt`(평균 제거 후). 파일 190개(train 150 + val 40, A는 라벨 안 씀)
- A1: 고역 log RMS·첨도 ↔ 출렁임(20 Hz 저역 신호 log RMS)의 스피어만 ρ. 선택 규칙 = train 정상에서 RMS ρ가 다음 격자와 |Δρ| < 0.05가 처음 되는 fc
- A2: train 정상 중앙 PSD(Welch 8192, Hann, 50%, detrend=False)의 0.5–3 kHz 봉우리(로그 돌출 ≥ 0.2 dec로 거름)와 fc별 진폭 통과율 |H|²
- A3: `final.impact_rings`를 fc 인자로 일반화(`run.py`의 `rings_from_hp`, 사전은 1–12 kHz 그대로). **fc=1000 결과가 `final.impact_rings`와 완전히 같음을 assert**(충격 1757개, 배열 일치). 피처 쪽도 fc=1000이 `final.ring_table`과 같음을 assert
- B: 피처 8개(고역 log RMS, 첨도, 파고율, log1p 충격 수, 5.5–7.75 kHz 울림 몫, 2.125–4.125 kHz 울림 몫, ζ ≥ 0.04 충격 비율, 8.0–8.7 kHz·ζ ≤ 0.02 최대 fit). 충격 0개면 몫은 −1. B1 단변량 AUC, B2 `quick_cv`(5-fold PR-AUC) × ExtraTrees(`make_et`) × seed 5개, B3 파일 추적
- 값은 모두 `result.json`

## 해석과 결정
- **고정 규칙의 출력은 fc = 500 Hz.** 그러나 이 선택은 규칙의 결함 때문이다: 격자 간격(250–500 Hz)당 ρ 변화가 항상 0.008–0.027로 0.05 미만이라, "평탄해지는 지점"을 못 찾고 첫 격자를 골랐다. ρ는 fc에 대해 단조로 계속 내려간다. 따라서 A1은 "어느 fc부터 길 끌림이 없다"를 말해 주지 못하고, 단지 "fc를 올릴수록 길 끌림이 조금씩 준다(0.40 → 0.26, 약 1/3 감소)"만 말한다. 규칙은 바꾸지 않고 이 사실을 그대로 보고한다.
- 길 끌림 ρ는 fc 1000 → 1500에서 0.348 → 0.301 (Δ 0.047)이고 전체 190 기준은 0.340 → 0.312 (Δ 0.028)로 작다. 1.5 kHz로 올려 얻는 길 끌림 감소는 작은 반면, 그 대가로 정상 1.31 kHz 모드와 abn_017의 1.6 kHz 울림의 진폭을 각각 24%·63%로 깎고(A2), 울림 주파수 < 2 kHz 정보는 13.5% → 4.2%로 줄어든다(A3).
- B(선택에 안 썼음): fc 500·750은 quick_cv가 크게 나쁘고(0.789·0.801), 1000이 최고(0.888)지만 1250–1750과는 sd 안이다. 1000 vs 1500 차이 0.013은 sd 안이라 라벨 기준으로는 두 값을 구분할 수 없다. 즉 데이터는 1.5 kHz가 나쁘다는 증거도, 낫다는 증거도 주지 않는다.
- 권고(사용자 결정 사항): 규칙 결과 500은 B에서 확연히 나쁘고 A1이 퇴화했으므로 채택을 권하지 않는다. 라벨 없는 근거만으로는 1000 유지(1–2 kHz 정보 보존, 현재 파이프라인과 동일, 재현 비용 없음)가 가장 보수적이고, 1500은 길 끌림을 약간 줄이는 대신 1–2 kHz 정보를 잃는다. 고주파 블록을 1.5 kHz로 올릴지는 "길 끌림 감소 vs 1–2 kHz 정상·고장 정보"의 교환이라 사용자가 정한다. 라벨을 본 뒤 고르는 결정이 되지 않도록 B는 참고로만 쓴다.
- 확인 못 한 것: (1) 길 끌림을 줄이는 것이 실제 판별에 도움이 되는지(8피처 ET는 fc 1000이 최고라 도움 증거 없음), (2) 피처가 8개뿐이라 현재 최종 모델(EXP-034 c)에 fc만 바꿔 끼웠을 때 F2는 안 돌렸다(중첩 CV 필요), (3) 사전이 1 kHz부터라 fc 500·750의 0.7–1 kHz 울림은 정확히 표현되지 않는다, (4) 봉우리 목록의 돌출 문턱 0.2 dec는 PSD 모양만 보고 정한 값이다(라벨 안 씀).

## 개념
- **고역통과 차단 주파수 fc**: 이 주파수보다 낮은 성분을 줄이는 필터의 경계. 4차 Butterworth를 정방향·역방향으로 두 번 통과(`sosfiltfilt`)시키므로 진폭 통과율은 단일 필터 응답의 제곱 |H|²이고, fc에서 정확히 0.5다.
- **스피어만 ρ**: 두 값의 순위가 얼마나 같이 움직이는가(−1~1). 고역 RMS와 출렁임의 ρ가 크면 고역 신호가 길 상태를 따라간다는 뜻이다.
- **PR-AUC (quick_cv)**: 임계값 없이 고장을 점수 위쪽에 모으는 정도. 5-fold OOF로 구한다. 탐색 비교용이다(중첩 CV F₂는 최종 후보 확인용).
- **감쇠 사인파 사전**: 충격 뒤 8 ms를 주파수 1–12 kHz × 감쇠비 4개 원자에 투영해 가장 닮은 울림 주파수를 읽는 방법(final.py).
