# 2단계 탐색적 데이터 분석

상태: **11-25 정리.** 최종 모델([EXP-062](../5_모델실험/6_최종모델/EXP-062_11kHz상한·그룹CV/README.md))의 부품 순서 = 발표 순서로 번호를 다시 매겼다. 조각 폴더마다 `README.md` 하나와 `자료/`(코드 · 그림 · 표)만 있다. 전처리 결정(11 kHz 상한 · 검출기 · 저주파)은 [3_전처리](../3_전처리/README.md)로 옮겼다.

## 목적
라벨을 손으로 대역 고르는 데 쓰지 않으면서, 정상과 고장 신호가 어떻게 다른지 눈으로 이해한다. 물리가설(H1–H6)과 그림을 하나씩 맞춰 본다.

## 진행 방식 (11-13 사용자 결정)
- 2단계 EDA와 3단계 전처리를 이어서, 데이터를 뜯어보는 한 흐름으로 진행한다
- 조각 단위: 그림·해석 → 사용자 확인 → 다음. **조각 하나 = 번호 붙은 폴더 하나** (`2-n_MMDD_이름/` 안에 해석 md · 코드(`# %%` 셀 .py 또는 노트북) · `figs/`)
- 코드의 루트 찾기는 `src/`가 있는 상위 폴더를 거슬러 찾는 방식을 쓴다(폴더를 옮겨도 안 깨짐). 예전 조각 일부는 고정 깊이(`"..", "..", "..", ".."`)
- 라벨을 보고 대역·주파수를 고르지 않는다는 원칙은 그대로 (결정 "대역"). 그림을 본 뒤 정한 정의는 "사후"로 표시한다

## 해석과 결정
- 회색지대는 경계 모양이 아니라 **정보 부족** 문제였다 → EDA에서 물리적으로 다른 축(8.3 kHz 모드 폭, 유격 반복)을 찾은 것이 점수를 올렸다 (0.857 → 0.942)
