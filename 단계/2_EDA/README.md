# 2단계 탐색적 데이터 분석

상태: 시작 전

## 목적
라벨을 손으로 대역 고르는 데 쓰지 않으면서, 정상과 고장 신호가 어떻게 다른지 눈으로 이해한다. 물리가설(H1–H6)과 그림을 하나씩 맞춰 본다.

## 이 단계에서 답할 질문
- 파형: 정상에도 큰 충격이 있다(nor_001·050). 고장 충격과 무엇이 다른가 (H1)
- PSD: 정상 5–95% 범위와 고장 비교, 8.3 kHz 협대역 피크 (H2)
- 조용한 고장(abn_002·022·029)은 어디가 다른가 (H3), 저주파 흔들림 반전점 충격 (H4)
- 평균 −1 g 파일 4개(nor_097·101·120, abn_016)는 무엇인가

## 진행 방식 (11-13 사용자 결정)
- **2단계 EDA와 3단계 전처리를 이어서, 데이터를 뜯어보는 한 흐름으로 진행한다.** 여기서부터 본격적인 데이터 이해
  1. 전체 데이터가 어떻게 생겼는지 먼저 시각화한다 (150개 전체: 파형·분포·PSD, 정상 5–95% 범위와 고장 겹침)
  2. 전처리를 한 단계씩 적용할 때마다 신호가 어떻게 바뀌는지 그림으로 확인한다 (평균 제거 → MA → 저주파 제외 → 대역 분할 …)
  3. 그 관찰을 피처 추출의 근거로 삼는다. 지금까지의 확장 150 피처는 이해 없이 한꺼번에 만든 것이라, 4단계 피처는 여기서 본 차이에서 다시 출발한다
- 라벨을 보고 대역·주파수를 고르지 않는다는 원칙은 그대로 (결정 "대역")
