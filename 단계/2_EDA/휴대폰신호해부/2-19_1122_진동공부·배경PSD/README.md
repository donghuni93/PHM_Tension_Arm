## 공부 노트 (요약)
- 가속도 = 변위의 2차 미분 → ω² 가중이라 고주파가 크게 보이고 저주파는 작게 보인다. 속도로 바꾸면 kHz 고장 신호가 사라진다(4-5 S1-b 기각과 같은 결론)
- 200 Hz 아래는 정상 에너지의 약 74 %(결정.md)지만 구분력이 없다 → J는 저주파를 크기가 아니라 비율(H18 · E2) · 시점(박자 S)으로만 쓴다
- 충격 하나 = 고유진동수로 울리는 감쇠 사인파. 공진 증폭 Q ≈ 1/(2ζ)(ζ 0.01 → 50배, 0.08 → 6배), 봉우리 폭 ≈ 2ζf
- 주파수는 강성 · 질량이 정하고 세기와 무관(선형일 때). 유격 같은 접촉은 비선형이라 세기에 따라 주파수가 바뀔 수 있음(미확인)
- FRF H = X/F. 충격 직후 울림의 스펙트럼 ≈ FRF지만 힘 F를 재지 않아 직접 못 구함(운전 모달 해석 영역)
- Welch PSD = 조각마다 |FFT|²를 평균(위상 상쇄를 피함). 2048점 → 12.2 Hz 해상도
