# 2-18 휴대폰 분석 — 원시 진동 신호를 물리량 하나씩 해부

> 11-19에 브랜치를 main에 병합하며 재구성했다. 신호 해부(1·9·12·13·14번)는 이 폴더, 피처·모델·val 탐색(15–18·20·21번)은 [4-4](../../../4_피처/base/4-4_1119_휴대폰_피처·모델탐색/README.md), 코드 없는 공부용 9개는 [방법론_공부.md](방법론_공부.md)에 합쳤다. 세션 산출물 구분표: [만든것_구분.md](만든것_구분.md)

목적: 모델·규칙을 더하지 않고, 오탐 경계 파일(정상인데 고장처럼 보이는 파일)이 **주변 고장과 닮았는지, 다르다면 어디가 다른지**를 원시 신호 분석으로 설명한다.
방식: 기법 하나당 폴더 하나. 폴더마다 `README.md`(원리 · 우리 데이터에서 볼 것 · 구현 현황 · 한계)를 두고, 구현할 차례가 되면 `run.py`(`# %%` 셀)와 결과 칸을 채운다.

결과는 [결과요약.md](결과요약.md)에 방법론별로 모은다(유의미 판정 기준 포함).

## 작업 원칙
- 대역·주파수를 라벨 본 뒤 손으로 고르지 않는다. 그림은 **보기용**이고, 피처로 쓰려면 새 EXP로 중첩 CV 비교한다.
- 실행은 PC(conda `qe-phm`)에서. 스크립트는 `data/TeamProject_train_변경/`가 있어야 돈다.
- 결과는 각 폴더 README의 "결과 · 해석" 칸에 채운다(해석은 사전 가설과 대조해서).
