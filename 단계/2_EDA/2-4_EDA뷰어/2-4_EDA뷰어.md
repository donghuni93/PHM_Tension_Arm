상태: 뷰어 v2 (개념 사전 반영), 사용자가 파일별 특징 정리 중 (2026-11-14)

**신호 전환 (v3, 11-14)**: 머리줄 "신호"에서 평균 제거 ↔ 200 Hz 고역통과를 고르면 모든 그림·지표·태그·정상 백분위가 그 신호로 계산한 값으로 바뀐다 (두 벌을 미리 계산해 실음). 한 개씩 보기 지표 표의 회색 숫자·속 빈 원 = 반대 신호 값. 이에 따라 `h_std`·`h_kurt`는 없앴고(= 고역통과 쪽 `std`·`kurt`), 스펙트럼 모양·물리 대역 비율은 전 대역 기준으로 바꿨다(고역통과 쪽 값 ≈ 예전 "200 Hz 이상" 값). Welch PSD는 `detrend=False`로 바꿔 6 Hz 아래 드리프트가 저주파 비율에 들어간다. 고역통과 쪽의 "저주파" 묶음 값은 필터가 남긴 찌꺼기라 해석하지 않는다

**왼쪽 메뉴 · 분석 조각 화면 (v7, 11-14)**: 머리줄의 화면 버튼을 VS Code식 왼쪽 메뉴로 옮겼다(EDA = 한 개씩·5개씩·지표 표·산점도 / 모델 = 로지스틱 경계 / 분석 조각 = 유격 반복·주기 잠금 / 참고 = 개념 사전, 아래 "메뉴 접기"). 머리줄 오른쪽 = 밝게·어둡게·시스템 전환. 새 화면 둘 — **유격 반복 · 저에너지(2-12)**: ① D6 × D1 지도(r = 1·2 원, 점 크기 = R(2위/1위), 초록 원 = 유격 규칙 켜짐, ✕ = 최종이 틀림) ② **R × 결합 결정값**(EXP-025 평면): 오경보 정상이 "큰 사건 한 번"(R 낮음)에 몰리는지, 같은 자리에 고장이 있는지(= R로 내리면 함께 내려갈 고장) 확인용 / **주기 잠금 충격(2-13)**: r_LP × hit 지도, S 같은 선(정상 95%·정상 최대), S 상위 25. 값은 각 조각 run.py가 남긴 `figs/features.csv`·`figs/lock_score.csv`를 읽는다(조각을 다시 실행하면 뷰어도 다시 만든다). 문서 그림(PNG)은 접어서 함께 실음

**경계 화면 (v6, 11-14)**: 머리줄 "경계" = 유의미 실험(EXP-025·021·020·014·012)을 골라 두 전문가 z 평면(AE z · ET z, OOF seed 0)에 로지스틱 경계(실선 0, 점선 ±1)·고장 쪽 바탕·규칙(◇ 8.3k, ○ 유격)·틀린 파일(✕, 굵게 = 3/5 이상)을 그린다. 경계 근처(|결정값| ≤ 0.5–2, 고를 수 있음)와 틀린 파일은 이름을 자동 표시(겹치면 비켜 놓고, 그래도 겹치면 생략)하고, 오른쪽에 결정값 순 목록을 둔다. 점·목록 클릭 = 정보 카드(결정값·z·이 실험 결과·규칙·실험별 결과·태그, "한 개씩 보기로 열기"). 정의는 `단계/5_모델비교/fig_logistic_plane.py`와 같음

**모델 결과 = 최종 모델만 (v5, 11-14)**: 최종 모델을 **EXP-025**(EXP-014 결합 + 8.3 kHz 모드 규칙 + 유격 반복 규칙, 중첩 F2 0.942)로 바꾸고 AE·ET·결합 비교는 뺐다. 배지·표 열 = 최종 미탐·오경보 횟수 + **8.3k 규칙**(돌출·폭) + **유격 규칙**(r · 2위/1위). 필터 "모델 결과" = 최종이 틀림 · 미탐 · 오경보 · 한 번이라도 틀림 · 규칙 켜짐(8.3k / 유격 / 둘 중 하나). 묶기 "모델 결과" = 고장: 최종이 놓침 / 8.3k 규칙으로 잡음 / 유격 규칙으로 잡음 / 결합 점수로 잡음 · 정상: 최종 오경보 / 가끔 오경보 / 문제 없음. 유격 규칙 켜짐은 정상 150개 중심 기준 설명용(평가에서는 fold 안, 켜지는 파일은 25번 모두 같음)

(이전 v4) 기준 모델을 **최종 EXP-021**(EXP-014 결합 + 8.3 kHz 모드 규칙, F2 0.892)로 바꿨다. 배지·표 열 = 최종 · 결합(EXP-014) · AE(EXP-012) · ET(EXP-007) + **8.3k 규칙**(돌출 ≥ 0.75 dec & 폭 ≥ 150 Hz, 돌출·폭 값 표시). 필터 "모델 결과"에 최종 미탐·오경보, 최종에서 새로 잡힘·새로 놓침·오경보 해소, 8.3k 규칙 켜짐 추가(AE·ET 항목은 '전문가' 묶음). 묶기 "모델 결과"와 산점도 검은 테두리는 최종 모델 기준
다시 만들기: Tasks: Run Task → "EDA 뷰어 다시 만들기" (= `build_viewer.py`). 지표·태그 규칙은 [build_viewer.py](build_viewer.py), 화면은 [viewer_template.html](viewer_template.html), 개념 설명은 [개념사전.md](../../개념사전.md)

## 목적
모델이 왜 놓치고 왜 오경보를 내는지 분류하려면, 먼저 **특이한 정상·특이한 고장이 어떤 모양인지** 알아야 한다.
파일을 화살표로 넘기며 시간·주파수 영역 지표와 그림을 함께 보고, 지표마다 개념(정의·원문 주장·우리 데이터·주의)을 바로 연다.

## 화면
| 모드 | 내용 |
|---|---|
| 한 개씩 (← →) | 파형 2초(평균 제거 / 200 Hz 고역통과, 충격 눈금), 최대 충격 ±20 ms, 스펙트로그램, **창별 RMS·첨도**(50 ms × 40), PSD(정상 띠 + **물리 대역·추정 대역 음영**), **스펙트럼 첨도**, **포락선 스펙트럼**, 지표 묶음 8개 |
| 5개씩 (← →) | 파형 + PSD + 핵심 지표 9개. y축 파일별/같게 |
| 표 | 모든 파일 × 지표 52개. 정상 5–95% 밖은 노란 칸(▲▼), 묶음 경계는 굵은 선 |
| 산점도 | 지표 두 개(묶음별 목록) 비교. 로그/부호 로그. 테두리 = 모델이 틀린 파일 |
| **개념** | 개념 사전 40항목 검색. 지표 코드 클릭 = 그 지표로 정렬한 표, Shift+클릭 = 산점도 y |

지표 이름·그림 제목의 점선 밑줄을 클릭하면 오른쪽에 개념 설명이 열린다 (Esc로 닫기).

## 지표 묶음 (개념 사전 분류)
| 묶음 | 지표 |
|---|---|
| 기본 크기 | 평균, RMS, Peak, Peak-to-Peak, MAV |
| 형상 지표 | 첨도(Fisher), 왜도, 파고율·충격·형상·여유 계수, Hjorth 이동도·복잡도 |
| 충격·비정상성 | 충격 수·돌출도·간격, TKEO 첨도·최대/평균, 창 RMS 변동계수·최대/평균, 창 첨도 최대, 조용한 바탕, 영교차율·창 변동계수 |
| 저주파 | 0–20 / 0–200 Hz 비율, 0–20 / 20–200 Hz 에너지 |
| 스펙트럼 모양 | 200 Hz 이상 에너지, 중심·대역폭·85%/95% 롤오프, 고역 비, 엔트로피·평탄도, 최대 돌출 피크 주파수·돌출도 |
| 물리 대역 | 노션 예시 분할 저 200–2k / 중 2–5k / 고 5–12.5k 에너지와 비율 |
| 포락선·스펙트럼 첨도 | 포락선 첨도, 포락선 반복 주파수·돌출도, 스펙트럼 첨도 최대·그 주파수 |
| 1 kHz 대역 | 고정 격자 13칸 에너지 |

- **충격 정의**: 200 Hz 고역통과 신호가 바탕 σ(MAD × 1.4826)의 8배를 넘은 사건, 10 ms 안은 하나로 (라벨 보기 전에 정함)
- **노션 원문에서 고친 것**: 첨도 기준 명시(Fisher 0 = Pearson 3, 사인 −1.5), 물리 대역은 200 Hz부터(아래는 흔들림이 지배), 고조파 비율·공진 이동은 기준 주파수가 없어 계산하지 않음, Gemini 추정 공진 대역은 음영으로만(피처 아님)

## 처음 보이는 것 (정리 전 메모)
1. **충격이 0–2개인 고장은 1개뿐이다** (정상 52개). 정상도 68개가 3번 이상이라 횟수·간격·크기 조합을 볼 차례 (EDA ③, H1)
2. **고주파 우세는 고장 18개, 정상 6개** — 단일 태그 중 가장 고장 쪽
3. **정상 범위 밖 지표 수**: 정상 중앙 2개인데 정상 95% 분위는 19개 → 정상 안에 많은 지표에서 동시에 벗어나는 "특이한 정상" 무리가 있다. 고장 중앙은 11개
4. 설명용 단변량 AUC 상위: 창 첨도 최대 0.84, Peak·여유 계수·중 2–5k 에너지·충격 계수·P2P 0.80, 파고율·충격 돌출도·고역 비 0.79 (선택에 쓰지 않음)
5. "협대역 피크"·"잡음·연속형"은 정상에만 있다 → 정상 안의 운전 상태 차이 후보 (2-1 관찰 4)
