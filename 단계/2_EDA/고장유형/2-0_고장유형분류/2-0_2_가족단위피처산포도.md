## 결론
1. **가족 단위 5개는 대부분 "충격 크기" 정보다.** 5개 중 하나라도 정상 95%를 넘는 파일 = 고장 27/30, 정상 18/120. 특히 P02 Peak 2.5–3.75 kHz는 L3 고장 11/12를 잡지만, 같이 넘는 정상 6개(006 025 050 055 095 116)에 **EXP-025 오경보 셋(025 055 116)이 모두** 들어 있다 = 2-15의 "큰 사건 한 번" 정상
2. **5개 어디서도 안 넘는 고장 = 002 · 020 · 029.** 002·029는 5개 피처 모두 정상 27–92 백분위(정상 한가운데)인데, **8.3 kHz 모드 축에서는 정상 최대보다 위**(돌출 정상 100 백분위, 두 모드 차 98–99) → 충격 피처와 스펙트럼 모양이 서로 다른 고장을 잡는다. EXP-027 "H3는 P02와 다른 정보"의 실체
3. **8–9 kHz 스펙트럼 모양은 평균하면 안 된다.** 같은 대역 안에서
   - 8.20–8.45 kHz 봉우리(고장 모드): 정상 95% 위 고장 6(002 006 007 010 029 030) / 정상 6(004 019 070 088 092 119)
   - 8.45–8.75 kHz 봉우리(정상 모드): 정상 95% 위 **고장 0** / 정상 6 → 이 칸이 크면 오히려 정상
   - 정상 004·019는 8.3 kHz 돌출은 크지만 폭이 좁아(약 95 Hz, 순음) 규칙 상자(돌출 ≥ 0.75 & 폭 ≥ 150 Hz) 밖. 상자 안 = 고장 002 006 010 029 030, 정상 0 (EXP-021 규칙과 같은 결과)
   - EXP-027이 쓴 H3 모양은 250 Hz 칸 평균이라 이 두 모드를 한 칸에 섞는다. 8.25–9.75 kHz 6칸 평균을 처음에 그려 보니 고장 13 · 정상 6이 위에 있었지만, 두 모드를 가르는 정보는 사라진다 → 이 문서에서는 평균 대신 두 모드 축을 쓴다
4. **H3 9.5–9.75 kHz 칸(EXP-027 대표 칸)은 L1 고장(4/5: 003 007 013 026)을 잡지만 오경보 정상 055·116도 높다**(116은 정상 최대). 2-15 그림 3에서 116의 큰 사건이 9.5 kHz 좁은 봉우리로 울린 것과 같은 현상으로 보인다 → 이 칸은 "고주파 링잉 고장"과 "높은 공진 하나로 울리는 정상 큰 사건"을 함께 올린다

## 용어 (피처 이름 읽는 법)
- 전체 피처 사전 = [4-2 피처 목록](../../../4_피처/base/4-2_피처목록/4-2_피처목록.md)
- **P02 = 대역을 잘라 낸 뒤 본 충격 지표.** 원신호를 1.25 kHz 폭 대역 하나만 남기고(4차 Butterworth 대역통과, 앞뒤로 걸어 위상 지연 없음) 그 신호에서 값을 잰다. 이름 뒤 숫자 = 대역 시작(012 = 1.25–2.5 kHz, 025 = 2.5–3.75 kHz, 075 = 7.5–8.75 kHz). 대역은 데이터를 보기 전에 정한 균등 10칸이다 ([src/features.py](../../../../src/features.py))
  - **P02 Peak** = 그 대역 신호의 최대 |진폭|(g). "그 대역에서 가장 크게 울린 한 번"
  - **P02 첨도** = 그 대역 신호 값 분포의 첨도(Pearson, 정규분포 = 3). 대부분 조용하다가 가끔 튀면 커진다 = "충격이 드물고 뾰족한 정도". 크기(게인)와 무관하다
- **S01 시간 변동(CV)** = 약 41 ms 창으로 STFT를 하고, 그 대역 에너지를 시간 순서로 늘어놓은 뒤 표준편차 ÷ 평균. 에너지가 고르면 작고, 어떤 순간에 몰리면 크다
- **K1** = 8σ 사건 중 두 번째로 큰 사건의 높이 ÷ 바탕 σ(log10). "큰 충격이 두 번 이상 있었나"
- **H3 모양** = 250 Hz 칸 로그 PSD에서 파일 평균을 뺀 값. 크기와 무관한 "스펙트럼 생김새"
- **돌출(dec)** = 봉우리가 주변 바탕보다 로그 PSD로 몇 자리(10배 단위) 높은가. **폭** = 그 봉우리의 반높이 폭(Hz)

## 그림 읽는 법 (모든 그림 공통)
- 회색 = 정상, 색·기호 = 고장의 2-0 유형(L4 ◆ 노랑 · L3 ■ 초록 · L2 ▲ 주황 · L1 ● 파랑 · 미분류 ✕ 회색)
- 띠 그림: 왼쪽 = 정상, 오른쪽 = 고장. 파란 띠 = 정상 5–95%, 점선 = 정상 95%. 파란 이름 = EXP-025 오경보 정상 + 정상 상위 3개. 크기·첨도·변동계수는 log10
- 평면 그림: 점선 = 각 축의 정상 95%. 파란 테두리 = EXP-025 오경보 정상, ◇ = 8.3k 규칙 켜짐

## 해석
- EXP-027의 두 정보 덩어리를 도메인 유형에 맞춰 보면: **P02 충격 크기 = L3 금속 타격**, **8.3 kHz 모드 = 002·029(조용한 초기 고장)**, **9.5 kHz 모양 = L1 고주파 링잉**. 각각 다른 고장 무리를 맡는다
- 남은 오경보는 P02 Peak·9.5 kHz 모양 두 축에서 고장 쪽으로 보이는 정상(025 055 116)이다. 두 축 모두 "크게 울렸다"만 보고 **어떻게 울렸는지**(사건 울림 주파수·봉우리 폭)는 보지 않는다 → 2-15의 사건 주파수 중심(FC)과 같은 결론
- 022(L2)는 P02 첨도 1.25–2.5 kHz만 정상 95 백분위, 나머지는 정상 안 → 2-13 주기 잠금이 필요한 이유 그대로

## 주의
- K1, 8.20–8.45 / 8.45–8.75 kHz 경계, 규칙 문턱(0.75 dec, 150 Hz)은 라벨을 본 뒤 정한 값이다(결정 '대역 예외'). 이 그림이 깔끔해 보이는 몫의 일부는 사후 선택 때문이다
- EXP-027의 유의성은 RF 중요도 기준이다. 정상 95% 위 개수는 설명용 단변량 비교로, 모델 기여와 같지 않다
- 오경보 표시는 EXP-025 기준(2-0과 같게). 지금 최종 후보 EXP-029에서는 116·055 오경보가 없어졌다(5_모델비교 README)
