# 2-34 피처 점검 ③ 첨도 · 봉우리 (H3 · H5 · H16 · H17), 11-23

점검만 하고 피처는 고치지 않는다. 판정은 후보이며 사용자가 정한다. 수치 전체 = [결과.md](결과.md), 코드 = run.py

- 정의: H3 · H5 = 1–2 · 4–8 kHz 대역통과 신호의 log10(Pearson 첨도), H16 · H17 = 1 kHz 위 log PSD에서 정상 중앙 대비 가장 솟은 봉우리의 높이(dec) · 반높이 폭(Hz). 재계산 차이 4e-16
- 분리도 / val 이동도: H3 0.74 / 0.37 · H5 0.45 / 0.15 · H16 0.68 / 0.44 · H17 0.68 / 0.43. 제외된 짝 H4(2–4k) 0.69 / 0.17 · H6 0.39 / 0.16
- 첨도는 충격 수를 넘는 정보가 있다(n=4~9 H3 분리도 0.63, n≥10 0.66). H5는 n≥10에서 0.22로 약하다
- 봉우리: 정상 오경보 025 · 055 · 065 · 116이 모두 H16 정상 95~98백분위. 정상의 좁은 지속음(9.4 · 10.2 kHz)이 봉우리로 잡힌다. 8.3k 규칙 고장 002 · 029는 83~86백분위뿐
- val 봉우리 위치가 4–4.4 kHz에 모인다(정상은 거의 없음)
