## 지금까지 나온 판정 후보 (결정 전)
- H1 유지. 문턱 K 3~12에서 분리도 0.57~0.63, 현재 4.5가 quick_cv PR-AUC 최고(0.968). 시그마(MAD) 문턱은 더 나쁨(최고 0.963, 이동도 0.15). 잔향 꼬리 병합(100 ms)은 0.976 ± 0.014로 sd 안
- H2(2위÷1위) 제거 또는 수정 검토: 충격 ≥ 2개 파일끼리 분리 없음(AUC 0.47), 2위가 1위의 잔향일 수 있음. 재설계 후보 C3(3위÷1위) quick_cv 0.981 ± 0.004, C4(포락선 자기상관 최대) 분리도 0.53(n≥2 파일만 0.41) — 둘 다 중첩 CV 미확인, 5개 중 고른 값이라 낙관적
- H7 제외 검토(분리도 0.15~0.29). H8 유지(0.75). H9 유지 + 충격 0개 −1 처리 재검토(−1 포함 0.47 대 충격 있는 파일만 0.71). H10은 정상의 좁은 지속음을 울림으로 오인(오경보 059 · 065, val 021) → 수정 또는 제외 검토
- 울림 주파수 격자: 옥타브 경계 2000 Hz에 2 kHz 군집이 걸쳐 H7/H8로 갈림(val 충격의 25.5%가 정확히 2000 Hz). 경계는 라벨 없는 규칙으로만 다시 정할 것
- val에서 정상의 7.0–7.5 kHz 울림 지문이 거의 없다(충격 ≥ 2개 파일 중 50% 이상: 정상 34/91 · 고장 1/30 · val 1/29) → 공진이 약 0.5 kHz 아래로 이동했을 가능성(조교 질문 후보)
- H3는 H4(2–4k, 제외됨)로 대체 검토: 상관 0.88, val 이동 0.37 대 0.17, 분리 0.74 대 0.69. 과거 H3 선택은 번호 순서 타이브레이크였음
- H5 제외 검토(분리도 0.45, 충격 ≥ 10개에서 0.22)
- H16 수정 또는 제외 검토: val 이동 0.44, 오경보 025 · 055 · 065 · 116을 모두 정상 95~98백분위로 올림(정상의 좁은 지속음이 봉우리로 잡힘). 8.3k 고장 002 · 029는 83~86백분위뿐. 지속음(시간 구간 전체에 일정한 봉우리)을 따로 구분하는 정의가 후보
- 충격 크기(포락선 ÷ 바탕 최대)를 담은 피처가 없다. 단독 분리도 0.71이지만 quick_cv 개선 없음(0.956)
