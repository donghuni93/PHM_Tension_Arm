# 2-27 스펙트럼 비교 (정상 · 고장 · val · 전체) — 11-22 휴대폰 세션

- 목적: 정상 · 고장 · val의 파워 스펙트럼 모양을 한눈에 비교 (시각화만, 피처 아님)
- 방법: 평균 제거 → Welch PSD 4096점(≈6.1 Hz) → dB, 필터 없음. 요약 세 가지: 선형 평균 · dB 평균(기하평균) · 중앙값. 100 Hz 이동평균
- 그림: `스펙트럼_4패널.png`(파일별 선 + 중앙값) · `스펙트럼_평균.png` · `스펙트럼_평균_정리.png`(선형 평균) · `스펙트럼_dB평균_중앙값.png` · `스펙트럼_val분할.png`(EXP-044 판정으로 val을 확실한 정상 23 · 확실한 고장 5 · 경계 12로 나눔, 목록 `val분할.txt`)
- 코드: `run.py`(앞 네 그림) · `val분할.py`(QE_FULL=1)

## 관찰
- 선형 평균은 큰 파일 몇 개가 정한다. 정상 평균의 8–10 kHz 봉우리는 116 · 055 · 065 세 파일 몫([2-9](../../../2-9_정상고주파지속음/README.md)). dB 평균 · 중앙값에서는 사라진다
- 고장은 2–5 kHz(+5–10 dB)와 8–12 kHz(+15–20 dB)에서 정상보다 높다(중앙값 기준). 0.2–1.5 kHz는 차이가 작다
- val 확실한 정상은 train 정상과 모양이 비슷하다. 단 val 분할은 J 판정으로 나눈 것이라 순환적이다
