# 진동공부 EDA — 진동 기초(Stage 1–4)를 우리 데이터와 모델에 적용

진동 기초 공부(뷰어 `참고자료/진동공부/`, 인수인계 `진동 세션_1121.md`)에서 배운 개념으로 우리 데이터를 다시 본다. 결과는 피처 변경 후보 목록 [4-5](../../../4_피처/아카이브/4-5_1120_진동기초_피처점검/README.md)에 반영한다. 코드는 바꾸지 않았다. 후보는 EXP 하나로 한 번에 비교한다(11-20 결정).

## 조각 (11-21)
| 조각 | 배운 개념 | 한 줄 결론 | 피처 후보 |
|---|---|---|---|
| [2-19 낮은 음 찾기](2-19_1121_낮은음_부싱출렁임/README.md) | 질량-스프링 · 공진 봉우리 · 분해능 | 낮은 봉우리 37 · 81 · 113 · 134 · 195 · 220 · 278 Hz. 고장 때 옮겨 가지 않음, 크기 · 모양 모두 못 가름 | C3 기대 낮춤 |
| [2-20 울림 감쇠](2-20_1121_울림감쇠/README.md) | 감쇠 사인파 · 봉우리 폭 = 2 × 감쇠비 × 주파수 | 감쇠 중앙값은 비슷(AUC 0.59), **빨리 꺼지는 충격 비율**은 다름(0% vs 29%, AUC 0.73). 8.3 kHz 넓은 폭은 "충격마다 음이 다름" 쪽(잠정, 5개 파일) | C5 수정 |
| [2-21 뾰족함 지표 중복](2-21_1121_뾰족함지표_중복/README.md) | 시간 그래프 모양(첨도 · 파고율) | 62개 = 21묶음. 같은 대역의 첨도 · 파고율 · 포락선 첨도 · 최대/평균은 같은 값, 충격 수와 첨도는 다름(0.6) | C6 신규 |
| [2-22 출렁임 · 센서 방향](2-22_1121_출렁임·센서방향/README.md) | 오프셋 = 중력 · 대역별 파워 몫 | 원래 평균 AUC 0.50(정보 없음). RMS · 창 RMS 흩어짐은 출렁임에 끌려감(0.79 · 0.71), 200 Hz 고역통과로 절반 | C1 지지 · C2 좁힘 |

## 공통
- 실행: 각 폴더에서 `conda run -n qe-phm python run.py`. 숫자는 `result.txt`(UTF-8)에, 그림은 `figs/`에 저장된다
- 공용 준비(루트 찾기 · 색 · 글꼴): [_common.py](_common.py)
- 라벨은 색칠과 비교에만 썼다. AUC는 모두 "사후" 관찰이라서 라벨을 보고 대역을 고르는 데 쓰지 않는다
