# 2-24 정상의 고주파 지속음 (8–11 kHz) — 11-22 휴대폰 세션

- 질문: 정상 평균 스펙트럼의 8–10 kHz 봉우리와 11 kHz 봉우리는 어디서 오나
- 방법: Welch PSD 4096점 대역 몫(파일별) · 세 파일 스펙트럼 · 스펙트로그램(512 · 1024점 창). 11 kHz 돌출 = 10.8–11.2 kHz 최대 − 이웃(10.2–10.6 · 11.4–11.8) 중앙값
- 주의: 대역은 그림을 보고 정했다(라벨을 본 뒤) → 기술 통계일 뿐, 피처로 쓰려면 라벨 없는 정의로 바꿔야 한다(결정.md '대역')

## 결과
- 8–10.5 kHz 정상 에너지의 59%가 116, 22%가 055. 10.0–10.4 kHz는 065가 37%. 평균/중앙값 16.7 dB (`몫.txt`, `그림1`)
- 116 · 055는 **9.5 kHz**, 065는 **10.2 kHz** 좁은 지속음이 2초 내내 있고, 큰 광대역 충격이 한 번씩 있다(`그림3`). 고장 019의 고주파는 넓고 시간에 따라 흔들린다
- 116(J 오경보 5/5)과 055(0/5)는 같은 9.5 kHz 지속음 → 지속음만으로 오경보가 나는 것은 아니다
- 11 kHz 지속음(≈10.96 kHz, 폭 ≈160 Hz): 돌출 ≥ 6 dB 비율 정상 57% · 고장 23% · val 78% (`그림4`, 정상 037 · 006 스펙트로그램). 고장은 바탕이 높아 덜 튀어 보일 수 있다
- 원인 미확인: 구조 공진의 지속 가진 / 일정 속도 부품(모터 · 기어) / 계측 간섭. 조교 질문 후보
