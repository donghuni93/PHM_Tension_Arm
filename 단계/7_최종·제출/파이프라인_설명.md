# 최종 파이프라인 설명 — 텐션암 이상감지 9조

작성 2026-11-16 · 이동훈. 독자 기준: 데이터 분석 경험은 있으나 진동·기계 지식은 적은 산업공학 전공자.
수치는 모두 학습 데이터 150개의 중첩 교차검증 결과이며 출처는 [EXP-030](../5_모델비교/유의미/EXP-030_1116_최종후보고정_규칙감사/README.md)이다.

## 1. 과제의 통계적 구조

| 항목 | 내용 | 산업공학 용어 대응 |
|---|---|---|
| 관측 단위 | 파일 1개 = 가속도 50,000점 (2초 × 25,000 Hz, 단위 g) | 검사 로트 1개 |
| 표본 | 정상 120개 · 고장 30개 (수리 후 · 수리 전 측정) | n = 150, 불량률 20% |
| 출력 | 파일별 0(정상) / 1(고장) | 합격 / 불합격 판정 |
| 평가 | F2 = 5·TP / (5·TP + 4·FN + FP) | 미탐(FN, 2종 오류) 1건의 비용 = 오경보(FP, 1종 오류) 4건 |
| 바닥 점수 | 전부 고장으로 판정 0.556 · RMS 관리도(평균 + 3σ) 0.080 | 전수 불합격 처리 · 단변량 관리도 |

RMS 관리도가 0.080인 이유는 고장 30개 중 28개의 진동 크기(RMS)가 정상 범위 안에 있기 때문이다. 고장은 진동의 크기가 아니라 **형태**(충격의 반복, 특정 주파수의 돌출)에서 정상과 구분된다. 이후 단계는 모두 형태를 수치로 변환하는 절차다.

## 2. 전체 흐름

```
신호 1개 (50,000점)
   │ ① 평균 제거 (센서 영점 보정)
   ├───────────────┬────────────────┬────────────────┐
   ▼               ▼                ▼                ▼
② 스펙트럼        ③ 충격·대역       ④ 8.3 kHz        ⑤ 타격 반복
   1초 구간 8개      피처 150개        봉우리 돌출·폭     2위 타격 크기, 2위/1위
   │               │                │                │
 [전문가 1] AE     [전문가 2] ET     [규칙 1]          [규칙 2]
 정상만 학습        정상·고장 학습     돌출 ≥ 0.75 dec    정상 중심 거리 ≥ 2
 복원 오차         고장 확률          폭 ≥ 150 Hz        2위/1위 ≥ 0.7
   │               │                │                │
   └── ⑥ 정상 기준 z ──┘              │                │
            │                        │                │
   ⑦ 로지스틱 결합 점수               └── ⑧ 하나라도 충족 → 고장 ──┐
            │                                                   │
   ⑨ 점수 ≥ 임계값 → 고장 ───────────────────────────────→ 최종 판정 (0 / 1) + 근거
```

구조는 두 층이다. 아래층(②③⑥⑦⑨)은 데이터에서 학습한 통계 모델이고, 위층(④⑤⑧)은 물리 가설에서 도출한 규칙 2개다. 통계 모델은 다수의 고장을 검출하고, 규칙은 통계 모델의 점수가 정상 범위에 머무는 고장을 보완한다.

코드는 [`src/final.py`](../../src/final.py) 한 파일에 위 순서대로 배치하였다 (`signal_tables` → `Core.fit` → `Core.parts` → `FinalModel`).

## 3. 단계별 설명

### 3.1 ① 평균 제거
- 역할: 파일마다 신호 평균을 차감한다.
- 근거: 평균이 −1 g인 파일이 4개 있다(센서 장착 방향 차이로 추정). 평균은 진동 형태와 무관한 측정기 영점이다.
- 이동평균(MA)을 적용하지 않은 근거: MA 창이 커질수록 정상·고장의 첨도 비가 4.2 → 1.4로 감소한다. 충격은 짧고 빠른 성분이라 평활화하면 소실된다.

### 3.2 ② 스펙트럼 — 주파수별 분산 분해
- 개념: 파워 스펙트럼(PSD)은 신호의 분산을 주파수 성분별로 분해한 값이다. 분산분석(ANOVA)이 총변동을 요인별 변동으로 분해하는 것과 같은 구조이며, 요인이 "진동의 빠르기(Hz)"다. 전 주파수의 합은 신호의 분산과 같다.
- 절차: 200 Hz 미만 제거(고역통과) → 1초 길이 구간 8개 → 구간마다 PSD 1,025칸 → log10.
- 200 Hz 미만을 제거하는 근거: 차체의 느린 출렁임(하중)이 분산의 대부분을 차지하여 나머지 주파수의 차이가 드러나지 않는다.
- 구간 8개로 분할하는 근거: 파일 1개에서 스펙트럼 표본 8개를 확보한다 (정상 120개 → 960행).

### 3.3 전문가 1 — 오토인코더(AE): 정상 스펙트럼의 다변량 관리도
- 역할: **정상 파일의 스펙트럼만** 학습하여 1,025칸을 16개 값으로 압축한 뒤 복원한다. 새 파일의 스펙트럼이 정상 패턴으로 복원되지 않는 정도(복원 오차)가 이상 점수다.
- 산업공학 용어 대응: 다변량 통계적 공정관리(MSPC)에서 주성분분석(PCA)으로 정상 공정을 모형화하고 잔차 제곱합(SPE, Q 통계량)을 관리하는 방법과 같다. AE는 PCA의 선형 압축을 비선형으로 확장한 것이다.
- 특성: 고장 라벨을 쓰지 않으므로 "정상에서 벗어난 정도"만 측정한다. 학습 데이터에 없는 유형의 고장에도 반응할 수 있다.
- 단독 성능: F2 0.845 ± 0.017 (재현율 0.907, 오경보율 0.115).

### 3.4 전문가 2 — ExtraTrees(ET): 충격 피처 150개의 분류기
- 피처: 파일마다 150개 요약값을 산출한다. 대표 항목은 다음과 같다.

| 피처 | 의미 | 고장에서의 변화 |
|---|---|---|
| RMS | 진동의 전체 크기 (표준편차) | 대부분 정상 범위 |
| Peak · 파고율(Peak/RMS) | 최대 순간값 · 전체 크기 대비 최대값 | 충격이 있으면 상승 |
| 첨도 | 분포 꼬리의 두께. 드물게 발생하는 큰 값에 민감 | 충격이 있으면 상승 |
| 대역 필터 후 첨도·Peak | 주파수 대역 10개로 분리한 뒤 대역별로 산출 | 1.25–2.5 kHz 대역에서 구분력이 최대 (단변량 AUC 0.878) |
| 대역 에너지 비율 | 전체 분산 중 대역별 분산의 비율 | 일부 고장에서 고주파 비율 변화 |

- 대역 경계는 데이터를 보기 전에 정한 균등 격자(1,250 Hz, 625 Hz)다. 라벨을 보고 대역을 선택하면 교차검증 점수가 과대 산정된다.
- 모델: ExtraTrees는 랜덤 포레스트 계열의 결정나무 300그루 앙상블이다. 피처 수(150)가 표본 수(150)와 같은 조건에서 선택한 근거는 피처의 척도·공선성에 둔감하다는 점이다 (상관 0.9 초과 피처를 제거해도 성능이 같았다, EXP-007).
- 단독 성능: F2 0.823 ± 0.025 (재현율 0.867, 오경보율 0.100).

두 전문가의 미탐 파일은 서로 다르다. AE는 스펙트럼이 정상 범위인 고장(014·017)을, ET는 충격이 없는 스펙트럼형 고장(002·029)을 검출하지 못한다. 이 차이가 결합의 근거다.

### 3.5 ⑥ 정상 기준 z — 두 점수의 척도 통일
- 정의: z = (점수 − 정상 중앙값) / (정상 90% 분위 − 정상 중앙값). z = 1은 정상의 90% 분위에 해당한다.
- 산업공학 용어 대응: 관리도의 중심선과 관리한계를 정상(관리 상태) 데이터만으로 설정하는 것과 같다. 평균·표준편차 대신 중앙값·분위를 쓴 근거는 정상 중 특이한 파일의 영향을 억제하기 위해서다 (로버스트 추정).
- OOF(out-of-fold) 점수 사용: 학습 파일의 전문가 점수는 그 파일을 제외하고 학습한 모델로 산출한다 (4등분). ET는 학습에 사용한 파일에 거의 0 또는 1의 확률을 출력하므로, 이 값으로 다음 단계를 학습하면 새 파일의 점수 분포와 불일치한다.

### 3.6 ⑦ 결합 — 로지스틱 회귀
- 결정값 = a × (AE z) + b × (ET z) + c. 추정 모수는 3개다.
- 모수를 3개로 제한한 근거: 고장 표본이 30개다. 경계를 곡선으로 확장한 시도(RBF SVM, 축 추가, 모수 튜닝)는 모두 성능이 하락하였다 (EXP-015·016·026). 오류 파일은 경계의 형태가 아니라 입력 정보의 부족에서 발생하였다.
- 결합 성능: F2 0.857 ± 0.031. 오경보율이 0.100–0.115에서 0.063으로 감소한다.

### 3.7 ④ 규칙 1 — 8.3 kHz 모드
- 물리 개념: 부품은 충격을 받으면 고유한 주파수로 진동한다(고유진동수, 공진). 종의 음높이가 형상과 재질로 정해지는 것과 같다. 스펙트럼에서는 해당 주파수의 봉우리로 나타난다.
- 관찰: 고장 5개에서 8.20–8.45 kHz 봉우리가 주변보다 크고 넓다. 정상에도 같은 위치의 봉우리가 있으나 폭이 좁다(92 Hz, 단일 주파수 성분).
- 규칙: 돌출 ≥ 0.75 dec(주변 대비 약 5.6배) **이고** 반높이 폭 ≥ 150 Hz이면 고장.
- "돌출"의 정의: 봉우리 높이 − 주변 1.2 kHz 구간의 중앙값. 파일 전체의 진동 크기와 무관하므로 측정 조건(게인) 차이의 영향을 받지 않는다.
- 대상: 고장 002·006·010·029·030, 정상 0개. 002·029는 충격과 에너지가 모두 정상 범위인 고장으로, 두 전문가의 점수만으로는 검출되지 않는다.
- 적용 후 성능: F2 0.892 ± 0.015.

### 3.8 ⑤ 규칙 2 — 유격 반복
- 물리 개념: 연결부(부싱·볼조인트)가 마모되면 부품 사이에 틈(유격)이 발생한다. 하중이 걸릴 때마다 부품이 틈을 건너 충돌하므로 **비슷한 크기의 타격이 반복**된다. 정상 부품의 큰 타격은 노면 요철 같은 외부 입력으로 1회 발생하고 종료되는 경우가 많다.
- 측정값
  - 바탕 σ: 200 Hz 고역통과 신호의 로버스트 표준편차(1.4826 × MAD). 큰 타격이 포함되어도 값이 변하지 않는다.
  - 타격: 신호가 바탕의 8배를 초과한 순간. 10 ms 이내는 1건으로 계수한다. 타격 높이 = 최대값 / σ (신호 대 잡음비).
  - K1 = log10(두 번째로 큰 타격 / σ), K2 = log10(저주파 RMS / σ), 2위/1위 = 두 번째 타격 높이 / 첫 번째 타격 높이.
  - r = K1·K2를 학습 정상의 중앙값·MAD로 표준화한 값의 제곱평균제곱근. 이변량 관리도에서 중심으로부터의 거리에 해당한다.
- 규칙: r ≥ 2 **이고** 2위/1위 ≥ 0.7이면 고장.
- 대상: 고장 10개(003 004 008 010 011 014 017 019 028 030), 정상 0개. 014·017은 진동이 정상보다 작아 두 전문가의 점수가 정상 범위에 있는 고장이다. 타격을 그 파일의 바탕으로 나누어 측정하므로 진동이 작은 파일에서도 반복 타격이 검출된다.
- 적용 후 성능(최종 구성): F2 0.942 ± 0.012 (재현율 0.960, 오경보율 0.033).

### 3.9 ⑧ 규칙의 결합 방식
규칙 중 하나라도 충족되면 결합 점수와 무관하게 고장으로 판정한다(코드에서는 점수에 100을 가산한다). 검사 공정의 병렬 판정(어느 한 검사에서 불합격이면 불합격)과 같다. 병렬 판정은 재현율을 상승시키고 오경보를 합산한다. F2에서 미탐 비용이 오경보의 4배이므로 병렬 구조가 적합하다.

규칙만 사용하고 통계 모델을 제외하면 F2는 0.489다. 전부 고장으로 판정하는 경우(0.556)보다 낮다. 규칙의 대상은 고장 30개 중 13개(두 규칙의 중복 2개 제외)이므로 단독으로는 불충분하며, 통계 모델의 보완 수단이다.

### 3.10 ⑨ 임계값
- 결합 점수가 임계값 이상이면 고장이다. 임계값은 학습 파일의 OOF 점수에서 F2가 최대인 값이다. 관리한계를 3σ로 고정하지 않고 손실(F2)이 최소가 되는 위치로 설정한 것이다.
- 임계값의 위치: F2가 최대인 값 중 가장 낮은 값을 선택하며, 이 값은 "검출되는 고장 중 점수가 가장 낮은 고장"의 점수다. 그 아래 정상 최고점까지의 간격(중앙값 0.13)은 정상 쪽 여유가 된다. 임계값을 간격의 중간·하단으로 이동한 정책의 중첩 교차검증 F2는 0.933–0.945로 현재 정책과의 차이가 표준편차 이내여서 현재 정책을 유지하였다 (EXP-030 추가 확인 2).
- 임계값은 학습 파일을 분할하는 난수(seed)에 따라 변동한다. 분할에 따라 점수가 가장 낮은 고장이 달라지기 때문이다. 한 분할에서는 0.89–1.35 구간에 고장 5개가 분포하였다. 이 구간의 점수를 받은 새 파일은 판정이 불안정하다. 최종 모델은 seed 3개에서 산출한 값의 중앙값을 사용한다. 중첩 교차검증 F2는 seed 1개 0.942 ± 0.012, 3개 중앙값 0.938 ± 0.014로 차이가 표준편차 이내다. 중앙값의 목적은 성능 향상이 아니라 특정 seed에 대한 의존 제거다. 최종 임계값은 1.326이다(seed별 1.345 · 0.891 · 1.326).
- seed별 임계값의 최솟값과 최댓값 사이의 점수를 받은 파일은 근거표에 "경계"로 표시된다.

|---|---|---|---|---|

규칙을 추가할 때 오경보율도 함께 감소한다(0.063 → 0.043 → 0.033). 규칙이 없으면 점수가 낮은 고장(002·014·017)까지 포함하려고 임계값이 하락하고, 그 결과 경계 근처의 정상이 고장으로 판정된다. 규칙이 이 고장들을 별도로 처리하면 임계값이 상승한다.

최종 구성에서 남는 오류는 미탐 022(5회 중 5회), 경계 005(1회), 오경보 025(5회)·116(4회)·055(3회)·059(3회)다.

## 5. 최종 구성의 선정 근거

11-16 시점의 후보는 EXP-025(위 표의 최종 행, F2 0.942)와 EXP-029 계열(EXP-025 + 단일 타격 감점 0.954, + 주기 잠금 규칙 0.966, + 둘 다 0.978)이었다. 교차검증 점수는 후자가 높다. 학습 데이터만 있는 조건에서 과적합을 방지하기 위해 규칙마다 다음 4개 기준을 적용하였다 ([EXP-030](../5_모델비교/유의미/EXP-030_1116_최종후보고정_규칙감사/README.md)).

| 기준 | 내용 |
|---|---|
| C1 기전 | 물리 가설에 연결되고 한 문장으로 기술할 수 있다 |
| C2 지지 | 규칙의 대상인 학습 파일이 3개 이상이다 |
| C3 문턱 여유 | 문턱을 ±20% 변경한 모든 조합에서 반대쪽 파일이 대상에 포함되지 않는다 |
| C4 오류 방향 | 고장으로 올리는 규칙의 오류는 오경보 1건, 정상으로 내리는 규칙의 오류는 미탐 1건(오경보 4건의 비용)이다. 내리는 규칙에는 측정 구간을 변경해도 조건에 해당하는 고장이 1개 이하일 것을 요구한다 |

| 규칙 | 방향 | C2 지지 | C3 ±20% | C4 | 판정 |
|---|---|---|---|---|---|
| 8.3 kHz 모드 | 올림 | 고장 5 | 미달: 돌출 문턱을 19% 완화하면 정상 092, 돌출 17%와 폭 11%를 함께 완화하면 정상 070 포함 (±10%에서는 0개) | 해당 없음 | 유지 (11-14 채택), 여유 경고 |
| 유격 반복 | 올림 | 고장 10 | 미달: 2위/1위 문턱을 14% 완화하면 정상 009, r 문턱을 19% 완화하면 정상 001 포함 (±10%에서는 0개) | 해당 없음 | 유지 (11-14 채택), 여유 경고 |
| 주기 잠금 | 올림 | **고장 1 (022)** | 통과 (문턱이 정상 최댓값 + 0.1로 정의되어 하한과 정상 103의 차이는 0.002) | 해당 없음 | **제외** |
| 단일 타격 감점 | **내림** | 정상 38 | 미달: 문턱 22σ에서 고장 019 포함 | **미달: 1.5초 구간에서 고장 5개가 조건에 해당** | **제외** |

- 주기 잠금 규칙: 대상이 022 1개다. 파일 1개에서 정의한 규칙은 같은 유형이 새 데이터에 존재하는지 확인할 수 없다. 교차검증에서는 정상 103도 5회 중 2회 포함되었다.
- 단일 타격 감점: "큰 타격이 정확히 1개인 파일은 정상 쪽으로 점수를 낮춘다"는 장치다. 2초 전체에서는 해당하는 고장이 0/30이나, 측정 구간을 1.5초로 줄여 이동하면 고장 5개(017·019·020·022·026)가 "정확히 1개"가 된다. 조건이 측정 시점에 좌우된다. 0/30 관측에서 실제 비율의 95% 신뢰 상한은 9.5%다.
- 기대 손실 비교(val 40개 = 고장 8 + 정상 32 가정): 감점으로 감소하는 오경보는 약 0.5건이다(오경보율 0.033 → 0.018, 32 × 0.015). 고장이 감점 조건에 해당할 비율을 p라 하면 미탐 증가는 8p건이고 비용은 오경보 32p건에 해당한다. p가 1.5%를 초과하면 손실이 이득을 초과한다. 0/30 관측만으로는 p < 1.5%를 보장할 수 없다(95% 상한 9.5%).
- 두 장치를 모두 적용한 구성의 교차검증 F2는 0.978 ± 0.010으로 최종 구성보다 0.036 높다. 이 차이는 주로 022 1개의 검출(주기 잠금)과 정상 116·055의 오경보 제거(감점)에서 발생한다. 점수 차이의 원인이 소수의 학습 파일에 한정되므로 새 데이터에서의 재현을 확인할 근거가 없다고 판단하였다.
- 기존 두 규칙도 C3 ±20%에는 미달하였다. 두 규칙은 올리는 방향이므로 오류 비용이 오경보 1건으로 제한되고, 규칙으로만 검출되는 고장이 4개(002·029·014·017, 전체의 13%)다. 기대 이득이 비용보다 크다고 판단하여 유지하였다. 문턱 여유가 14–19%라는 점은 val에서 확인할 항목이다.
- 유격 반복 규칙의 r은 정상 중심(중앙값·MAD)의 추정값에 따라 변동한다. 정상 120개를 복원추출하여 중심을 재추정하면(2,000회) 정상 001·093·106이 22–33%의 비율로 규칙 대상이 되고, 고장 014는 85%만 대상이 된다. 학습 표본에서의 "정상 0개"보다 **정상 오작동률 약 1%**(120개 중 평균 1.17개)가 적절한 추정이다. 최종 모델은 정상 120개 전체로 산출한 중심을 고정값으로 사용하므로 val 파일의 판정은 val 표본 구성에 좌우되지 않는다.

## 6. 과적합 방지 장치와 잔여 낙관 요인

| 장치 | 내용 |
|---|---|
| 중첩 교차검증 | 성적 산출용 파일을 학습·표준화·임계값 선택에 사용하지 않는다 |
| 폴드 내 기준값 | z 기준, 유격 규칙의 정상 중심은 학습 쪽 정상만으로 산출한다 |
| 사전 고정 격자 | 피처의 대역 경계를 라벨을 보기 전에 정하였다 |
| 소수 모수 결합 | 결합 단계의 모수는 3개다 |
| 올림 방향 규칙만 채택 | 규칙 오류의 비용을 오경보로 제한한다 |
| 기각 기록 | 모델 교체·축 추가·튜닝·학습 정상 배제 등 기각한 시도를 EXP-015~028로 기록하였다 |
| val의 용도 제한 | val은 확인용이며 val 결과로 문턱을 변경하지 않는다 |

잔여 낙관 요인은 다음과 같다.
- 규칙 2개의 문턱(0.75 dec·150 Hz·r 2·0.7)과 8.3 kHz 대역 경계는 학습 150개의 라벨을 본 뒤 정한 값이다. 따라서 최종 F2 0.942는 낙관적이다. 규칙을 제외한 결합 모델의 F2 0.857에는 사후 문턱에 의한 편향이 없다(같은 150개로 여러 구성을 비교하여 선택한 데 따른 편향은 남는다). 새 데이터의 기대 성능은 두 값 사이로 예상한다.
- val·test는 각 40개다. 표본 1개의 F2 표준편차는 약 0.09다(단계/1_기준·기록/결정.md 'val 점수' 항목, 원 저장소 1-2 조각 4의 산정값). 학습 파일 40개(고장 8 · 정상 32)를 val로 가정하고 나머지 110개로 학습한 리허설 3회의 F2는 1.000 · 0.976 · 0.909였다(3회 모두 고장 8개 전부 검출, 오경보 0 · 1 · 4건). 같은 절차에서도 표본에 따라 이 정도의 차이가 발생한다.


## 7. 한계

- 주기 잠금형 고장(022): 에너지·스펙트럼·충격 크기가 모두 정상 범위이며 충격의 발생 시점만 하중 주기와 일치한다. 학습 데이터에 1개뿐이어서 규칙으로 채택하지 않았다. 같은 유형은 검출되지 않는다.
- 상시 오경보 정상(025): 큰 타격이 4회 있는 정상 파일이며 교차검증 5회 모두 오경보다. 반복 타격이 있는 정상과 고장을 구분하는 정보가 현재 피처에 없다.
- 물리 해석("정상의 큰 타격 = 노면 입력, 고장 = 유격 충돌")은 신호 형태에서 도출한 가정이다. 노면·속도·교체 부품 정보가 없어 원인은 확인되지 않았다.
- 학습 데이터에 없는 유형의 고장은 AE 점수에만 의존한다.
- 학습 데이터에 없는 측정 조건의 정상은 오경보가 된다. 평균 −1 g 정상 3개(097·101·120, 12.4 kHz 에너지가 큰 측정)를 학습에서 제외한 분할에서는 3개 모두 고장으로 판정되었다. 최종 모델은 3개를 학습에 포함한다.
