## 1. 과제의 통계적 구조

| 항목 | 내용 | 산업공학 용어 대응 |
|---|---|---|
| 관측 단위 | 파일 1개 = 가속도 50,000점 (2초 × 25,000 Hz, 단위 g) | 검사 로트 1개 |
| 표본 | 정상 120개 · 고장 30개 | n = 150, 불량률 20% |
| 출력 | 파일별 0(정상) / 1(고장) | 합격 / 불합격 판정 |
| 평가 | F2 = 5·TP / (5·TP + 4·FN + FP) | 미탐(FN, 2종 오류) 1건의 비용 = 오경보(FP, 1종 오류) 4건 |
| 바닥 점수 | 전부 고장으로 판정 0.556 · RMS 관리도(평균 + 3σ) 0.080 | 전수 불합격 처리 · 단변량 관리도 |

RMS 관리도가 0.080인 이유는 고장 30개 중 28개의 진동 크기(RMS)가 정상 범위 안에 있기 때문이다. 고장은 진동의 크기가 아니라 **형태**(충격의 반복, 충격이 울리는 주파수, 특정 주파수의 돌출)에서 정상과 구분된다. 이후 단계는 모두 형태를 수치로 변환하는 절차다.

## 2. 전체 흐름

```
신호 1개 (50,000점)
   │ ① 평균 제거 (센서 영점 보정)
   ├──────────────────────┬──────────────────┬───────────────┬────────────────┐
   ▼                      ▼                  ▼               ▼                ▼
② 충격 · 고주파 피처     ③ 박자(주기 잠금)   ④ 스펙트럼       ⑤ 하중 대비      ⑥ 8.3 kHz
   1 kHz 고역, 15열        느린 흔들림에       1초 구간 8개     고주파 H18       봉우리 · 공진 충격
   (울림 비율은 축소)       충격이 맞춰 나나
   │                      │                  │               │                │
 [전문가 1] ET            [전문가 2] 박자 z   [전문가 3] AE   [규칙 E2]         [규칙 8.3k]
 정상·고장 학습             정상 기준 z         정상만 학습      정상 99 % 초과    돌출 · 폭 OR 공진
 고장 확률(logit)                             복원 오차
   │                      │                  │               │                │
   └──────── ⑦ 정상 기준 z → 로지스틱 결합 ────┘               └── ⑧ 하나라도 → 고장 ──┐
                         │                                                          │
                ⑨ 결합 점수 ≥ 문턱 → 고장 ─────────────────────────────────→ 최종 판정 (0 / 1) + 근거
```

구조는 두 층이다. 아래층(②③④⑦⑨)은 데이터에서 학습한 통계 모델이고, 위층(⑤⑥⑧)은 물리 가설에서 도출한 규칙 2개다. 통계 모델이 다수의 고장을 검출하고, 규칙은 통계 모델의 점수가 정상 범위에 머무는 고장을 보완한다.

코드는 [`src/final.py`](../../src/final.py) 맨 아래 J-축소 절에 위 순서대로 배치하였다 (`j_tables` → `JShrink.fit` → `JShrink.parts` → `FinalJ`). 실험 코드와 같은 판정을 내는지는 [검증_동등성.py](검증_동등성.py)가 확인한다(학습 150 · val 40 판정 모두 같음, [동등성_J.txt](결과/동등성_J.txt)).

## 3. 단계별 설명

### 3.1 ① 평균 제거
- 역할: 파일마다 신호 평균을 차감한다.
- 근거: 평균이 −1 g인 파일이 4개 있다(센서 장착 방향 차이로 추정). 평균은 진동 형태와 무관한 측정기 영점이다.
- 이동평균(MA)을 적용하지 않은 근거: 충격은 짧고 빠른 성분이라 평활화하면 소실된다(MA 창이 커질수록 정상·고장 첨도 비 4.2 → 1.4).

### 3.2 ② 충격 · 고주파 피처 (H 피처) — "어떤 충격이 몇 번, 어디서 울렸나"
- 전처리: 1 kHz 고역통과(4차 Butterworth 양방향). 1 kHz 아래의 차체 출렁임(하중)을 지워 충격만 남긴다 ([3-2](../3_전처리/3-2_1121_고역차단주파수/README.md)).
- 충격 정의: 1 kHz 고역 신호의 포락선(|Hilbert|)을 1,000 Hz로 다듬고, 100 ms 이동 중앙값(바탕)의 4.5배를 넘는 봉우리. 간격 ≥ 6.75 ms, 파일 앞뒤 10 ms 제외 ([4-6](../4_피처/4-6_1121_충격재정의/README.md)).
- 울림: 충격 뒤 8 ms를 감쇠 사인파 사전과 비교해 가장 닮은 주파수를 그 충격의 "울림 주파수"로 기록한다. 종을 치면 종 고유의 음으로 울리듯, 울림 주파수로 **어느 부품이 울렸는지** 알 수 있다.
- 대역은 데이터를 보기 전에 정한 옥타브 4칸(1–2 · 2–4 · 4–8 · 8–12.5 kHz)만 쓴다. 라벨을 보고 대역을 고르면 교차검증 점수가 과대 산정된다.

| 피처 | 의미 | 고장에서의 변화 (근거 EDA) |
|---|---|---|
| H1 충격 수 (log) | 2초 동안 충격이 몇 번 | 고장은 큰 타격이 **반복**된다 ([2-5](../2_EDA/2-5_큰타격반복/README.md)) |
| H2 2위/1위 | 두 번째 큰 충격 ÷ 가장 큰 충격 | 반복 타격이면 1에 가깝다 |
| H3 · H5 옥타브 첨도 | 1–2 · 4–8 kHz 대역 신호의 꼬리 두께 | 충격이 있으면 상승 |
| H7–H10 울림 비율 | 충격 중 각 옥타브로 울린 비율 | 정상은 6.5–7.5 kHz(본체 모드), 고장은 2–4 kHz · 8 kHz대 ([2-7](../2_EDA/2-7_충격울림주파수/README.md)) |
| H12–H15 옥타브 파워 몫 | 1 kHz 위 파워 중 각 옥타브의 몫 (크기로 나눈 비율) | 스펙트럼 모양 |
| H16 · H17 가장 솟은 좁은 봉우리 | 학습 정상의 중앙 스펙트럼보다 가장 많이 솟은 곳의 높이 · 폭 | 정상에 없는 봉우리 |
| H18 하중 대비 고주파 | 1 kHz 위 포락선 중앙값 ÷ 20 Hz 아래 흔들림 RMS | 작은 고장도 하중에 비해 덜컥거림이 크다 ([2-4](../2_EDA/2-4_하중대비고주파/README.md)) |

- 진동 **크기**는 넣지 않는다. 센서가 하나라 크기는 "길(노면) × 부품"이 섞인 값이고, 크기로 나눈 비율 · 모양 · 박자가 부품 상태를 더 잘 드러낸다.

### 3.3 울림 비율 축소 — 충격이 적은 파일의 비율을 믿을 만큼만 (EXP-050)
- 문제: 충격이 2–3개뿐인 파일은 울림 비율(H7–H10)이 충격 한두 개로 0이나 1까지 크게 움직인다. 경계 근처 파일 13개 중 8개가 이 유형이었다 ([6-4](../6_오류분석/6-4_1122_경계파일진단/README.md)).
- 처리: 비율 = (그 대역으로 울린 충격 수 k + 3 · p0) / (충격 수 n + 3). p0는 학습 정상의 모든 충격에서 그 대역 비율이다(4–8 kHz 0.835 등). 충격이 많으면 원래 비율 그대로, 적으면 정상 쪽으로 당긴다.
- 산업공학 용어 대응: 표본이 적은 로트의 불량률을 공정 평균 쪽으로 당기는 **베이즈 축소**(경험적 베이즈, 라플라스 평활)와 같다. α = 3은 "가상의 정상 충격 3개를 더한다"는 뜻이며 실행 전에 고정하였다.
- 효과: 중첩 F2는 J와 같은 0.977 ± 0.010이고, val 결합 고장 수의 부트스트랩 5–95 % 범위가 8–21 → 8–14로 좁아졌다(판정이 덜 흔들림).

### 3.4 전문가 1 — ExtraTrees(ET): "아는 고장과 닮았나"
- 입력: H 피처 13열(울림 비율 축소 후) + 봉우리 2열 = 15열. 모델: 결정나무 300그루 앙상블.
- 출력: 고장 확률의 logit (log(p / (1 − p))). 결합에는 **안쪽 4등분 OOF**(그 파일을 빼고 학습한 모델의 점수)를 쓴다. ET는 학습에 쓴 파일에 거의 0 또는 1을 내므로, 이 값으로 다음 단계를 학습하면 새 파일의 점수 분포와 맞지 않는다.

### 3.5 전문가 2 — 박자 z: "하중의 흔들림에 맞춰 덜컥거리나" (2-6)
- 계산: 30 Hz 아래 느린 흔들림의 자기상관이 가장 큰 주기 T를 찾고(0.3–1.2 초), 충격 중 "T 떨어진 곳에 다른 충격이 있는" 비율을 곱한 값 S ([2-6](../2_EDA/2-6_주기잠금_022/README.md)).
- 근거: 고장 022는 에너지 · 스펙트럼 · 충격 크기가 모두 정상 범위이고, 충격이 하중 주기(0.94 초)에 잠겨 있는 것만 다르다.
- 정상 기준 z = (S − 학습 정상 중앙값) / (1.4826 × 정상 MAD). 정상의 약 79 %가 S = 0이라 MAD가 0이면 정상 90 % 분위로 대신한다.

### 3.6 전문가 3 — 오토인코더(AE): 정상 스펙트럼의 다변량 관리도
- 입력: 200 Hz 고역통과 → 1초 구간 8개 → 구간마다 PSD 1,025칸 → log10. 파일 1개에서 스펙트럼 표본 8개 (정상 120개 → 960행).
- 역할: **정상 파일의 스펙트럼만** 학습하여 1,025칸을 16개 값으로 압축한 뒤 복원한다(1025-128-16-128-1025). 복원 오차 평균의 log가 이상 점수다.
- 산업공학 용어 대응: MSPC에서 PCA로 정상 공정을 모형화하고 잔차 제곱합(SPE, Q 통계량)을 관리하는 것과 같다. AE는 PCA를 비선형으로 확장한 것이다. 정상 PCA로 바꾸면 0.970으로 낮았다([EXP-049](../5_모델비교/아카이브/EXP-049_1122_정상PCA_full재확인/README.md)).
- 몫: AE를 넣으면 G 0.959 → J 0.977이고, 대부분 **오경보 감소**(0.047 → 0.030)에서 온다. 충격형 정상(095 · 110)이 "스펙트럼은 정상"이라는 근거로 내려간다.

### 3.7 ⑦ 정상 기준 z와 로지스틱 결합
- 결합 입력 3개: ET OOF logit, 박자 z, AE z (AE도 안쪽 4등분 OOF 점수를 학습 정상 중앙값 · MAD로 z).
- 결정값 = +1.642 × ET logit + 0.461 × 박자 z + 0.470 × AE z − 0.004 (학습 150 전체, [학습요약](결과/학습요약.txt)). 추정 모수 4개.
- 로지스틱을 쓴 근거: 같은 3입력에서 비선형 결합기 7종 × 용량 52칸을 비교했고, 기준을 표준편차 넘게 넘은 칸이 0이었다(최선 SVM 0.969 ± 0.021, [EXP-052](../5_모델비교/5_울림비율축소/EXP-052_1122_비선형결합_재실험/README.md)). 경계가 거의 대각선이라 유연한 모델은 폴드마다 경계를 흔든다.

### 3.8 ⑤ 규칙 E2 — 하중 대비 고주파 (유격)
- 물리 개념: 연결부(부싱 · 볼조인트)가 마모되어 틈(유격)이 생기면 하중이 걸릴 때마다 부품이 틈을 건너 충돌한다. 진동 전체가 작은 고장도 **하중에 비해** 고주파 덜컥거림이 크다.
- 규칙: H18 > 학습 정상 H18의 99 % 분위(0.660) **이고** 충격 ≥ 1개이면 고장. 문턱이 라벨이 아니라 정상 분포의 고정 분위수라 사후 문턱이 아니다.
- 대상(학습 재대입): 고장 004 · 011 · 017 · 019, 정상 0개. 017은 진동이 작아 다른 전문가 점수로는 정상 범위다.

### 3.9 ⑥ 규칙 8.3k — 8.3 kHz 모드
- 물리 개념: 부품은 충격을 받으면 고유한 주파수로 진동한다(고유진동수, 공진). 고장 파일에서 8.3 kHz 모드가 **크고 넓게** 들뜬다. 처음 가설("공진이 옮겨 간다")은 기각되었다 ([2-2](../2_EDA/2-2_8.3kHz모드/README.md) · [2-3](../2_EDA/2-3_AE오차_8kHz/README.md)).
- 규칙(둘 중 하나): (스펙트럼) 8.20–8.45 kHz 봉우리 돌출 ≥ 0.75 dec(주변 대비 약 5.6배) **이고** 반높이 폭 ≥ 150 Hz, OR (공진 충격) 8.0–8.7 kHz로 울린 충격 중 감쇠비 ζ ≤ 0.02 · 감쇠 사인파 fit ≥ 0.7인 충격이 하나라도 있으면 고장.
- 대상(학습 재대입): 스펙트럼 002 · 006 · 010 · 029 · 030, 공진 002 · 003 · 006 · 010 · 029, 정상 0개. 002 · 029는 충격과 에너지가 모두 정상 범위라 통계 모델만으로는 잡히지 않는다.
- **사후 문턱**: 대역과 문턱을 라벨을 본 뒤 정하였다. 기전이 설명되고 겨냥한 고장이 여럿(5개)이라 예외로 허용하였으며 점수는 낙관적이다 ([결정](../1_기준·기록/결정.md) "사후 문턱 예외").

### 3.10 ⑧ 규칙의 결합 방식
규칙 중 하나라도 충족되면 결합 점수와 무관하게 고장으로 판정한다(OR). 검사 공정의 병렬 판정(어느 한 검사에서 불합격이면 불합격)과 같다. 병렬 판정은 재현율을 올리고 오경보를 합산한다. F2에서 미탐 비용이 오경보의 4배이므로 병렬 구조가 적합하다. 규칙은 모두 **올리는 방향**뿐이라 규칙 오류의 비용은 오경보로 제한된다.

### 3.11 ⑨ 문턱
- 결합 점수가 문턱 이상이면 고장이다. 문턱 = 학습 파일의 결합 점수(OOF 입력)에서 F2가 최대인 값이다 (학습 150 전체로 1.142). 관리한계를 3σ로 고정하지 않고 손실(F2)이 최소가 되는 위치로 설정한 것이다.
- 중첩 교차검증(0.977)에서 평가한 것과 **같은 절차**다. 그래서 평가한 모델과 제출하는 모델이 같다. 예전 최종(EXP-034 c)의 고정 문턱 1.0은 그 모델의 점수 눈금 기준이라 쓰지 않는다.
- 근거표의 `margin`(결합 점수 − 문턱)이 0에 가까운 파일은 판정이 흔들리기 쉽다. val에서는 val_025(−0.09) 하나다.

## 4. 층별 성능

중첩 교차검증: 바깥 5등분(성적 산출용) × 안쪽 4등분, 난수 5회 반복. 성적 산출용 파일은 모델 학습 · 정상 기준 · 문턱 선택에 사용하지 않는다.

|---|---|---|---|---|---|
| 전부 고장으로 판정 | 0.556 | 1.000 | 1.000 | — | |
| ET(H 피처) + 박자 z → 로지스틱 | 0.907 ± 0.009 | 0.927 | 0.045 | 002 017 | EXP-040 C |
| + E2 | 0.933 ± 0.014 | 0.960 | 0.047 | 002 | EXP-043 F |
| + 8.3k 규칙 (G) | 0.959 ± 0.014 | 0.993 | 0.047 | — | EXP-043 G |
| + AE z (J) | 0.977 ± 0.010 | 1.000 | 0.030 | — | EXP-044 J |
| **+ 울림 비율 축소 (J-축소, 최종)** | **0.977 ± 0.010** | **1.000** | **0.030** | — | EXP-050 |

규칙을 빼면 002 · 017을 놓친다(K). 8.3k가 002를, E2가 017을 맡는다. AE는 재현율보다 오경보율(0.047 → 0.030)을 낮춘다.

## 6. 과적합 방지 장치와 잔여 낙관 요인

| 장치 | 내용 |
|---|---|
| 중첩 교차검증 | 성적 산출용 파일을 학습 · 정상 기준 · 문턱 선택에 사용하지 않는다 |
| 폴드 내 기준값 | 정상 기준 z · 봉우리 기준 · 울림 비율 축소의 p0 · E2 문턱은 학습 쪽 정상만으로 산출한다 |
| 사전 고정 격자 | 피처 대역은 옥타브 4칸, 축소 세기 α = 3은 실행 전에 고정하였다 |
| 소수 모수 결합 | 결합 단계의 모수는 4개다 |
| 올림 방향 규칙만 채택 | 규칙 오류의 비용을 오경보로 제한한다 |
| 실행 전 교체 규칙 | 새 구성은 기준을 sd 넘게 넘고 val 판정이 덜 흔들릴 때만 교체한다 (EXP-051 · 052는 이 규칙으로 기각) |
| val의 용도 제한 | val은 판정 안정성 확인용이며 val 결과로 문턱을 변경하지 않는다 |

잔여 낙관 요인은 다음과 같다.
- 8.3k 규칙의 대역 · 문턱은 학습 150개의 라벨을 본 뒤 정한 값이다. 따라서 최종 F2 0.977은 낙관적이다. 8.3k 규칙을 뺀 구성(EXP-044 L, 0.950 ± 0.009)에는 이 편향이 없다(같은 150개로 여러 구성을 비교해 고른 편향은 남는다). 새 데이터의 기대 성능은 두 값 사이로 예상한다.
- val · test는 각 40개다. 표본 1개의 F2 표준편차는 약 0.09다. 학습 파일 40개(고장 8 · 정상 32)를 val로 가정하고 나머지 110개로 학습한 리허설 3회의 F2는 0.976 · 0.930 · 0.976이었다(3회 모두 고장 8개 전부 검출, 오경보 1 · 3 · 1건). 같은 절차에서도 표본에 따라 이 정도의 차이가 발생한다.

## 7. 한계

- 상시 오경보 정상 116 · 065 · 059: 2초 내내 이어지는 좁은 고주파 지속음(9.2–11 kHz)이 있는 정상이다. 어떤 피처 · 모델로도 내려가지 않아 **정보 한계**로 두었다 ([2-9](../2_EDA/2-9_정상고주파지속음/README.md)). 지속음의 출처(구조 공진 · 일정 속도 부품 · 계측 간섭)는 확인되지 않았다.
- 측정 조건 차이: val은 충격을 뺀 배경 3–5 kHz가 학습보다 약 +10.9 dB 높다. AE z가 val 전체에서 올라가지만 재보정하면 판정이 거의 같아(10 → 9) 학습 데이터로 만든 그대로 제출한다 ([2-8](../2_EDA/2-8_val배경이동/README.md)).
- val 판정 안정성: 학습 분할만 바꾼 모델 25개로 val을 판정하면 40개 중 31개는 모두 같은 판정이고, 흔들리는 파일은 001(8.3k 규칙만으로 고장) · 025(2 kHz 대역 경계) · 018(AE 배경) 등이다 ([6-7](../6_오류분석/6-7_1122_val확실도/README.md)).
- 물리 해석("정상의 큰 타격 = 노면 입력, 고장 = 유격 충돌")은 신호 형태에서 도출한 가정이다. 노면 · 속도 · 교체 부품 정보가 없어 원인은 확인되지 않았다.
- 학습 데이터에 없는 유형의 고장은 AE(정상에서 벗어난 정도)에 주로 의존한다.
