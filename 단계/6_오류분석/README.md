# 6단계 오류 분석

상태: J-축소 기준 오류 · val 경계 진단 (11-22). 바로 아래 = 지금 모델(J · J-축소)을 진단한 조각, `아카이브/` = 예전 구성 기준 조각(6-1, EXP-030 시절)

## 목적
자주 놓친 고장과 오경보를 정상 5–95% 범위와 겹친 그림으로 보고 원인을 물리가설로 설명한다.

## 이 단계에서 답할 질문
- abn_002·022·029는 왜 정상 분포 안에 있는가
- 반복 오경보 정상 파일(nor_008·025·027·054·055·073·095 등)의 공통점
- 개선이 가능한가, 아니면 한계로 발표할 것인가

## 결과

- [6-2 (11-22) 기본 t-SNE 위의 J 판정 + 11-22 그림 총정리](6-2_1122_J판정_tSNE/README.md): 섞인 고장 8개는 결합(AE · 박자 z)이나 규칙(A002 8.3k · A017 E2)이 잡는다. 오경보 4개는 두 무리 사이 경계에 있다
- [6-4 (11-22) J 경계 파일 진단](6-4_1122_경계파일진단/README.md): 경계 파일 13개 중 8개는 "충격 2–6개 + 4 kHz 아래 울림" 유형. 시간 구조 피처(사건 수 · 후속 충격 · 몰림)는 충격 수와 같은 정보(ρ 0.74–0.96). 이 유형을 보정하는 실험 = [EXP-050](../5_모델비교/5_울림비율축소/EXP-050_1122_울림비율축소_H10/README.md)(울림 비율 축소, J와 같은 점수)
- [6-6 (11-22) V025 진단](6-6_1122_V025진단/README.md): J-축소 여유 −0.09의 주원인은 울림 2.0 kHz가 대역 경계(2000 Hz는 2–4k로 셈)에 걸린 것. 1–2k로 셌다면 −2.05. 그 위에 val 공통 AE 상승 +0.61. 주기 잠금 점수는 0(원인 아님). 폴드 모델 6개 중 4개는 고장
- [6-7 (11-22) val 확실도 · 경계 val 점검](6-7_1122_val확실도/README.md): J-축소 val 40개 중 31개 확실(정상 23 · 고장 8). 흔들리는 건 001(8.3k 규칙만) · 025(19/25) · 018(12/25). 001은 규칙 기준 자료(2-11)로는 고장 자리지만, 고정 공진이 아니라 8.56 → 8.13 kHz로 미끄러지는 지속음(+4.2 kHz 짝)이고 8.3 kHz 충격 울림이 없음 → 학습에 없던 새 모양, 확실하지 않음. 제출 모델 문턱이 120개 모델들보다 높아 체계적으로 정상 쪽
- [6-8 (11-22) V018 진단](6-8_1122_V018진단/README.md): J-축소 여유 −0.72(25개 중 12 고장). ET는 정상 쪽(−0.71, 약한 충격 3개 · 3.15 kHz), AE가 고장 쪽(+1.14, 학습 정상 100 % — val 공통 배경 상승과 같은 방향). 가장 가까운 고장 A021과 충격 모양이 닮았지만 세기 3분의 1
