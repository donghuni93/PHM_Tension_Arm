# D_1 — 진단 담당 제안서 (11-22, 라벨 사용 원칙)

## 결론
1. **val 판정이 흔들리는 주원인은 규칙 의존이 아니라 AE 점수의 분포 이동이다.** 규칙이 바꾼 val 판정은 1개(val_001)뿐이다. 반면 AE z를 val 하위 25%에 맞춰 0.5 내리면 판정 11 → 8, 1.0 내리면 → 4다.
2. **오경보의 정보는 "사건 구조"에 있고 점수 축(AE z, ET z)에는 없다.** A의 오경보 5개(116 · 065 · 059 · 055 · 025) 중 3개(055 · 065 · 059)는 충격이 1–3개이고, 같은 점수대 고장 16개 중 14개는 사건이 4개 이상이다. 단 선형 축으로는 055 · 116을 내리지 못한다(lr 3.5 · 3.2).
3. **제안은 둘이다.** 사건 구조 축 한 쌍(dom, n_ev, L 등급)과 평가 지표 추가(S6, AE 이동 민감도). 내림 게이트와 본체 모드 규칙은 제안하지 않는다.
4. 함께 확인한 것: 055 · 116 · 009는 ET 입력 공간에서 같은 "큰 타격" 무리이고 009(고장)만 섞여 있다. 이 셋은 지금 정보로는 진짜 회색이다(다).

## 3. 제안 (D · L 등급만)

### D-1 [L] 반복 구조 축: 지배 사건 몫 dom (음의 계수) + 사건 수 n_ev
- **정의**: 충격(새 정의)을 50 ms 안에서 묶은 사건의 높이(사건 최대 height_x)를 모아, dom = 최대 사건 / 사건 높이 합, n_ev = 사건 수(log1p). 정상 중앙·p90 기준 z로 AE z · ET z 옆의 3 · 4번째 축으로. 사건이 0개면 dom = 1, n_ev = 0.
- **기전(D)**: 유격 타격은 하중과 무관하게 비슷한 크기로 반복(H1′), 정상 외부 타격은 한 번 크게 오고 끝난다.
- **겨냥**: 오경보 055 · 065(n_ev 1), 097 · 101 · 120(0개), 놓침 022 · 009 쪽 상승. val 경계 6개(위 표).
- **근거 수치(재측정)**:
  - n_ev ≤ 1: 정상 36 · 고장 0, n_imp = 0: 정상 17 · 고장 0. dom ≥ 0.9: 정상 38 · 고장 2(012 · 018).
  - 점수대 안(규칙 꺼짐 27개) AUC: n_ev 0.78, n_imp 0.80, dom 0.36(역방향).
  - 로지스틱 계수(5겹 × 20 seed): n_ev +0.96 ± 0.17, dom −1.21 ± 0.13, 부호 일치 100%. 둘을 같이 넣으면 n_ev 0.35(98%) · dom −1.01(100%)로 dom이 대부분을 흡수한다 → **dom을 주축, n_ev는 ET 입력으로**.
  - 규칙 없는 결합(OOF seed 10): 기준 ROC 0.945 · PR-AUC 0.839 → +dom 0.959 · 0.900, +n_ev 0.954 · 0.898. F2@최적 임계(낙관): 0.869 → +n_ev 0.873.
  - **폴드 안 안정성**: n_ev ≤ c 컷은 96%가 c = 1(테스트 폴드에서 고장 012 · 030이 4번씩 켜짐), 연속 축으로 쓰면 컷 재선택이 필요 없다. dom ≥ c 컷은 0.8 4번 · 0.95 96번으로 흔들려 컷으로는 쓰지 않는다.
  - **val 이동 없음**: n_ev ≤ 1 정상 0.30 · val 0.30, dom ≥ 0.9 0.32 · 0.33, n_imp ≤ 2 0.34 · 0.35. (본체 울림 몫 ≥ 0.9는 0.48 vs 0.12로 이동이 크다.)
- **t-SNE(5-NN 대용) 분리 효과**: 고장 5-NN 순도(z 공간 AE z, ET z + 축; 무작위 0.20) 0.747 → +n_ev 0.787 · +dom 0.807 · +n_imp,dom 0.833(+res 포함 0.853). 같은 틀의 실제 t-SNE는 협의 후 EXP에서 그린다.
- **val 효과(규칙 없음, 임계값 train 전체 최적)**: `|val − 임계| < 0.5` 13 → 6(+n_ev), 판정 16 → 14.
- **위험**: ① 오경보 8개의 정상 5-NN 순도는 0.70 → 0.57–0.65로 **낮아진다**. 025 · 037 · 110 · 095(n_ev 5–9, 고장 사건 수 백분위 53–87)가 고장 쪽으로 이동하기 때문이다. ② 055 · 116(lr 3.5 · 3.2)을 연속 항으로는 내리지 못한다(백분위 99–100 유지). ③ 정상 037의 OOF 백분위가 92 → 96으로 오른다. ④ 사건 0개 · 1개의 고장이 test에 있으면 내려간다(train 고장 최소 n_imp 3, n_ev 2).

### D-2 [D] 평가 지표 추가 S6: AE 점수 이동 민감도
- **정의**: val(또는 test)의 AE z에서 s = 0.25, 0.5, 0.75를 빼고 판정이 바뀌는 파일 수와 `|점수 − 임계| < 0.5` 파일 수를 센다(ET도 같은 방식). 라벨 없음.
- **근거**: A는 s 0 → 0.5에서 판정 11 → 8, 경계 밀집 7 → 2, s 1.0에서 판정 4. val AE 이동(약 +1.1)이 선택 규칙의 흔들림 지표에 들어가야 한다.
- **효과**: 새 구성이 이동에 덜 민감한지 라벨 없이 비교(S3 부트스트랩은 같은 이동을 못 봄).
- **위험**: 이동의 일부가 val에 섞인 고장 때문이면 민감도가 낮은 구성이 "고장을 못 보는" 구성일 수 있음 → S1(중첩 F2)과 함께만 쓴다.

### D-3 [L] 고장 전문가 · 규칙 계열은 충격 ≥ 1을 요건으로
- **정의**: 충격 기반 · 하중 대비 고주파 점수는 n_imp = 0이면 정상 중앙값으로 둔다(값이 정의되지 않음).
- **근거**: D2의 E1이 켠 097 · 101 · 120이 모두 n_imp = 0(정상 17 · 고장 0, 고장 최소 n_imp 3). 값이 없는데 DC 방향 때문에 켜진 경우다. 겨냥 3개(C2).
- **위험**: 충격이 없는 고장(028형, 0–20 Hz만 있음)은 어차피 못 잡는다(포기 결정). val n_imp = 0인 파일 4개(003 015 028 030)는 영향 받음.
- G0(A)와는 무관하고 새 3번째 축 구성에서만 해당.

## 4. 제안하지 않는 것 (이유)
- **n_ev ≤ 1 내림(veto)**: 정상 36 · 고장 0, 폴드 안 같은 컷 96%로 L 조건은 충족한다. 그러나 055(lr 3.46)를 내리려면 사실상 점수를 강제로 내려야 하므로 옛 "내림 if문"의 재도입이다. 테스트 폴드에서 고장 012 · 030이 켜졌고, val에서는 A가 고장으로 본 016(사건 1, 447x)과 001을 뒤집는다. 사전등록서에서 의장이 "연속 항 + 값"과 "veto"를 비교 구성(G)으로 정하게 맡긴다.
- **본체 모드 울림 몫 내림**(#11 · #12): 고장 028 한 파일(0.69)과 정상 여유 0.01, val 이동 큼.
- **큰 타격 1개 감점**(#13): 옛 정의 기반, 새 정의에서 성립하지 않음.
- **DC 방향 피처**(#27): 고장 016도 DC −1.04라 정상 증거가 아님.
- **res_fit 축**: 고장 증거(정상 019 · 092가 같이 올라 백분위 68 → 93–97)로 위험이 있으나 F · R 담당. D는 "좁은 순음" 정상 증거가 같이 와야 한다는 점만 표시.
