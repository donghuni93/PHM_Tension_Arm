# D_2 — 진단 담당 2라운드 (11-22, 상호 반박)

## 결론
1. **기준 공간은 F의 new14로 합의한다.** 단, D_1의 사건 구조 축(dom 음의 계수 3번째 축)은 철회한다. new14 위에서는 새 정보가 sd 안이다 (아래 1절, 직접 계산).
2. **R의 A3(u_ring·u_spec·u_L 최댓값 축)과 E(body_frac 음의 축)는 "A의 ET 입력(ext150)" 대비 이득이다.** new14가 이미 같은 고장군을 올려서(8.3k군 0.17 → 0.02, 유격·조용군 0.11 → 0.02, F 표) new14 위의 추가 이득은 증명되지 않았다. A3·E는 후보 구성에서 한 가지씩만 두고, 기본 구성에는 넣지 않는다.
3. **"결합 점수를 경계에서 멀어지게 하는가"는 피처로 풀리지 않는다.** val 경계 밀집의 주원인은 AE 점수 이동(D_1)인데 F·R의 피처 제안 어느 것도 AE 쪽을 건드리지 않는다. R 자신의 수치도 ±0.5 sd 안 23 → 20 → 19뿐이다. 평가 지표 S6(이동 민감도)을 EXP-043 필수로 두고, 이 기준에서 "더 안전"을 주장하지 않는다. 안전성은 t-SNE 분리와 오경보 수로만 주장한다.
4. **val 이동 위험은 문턱형 지표가 과장한다.** 몫 ≥ 0.9 같은 문턱형은 val에서 0.54 → 0.175로 크게 이동하지만, 연속값 H14_share_4-8k는 val 중앙 이동이 정상 IQR의 -0.21이고 정상 5–95% 밖은 5%다(2절). 정상 증거는 연속 열로만 쓴다.

## 2. new14 열의 val 이동 (정상 중앙 대비 val 중앙, 정상 IQR 단위 / val 중 정상 5–95% 밖 비율)

- **val 위험은 2–4 kHz 창에 모여 있다.** F가 제안한 `ring_mid_n`은 같은 창(H8과 ρ 0.91, val에서 창에 충격이 있는 파일 0.475 vs 정상 0.20)이라 이 위험을 한 열 더 키운다. → **ring_mid_n은 기본에서 뺀다.** 위험 정상 2.4 → 0.8 이득은 train에서만 확인됐고 val 위험과 맞바꾸는 것이다.
- 본체 몫 연속값은 이동이 작다(-0.21). R이 본 body_frac 0.67 → 0.30은 "fit ≥ 0.5로 울린 충격" 정의라 문턱이 들어간 값이다. 같은 기전의 값이 정의에 따라 이동량이 다르므로, **val에 가장 덜 이동하는 정의(H14)를 쓴다.**

## 4. 남는 쟁점 (직접 못 닫은 것)
- **059 · 116 · 095는 어느 피처 공간에서도 정상 무리 안으로 오지 않는다(F). 097 · 101 · 120의 해결은 정상 증거를 만든 효과가 아니라 충격 기반 공간으로 바꾼 부산물**이다. 사용자 요구("정상 증거를 같은 비중으로")에 대해서는 "새 정상 피처"가 아니라 "고장 피처 쪽 열과 같은 공간에 이미 있는 정상 쪽 열(H1_nimp, H14)을 확인했다"가 정직한 답이다.
- **AE 이동**: val AE z가 +1.1. 이 이동의 구조는 아직 모른다(3–5 kHz, 8–10 kHz 대역이 높음). 라벨 없이 val에서 재보정하면 안 된다. EXP-043에서 S6만 기록하고, AE 쪽 변경은 이번 범위 밖으로 둔다.
- 순도 sd 0.11–0.13 때문에 0.05 안팎은 승부로 쓰지 않는다.

## 5. 최종 제안 (우선순위: t-SNE 분리 > 경계에서 멀어짐 > 규칙 대체)
| 순위 | 제안 | 등급 | t-SNE 분리 | 경계에서 멀어짐 | 규칙 대체 |
|---|---|---|---|---|---|
| 1 | **ET 입력 = new14** (충격 기반, 방향 무관, 14열) | D | 고장 5-NN 0.453 → 0.66 (폴드 밖), t-SNE 0.62 → 0.78 | 위험 정상 10.4 → 2.4. val 결합은 EXP-043에서 | 8.3k·유격·조용군 순위 0.17/0.11 → 0.02 (유격·8.3k 규칙이 하던 일) |
| 2 | **S6 이동 민감도 + val 경계 개수를 EXP-043 필수 지표로** | D | — | AE −0.5 이동 시 판정 변화 수, ±0.5 안 파일 수 | — |
| 3 | **연속 정상 증거 = H1_nimp, H14 (이미 new14 안)**. 문턱·음의 축·veto 만들지 않음 | L | FA 정상 5-NN 0.729 → 0.810 | 097 · 101 · 120이 충격 0개 영점 | 옛 "내림 if문" 대체 |
| 4 | 후보 열 `u_ring`(8.25–8.75 kHz 깨끗한 울림, 폴드 안 재선택) 1열 | L− | 8.3k군 순도 0.70 → 0.95 (R, 기준 공간 base16) | val 켜짐 0이라 영향 없음 (test 대비) | 8.3k 공진 규칙 대체 |
| 5 | 후보 열 `n_ev`(log1p) 1열 | L | 순도 +0.01 | 위험 정상 2.4 → 0.8 | 유격 반복 규칙 일부 대체 |

구성 (≤ 5):
- **G0 = A** 그대로(비교용).
- **G1 = AE + ET(new14) → 로지스틱**, 규칙 없음. 핵심 비교.
- **G2 = G1 + ET에 u_ring, n_ev 열 추가**(new14 + 2열 = 16).
- **G3 = G2 + ring_mid_n**(F-2 옵션. val 이동 위험을 지표로 측정하기 위한 구성).
- **G4 = G1에서 L1_S 제거**(P 등급 열 한 개 제거, 보험).
- 제외: A3 축, E 음의 축, veto 게이트, F19, dom 축, 사후 규칙 부착.

판정 규칙(사전 등록 제안): G1이 A에 대해 (a) 중첩 F2가 sd 안이거나 더 높고 (b) 오경보율 ≤ 0.032 (c) S6 판정 변화가 A보다 작을 때만 "더 안전"이라 부른다. 하나라도 어긋나면 "t-SNE 분리는 오름, 안전성은 미확인"으로 적는다.
