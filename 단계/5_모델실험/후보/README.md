## 공통 판단 기준
F2가 sd를 넘게 오르거나, sd 안이면서 계속 틀리는 파일이 줄거나 val 판정이 더 안정할 때만 최종 모델에 반영한다. `[사후 값]`은 Train 라벨을 보고 정한 값이라 점수가 낙관적이다.
