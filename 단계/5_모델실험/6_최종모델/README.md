# 6. 최종 모델 — 11 kHz 상한 · 그룹 CV (11-25)

**질문**: J-축소를 "정직한 평가"(같은 세션 후보 097 · 101 · 120을 한 CV 그룹, 이상치 정상도 학습)로 다시 재면 몇 점이고, 측정에 의미 없는 11 kHz 위를 잘라내면 나아지나.

**출발**: 11 kHz 위는 에너지 ≈ 0이고 이 대역 울림은 맞춤이 나쁘다([3-3 11 kHz 상한](../../3_전처리/3-3_11kHz상한/README.md)) · 검출기 입력을 1–11 kHz 대역통과로 바꿔도 충격은 거의 그대로([3-4](../../3_전처리/3-4_검출기대역통과/README.md) · [3-5](../../3_전처리/3-5_검출기검증/README.md)) · 097 · 101 · 120은 평균 −0.86 g로 같은 세션 후보(결정.md 11-25)

| 실험 | 한 일 | F2 (중첩 CV) | 판단 |
|---|---|---|---|
| **[EXP-062](EXP-062_11kHz상한·그룹CV/README.md)** 구성 1 | J-축소 + K83, 파일 그룹 CV (= EXP-050) | 0.977 ± 0.010 | K83은 학습 판정을 하나도 안 바꿈 |
| 구성 2 | + 그룹 CV (097 · 101 · 120 한 그룹) | 0.950 ± 0.035 | 분할이 바뀐 효과가 섞임 |
| **구성 3 = 최종 모델** | + 11 kHz 상한 · 검출기 1–11 kHz | **0.971 ± 0.022** · 재현율 0.987 · 오경보율 0.023 | 같은 분할에서 +0.021(sd 안), 놓침 5 → 2회 · 오경보 18 → 14회. **최종 채택(사용자 11-25)** |

**최종 모델 구조**: [ET(H 15열, 울림 비율 H7–H10 축소) OOF logit, 박자 z, AE z] → 로지스틱 ≥ 문턱 OR E2(L2_hfl) OR 8.3k 규칙(P83 · W83 · K83 > 3 OR 공진 충격), 모든 입력 ≤ 11 kHz (`src/final.py` `FinalJ(fmax=11000)`)
