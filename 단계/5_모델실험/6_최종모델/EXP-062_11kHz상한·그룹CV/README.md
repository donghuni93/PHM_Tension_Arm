## 해석

같은 그룹 분할에서 11 kHz 상한(3)은 기준(2)보다 0.950 ± 0.035 → 0.971 ± 0.022 (+0.021, sd 안). 놓침 5회 → 2회, 오경보 18회 → 14회. 그룹 CV(2)가 파일 그룹(1, 0.977 = EXP-050 그대로, K83은 train에서 바뀌는 것 없음)보다 낮은 것은 분할이 바뀐 탓이 섞여 있다(097 · 101 · 120은 셋 다 오경보 0회).
