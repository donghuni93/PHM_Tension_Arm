# 1-3 고장 유형 (열화 단계 가설)

상태: 정리 (11-14), **미검증 가설** — 2단계 EDA에서 그림으로 확인할 대상 (유형별 라벨링은 하지 않음)
형식: **사실**(원문·데이터로 확인) / **논의** / **합의·미정**

## 사실
- 라벨은 정상 0 / 고장 1 둘뿐이다. "Level 1–4" 같은 고장 단계 라벨은 데이터에 **없다** (1-1: 수리 전 = 고장, 수리·교체 후 = 정상)
- 아래 표는 train 고장 파일을 살펴본 분석을 정리한 것이다. 파일별 수치(첨도·g·충격 횟수 등)는 이 문서에서 다시 계산하지 않았다 → **EDA(2-3 고장모드)에서 재확인 전까지 가설**

## 신호 유형 4가지 ↔ 열화 단계 (가설)
텐션암의 열화 순서: 러버 부싱 경화·찢어짐 → 볼조인트 미세 유격 → 유격 확대와 금속 간 타격 → 체결 이완·구조 공진.

| 단계 | 물리 상태 | 신호 유형 (고장 파일) | 신호 징후 |
|---|---|---|---|
| **L1 초기 미세 열화** | 부싱 미세 균열, 볼조인트 윤활 소실, 극소 유격. 큰 외력에서만 간헐적 "틱" | **③ 초희소·국소 위장형** (abn_014, 017, 021) | 전체 에너지는 정상과 같거나 더 작음(017). 2초 중 1–2번 짧은 마찰·타격(014), 11 kHz대 고주파 링잉(021) |
| **L2 부싱 유격 확대** | 부싱 강성 저하로 저주파 하중 시 암이 크게 출렁이고 변위 끝단에서 간헐 타격 | **② 저주파 출렁임 + 고주파 충격 복합형** (abn_005, 022, 028) | 0–20 Hz 요동이 파형을 지배해 원신호 첨도는 묻힘. 출렁임 정점마다 고주파 충격이 포개짐 (고역통과 후 첨도로 드러남) |
| **L3 볼조인트 마모·금속 타격** | 유격이 커져 노면 진동마다 볼스터드와 하우징이 연속 충돌 (knocking) | **① 광대역·공진형 강한 충격** (abn_004, 008) | 잦은 연발 충격(004: 46회)으로 0–12.5 kHz 광대역 에너지 상승, 또는 강한 타격(008: 3.38 g)이 암 고유진동수(2–3.5 kHz)를 울림 |
| **L4 체결 이완·구조 공진** | 볼트 풀림·부싱 파단으로 특정 주파수에서 암 전체가 떨림 (flutter/shimmy) | **④ 순수 저주파 대진폭 공진형** (abn_015) | 충격 0회. 10–200 Hz 대역의 거대한 사인파 진동 (3.34 g, 에너지 99% 집중) |

## 논의
- **L1–L2가 PHM에서 가치 있는 구간이지만 모델의 사각지대.** 에너지가 작거나 저주파 출렁임에 충격이 가려져 평균·단순 통계 피처에서 미탐(FN)이 몰린다. F2가 재현율에 가중하는 이유와 맞물린다
- 1-1 정리자 주의와의 관계: 원인이 부싱인지 볼조인트인지는 PDF로 알 수 없다. 이 표는 둘을 한 열화 사슬로 묶은 **해석**이다
- **대역과 평가 원칙 3 (사용자 관찰, 11-14):** EDA에서 라벨을 보지 않고 전 파일의 주파수 분포를 훑으면, 0–200 Hz 이하에서 파일 간 특징이 갈리고 위 표의 나머지 대역(2–3.5 kHz, 9–12.5 kHz 등)에서도 라벨이 짐작된다고 한다. 따라서 대역은 "고장 라벨을 보고 손으로 고른 값"이 아니라 **라벨 없이 EDA에서 드러난 구조**로 다룬다. 이 관찰은 아직 그림으로 남기지 않았다 → 2-2 주파수 개관에서 라벨 없는 PSD로 확인하고 그림을 기록한다
- 표의 파일 번호는 위 유형 설명을 위한 예시일 뿐, 고장 30개 전체를 유형별로 분류하지 않는다 (미분류 파일은 그대로 둔다)
- 탐지 방향은 논의 수준으로만 남기고, 모델 실험(5단계) 때 참고한다 (아래 목록은 가설, 확정 아님):
  - L1: 2초 평균을 버리고 짧은 서브윈도우(0.1–0.25초) max-pooling, 무차원 형태 피처(파고율, 고역통과 첨도), 9–12.5 kHz 감시
  - L2: 저주파 에너지(0–20 Hz 비율) × 고주파 충격(고역통과 첨도) 상호작용 피처
  - L3–L4: 전 대역 PSD 에너지, 2–3.5 kHz 구조 공진 대역, 0–200 Hz 저주파 대진폭 RMS
- 병목 고장 abn_002·022·029 중 표에 있는 것은 022(L2)뿐이다. 002·029는 EDA(2-4)에서 따로 본다

## 합의·미정
- **합의 (11-14) 고장 파일을 유형별로 라벨링·분류하지 않는다.** 이 문서는 물리 해석과 EDA 관찰의 참고용이다
- 가설: 이 열화 단계 구조가 우리 데이터에서 모두 표현되는지는 모르지만 연결될 것으로 본다 → 2단계 EDA 그림으로 확인
- 미정: "레벨"이 실제 열화 순서인가. 진행 시간 정보가 없어 순서는 가정이다 → 발표에서는 "신호 유형"으로 말하고 "열화 단계"는 해석으로 표시
- 다음: 2-2에서 라벨 없는 PSD로 대역 구조 확인 → 4단계 피처는 확인된 구조에 연결, 탐지 방향은 5단계 실험 때 참고
