## 이 배경지식을 읽는 법
- **등급** (지식 감사 11-22, 근거는 4번 파일): D = 도메인 기전 · 구조 사실 / L = 라벨로 확인되고 겨냥한 고장이 여럿이며 폴드 안에서 안정 / P = 사후 맞춤(쓰지 않음) / X = 이상한 실험(근거에서 뺌).
- **라벨을 본 뒤 정한 것이 많다.** 이전 프로젝트의 대역 · 문턱 상당수가 라벨을 보고 정해졌고 점수가 낙관적이다. 재현 확인이 없으면 "가설 후보"로 읽는다.
- **이전 모델의 점수(중첩 CV F2 0.978 ± 0.013)는 새 근거가 아니다.** 사후 문턱 · 이상치 정상 학습 제외 · 같은 150개에서의 선택이 섞여 있다.

## 이전 모델 한 장 요약 (J-축소)
- 입력: ET(ExtraTrees)가 충격 · 울림 · 옥타브 몫 같은 H 피처 15열(+ 울림 모드 3열) → 정상으로 학습한 스펙트럼 AE의 복원 오차(정상 기준 z) → 박자 z(주기 잠금)와 함께 **로지스틱**으로 결합, 학습 150개에서 F2가 최대인 문턱.
- 그 위에 규칙 둘을 OR로 얹음: E2(하중 대비 고주파가 학습 정상 99 % 초과 & 충격 ≥ 1)와 8.3 kHz 규칙.
- 점수: 중첩 CV F2 0.977–0.978 ± 0.010–0.013, 재현율 0.99–1.00, 오경보율 0.022–0.030. 낙관적이다(위 "읽는 법").
- 이 구조를 만든 이유와 닫힌 질문은 3번 파일에 있다.
