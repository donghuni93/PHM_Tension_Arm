# 2. 신호에서 알게 된 것 (배경지식)

출처: 이전 프로젝트의 2단계 EDA · 4단계 피처 · 지식장부. 등급은 D 도메인 / L 라벨 확인 / P 사후 / X 근거 제외(4번 파일). 오른쪽 "new"는 new_단계 재확인 여부다.

## 1. 충격(이벤트)과 정상 충격의 성격
- **충격 정의(D, 사전 고정, 11-21)**: 평균 제거 → 1 kHz 고역통과(4차 Butterworth 양방향) → |Hilbert| 포락선 → 1000 Hz 다듬기 → 바탕 = 100 ms 이동 중앙값 → 포락선/바탕 ≥ 4.5인 봉우리, 간격 ≥ 6.75 ms, 파일 앞뒤 10 ms 제외. 가짜(위상 무작위) 신호에서 가짜 충격이 ≤ 0.05/파일이 되도록 정한 문턱. 합계 정상 854 · 고장 402 · val 247. (문턱은 신호 크기가 아니라 바탕 대비 배수라 배경 소음에 적응한다.) — new: 2-2에서 같은 검출기를 그대로 사용
- **정상 충격은 본체 모드(약 7 kHz)로 운다(D)**: 정상 충격 854개 중 3.4–7.9 kHz가 84 %. 외부 입력(노면)이 암 전체를 치기 때문. — new: 2-2 이벤트 대표 울림의 73 %가 5.5–8 kHz(재현)
- **충격 0개 → 정상 쪽**(L5): 정상 17 · 고장 0. **사건 수 ≤ 1 → 정상**(L6): 정상 36 · 고장 0. 둘 다 학습 150개에서 확인. — new: 2-2에서 정상 이벤트 0개 14 %, 고장 0개 0 %
- 한 번의 충격에 모드가 여러 개 울리므로 검출이 여러 개로 찍힌다(예: 정상 116은 검출 6개가 이벤트 2개). — new: 2-2

## 2. 울림 모드 지도 (11-23, 라벨 없이 190개 파일)
- 봉우리: 1275 · 1925 · 3175 · 4875 · 5975 · 7225 · 8325 Hz. 골짜기: 1575 · 2575 · 4525 · 5525 · 6275 · 8025 Hz.
- 이전 해석(라벨 없이 찾은 경계를 라벨로 확인):
| 대역 | 누가 우나 |
|---|---|
| 공유 저주파 1.0–1.6 kHz | 정상 · 고장 모두 |
| 연결부 1.6–4.5 kHz | **고장**(단 1.9 kHz 모드는 정상도 운다 → 2.2 kHz부터 고장 전용) |
| 전이 4.5–5.5 kHz | 정상 · 고장 모두 |
| 본체 5.5–8 kHz | **정상**(고장 충격은 이 대역에서 적음) |
| 고주파 8–12.5 kHz | **고장** + 이상치 정상 |
- 1.9 kHz 모드는 정상에서 파일당 1–2번, 고장에서 여러 번 반복한다(2-29) → 비율이나 에너지보다 **반복 횟수**로 세는 것이 낫다.
- 경계를 옥타브(2 · 4 · 8 kHz) 대신 모드 골짜기에 두면 점수는 같고, **옥타브를 모드로 바꾸면 하락, 모드를 더하면 같은 점수**였다(모델 반영, EXP-056–058).
- 라벨 없는 모드 지도로는 초기 시도에서 3.8 kHz 경계 하나만 복원됐다(4-8). 8 kHz 이상 경계는 라벨을 봐야 보였다. — new: 2-4에서 골짜기 1.55 · 5.35 · 8.05 kHz 재현, 4.5 kHz는 3.75 kHz로 대체됨

## 3. 8.3 kHz 모드와 규칙
- 8.2–8.45 kHz 협대역 봉우리가 고장 002 · 029 등에서 크게 나타난다. 정상에도 22개(18 %)가 있어 "새로 생긴 공진"이 아니라 **원래 있는 모드가 고장에서 더 크게 들뜬 것**(H2′, D).
- 규칙(사후): 돌출 P83 ≥ 0.75 dec · 폭 W83 ≥ 150 Hz · 포락 첨도 K83 > 3, OR 8.0–8.7 kHz · ζ ≤ 0.02 · fit ≥ 0.7 충격. 고장 6(002 003 006 010 029 030) · 정상 0. 문턱 ±10 %에서 정상 0, −14 %부터 정상 009류가 켜진다는 여유 경고도 있었다.
- K83 조건은 val_001(8.6 → 8.15 kHz로 2초 내내 미끄러지는 지속음)이 규칙에 걸리는 것을 보고 추가했다. val 파일을 보고 규칙을 고친 것이라 **val을 보고 고치지 않는다**는 원칙과 부딪힌다고 기록돼 있다.
- 정상 019(8.25 kHz 고정 음 앞 1초) · 092가 폭 · 돌출 문턱 위치를 정했다. 문턱이 이 두 파일 바로 위에 앉는다.
- — new: 2-4에서 같은 숫자 재현. val_037(폭 4 Hz 모자람) · val_020(19 Hz 모자람)이 경계 근처.

## 4. 고장 도메인 유형 L1–L4 (설명용, 11-16)
고장 30개를 지표 규칙으로 나눈 설명용 분류다. **모델 입력 · 선택에는 쓰지 않았다**(P6). 문턱은 정상 분포 분위만 썼지만 어떤 지표를 고를지는 고장 값을 본 뒤 정했다.

| 유형 | 물리 상태 | 고장 | 닮은 정상 |
|---|---|---|---|
| L4 체결 이완 · 구조 공진 | 저주파로 크게 떨림, 충격 없음 | 015 | 090 |
| L3 볼조인트 마모 · 금속 타격 | 광대역 에너지, 충격 | 12개(연발 004 011 019 · 강타 008 009 010 012 016 018 027 030 · 광대역 024) | 강타 025 032 055 086 095 116 |
| L2 부싱 유격 확대 | 저주파 출렁임 끝단에서 타격 | 9개(001 005 006 014 020 022 025 028 029) | 33개(정상 운전 상태와 거의 구분 안 됨) |
| L1 초기 미세 열화 | 에너지는 정상 수준, 고주파 링잉 | 5개(002 003 007 013 026) | 9개 |
| 미분류 | 어느 축에서도 정상 범위 | 3개(017 021 023) | — |

- 모델의 남은 오류는 L3 강타형 정상(큰 사건 한 번)과 L2 고장 022에 몰렸다.
- "열화 단계"는 해석이다. 진행 시간 정보가 없어 L1 → L4 순서는 확인할 수 없다. 발표에서는 "신호 유형"으로 말한다.

## 6. 경계 정상 파일 (오경보 후보)
- **059 · 065 · 116**: 고장과 같은 주파수 칸(9.5 · 10.25 · 8.75–9 kHz)에서 금속 울림이 한 번 있는 파일. 2초 안의 한 번은 고장 003 · 007 · 020 · 026과 구분할 수 없어 **정보 한계**로 보고 학습에서만 뺐다(평가에는 포함). 새 피처로도 끌어내리지 못했다(PHO-001–004 · 006 · 008 · 009, 4-9). 이 셋을 학습에서 빼는 것은 사후 선택이고, 비슷한 시도(EXP-028 · 038)는 기준 아래로 기각된 적이 있다.
- **097 · 101 · 120**: 평균(DC) −0.86 g, 12.4 kHz 톤, 충격 0개 영점의 부산물로 해결된 정상(오경보 정상 11개 목록: 116 065 059 037 110 095 055 025 097 101 120). — new: 2-1에서 같은 DC · 톤 확인, 같은 세션 후보
- **충격성 정상 027 · 073 · 066 · 095 · 106 · 110**: 공통 기전이 없다(073 주기 충격 60개, 066 저주파 쿵, 106 처프, 027 약한 충격 다수). 파일별 피처는 만들지 않았다.
- 정상 중 8–12.5 kHz 배경 봉우리 돌출 ≥ 10 dB인 파일이 33/120, 고장은 8/30, val은 18/40 → 흔하지만 가르는 힘이 없다(지속음 → 정상 피처는 고장 002 · 013을 정상 쪽으로 끈다).

## 7. val이 학습과 다른 점 (라벨 없는 진단, 사실)
- AE z 중앙 +1.1, ET z +0.63. 배경 3–5 kHz가 +10.9 dB 이동(학습 고장 배경은 +1.4 dB). 이동은 충격 수 · 게인과 무관했다(D11).
- 2–4 kHz 창에 충격이 있는 파일 0.20 → 0.475, 충격 < 3.4 kHz 15 % → 52 %.
- val의 본체 모드가 7.2 kHz가 아니라 6.5–7.0 kHz에 모이고 1.2 · 3.2 kHz 봉우리가 새로 있다(4-16). — new: 2-4 그림에서 val 본체 봉우리 약 6.6 kHz
- 4-16: val이 "학습 고장 40 %가 섞인 경우"의 범위를 넘은 피처 10열은 모두 절대 에너지이거나 1.6–5.5 kHz 몫이었고, 첨도 · 파고율 · 봉우리/σ · 충격 개수 같은 무차원 충격성 열은 안정적이었다.
- val_001(미끄러지는 지속음)은 학습에 없던 유형이다.

## 8. DC 평균
- 평균은 센서 방향 · 중력 성분이라 고장 정보가 없다(D1). 피처는 평균 제거 후. **고장 016도 −1.04 g라서 "평균 −1 g = 정상 증거"는 아니다.** DC 값을 피처로 쓰지 않는다.
- 주의: 결정.md에 "평균 −1 g 정상 097 · 101 · 116 · 120"이라고 적힌 곳이 있으나 116의 평균은 +0.019 g다(new_단계 2-1 측정). 097 · 101 · 120이 맞다.
