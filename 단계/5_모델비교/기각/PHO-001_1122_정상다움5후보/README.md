## 해석

- 1–4는 기준보다 높은 것이 없다. 하위군(k=4)은 하위군 없는 대조(k=1)보다도 낮아 "정상이 여러 무리"라는 구조가 ET에 새 정보를 주지 않는다.
- 3(fit ≥ 0.7)은 오경보 065 · 059의 고장다움을 0.12 · 0.16 → 0.06 · 0.02로 낮췄지만 대신 025가 0.06 → 0.19로 올라가고 PR-AUC가 떨어졌다. 오경보 파일이 바뀔 뿐 줄지 않는다.
- 5: 충격을 뺀 배경 스펙트럼만으로 AE를 학습하면 고장 정보가 크게 빠진다(학습 고장 AE z 중앙 +2.25 → +1.58). val 이동은 그대로(+1.59 → +1.66)라서 **val AE 이동은 충격이 아니라 배경 자체에 있다**. 같은 세션의 배경 PSD 비교(val 3–5 kHz +10.9 dB, 훈련 고장 +1.4 dB)와 맞는다.
- 결론: 기각. J의 ET 입력은 바꾸지 않는다.
