## 해석

**8.3 kHz 규칙은 충격 울림으로 대신할 수 없지만, 울림은 같은 고장을 독립적으로 확인해 준다.** 울림 규칙만 쓰면(0.907) 002를 놓친다. 002는 충격이 1개뿐인 조용한 고장이라 8.3 kHz 봉우리가 스펙트럼에만 보인다. 반대로 울림 규칙은 스펙트럼 규칙이 놓친 003 · 013을 켜고, 정상은 하나도 켜지 않는다(정상 최대 0.06 = N019, 문턱 ±20%에서도 정상 0). OR로 붙이면 점수는 그대로다(0.942, 003 · 013은 이미 모델이 잡음). 대신 6개 고장에서 두 근거가 겹쳐, 스펙트럼 문턱 근처 정상(092 · 004 · 070)이 켜질 위험 없이 규칙이 튼튼해진다. ET 울림 피처는 2.25–4 kHz 1열로 바꾸자 오경보 감소 폭이 1차(3열, 0.020)보다 작아졌다(0.027). 1차 3열에 들어 있던 "5–8 kHz로 울림 = 정상 근거"가 055 · 059를 내리는 데 기여했다고 본다. 022는 모든 구성에서 5/5 미탐이다.

**그림 읽는 법**
- logistic_plane: 가로 = AE z(스펙트럼 모양 이상), 세로 = ET z(충격 피처 이상), 실선 = 로지스틱 경계, 주황 바탕 = 고장 쪽. 규칙이 잡은 고장은 빼고 오른쪽 아래 상자에 적었다. × = 5번 중 2번 이상 틀림. 위 = 8.3k 규칙(현행) 있음, 아래 = 뺌. 왼쪽 = ext150, 오른쪽 = ext150 + 2.25–4 kHz 울림
- rule83_v2 왼쪽: 가로 = 충격 중 8.0–8.7 kHz로 울린 비율(울림 규칙), 세로 = 8.20–8.45 kHz 스펙트럼 돌출(현행 규칙). 회색 띠 = 울림 문턱 0.1 ±20%, 초록 띠 = 돌출 문턱 0.75 ±20%. 오른쪽 = 규칙별로 켜지는 파일

1. **울림 규칙이 켜는 파일 (학습 150개 전체)**

   | 규칙 | 켜지는 고장 | 정상 |
   |---|---|---|
   | 스펙트럼(현행) | 002 006 010 029 030 | 0 |
   | 울림 | 003 006 010 013 029 030 | 0 |
   | OR | 002 003 006 010 013 029 030 | 0 |
   | AND | 006 010 029 030 | 0 |

   - 울림 축에서 정상은 최대 0.06(N019)으로, 문턱 0.1의 ±20%(0.08)보다 낮다. 스펙트럼 축은 문턱 ±20% 안에 정상 004 · 070 · 092가 있다(EXP-030 여유 경고)
   - 그림 왼쪽에서 정상 019는 스펙트럼 돌출이 0.96으로 높지만(좁은 순음이라 폭 조건에서 꺼짐) 울림은 0.06이다. **두 축을 함께 보면 정상과 고장이 더 멀어진다**
2. **002는 울림으로 볼 수 없다**: 충격이 1개(포락선 바탕의 7배)뿐이라 '충격 2개 이상' 조건에서 빠진다. 그 1개도 8.25 kHz로 울리지만 비율 하나로는 근거가 약하다. 002를 잡는 것은 스펙트럼 규칙뿐이다 → AND · 울림 단독은 002를 놓쳐 0.907
3. **OR = 현행과 점수가 같다**: 울림이 새로 켜는 003 · 013은 원래 모델이 잡던 고장이다. 점수 이득은 없고 **근거의 중복(튼튼함)**만 얻는다. val에서 스펙트럼 봉우리가 문턱 바로 아래로 나오는 고장이 있을 때 울림이 받쳐 준다
4. **ET 울림 피처: 1열(2.25–4 kHz)보다 1차 3열이 낫다**: 교체판 ②는 오경보율 0.027(055 · 059 해소, 025 5/5 그대로), 1차 ②는 0.020(025 3/5). 1차에 있던 `ring_5_8k`(5–8 kHz로 울린 비율, 정상 64개가 0.8 이상 · 고장 0)가 "노면 충격 = 정상"의 근거로 쓰였다고 본다. 반면 2 kHz 칸을 제외하는 것은 맞다(사용자 지적, 정상 044 · 046 · 066 · 008 · 028이 2 kHz로 울림)
5. **022는 움직이지 않는다**: 022의 울림은 2 kHz 칸(0.6)이라 2.25–4 kHz 피처에서는 0이다. 2 kHz 칸에는 정상 008 · 028도 2 kHz 충격이 5–7개라 022와 갈리지 않는다
6. **다음 제안**
   - ET 울림 입력 = 2.25–4 kHz 비율 + 5–8 kHz 비율(정상 근거) 2열, 충격 0개 = −1 → 1차 3열의 이득을 2 kHz 칸 없이 얻는지 확인
   - 8.3k 규칙 = 스펙트럼 OR 울림(점수 같음, 근거 둘). 채택하면 결정.md "대역 예외(8 kHz 두 모드)"에 울림 규칙을 덧붙인다(사후 경계 8.0–8.7 kHz)
7. **한계**: 울림 대역 경계(2.125–4.125 · 8.0–8.7 kHz)는 라벨을 본 뒤 정한 값이라 점수가 낙관적일 수 있다. 울림 피처는 다른 차종에서 무너졌다(권소린 보고서, AUC 0.53–0.62)
