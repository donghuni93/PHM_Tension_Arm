## 한눈에 보기

```
원신호 (파일 150개 × 50,000점, 2초, 25 kHz, 단위 g)
 │ ① 문제 설정: 정상만 학습하는 이상탐지
 │ ② 전처리:   평균 제거 → 200 Hz 고역통과
 │ ③ 구간 분할: 1초 구간 8개 (겹침)
 │ ④ 피처:     구간마다 log Welch PSD → 1025칸
 │ ⑤ 표준화:   칸별 z (학습 정상 기준, 모델 안에서)
 │ ⑥ 모델:     AE 1025-128-16-128-1025, 정상 구간만 학습
 │ ⑦ 점수:     복원 제곱오차 → 구간·칸 평균 = 파일 점수 1개
 │ ⑧ 판정·평가: 중첩 CV (바깥 5 × 안쪽 4 × seed 5), 임계값 = 안쪽 OOF F2 최대
 │ ⑨ 이해 도구: t-SNE · 복원 오차 그림 · 놓친 고장 PSD
 ▼
F2 0.832 ± 0.027 · 재현율 0.853 · 오경보율 0.068 · 놓침 005 014 017 022
```

각 단계에서 고른 값은 **신효섭 보고서 5장을 그대로 따른 것**이다(재현 실험). "판단"은 그 선택이 무엇을 얻고 무엇을 잃는지를 우리 데이터 기준으로 정리한 것이다.

## ① 문제 설정 — 무엇을 배우게 할 것인가

| 선택지 | 내용 |
|---|---|
| 지도학습 (예: ext150 + ET) | 정상·고장 라벨을 둘 다 써서 경계를 배운다 |
| **이상탐지 (이번 선택)** | **정상만** 배우고, "정상과 얼마나 다른가"를 점수로 쓴다 |

- **왜**: 고장이 30개뿐이고 종류가 섞여 있다. val·test에 학습 때 못 본 고장 유형이 나와도, 정상에서 벗어나기만 하면 잡을 수 있다.
- **대가**: 고장 라벨의 정보를 버린다. "정상과 다른 것" ≠ "고장"이라서 ① 정상처럼 생긴 고장(017·022)은 못 잡고 ② 특이한 정상은 오경보가 된다.
- **라벨을 쓰는 곳은 딱 하나**: ⑧의 임계값 정할 때. 학습 폴드 안의 고장 파일은 AE 학습에는 들어가지 않고, 임계값 선택에만 쓰인다.

## ② 전처리 — 원신호에서 무엇을 지우나

```python
Xc = X - X.mean(1, keepdims=True)                                   # 평균 제거
H  = sosfiltfilt(butter(4, 200, btype="highpass", fs=FS, output="sos"), Xc, axis=-1)
```

| 처리 | 판단 | 이유 | 대가 |
|---|---|---|---|
| 평균 제거 | 파일마다 DC를 뺀다 | 평균이 −1 g인 파일(nor_097·101·120, abn_016)이 있다. 설치 자세·중력 성분이지 진동이 아니다. 단, 바로 뒤 고역통과가 DC를 어차피 지우므로 EXP-012에서는 결과가 같다(차이 1e-14 g, [3-1](../../../3_전처리/3-1_평균제거·고역통과/3-1_평균제거·고역통과.md)) | 평균 자체에 정보가 있었다면 사라진다 (EDA상 평균은 고장 구분력 없음, AUC 0.50) |
| 200 Hz 고역통과 | 200 Hz 아래를 지운다 | 정상 에너지의 74%가 200 Hz 아래의 느린 흔들림(차량·설비 거동)인데 구분력이 없다(AUC 0.43–0.58, 200 Hz 이상은 0.73). 지우지 않으면 PSD·오차가 흔들림 크기에 끌려간다 | **0–200 Hz 정보 손실.** abn_017이 정상에서 가장 크게 벗어난 곳이 0–300 Hz였다(정상 5% 하한보다 1.6 dec 아래, 전 대역 평균은 0.4 dec 아래). H4(하중 반전 유격, 저주파 위상)도 볼 수 없다 |
| Butterworth 4차 | 통과대역이 평평한 필터 | 통과 대역 진폭을 왜곡하지 않는다 | 경계가 칼같지 않다: 남는 에너지 100 Hz 0.4% · 150 Hz 9% · 200 Hz 50% · 300 Hz 96% |
| `sosfiltfilt` (양방향) | 앞으로 한 번, 뒤로 한 번 | 위상 지연이 0 → 충격 시점이 밀리지 않는다 | 실시간 처리에는 못 쓴다 (우리는 오프라인이라 문제없음) |

- **누수 판단**: 이 단계는 라벨도, 다른 파일도 보지 않는다(파일 하나씩 독립 계산). 그래서 CV 밖에서 전체에 한 번 계산해도 누수가 없다.
- **원칙 3 확인**: 200 Hz는 우리가 라벨을 보고 고른 값이 아니라 보고서 값이다.

## ③ 구간 분할 — 파일 하나를 몇 조각으로 보나

```python
SEG, NSEG = FS, 8                                         # 1초, 8개
starts = np.linspace(0, X.shape[1] - SEG, NSEG).astype(int)   # 0, 3571, 7142, … 25000
```

- **판단**: 2초 파일에서 1초 구간 8개를 3,571점(0.14초) 간격으로 자른다. 이웃 구간은 **약 86% 겹친다**.
- **이유**
  1. 학습 샘플 늘리기: 정상 96개 파일 → 768개 구간
  2. 시간에 따라 바뀌는 신호(비정상성)를 여러 시점에서 본다
- **대가**
  - 겹침이 커서 8개 구간이 거의 같은 정보다. 샘플 **수**는 8배지만 **독립 정보**는 그만큼 늘지 않는다 → ⑥의 과적합과 연결
  - 짧은 충격 하나는 몇 개 구간에만 들어가는데, ⑦에서 8개를 평균하므로 다시 희석된다
- **파일 단위 유지**: 구간은 늘 자기 파일에 묶여 있다(`LP[파일, 구간, 칸]`). CV는 파일 단위로 나누므로 같은 파일 구간이 학습·평가에 갈라져 들어가는 누수가 없다.

## ④ 피처 — 구간을 무엇으로 요약하나

```python
f, P = welch(S, fs=FS, nperseg=2048, axis=-1)   # 구간마다 PSD
LP   = np.log10(P + 1e-20)                      # (파일 150, 구간 8, 칸 1025)
```

| 판단 | 이유 | 대가 |
|---|---|---|
| **시간 → 주파수 (PSD)** | 고장은 공진·마찰 주파수의 에너지 변화로 드러난다는 가정(H2) | **언제** 일어났는지 정보를 버린다 |
| **Welch, nperseg 2048** | 1초(25,000점)를 2048점 창 23개(50% 겹침)로 나눠 PSD를 평균 → 잡음이 줄어든 안정된 스펙트럼 | 23개 창 평균 = **짧은 충격 희석.** 005·014는 2.5–3.75 kHz 첨도가 정상 99% 분위인데 PSD에서는 정상 띠 안이다 → AE가 놓친 직접 원인 |
| 칸 1025개, 간격 12.2 Hz | 25,000 / 2048. 협대역 공진 피크(002·029의 8.2–8.4 kHz)를 볼 수 있는 해상도 | 칸이 많아 ⑥의 입력 차원이 커진다 |
| **log10** | 진동 에너지는 칸마다 10⁻¹¹~10⁻⁴로 7자리 차이. log로 펴야 고주파 칸도 학습에 반영된다. 게인(곱셈) 차이가 덧셈으로 바뀐다 | 아주 작은 값(잡음 바닥) 차이도 크게 보인다 |
| `+1e-20` | log(0) 방지 | 영향 없음 |

- **캐시**: 결과를 `outputs/cache/seg_logpsd_hp200_8x1s.npz`로 저장. ②–④ 처리를 바꾸면 이 파일을 지워야 한다.
- **누수 판단**: ②와 같다. 파일별 독립 계산이라 전체에 한 번 계산해도 된다.

## ⑤ 표준화 — 칸마다 눈금을 맞춘다 (모델 안에서)

```python
S = LP[학습 파일][정상].reshape(-1, 1025)       # 학습 정상의 모든 구간
self.mu_, self.sd_ = S.mean(0), S.std(0) + 1e-8
Z = (S - self.mu_) / self.sd_
```

- **판단**: 칸 1025개 각각을 "학습 정상의 평균 0, 표준편차 1"로 맞춘다.
- **이유**: log를 써도 저주파 칸(−5)과 고주파 칸(−10)은 크기가 다르다. 맞추지 않으면 AE가 큰 칸만 열심히 복원한다.
- **누수 판단 (중요)**: 평균·표준편차는 **데이터 분포를 보는 계산**이다. 그래서 ②–④와 달리 전체에 미리 하지 않고 `SpecAE.fit` 안에서 **그 폴드의 학습 정상으로만** 계산한다. 평가 파일은 그 값으로 변환만 한다.
- **대가**
  - 정상끼리 거의 차이가 없는 칸(표준편차가 작은 칸)은 작은 차이도 크게 키운다 → 처음 보는 정상이 "이상"으로 보이기 쉽다 (오경보)
  - 200 Hz 고역통과로 이미 지워진 0–200 Hz 칸(약 16칸)도 잡음인 채로 표준화되어 같은 비중으로 들어간다

## ⑥ 모델 — 정상 스펙트럼을 외우는 오토인코더

```python
MLPRegressor(hidden_layer_sizes=(128, 16, 128), activation="relu", solver="adam",
             learning_rate_init=1e-3, max_iter=60, alpha=0.0).fit(Z, Z)   # 입력 = 정답
```

```
입력 1025 → 128 → [16 병목] → 128 → 1025 출력      (입력을 그대로 다시 내도록 학습)
```

| 판단 | 이유 | 대가 |
|---|---|---|
| **병목 16** | 1025개를 16개로 줄이게 강제 → "정상이 흔히 가지는 모양"만 남는다. 이 틀에 안 맞는 입력은 복원이 안 된다 | 작으면 정상도 못 그리고(오경보↑), 크면 고장도 잘 그린다(놓침↑). 보고서 값 그대로, 우리가 비교하지 않았다 |
| `fit(Z, Z)` 정상 구간만 | 정상만 외워야 "정상답지 않음"이 오차로 드러난다 | ① 참고 |
| ReLU, MSE, Adam 0.001 | 보고서와 동일 | — |
| **60 epoch 고정, 조기 종료 없음** | 보고서와 동일 | 검증 손실을 보지 않으니 과적합 시점을 모른다 |
| **`alpha=0` (가중치 규제 없음)** | 보고서(torch 기본)와 맞춤 | 과적합을 막는 장치가 없다 |
| torch 대신 sklearn | 새 라이브러리 없이 같은 구조 재현 | 드롭아웃 등은 못 쓴다 |

- **규모 판단 — 과적합의 근거**: 가중치 수 ≈ **26.8만 개** (1025×128 + 128×16 + 16×128 + 128×1025 + 편향). 학습 구간은 바깥 폴드 기준 정상 96개 × 8 = **768개**(안쪽 폴드는 576개)이고, 그나마 ③에서 본 것처럼 서로 많이 겹친다. 파라미터가 샘플보다 300배 이상 많다 → 학습 정상은 외워서 오차가 작고, **처음 보는 정상은 오차가 약 2배** (recon_error 그림). 오경보는 여기서 나온다.

## ⑦ 점수 — 파일 하나를 숫자 하나로

```python
R   = AE.predict(Z)                    # 복원
err = ((R - Z) ** 2).mean(1)           # 칸별 제곱오차, 구간 8개 평균 → (파일, 1025)
score = err.mean(1)                    # 칸 1025개 평균 → 파일 점수
```

| 판단 | 이유 | 대가 |
|---|---|---|
| 제곱오차 (MSE) | 학습 손실과 같은 기준 | 큰 차이 몇 칸이 점수를 좌우한다 |
| **구간 8개 → 평균** | 보고서에 집계 방식이 없어 우리가 정함. 가장 안정적인 선택 | 한 구간에만 이상이 있으면 1/8로 희석. 최댓값을 쓰면 충격 구간을 살릴 수 있지만 오경보도 늘 수 있다 → 비교 안 함 |
| **칸 1025개 → 평균** | 특정 대역을 미리 고르지 않는다 (원칙 3) | "어느 대역에서 틀렸나" 모양 정보는 버린다. t-SNE 출력 끝 그림에서 고장이 모이는 것은 이 모양 정보 때문이다 |

- **점수의 뜻**: 클수록 "정상 틀에 안 맞는다" = 고장 의심. 확률이 아니므로 0.5 같은 고정 기준이 없다 → ⑧에서 임계값을 데이터로 정한다.

## ⑧ 판정·평가 — 점수를 고장/정상으로 바꾸고 정직하게 채점

```
seed 5번 반복
 └ 바깥 5-fold (파일 단위, 정상·고장 비율 유지)
     ├ 바깥 학습 (파일 120개: 정상 96 + 고장 24)
     │   ├ 안쪽 4-fold: 정상 72개로 AE 학습 → 나머지 30개 채점 (×4 = 학습 120개 전부 OOF 점수)
     │   ├ 임계값 t = OOF 점수에서 F2가 최대인 값 (같으면 가장 낮은 t = 재현율 우선)
     │   └ 정상 96개로 AE 다시 학습
     └ 바깥 평가 (파일 30개): 점수 ≥ t → 고장
```

| 판단 | 이유 | 대가 |
|---|---|---|
| **중첩 CV** | 임계값도 "학습"이다. 평가 파일로 임계값을 고르면 점수가 부풀려진다. 안쪽에서 정하고 바깥에서 채점 | AE를 seed당 25번, 총 **125번** 학습 → 느리다 (`n_jobs=-1` 병렬) |
| 파일 단위 분할 (`groups = 파일 번호`) | 같은 파일의 구간이 학습·평가에 갈라지면 누수 | — |
| 층화 (Stratified) | 폴드마다 고장 비율 20% 유지 | — |
| **임계값 = F2 최대** | 과제 평가가 F2 (재현율에 4배 가중) | 고장 24개로 정한 임계값이라 폴드마다 흔들린다 |
| seed 5번 | 폴드 분할 운에 따른 흔들림을 ± sd로 보고 | — |

- **주의할 미묘한 점**: 임계값은 정상 **72개**로 학습한 AE의 점수에서 고르고, 실제 판정은 정상 **96개**로 학습한 AE에 적용한다. 학습량이 다르면 점수 눈금이 조금 달라질 수 있다. 지도학습 모델에도 있는 문제지만, 복원 오차는 학습 정상 수에 민감해서 더 클 수 있다(아직 확인 안 함).
- **보고 지표**
  - F2, 재현율, 정밀도: seed마다 바깥 예측 150개를 모아 계산 → 평균 ± sd
  - **오경보율** = 오경보 / 정상 수. 고장 비율과 무관해서 val·test 비율이 달라도 비교 가능
  - F2 (고장 10%·40%): 재현율·오경보율을 고정하고 고장 비율만 바꿔 다시 계산 → val·test 비율을 모를 때 대비
  - **자주 놓침 / 자주 오경보**: seed 5번 중 3번 이상 → 원칙 4의 오류 분석 대상

## ⑨ 이해 도구 — 점수가 아니라 "왜"를 보는 단계

평가(⑧)와 **별개로** 그림용 AE를 하나 더 학습한다. 점수에는 쓰지 않는다.

```python
held  = 정상 120개 중 24개 무작위 (seed 0)    # "보지 않은 정상"
train = 나머지 정상 96개                       # AE 학습
```

- **판단 — 보지 않은 정상을 남긴 이유**: 고장 30개는 모두 AE가 처음 보는 파일이다. 정상도 처음 보는 것이 있어야 공정하게 비교할 수 있다. 학습한 정상과 고장을 비교하면 "외운 것 vs 처음 본 것"이 되어 AE가 실제보다 좋아 보인다.
- 여기서 빠진 24개 중에 CV 상습 오경보 **nor_055·nor_062**가 들어 있다.

## 아직 비교하지 않은 판단 (다음 실험 후보)

같은 중첩 CV로 비교해야 정할 수 있는 것들이다. 라벨을 보고 손으로 고르지 않는다.

1. ⑥ 병목 크기·epoch·`alpha`(규제) → 과적합 간격과 오경보
2. ⑦ 구간 집계 평균 vs 최댓값 → 005·014 같은 충격형 고장
3. ② 고역통과 차단 주파수 (예: 20 Hz) → 017 같은 저주파 이상 (H4와도 연결)
4. ① 피처 모델과 OR 결합 → 놓친 고장 집합이 서로 다르다는 점 이용
