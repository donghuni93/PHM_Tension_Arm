# F_1 — 피처 담당 제안서 (11-22, 라벨 사용 원칙 · 정상 증거 포함)

결론: **ET 축의 입력을 ext150 + 울림 2열에서 2차 설계 14열(new14)로 바꾸고, 라벨로 확인한 열 5개를 더한 19열("F19")을 후보로 제안한다.** 라벨로 찾은 고장 대역(고주파 ≥ 8 kHz, 2.0–3.4 kHz 유격 창)은 L을 통과했지만 new14의 옥타브 칸과 겹쳐서 단독으로는 새 정보가 크지 않다. 오경보를 줄이려고 만든 정상 증거 피처 중 "한 사건 집중"과 "좁은 순음 폭"은 새 충격 정의에서 재현되지 않아 제안에서 뺐다. 정상 증거로 남은 것은 "충격이 본체 모드(3.4–8 kHz)에 몰림"과 "충격 0개"뿐이다.

- 수치는 모두 train 150(고장 30 · 정상 120)에서 쟀다. 열 선택과 경계는 학습 폴드 안에서 다시 골랐다(5겹, seed 5개). 원본 로그와 코드는 `code_F/`.
- 용어: **5-NN 순도** = 고장 파일의 가까운 이웃 5개(자기 제외) 중 고장 비율(무작위 0.195). **FA 정상** = 자주 오경보를 내는 정상 11개(065 116 037 110 095 059 055 025 097 101 120). **FA 정상 5-NN 순도** = 이들의 이웃 5개 중 정상 비율(전체 정상 평균은 0.92–0.97, 높을수록 정상 무리 안).
- **위험 정상 수** = OOF 점수가 "고장 하위 10% 선"보다 높은 정상 수(작을수록 경계가 안전). **8.3k군** = 002 006 010 029, **유격·조용군** = 014 017 005 009 016 021 022의 OOF 순위 백분위(0 = 가장 잘 잡힘).

## 2. 제안

### F-1. ET 축 기준 공간 = new14 (D)
- **정의**: `src/features2.py`의 2차 설계 H 피처에서 상관 묶음(H4, H6)을 뺀 14열: `H1_nimp H2_ratio21 H3_kurt_1-2k H5_kurt_4-8k H7–H10_ring_(옥타브 4칸) H12–H15_share_(옥타브 4칸) H18_hfl L1_S`. H16·H17은 폴드 안 정상 기준이라 이 비교에서 빠졌다(최종 16열 중 14열). 충격 정의는 결정.md의 새 정의 하나.
- **등급**: D. 정의가 라벨 없는 규칙(옥타브 칸, 사전 고정 충격 규칙)이다.
- **겨냥**: 전체. 특히 8.3k군(002 006 010 029) 순위 0.17 → 0.02, 유격·조용군 0.11 → 0.02.
- **근거 수치**: 위 표. 고장 5-NN 순도 폴드 밖 0.661 vs 0.567(A 입력), t-SNE 평균 0.784 vs 0.616, 위험 정상 2.4 vs 10.4, FA 정상 5-NN 순도 0.810 vs 0.729.
- **t-SNE 분리 효과**: 현재 기준(0.667 / 0.453)과 같은 방향 + 폴드 밖에서도 유지.
- **위험**: ① quick_cv는 임계값이 없는 순위 지표다. 같은 14열 ET 단독의 중첩 F2는 EXP-040 B 0.890 ± 0.024로 A 0.949(AE + 규칙 포함)에 못 미친다. 이 표는 "ET 축이 더 잘 가른다"를 보이지 "최종 F2가 오른다"를 보이지 않는다. ② `L1_S`(주기 잠금, 겨냥 022 하나)는 P 등급이다. 제거해도 quick_cv가 같다(0.962 ± 0.010 vs 0.968 ± 0.013, 위험 정상 3.4 vs 2.4)이므로 근거를 쓰지 않으려면 빼도 된다(보험 열을 유지할지는 사용자 결정).

### F-2. 2.0–3.4 kHz 유격 창 충격 수 `ring_mid_n` 1열 (L)
- **정의**: 충격(새 정의)의 울림 주파수 f(250 Hz 격자)가 [a, b)에 있는 충격 수의 log1p. 창 [a, b)는 학습 폴드에서 "창 안에 충격 ≥ 1개" 지표의 TPR − FPR(Youden)이 최대인 (a, b)를 고르고, 최대에서 0.01 안의 동률은 a·b 각각의 중앙값을 쓴다(`step5_final.py`의 `sel_win`).
- **등급**: L.
- **겨냥 파일**: 창 [2250, 4000)에서 고장 21/30(001 003 004 005 007 008 009 010 011 012 015 016 017 019 020 021 023 024 025 026 027) · 정상 9/120(025 030 043 046 080 095 102 103 108) · val 12/40. 단변량 AUC 0.907(`ring_mid_n`).
- **폴드 안 재선택 안정성**(5겹 × seed 20 = 100번): 하한 a는 2000 Hz가 95번(2250 4번, 2125 1번), 상한 b는 3250 Hz 76번 · 3375 13번 · 3500 6번 · 3625 2번 · 4000 1번 · 4250 1번 · 5250 1번. 전체 150 선택 [2000, 3375).
- **기전**: 연결부 틈에서 금속이 부딪치면 암 본체(7 kHz)보다 낮은 모드가 울린다(H1). 정상 충격은 84%가 3.4–7.9 kHz, 고장 충격은 45%가 3.4 kHz 아래다(충격 단위).
- **효과**: new14에 이 열 하나만 더하면 위험 정상이 2.4 → 0.8, 고장 5-NN 순도 0.661 → 0.675, FA 정상 5-NN 0.810 → 0.827, PR-AUC 0.971 ± 0.010(sd 안). 8.3k군 순위는 0.021 → 0.028(변화 없음 수준).
- **위험**: ① new14의 `H8_ring_2-4k`와 ρ 0.91이라 새 정보량은 작다. 이 열이 한 일은 "같은 정보를 폴드 안에서 고른 창으로 다시 센 것"이다. ② val에서 이 창에 충격이 있는 파일이 19/40(0.475)으로 정상 train(0.20)보다 훨씬 많다(분포 이동, 고장 비율로 환산하면 약 39%). val 정상이 이 열로 고장 쪽으로 밀릴 수 있다. ③ 창 상한이 폴드마다 3250–3625 Hz로 움직인다(안정성 76–89%).

### F-3. 고주파(≥ 8 kHz) 충격 수 `ring_hi_n` 1열 (L)
- **정의**: 충격 중 f ≥ b_hi인 충격 수의 log1p. b_hi는 학습 폴드에서 "충격 ≥ b_hi가 하나라도 있는가" 지표의 TPR − FPR(Youden)이 최대인 값(250 Hz 격자 7.5–10.5 kHz, 동률은 구간 가운데). `sel_hi`.
- **등급**: L.
- **겨냥 파일**: 충격 ≥ 8.0 kHz 있는 고장 20/30(001 002 003 004 006 007 010 011 012 013 015 018 019 020 024 025 026 028 029 030) · 정상 6/120(019 043 059 065 092 116) · val 2/40(006 021). 단변량 AUC 0.817.
- **폴드 안 재선택 안정성**(100번): b_hi = 8000 Hz 82번 · 8250 Hz 18번(최빈 ±250 Hz 안 1.00). 문턱을 올릴 때 (고장, 정상) 파일 수: 8.0k (20,6) · 8.5k (14,4) · 9.0k (13,4) · 9.25k (13,3) · 9.5k (13,2) · 10.0k (8,1).
- **기전**: 타격이 8.3 kHz 모드(H2′)와 더 높은 모드를 들뜨게 한다. 8.0–8.5 kHz 칸 정확검정 p = 0.007 · 0.0009 · 0.0014(250 Hz 칸마다, 정상은 0–2개).
- **효과**: 8.3k군 순위 0.021 → 0.011(`ring_hi_n` 단독) · 0.008(F19). 반대로 유격·조용군 0.019 → 0.036이고 위험 정상 2.4 → 4.0으로 나빠진다(희소 열이 ET의 열 무작위 선택을 희석). F19에서는 `ring_mid_n`·`body`와 함께 넣으면 위험 정상 2.4(변화 없음)다.
- **위험**: ① 정상 6개 중 059 065 116은 FA 정상이다. ② 이 열은 val에서 거의 켜지지 않는다(2/40, 정상과 같은 0.05). val에서는 효과가 보이지 않고 test 대비 장치다. ③ new14의 `H10_ring_8-12.5k`와 ρ 0.82. ④ "9.5–10 kHz는 정상에도 있어 고장 근거가 아니다"라는 예전 결론은 새 정의에서 뒤집혔다(지식장부 row 13, 정상 ≥ 9.25 kHz = 043 065 116 단 3개).

### F-4. 정상 증거: 본체 모드 몫 `ring_body_share` (L) — 이미 new14에 있음
- **정의**: 충격 중 f가 [b, b_hi)(중간창 상한 ~ 8 kHz)에 있는 비율. 충격 0개면 0. new14의 `H14_share_4-8k`와 ρ 0.99라 사실상 같은 열이다.
- **등급**: L. 충격 ≥ 3개이고 5.5–8.0 kHz 몫 ≥ 0.9인 파일은 정상 41/120 · 고장 0/30 · val 3/40(충격 ≥ 4면 36 · 0 · 3). 충격 수 조건 없이 3.4–8 kHz 몫 ≥ 0.9인 파일은 정상 65/120 · 고장 0/30 · val 7/40. 고장은 충격 ≥ 3인 30개 중 5.5–8.0 kHz 몫 중앙값이 0.07.
- **기전**: 외부 입력(노면)이 암 전체를 쳐서 본체 모드(7.0–7.25 kHz)가 울린다. 라벨 없는 KDE 봉우리(6.9–7.1 kHz)가 같은 곳을 가리킨다(4-8).
- **효과**: new14에 더해도 PR-AUC 0.968 → 0.961(sd 안), 위험 정상 2.4 → 3.4. 새로 더하는 열이 아니다. new14가 이미 담고 있음을 확인하는 것이 제안의 내용이다.
- **위험(핵심)**: **val에서 이 증거가 약해진다.** 몫 ≥ 0.9인 파일 비율이 정상 0.54 vs val 0.175, 몫 ≤ 0.1은 정상 0.24 vs val 0.40. val 정상 파일의 충격이 3.4 kHz 아래로 더 많이 몰려 있다(val 충격 52%가 < 3.4 kHz, train 정상 15%). 이 열은 연속값으로만 쓰고 if문(몫 ≥ 0.9이면 내림)으로 쓰지 않는다. 그리고 FA 정상(116: 0.67, 095: 0.72, 055: 1.00, 025: 0.96)에는 도움이 되지만 059·065(충격이 ≥ 8 kHz에만 있음, 본체 몫 0)와 037·110(2–3.4 kHz 충격 2개씩)에는 도움이 안 된다.

### F-5. 정상 증거: 충격 0개 (L) — 이미 new14의 `H1_nimp`
- **정의**: 충격 수 0. (새 정의, 앞뒤 10 ms 제외)
- **등급**: L. 충격 0개 파일은 정상 17/120 · 고장 0/30 · val 4/40(정상과 같은 비율). 097 · 101 · 120(평균 −1 g 오경보 정상)이 모두 여기에 해당한다. 기전: 연결부에 틈이 있으면 충격이 반드시 생긴다.
- **위험**: 충격 정의의 한계(꺼짐 0.5 ms 미만 울림 미검출)로 "충격 0개"가 약한 충격을 못 잡았을 수 있다. 연속 피처 `H1_nimp`로 두고 if문으로 쓰지 않는다.

### F-6. 방향 무관 정규화 (D)
- **정의**: 평균 DC에 의존하는 열을 쓰지 않는다. ext150에서 평균 DC와 ρ ≥ 0.5인 대표 열은 `T06_raw_mean`(0.86) 하나, 이 열은 폴드 안 AUC 거름에서 3%만 선택된다. new14는 충격 기반(평균 제거 후)이라 방향 무관이다. 스펙트럼 "솟은 봉우리"(H16, 예전 E1)는 097 101 120을 구조적으로 높게 보므로 쓰지 않는다(지식장부 row 62).
- **등급**: D.
- **겨냥**: 097 101 120 · 016. **효과**: 097 · 101 · 120이 new14 계열 공간에서 충격 0개 영점에 놓여 정상 쪽에 위치(FA 정상 5-NN 순도에 반영).

### F-7. 하지 말 것 (X · P로 내린 후보)
- **한 사건 몰림**(`ev_hi_top1`): 새 정의에서 갈리지 않음(정상 043 065 092가 1.0, 고장 007 012 030도 1.0). quick_cv에서 new14에 더하면 0.968 → 0.954, 위험 정상 2.4 → 3.8.
- **좁은 순음 폭**: 재측정에서 갈리지 않음(돌출 ≥ 1.0: 고장 12/30 · 정상 21/120, 폭 ≥ 150 Hz: 고장 11 · 정상 12). F19에는 `tone` 2열(돌출 · log 폭)이 들어 있지만 이는 "순음 규칙"이 아니라 연속 피처이고, 단독 효과는 PR-AUC 0.973 ± 0.009, FA 정상 5-NN 0.810 → 0.863이다. 효과가 sd 안이고 FA 정상 11개 표본이 작아서 이 열의 필요성은 **미확정(R2에서 반박 요청)**이다.
- **ext150 중복 열 덜어내기**: 5-NN 순도·quick_cv 모두 개선되지 않음(대표 60열 0.541 vs 0.555, 약한 열 제거 0.501). 가족 단위로 줄이는 것은 D(row 6, 40)지만 효과는 없다.
- **dev_tsa**(대표 울림이 본체에서 떨어진 정도): new14에 더하면 PR-AUC 0.968 → 0.962, 고장 5-NN 순도 0.661 → 0.621(하락). 충격 0개 파일은 NaN(정상 17 · val 4).

## 4. R3에 넘기는 사전 등록 정의 (구현 지침)

1. 충격: `src/impacts.py` 새 정의(합계 정상 854 · val 247 · 고장 402 assert). 울림 f는 `impact_rings_v2`(250 Hz 격자).
2. 폴드 안에서 학습 파일로 (a, b) = `sel_win`, b_hi = `sel_hi`를 다시 고르고, 이 경계로 `ring_mid_n`, `ring_hi_n`, `ring_body_share`(= [b, b_hi) 몫)를 계산한다. 경계는 seed·폴드마다 같은 방법으로 다시 고르므로 중첩 CV의 안쪽 루프에서 처리한다.
3. `tone` 2열(8.0–8.6 kHz Welch 봉우리 돌출 dex, log1p 폭): 라벨 없이 정의되고 폴드 안 선택이 없다(`code_F/step5a_tone.py`). 단 효과가 확정되지 않았다(F-7).
4. ET는 로버스트 z 입력(학습 폴드 정상의 중앙값·MAD) + ±10 클리핑을 평가에 썼다. 모델은 `make_et`(300그루). 5-NN 순도·FA 정상 순도의 입력도 같다.
5. 후보 구성 비교는 (a) new14 (b) new14 + `ring_mid_n` 1열 (c) F19 셋이면 충분하다. 구성 ≤ 5개 제약 안에서 A(G0)와 같이 돌린다.

## 5. 한계와 이해해야 할 점

- 고장 30개라 5-NN 순도·PR-AUC의 폴드 sd가 0.11–0.13이다. 표의 순도 차이는 대부분 sd 안이다.
- new14의 PR-AUC 0.968이 A 입력의 0.875보다 크게 앞서지만, 중첩 F2에서 D2(0.916)가 A(0.949)보다 낮은 이유는 ET 축의 순위 능력이 아니라 AE 부재, 결합, 문턱, E1의 오경보 쪽에 있다(R·D가 다룸). 이 제안서는 ET 축까지만 다룬다.
- val은 train과 충격 분포가 다르다: 충격이 < 3.4 kHz 52%(정상 15%), 충격 수 중앙 3(정상 4, 고장 10). 2.0–3.4 kHz 창 지표로는 val 고장 비율이 약 39%로, 본체 몫 ≥ 0.9 지표로는 68%로 환산돼 서로 맞지 않는다 → val 정상 일부가 train 정상과 다른 분포다. 라벨 없는 val이므로 이동의 원인을 확정하지 못한다.
