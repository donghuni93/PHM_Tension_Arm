# 지식장부 (통합) — F · R · D 세 장부를 합침 (11-22, 의장)

> 집계 수치는 이 파일 맨 아래 "집계 확인"에서 표의 행 ID로 다시 센 값이다. 원 장부: [F](지식장부_F.md) 66행 · [R](지식장부_R.md) 37행 · [D](지식장부_D.md) 50행 = 153행을 같은 주장끼리 합쳐 **통합 61행**으로 줄였다. 열 `원`은 원 장부 행(F# R# D#).
> 등급(11-22 개정): D 도메인 / L 라벨 확인(기전 + 겨냥 고장 ≥ 3 + 폴드 안 재선택 안정 → 적극 사용) / P 사후 맞춤(쓰지 않음) / X 이상한 실험(근거에서 뺌).
> 새 수치는 모두 탐색용(quick_cv, 중첩 CV 아님). 고장 30개라 PR-AUC sd 0.01, 5-NN 순도 sd 0.11–0.13 → 순도 0.05 안팎 차이는 승부로 쓰지 않는다.

**근거에서 빼는 X 목록** (이 13개를 EXP 설계·발표 근거로 쓰지 않는다)
1. X1 사건 주파수 중심 FC < 4.9 kHz, A형 정상 설명 (옛 충격 정의 + 한 틈에 그은 값)
2. X2 "큰 타격이 정확히 1개 → 정상" (옛 정의, 1.5초 창에서 고장 5개가 걸림)
3. X3 감쇠 ζ 기반 주장(빨리 꺼지는 충격 AUC 0.73, ζ < 0.0015 → 정상 18/고장 0) (ζ 두 방법 순위상관 0.475, 정렬 평균 신뢰 0.43)
4. X4 잔향 비 (사후 정의, 선형 항으로 넣으면 PR-AUC 하락)
5. X5 "9.5–10 kHz는 고장 근거가 아니다" (옛 충격 정의 결론, 새 정의에서 뒤집힘)
6. X6 "8.3 kHz와 9.4 kHz는 다른 칸" (사전 KDE 규칙으로 분리 안 됨)
7. X7 한 사건 집중 → 정상 (새 정의에서 정상 043·065·092와 고장 007·012·030이 같이 1.0)
8. X8 8.3k 봉우리가 좁은 순음 → 정상 (정상 2개 근거, 재측정에서 안 갈림)
9. X9 E1 = 스펙트럼 "솟은 봉우리" H16 (002 못 잡고 평균 −1 g 정상 4개만 켬)
10. X10 sd 안 차이로 채택한 결정들 (C ≥ B, D2 > W, D 입력 +0.018, AUC 소프트 가중 t-SNE 0.66, MIL +0.011, 0.949 vs 0.942, +0.002 등)
11. X11 열 수·스케일이 다른 공간끼리 5-NN 순도 비교(0.667 vs 0.453, ext150 0.47) — 같은 틀 재측정값(new14 0.61–0.66 / ext150 0.45–0.47)만 쓴다
12. X12 A 0.949와 규칙 단계별 기여(0.857 → 0.892 → 0.942 → 0.949), 고정 임계 0.85·1.0 값, val_001 규칙 판정 — 사후 문턱 + 비교 틀 혼재. G0 비교 기준으로만
13. X13 "라벨로 고른 ring 열을 new14에 더하면 개선" (F 재계산이 반증: 0.968 → 0.930–0.961)
