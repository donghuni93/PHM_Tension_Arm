# EXP-050 실행 방법

`코드/` 폴더에 EXP-050을 다시 돌리는 데 필요한 것이 모두 들어 있습니다. 구조는 저장소와 같습니다.

```
코드/
  src/                         공용 코드 (피처 · 모델 · 중첩 CV · 그림)
  단계/4_피처/4-7_…/최종피처.json  J가 쓰는 피처 목록
  단계/5_모델비교/EXP-050_…/run.py  실험 코드 (축소는 Shrink 클래스, α = ALPHA)
  data/                        ← 여기에 데이터를 넣는다 (아래 2번)
  requirements.txt
```

## 1. 환경
Python 3.12(우리 환경과 같은 버전 권장)와 `numpy scipy pandas scikit-learn matplotlib joblib`이 필요합니다.

```
pip install -r 코드/requirements.txt
```

우리 조 conda 환경(`qe-phm`)이 있으면 그대로 쓰면 됩니다.

## 2. 데이터 넣기
과제 데이터를 `코드/data/` 아래에 이 이름 그대로 넣습니다.

```
코드/data/TeamProject_train_변경/normal/     정상 120개
코드/data/TeamProject_train_변경/abnormal/   고장 30개
코드/data/TeamProject_val/val/               val 40개
```

## 3. 실행
`run.py`는 정식 모드(seed 5 · ET 300)로만 돌게 되어 있어서 `QE_FULL=1`이 필요합니다.

Windows PowerShell:
```
cd 코드
$env:QE_FULL = "1"; python 단계/5_모델비교/5_울림비율축소/EXP-050_1122_울림비율축소_H10/run.py
```

Mac / Linux:
```
cd 코드
QE_FULL=1 python 단계/5_모델비교/5_울림비율축소/EXP-050_1122_울림비율축소_H10/run.py
```

- 걸리는 시간: 32스레드 PC에서 약 10분입니다. 처음 실행할 때는 피처와 AE 캐시(`코드/outputs/cache/`)를 만드느라 더 오래 걸리고, 노트북이면 1시간 넘게 걸릴 수 있습니다.
- 결과: `run.py`가 있는 폴더에 `README.md` · `result.json` · `figs/` · 표(md)가 생깁니다. 우리가 낸 결과는 `실험결과/`에 있으니 비교해 보면 됩니다. 네 구성의 F2는 J 0.977 · J−H10 0.965 · J-축소 0.977 · J−H10+축소 0.964입니다.
- Mac에서는 그림의 한글이 네모로 보일 수 있습니다(그림 글꼴이 Windows 맑은 고딕 기준). 계산 결과에는 영향이 없습니다.
