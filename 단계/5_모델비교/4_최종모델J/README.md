# 4. 최종 모델 J (11-22)

**질문**: 2차 설계(G)에 AE를 다시 넣으면 남은 오류가 줄어드나.

**J = ET(H 피처) + 박자 z + AE z → 로지스틱, OR E2 OR 8.3k 규칙** ([EXP-044](EXP-044_1122_AE추가/README.md))
- 중첩 F2 **0.977 ± 0.010**, 재현율 **1.000**, 오경보율 0.030 (G 0.959 → +0.018, 오경보율 0.047 → 0.030)

**깨달음**
- AE의 몫은 고장을 더 잡는 것보다 **오경보 줄이기**였다. 1단계의 "정상과 다른가" 전문가가 2차 설계 피처와 다시 합쳐졌다
- val은 측정 조건이 다르다(배경 3–5 kHz +10.9 dB). 이 이동에 판정이 덜 흔들리게 만드는 것이 다음 과제 → [5. 울림 비율 축소](../5_울림비율축소/README.md)
