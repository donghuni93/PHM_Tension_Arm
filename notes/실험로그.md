# 실험 로그

평가는 모두 중첩 CV(바깥 StratifiedGroupKFold 5 × 안쪽 4, seed 0–4, 임계값은 안쪽 OOF F₂ 최대).
F2는 seed 5개 평균 ± 표준편차. "자주 놓침" = seed 5번 중 3번 이상 놓친 고장. 가설 id는 [물리가설](물리가설.md).
바닥 점수: 전부 고장 0.556, RMS 관리도 0.080.
오경보율(정상 중 고장 판정 비율)과 고장 10%·40% 환산 F2는 11-13부터 각 실험 README 결과 표에 자동 기록된다 (EXP-007부터).

**노션 공유**: 앞 6열(버전·팀원·모델·F2 점수·변경 사항·메모)이 노션 실험 DB 속성과 같다. 한 줄 = 노션 카드 하나.
각 실험 폴더 README 맨 위 '노션 카드' 표에도 같은 값이 자동으로 들어간다(`src/exp.py` `Experiment`).

## 실험별 메모

### 003 — 25년 3조 비교
- 25년 데이터 첨도 중앙값 정상 30 → 고장 444, 26년 4.6 → 19.5. 신호 상관도 0.03 이하 → 다른 데이터
- 3조식 CV(검증 fold에서 임계값 선택): 3조 피처 SVM 0.673, 확장 150 ET 0.880
- 3조 피처 28개를 확장 150에 더해도 0.816 (변화 없음)

### 004 — 진단
- 피처 단변량 AUC ≥ 0.8: 28개 / 178개, 상위는 모두 P02·S01·E01 1.25–2.5 kHz
- 놓친 고장의 정상 대비 극단 피처 수(백분위 0 또는 100): abn_002 1개, 022 1개, 029 1개. 잡히는 고장(009, 015, 017)은 17–28개

### 005 — 스펙트럼 모양
- Welch(nperseg 4096) → 격자별 평균 로그 파워 → 파일 평균 로그 파워를 빼서 게인 제거
- 100 Hz 격자: 단독 0.756, 확장 150과 합침 0.812 / 250 Hz: 단독 0.760, 합침 0.845
- 절대 로그 PSD 추가는 0.79–0.81로 항상 나빠짐 (H3 지지)
- 9개 구성 중 최고를 고른 값이라 선택 편향이 있음
