# 물리 가설 → 피처

모델 개발의 축. 피처·모델을 추가할 때는 아래 가설 중 하나에 연결하고, 실험 후 `검증` 열을 채운다.
개념 설명은 [1단계 README](../단계/1_문제·평가/README.md)의 도메인 절, 실험 수치는 [실험로그](실험로그.md).

## 가설 표

| id | 결함 → 물리 변화 | 예상 신호 징후 | 피처 (구현 위치) | 검증 (실험) | 상태 |
|---|---|---|---|---|---|
| H1 | 부싱 박리·유격 → 금속 타격(Clunk) | 짧은 간헐 충격: 첨도·파고율·TKEO 상승, 특정 대역에서만 뚜렷 | P02 대역 필터 후 첨도·파고율·Peak, E01 포락선 첨도, S01 시간 변동 (`src/features.py` ext) | EXP-002: 중요도 합 0.71, 단변량 AUC 최고 `P02_kurtosis_012` 0.878 (1.25–2.5 kHz) | 지지 |
| H2 | 부싱 경화(K↑) 또는 박리(K↓) → 공진 이동, 감쇠↓ → 공진 날카로움↑ | 특정 공진 피크의 위치·높이·폭(Q) 변화. 넓은 대역 에너지에서는 희석됨 | 스펙트럼 모양(정규화 로그 PSD, 고정 격자) → 다음: 공진 피크 Q·돌출도 | EXP-005: abn_002·029에 8.2–8.4 kHz 협대역 피크, PSD 빈별 AUC 최고 8,447 Hz 0.864. 모양 피처만 쓰면 002·029를 잡음 | 부분 지지 |
| H3 | 게인(가진 크기·차량 세팅) 차이 → 절대 크기 기준선이 흔들림. Payne 효과로 진폭 의존 강성 | 조용한 고장 존재 (abn_002, 022: 고주파 에너지가 정상 5% 아래) | 게인 무관 피처: 비율, 정규화 로그 PSD 모양 | EXP-005: 모양 피처 추가 시 +0.026, 절대 로그 PSD 추가는 매번 하락 | 부분 지지 |
| H4 | 하중 반전 시 유격 (볼조인트·부싱) | 저주파 흔들림(≈1 Hz)의 반전점에서 짧은 충격. 충격 시점이 저주파 위상에 동기 | 저주파(<20 Hz) 성분 진폭, 충격 시점과 저주파 극값의 동기도 | abn_022 파형 관찰(EXP-005). 현재 피처는 20 Hz 미만을 모두 제외함 | 미검증 |
| H5 | 감쇠 C 변화 | 충격 후 링다운이 길거나 짧아짐 | 충격 후 포락선 감쇠 시간, 자기상관 감쇠율 | — | 미검증 |
| H6 | 본체 호흡 균열 (이선형 강성) | 가진 주파수의 정수배 고조파 | 고조파 에너지 비율, 켑스트럼 | 가진 주파수 미상(공통 가진 피크 없음) | 보류 |

## 열린 질문 (실험에서 나옴)
- 1.25–2.5 kHz 대역 첨도가 가장 강하다. 원문 추정 "고차 모드 1–3 kHz(조립부)"와 겹침 → 유격 충격이 이 모드를 때리는가 (H1)
- 8.3 kHz 협대역 피크는 어떤 모드인가. 고장 중앙값에도 같은 위치에 혹이 있음 (H2)
- 정상 파일에 공통 가진 피크가 없음 → 광대역 랜덤 가진 또는 노면 재생? (H6, 조교 질문 후보)
- 평균 −1 g 파일 4개(nor_097·101·120, abn_016): 센서 방향?

## 규칙
- 라벨을 본 뒤 대역·주파수를 손으로 고르지 않는다 (예: "8.3 kHz 피처"). 고정 격자 + 폴드 안 선택으로만 쓴다
- 관찰은 놓친 파일을 정상 5–95% 범위와 겹쳐 보는 그림에서 시작한다
