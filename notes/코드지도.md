# 코드 지도

## 파이프라인

```mermaid
flowchart LR
    A[취득<br/>src/data.py] --> B[전처리<br/>평균 제거]
    B --> C[특징 추출<br/>src/features.py]
    C --> D[모델]
    D --> E[평가<br/>CV F2]
    E --> F[제출 CSV]
```

## 단계별 데이터 형태

| 단계 | 형태 | 담당 파일 |
|---|---|---|
| 취득 | `X` (150, 50000) g, `y` (150,) 정상 0/고장 1, `names` 150개 | `src/data.py` |
| 전처리 | 신호마다 평균 제거 (MA 미적용) | `src/features.py` 안 |
| 특징 | `F` (150, 13) DataFrame, 열 이름 = 스펙 id + 이름. 확장은 (150, 150), 대역 피처 이름 끝 숫자 = 대역 하한(100 Hz 단위, 예 `012` = 1,250 Hz) | `src/features.py` |
| 모델 | `make_pipeline(RobustScaler(), 모델)`을 만드는 함수 | `notebooks/04_베이스라인.ipynb` |
| 평가 | seed별 F₂·재현율·정밀도 배열, 파일별 미탐·오경보 횟수 | `src/evaluate.py` |

## 파일

| 파일 | 역할 |
|---|---|
| `src/data.py` | `load_dataset(data_dir)`: normal·abnormal 폴더의 CSV를 정렬 순서로 읽어 `X, y, names` 반환. train·val·test 공용 |
| `src/features.py` | `extract_features(x, fs)`: 신호 1개 → core 피처 13개 dict. `feature_table(X, fs)`: 배열 → DataFrame. `extract_features_ext`·`feature_table_ext`: core 13 + 확장 137 = 150개 (core는 `extract_features`를 그대로 호출) |
| `src/evaluate.py` | `nested_cv(F, y, groups, make_model, ...)`: 바깥 5-fold × 안쪽 4-fold 중첩 CV. `best_f2_threshold(y, scores)`: F₂ 최대 임계값 |
| `notebooks/04_베이스라인.ipynb` | 로지스틱 회귀·RBF-SVM 비교, 누수 버전 대조, 놓친 고장 분석 ([[30_실험/EXP-001]]) |
| `notebooks/05_천장확인.ipynb` | 확장 피처 150개 × L1 로지스틱·RF·ExtraTrees·HistGB, 놓친 고장 추적, 피처 묶음별 중요도 ([[30_실험/EXP-002]]) |
| `notebooks/01_데이터점검.ipynb` | 형태·결측·평균 점검, 바닥 점수(전부 고장, RMS 관리도) |
| `notebooks/02_EDA.ipynb` | 파형·평균 스펙트럼, 대역별 에너지, 최대 피크 주파수, MA 비교 (D1·D3·D4 근거) |
| `notebooks/03_피처점검.ipynb` | 피처 표 검증, 피처별 정상/고장 차이, 정상만의 상관 |

## 함수 호출 트리

```
notebooks/03_피처점검.ipynb
├── src.data.load_dataset
│   └── np.loadtxt (파일마다)
└── src.features.feature_table
    └── extract_features (파일마다)
        ├── 평균 제거
        ├── 시간 영역: RMS, Peak, 첨도, 왜도, Hjorth, TKEO, 창별 RMS
        └── 주파수 영역: rfft → 스펙트럼 중심, 1차 피크(20 Hz 이상), 대역 에너지 비율

notebooks/04_베이스라인.ipynb
└── src.evaluate.nested_cv (seed마다)
    └── 바깥 fold마다
        ├── _oof_scores (안쪽 4-fold) → best_f2_threshold → 임계값 t
        ├── make_model().fit(바깥 학습 파일 전체)
        └── 바깥 평가 파일 점수 ≥ t → 고장
```
