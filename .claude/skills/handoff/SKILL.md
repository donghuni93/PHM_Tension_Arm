# /handoff — 인수인계 노트 작성

## 1. 세션 번호 정하기
`vault/50_세션/`에서 오늘 날짜(YYYY-MM-DD) 파일 중 가장 큰 번호 + 1. 없으면 `_0`.
기존 세션 노트는 절대 덮어쓰지 않는다.

## 2. 사실 모으기
- 이번 대화에서 한 일, 결정과 그 이유, 막힌 점, 승인 대기 중인 것
- git 저장소면 `git status --short`, `git log --oneline -5` 실행. 아니면 "git 저장소 아님"
- 바뀐 파일: git 저장소면 status 결과, 아니면 대화에서 만들거나 고친 파일 경로
- 추측하지 않는다. 확인하지 못한 것은 "미확인"이라고 쓴다.

## 3. 세션 노트 작성
`vault/_templates/세션.md` 구조를 따른다. 결정에는 반드시 이유를 붙인다.
실험을 했다면(L1~L2) `vault/30_실험/EXP-nnn.md`도 함께 쓸지 사용자에게 묻는다.

## 4. `vault/00_NOW.md` 갱신
- 진행 중 작업, 최신 인수인계 링크, 다음 할 일, 최고 CV F2, 미해결 항목
- 완료한 할 일은 세션 노트에 기록이 남았으므로 00_NOW.md에서 지운다.
  00_NOW.md는 60줄 이내로 유지한다 (SessionStart 훅이 매 세션 주입하는 파일이라서).
- 자동화 단계는 사용자가 선언했을 때만 바꾼다.

## 5. git 코칭 (L1~L2: 실행은 사용자)
커밋 안 된 변경이 있으면 무엇을 한 커밋으로 묶을지, 명령(`git add …`, `git commit -m "notes: …"`)과
각 명령의 의미를 알려준다. Claude는 커밋하지 않는다.

## 6. 보고
작성한 두 파일 경로와 "다음 세션에서 할 첫 일" 한 줄을 사용자에게 알려준다.
