# /handoff — 인수인계

1. 사실 모으기: 이번 대화에서 한 실험·결정과 이유, 막힌 점, 승인 대기 항목. `git status --short`, `git log --oneline -5`. 확인 못한 것은 "미확인".
2. `단계/1_기준·기록/실험로그.md`: 기록 안 된 실험을 표에 한 줄씩 추가 (열 순서는 표 머리 그대로: 버전·팀원·모델·F2 점수·변경 사항(가설)·메모·날짜·재현율·정밀도·자주 놓침). 수치는 `단계/*/EXP-nnn_*/result.json`에서 가져오고, 해당 실험 README의 `## 메모`에 결론을 쓴다.
3. `단계/1_기준·기록/물리가설.md`: 검증된 가설의 `검증`·`상태` 열 갱신.
4. `단계/1_기준·기록/결정.md`: 새 결정과 이유 추가.
5. `단계/1_기준·기록/00_NOW.md`: 최고 F2, 다음 할 일, 마감. 60줄 이내. 끝난 할 일은 지운다.
6. 커밋 안 된 변경이 있으면 커밋 묶음과 메시지를 제안하고 승인받는다.
7. 보고: 바뀐 파일과 "다음 세션 첫 일" 한 줄.
