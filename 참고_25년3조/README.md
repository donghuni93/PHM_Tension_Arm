## 5 kHz에 맞춰 바꾼 정의 (2-4 대비)
창 50 ms × 200개, 대역 3분할 200–1k / 1–2k / 2–2.5k, 고정 격자 250 Hz × 10칸, 고역 비 = 2 kHz 이상, STFT 256 (51 ms), PSD 바탕 이동 중앙값 155칸(≈190 Hz), 최대 충격 확대 ±100 ms. 충격 수는 10초 기준이라 26년(2초)과 직접 비교하지 않는다 (비교 탭은 초당)

## 3조 코드에서 본 문제점 (노트북 탭에 셀별로)
1. 신호를 **최대 |x|로 나눔** → RMS·MAV·분산이 "Peak 대비 비율"로 바뀌어 크기 정보가 사라진다. `abs_max`는 1이어야 하지만 분모의 `+1e-8` 때문에 `1 − 1e-8/Peak`로 미세하게 남는다 (범위 0.9999982–1.0, 원래 Peak와 순위상관 1.000). StandardScaler가 이 1e-6 차이를 키워서 SVM에는 사실상 Peak가 들어간다 (25년 단변량 AUC 0.88)
2. **5–7초 창**은 정상 1개·고장 1개 그림을 보고 고른 구간 (라벨을 본 선택)
3. FFT 대역 2000–5000 Hz는 Nyquist(2.5 kHz)를 넘어 실제 2–2.5 kHz
4. **검증 폴드 정답으로 임계값을 고르고** 같은 점수로 모델 선택 → 낙관적
5. val 제출 임계값은 CV 값(0.37) 대신 손으로 0.20
6. 26년에 그대로 쓰면 FS = 5000 가정 때문에 "5–7초 창" = 실제 1.0–1.4초, "0–500 Hz" = 실제 0–2.5 kHz

## 해석 (빌드 후 관찰, 확인 필요)
- 25년 데이터는 원신호 평균이 이미 ≈0이고 0–20 Hz 흔들림이 거의 없다 (저주파 흔들림 우세 태그 0개). 26년에는 평균 −1 g 파일·6 Hz 드리프트가 있다 → 두 데이터는 전처리 상태부터 다르다
- 25년 PSD는 약 50 Hz 아래가 급히 꺼진다(고역통과된 채 배포된 모양). 26년(5 kHz로 낮춤)은 저주파가 그대로 크다. 고장 − 정상 차이: 25년은 20–300 Hz에서 고장 쪽이 뚜렷이 크고, 26년은 100 Hz 부근에서 오히려 작다 → 같은 주파수 피처가 옮겨 오지 않는 이유 후보
- 25년 단변량 AUC 상위는 TKEO 최대/평균·파고율·충격 계수·첨도 (0.91–0.93) — 형상(충격성) 지표만으로 거의 갈린다. 26년에서 같은 3조 피처는 0.6–0.8대로 내려간다 (비교 탭 AUC 그림)
